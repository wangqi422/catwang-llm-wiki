S9「猩红月影」指挥室主视觉

视觉高分辨率 CG（5760×3240）。角色居中靠坐在装备箱上，背景全息投影展开 Rebirth Island 战场态势图。暖色台灯 + 冷色全息蓝光形成冷暖对撞，前景道具（弹药箱/骷髅）做纵深层次。
点评单图叙事完整：角色身份（Ghost）、战场（Rebirth）、氛围（战前策划）三层信息一张图交代。全息投影的 UI 处理克制，没有压过人物主体。
借鉴「指挥室 + 全息战场」是 FPS 万圣/赛季预告经典框架。可参考其前景道具堆叠手法增强画面故事密度。

×Dead Space「Convergence」联动 CG

视觉CG 级联动主视觉。前景士兵侧身持枪（M4 形制）对峙中央 Necromorph，背景废弃城市废墟 + 直升机剪影。灰色阴云 + 橙色火光双色调，烟尘粒子丰富。
点评两个 IP 视觉元素融合自然——军事装备 + 太空恐怖怪物，通过「51 区实验事故」叙事框架合理化。构图重心在怪物与士兵的对峙张力。
借鉴跨界联动 KV 的关键：找到两个 IP 视觉公约数。死亡空间的怪物直接放进现代战场场景，比拼贴 logo 更有说服力。万圣节点精准（10.20–11.10）。
暗区突围 · Arena Breakout C2S0「战火重燃」10.29 上线，载具系统预热中 1 件

C2S0「载具登场」KV

视觉火光雪夜动态场景。前景角色骑机车冲出，中景吉普翻滚爆炸，背景另一辆吉普涉水而来。火光橙 + 雪夜蓝对比色，飞雪/火星粒子丰富，动感强。
点评「疾速满载撤离」文案 + 载具实机形象，功能性告知与视觉冲击兼顾。构图从左到右的运动方向感清晰。分辨率偏低（606×342）是唯一短板。
借鉴「爆炸 + 载具 + 运动模糊」是撤离类游戏动态 KV 的可靠公式。雪夜 + 火光的冷暖撞色值得在 CODM 冬季活动中参考。

视觉趋势

Visual Signals
01

万圣视觉双线分化

CODM 走亡灵节民俗风（暖橙花海/糖骷髅/烟火），BF6 走太空恐怖写实风（灰冷色/Necromorph/废墟）。同一节日节点，两种视觉路线均成立。

02

跨界 IP 联动 CG 标准化

BF6×Dead Space 的 CG 融合度极高——怪物直接置入现代战场。对比早期「拼贴 logo」式联动，场景级融合已是 AAA 联动标配。

03

功能型 KV 的动感表达

暗区载具 KV 用爆炸 + 运动模糊 + 冷暖撞色做「功能性告知」，不靠角色颜值。系统/玩法预告类型的视觉表达路径更清晰了。
