## 按产品归档

### A. 使命召唤手游 · CODM（3 件）

#### 主推：S9「猩红月影」指挥室主视觉
- **视觉**：高分辨率 CG（5760×3240）。角色居中靠坐在装备箱上，背景全息投影展开 Rebirth Island 战场态势图。暖色台灯 + 冷色全息蓝光形成冷暖对撞。
- **点评**：单图叙事完整——角色身份、战场、氛围三层信息一张图交代。全息 UI 处理克制。
- **借鉴**：「指挥室 + 全息战场」是 FPS 赛季预告经典框架。前景道具堆叠手法增强故事密度。

#### 补充
- **「集骨头唤军犬」**：亡灵节风格军犬 KV。橙色万寿菊花海 + 糖骷髅面绘 + 烟火夜空。动物主角质感到位。
- **「月圆之夜对局礼」**：骷髅面罩角色 + 暗红雷云背景。角色立绘品质高，奖品 UI 略重。

### B. 战地6 · Battlefield 6（1 件）

#### 主推：×Dead Space「Convergence」联动 CG
- **视觉**：CG 级联动主视觉。前景士兵对峙 Necromorph，背景废墟 + 直升机剪影。灰云 + 火光双色调。
- **点评**：两个 IP 视觉融合自然——军事 + 太空恐怖，「51 区事故」叙事合理化。
- **借鉴**：跨界联动 KV 的关键是找到视觉公约数。怪物直接放进战场场景，比拼贴 logo 有说服力。

### C. 暗区突围 · Arena Breakout（1 件）

#### 主推：C2S0「载具登场」KV
- **视觉**：火光雪夜动态场景。机车冲出 + 吉普爆炸 + 涉水吉普。冷暖撞色，粒子丰富。
- **点评**：功能性告知与视觉冲击兼顾。分辨率偏低（606×342）是短板。
- **借鉴**：「爆炸 + 载具 + 运动模糊」是撤离类动态 KV 可靠公式。

## 视觉趋势

1. **万圣视觉双线分化** — CODM 走亡灵节民俗风，BF6 走太空恐怖写实风。同一节点两条路线均成立。
2. **跨界 IP 联动 CG 标准化** — BF6×Dead Space 的场景级融合已是 AAA 联动标配。
3. **功能型 KV 的动感表达** — 暗区用爆炸 + 运动模糊做玩法预告，不靠角色颜值。
