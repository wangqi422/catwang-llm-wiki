## Definition

PureRef 是一款专为创意工作者设计的免费参考图管理软件（v2.0 为当前主流版本）。它提供一块无限画布，用户可以将网页图片、本地文件、截图等拖入其中，自由排列、缩放、旋转、分组，作为创作时的视觉参考板。

核心价值在于**无干扰叠加**——窗口可置顶、可穿透、可半透明，让参考图始终悬浮在工作软件之上而不影响操作。

## Core Content

### 核心功能

| 功能 | 说明 |
|------|------|
| 无限画布 | 自由放置、排列、缩放参考图 |
| 窗口穿透 | Ctrl+T 让窗口不可点击，纯视觉叠加 |
| 置顶 & 半透明 | Ctrl+Y 置顶 + Ctrl++/- 调透明度 |
| 自动排列 | Ctrl+P 一键整理画布 |
| 分组 & 注释 | Ctrl+G 编组 + Ctrl+N 文字标注 |
| 画布导出 | Ctrl+E 导出为单张图 |
| 幻灯片 | Alt+S 自动轮播展示 |

### 典型工作流

1. **收集**：拖入网页图片/本地素材/截图到 PureRef 画布
2. **整理**：Ctrl+P 自动排列 → Ctrl+G 分组 → Ctrl+N 添加注释
3. **参考**：Ctrl+Y 置顶 + Ctrl+T 穿透 → 在 PS/AI/Figma 等软件中创作时实时对照
4. **分享**：Ctrl+E 导出画布 / Ctrl+S 保存 .pur 场景文件

## Key Points

- 免费软件（可自愿付费），支持 Windows / macOS / Linux
- 当前主流版本 v2.0
- 设计师/概念画师/3D 建模师的标配参考工具
- 对 CODM 宣发工作的价值：角色精修、海报设计、KV 制作时整理视觉参考
- Mac 版快捷键将 Ctrl 替换为 ⌘

## Examples

- **角色精修参考板**：将官方角色原画、竞品角色截图、风格参考统一放入 PureRef，分组标注"姿态参考""配色参考""细节参考"
- **海报设计看板**：收集优秀海报案例，按构图/色调/字体风格分组，创作时 Ctrl+Y 置顶对照
- **团队评审**：Alt+S 幻灯片模式逐张展示参考图，替代临时拼 PPT
