## 收到 ai-batch-imagegen.zip 并分析

**来源**:企微 Cache 2026-07/ai-batch-imagegen.zip（agent_created: true 的 WorkBuddy Skill 包）

**解压路径**:`.workbuddy/tmp/inspect_skill/ai-batch-imagegen/`

### Skill 本质
**零 Token 批量生图工作流**——用 Playwright over CDP 操控本地已登录浏览器（Midjourney alpha 网页 + 司内 3000/woa 平台）无限循环出图。生图在浏览器里发生，不走 API 不耗模型 Token。

### 核心架构
- `components.yaml`（题材组件库：场景/色调/镜头/修饰/物体）→ 改题材改这个
- `config.yaml`（平台/模型/参数/垫图/停止/自愈）→ 改参数改这个
- `prompt_engine.py` 本地笛卡尔积随机组装提示词（零 Token）
- `run_woa.py` / `run_mj.py` while 循环发提示词
- `collect.py` 浏览器内 element.screenshot() 回收成图（绕防盗链）
- 总共 495 行 Python，2 个 yaml 配置

### 关键设计点
- **司内 3000 平台**：双模型（Nano Banana/Gemini + GPT-Image2），支持**垫图**（图生图保布局/保角色）——相比 MJ 最大优势
- **自愈 1**：司内 SSO 6-8h 过期 → 连续 N 次失败自动 reload
- **自愈 2**：CDP 慢（被历史标签拖到 3 分钟）→ `auto_clean_tabs: true` 启动时清
- **自愈 3**：MJ Fast hours 耗尽 → 检测弹窗自动切 Relax（免费无限）
- **停止机制**：优雅停（output_dir 下建空文件 STOP）+ 到点自停（stop_at: "10:30"）
- **当前题材**：太空（空间站/机甲/星云/EVA），output_dir: D:/WorkBuddy/space-quickbatch

### 含金量最高的踩坑（来自 references/troubleshooting.md）
- 🔴 参考图计数别校验（比例/历史图 class 污染）→ 上传不报错即视为成功
- 🔴 垫图是服务端会话态跨标签共享 → 每个模型固定一类，启动传一次全程不换
- ⚠️ MJ V8 只在 Alpha 支持；`--v 8.0` 必须 --fast → 默认用 `--v 6/7/8.1` 全 Relax 免费
- ⚠️ 3000 选 4K 后比例从 15 个缩成 9:16/16:9/原尺寸/智能（无 2:1）→ 必须先点解析度再点比例
- ⚠️ 俯视布局图里 "circular/ring" 会被理解成 3D 轨道环 → 强调 TOP-DOWN FLAT
- ⚠️ MJ 发送不要 element.click()（偶发 not enabled 死等）→ 用 fill()+focus()+keyboard.press(Enter)
- ⚠️ MJ Alpha 垫图不可靠（无可见 file input、槽内图不暴露为 img）→ 要垫图用 3000 平台

- ✅ 网络出站限定 alpha.midjourney.com + 3000.woa.com
- ⚠️ 司内 3000 平台仅司内同事可用——对外分享需 `woa.enabled: false`

3. **截图脚本加 retry + 60s timeout**（页面跑动画/加载会卡 30s+）
4. **openai 生成 4K 耗时 100+ 秒**（vs gemini 60-90s）—— 跑批量时要错峰抢焦点
5. **写实风 prompt 关键词优先级**：mood_base > quality > scenes，前两个最关键

### 跑批踩坑（已修复，沉淀代码）

#### 坑 1：textarea 被生成的大图覆盖，type 失败
**症状**：连续失败但日志说"已发"——textarea 在 DOM 但被生成的 4K 大图覆盖，click/fill/type 都没用
**修复**（`run_woa.py`）：用 JS 检测大图元素（>500x350 + 位置 100<x<800, 200<y<900），命中就 `page.reload()` 强刷
```python
big_img = page.evaluate("""()=>{
    const imgs=document.querySelectorAll('img');
    for(const im of imgs){
        const r=im.getBoundingClientRect();
        if(r.width>500&&r.height>350&&r.x>100&&r.x<800&&r.y>200&&r.y<900) return true;
    }
    return false;
}""")
if big_img: page.reload(wait_until="domcontentloaded", timeout=30000); page.wait_for_timeout(3000)
```

#### 坑 2：woa_type_prompt 字符乱码
**症状**：`delay=0` 太快，200+ 字符的英文 prompt 输入有 1/3 漏字/乱码
**修复**（`common.py`）：三连清空 + `delay=8` 慢输 + 长度校验 50<len<5000
```python
for _ in range(3):
    page.keyboard.press("Control+a"); time.sleep(0.1)
    page.keyboard.press("Delete"); time.sleep(0.25)
page.keyboard.type(prompt, delay=8)
```

#### 坑 3：prompt_engine.py 字段名错（palettes vs palette）
**症状**：palette 永远空字符串
**修复**：`self._pick_weighted("palette")` 不是 `"palettes"`（yaml 用单数）

#### 坑 4：Chrome 9222 标签丢失
**症状**：`browser.new_page()` 创建的标签在 CDP 断连后被销毁
**修复**：用 Chrome 老接口 `PUT /json/new?URL` 创建持久标签

#### 坑 5：collect.py 截到历史缩略图
**症状**：每张图都有 4-20 张 510x288 的缩略图混在 collected/
**修复**：跑完批量后用 PIL 筛 `w>=1000 and h>=500` 的保留为 `collected_big/`，其余移到 `collected_thumbs/`

### 跑批停止机制

- **到点自停**：`config.yaml` 的 `stop_at: "21:30"`
