## [18:59] H5 cursor "两孔雀" bug 修复

**症状**：8/5 日报 H5 在某些位置（特别是腮红色满幅背景）会出现两个小圆点（一实心+一空心环），用户俗称"孔雀"。

**根因**：8/5 版 cursor JS 用了 `gsap.set({x, y})` 替代 7/10 版的 `style.transform = translate(x,y) translate(-50%,-50%)`：
1. `gsap.set({x, y})` **覆盖**了 CSS 里的 `translate(-50%, -50%)` 居中变换 → cursor 中心不对齐
2. `mouseX, mouseY` 初始值是 `(0, 0)`，鼠标没动时 cursor 停在 (0, 0)
3. ring 用 `gsap.set delay 0.06` 代替 `rAF + lerp 0.18` → ring 完全同步 cursor，无滞后感
4. 设备检测 `!reduced` 代替 `matchMedia('(hover: hover)')` → 触屏上也启用了 cursor

**修复**：cursor JS 改回 7/10 版本的 rAF + lerp 写法
- `style.transform = translate(x,y) translate(-50%,-50%)` 完整居中
- `rAF + lerp 0.18` 让 ring 优雅滞后
- 初始 `mx, my = innerWidth/2, innerHeight/2`（屏幕中央）
- 设备检测用 `matchMedia('(hover: hover) and (pointer: fine)')`

**Commit**：`e8776e3` → push origin main

**经验**：
- cursor 元素**绝对不要**用 `gsap.set({x, y})` 定位——会覆盖 CSS 居中变换
- ring 跟随**必须**用 `rAF + lerp`，不要用 `gsap.set delay`
- 设备检测**必须**用 `matchMedia('(hover: hover) and (pointer: fine)')`
