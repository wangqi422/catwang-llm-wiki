## 经验

- **GSAP 配 Soft Editorial 风格**：缓动只用 `power2.out` + 偶尔 `back.out(1.4)`，禁用 `elastic`/`bounce`（会破坏暖调克制感）
- **stagger 间隔参考值**：meta-tag 50ms / sub-card 40ms / thesis-card 80ms / card 120ms / gallery 80ms
- **进入动画距离**：blur 浮现 8px / rise 14px / scale 0.96，避免大位移
- **ScrollTrigger 触发位置**：title `top 82%` / card `top 75%` / sub `top 70%`，让标题先于内容亮相
- **截图兼容**：截图脚本（如 `_deploy/daily-card/run.js`）需要 `await page.waitForTimeout(2500)` 等动画跑完，否则会截到半透明帧

## 经验补充

- **客户说"动态不明显"通常意味着 3 件事**：① 入场距离太小（<30px 视觉无感）② 没有持续动画（只有入场没有 ambient）③ 没有交互反馈（hover 静止）。MAX 版三件都补齐
- **持续动画很重要**：`repeat: -1, yoyo: true` 的 sine 慢速漂浮（10s+ 周期）让画面"活着"，比单次入场更有感知
- **3D tilt + conic 光环**是最容易让人"哇"一下的两个 hover 效果，成本极低

## VF 风格周报（victorfuruya.com 参考）

- 文件：`docs/ai-daily/ai-weekly-card-20260525-toc-vf.html`
- **关键洞察**：之前 GSAP 三版"不明显"不是强度问题，是哲学问题——VF 风的高级感来自 **Lenis 惯性滚动 + 整屏 yPercent 推送 + Preloader 仪式感**，而非堆砌花哨 effects
- 技术栈拆解（grep victorfuruya 打包后 JS 得到）：
  - Lenis（平滑惯性滚动）+ GSAP + ScrollTrigger + Flip + Observer
  - 缓动只用 power3.out / power4.out / power2.inOut（**完全不用 back/elastic/bounce**）
  - stagger 极小：0.005s / 0.015s / 0.032s（字符级几乎同步）
  - 大量 yPercent: 100 / -100 整屏位移，不是 px 微动
- 实现要点：
  - 接入 Lenis 1.1.13，duration 1.2，expo out 缓动 `(t) => 1 - Math.pow(2, -10*t)`
  - 自定义鼠标光标（8px 黑点 + 36px 描边圆环延迟跟随，hover 卡片变 48px 粉色大圆）
  - Preloader：96px Cormorant 斜体百分比计数 0→100% 1.8s + 280px 进度条 + 副标
  - Preloader 完成后 yPercent: -100 整块上推消失
  - h1 字符 stagger 0.015s 溅出（mask 容器 overflow:hidden + 字符 110%→0）
  - 章节滚动入场：vf-rise-100（translateY 100px）+ stagger 0.02-0.08s + power4.out
  - 锚点跳转劫持改用 `lenis.scrollTo(target, { offset: -32 })`
  - 三层兜底：reduced-motion / GSAP 失败 / Lenis 失败 → 都立刻显示页面
- ⚠️ 截图脚本兼容：要 `evaluate(() => { document.getElementById('vfPreloader')?.remove(); document.documentElement.classList.add('vf-revealed'); })` 再 `waitForTimeout(2500)`
