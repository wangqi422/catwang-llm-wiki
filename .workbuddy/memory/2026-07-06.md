### 经验沉淀（⭐ 长期规则）
- **GitHub Pages 偶发 deploy 失败**：`actions/deploy-pages@v4` 内部 git exit 128
- **绕过方案**：连续 `git commit --allow-empty && git push` 2-3 次通常会恢复
- **不要 force-push 历史**：会污染 commit graph 且 Pages 不受影响
- **诊断口诀**：先看 `raw.githubusercontent` 确认文件 → 再看 Actions run status → 再 curl Pages URL
