### #1 ⭐ Kimi 发布游戏开发与创意工作解决方案：Agent 直操 Godot / Blender / Unity / UE，20 小时无人干预交付原生工程

> **来源**：[Kimi 官方公众号](http://mp.weixin.qq.com/s?__biz=MzcwMjM3ODEzOA==&mid=2247487910&idx=1) · [上证报](https://www.cnstock.com/commonDetail/822746) · [凤凰网科技](https://original.ifeng.com/c/8xjEIumK3ad) | **评分**：9.4/10 | **标签**：Agent 落地 / 游戏开发 / 3D 资产

#### 核心事件
11 月 2 日，月之暗面 Kimi 发布「**游戏开发与创意工作解决方案**」。底座是 **Kimi K3.1 Pro** 模型，配 **Kimi Code**（代码开发与修改）和 **Kimi Work**（跨文件、多步骤制作任务）两条 Agent 产品线，再通过插件直接操作 **Godot、Blender、Unity、Unreal Engine** 等专业软件的现有工程。它覆盖的是游戏团队完整的四段链条：**立项前的玩法验证 → 美术资产适配 → 正式工程开发 → 发行与长线运营**。Kimi 援引 Unity《2026 Game Development Report》说明动机：52% 的开发者优先选择小规模项目降风险，67% 把原型阶段压在三个月以内——验证周期越紧，原型制作效率越值钱。

#### 技术亮点 / 影响分析
- **立项前：Godot 原型可试玩**。团队给参考图、视频和玩法要求，Kimi 用 Godot 搭出可跑的 Demo（官方示例是雨夜光影 + 挥剑/闪避/格挡的 2.5D 动作原型）。关键不是生成代码，而是它会**真的运行游戏**，结合渲染画面和试玩录像检查效果，发现问题后自主修改、重新验证，交付前完成多轮迭代。
- **美术：Blender 插件直接改工程**。用多视角视频与截图判断空间关系，定位比例、穿插、材质问题，再转成脚本让本地 Agent 操作 Blender 完成初步修改。官方案例：K3.1 Pro 用 Blender 建了一座机场室内雨林山谷场景，输出 17.5 秒 1920×1080 60fps 展示视频；另一个大教堂内部场景约 **330 万三角面**、为 **8368 个组件**做了动画。
- **正式开发：和 Unity 中国 Tuanjie Codely Agent + 团结引擎协同**。模型理解意图、生成代码、根据录屏与测试结果制定修改方案；Agent 通过 Editor / Runtime Script 直接在引擎里搭场景、改工程、跑验证。官方称一次演示中系统**无人工干预连续工作 20 小时**，不只复现原作，还产出了一份可持续开发的原生工程。UE 侧同理，用 UE 5.8 建了一座天宫场景（半径 1750 米的 36 间柱廊 + 程序化巨龙，约 **3600 万三角面**，Nanite 渲染 + Lumen 光照）。
- **运营侧同样被串起来**：批量制作获客素材并比较各版本投放数据、把 Kimi 接进游戏做 NPC 问答/阵容建议/赛后战报、把社区反馈按故障/平衡性/付费体验/内容需求分类并保留原帖来源、本地化初稿与抽样回译、UGC 初筛。这些还能设为定时任务自动批量跑。
- **官方自己给的边界建议**：从**边界明确、结果易检查**的单一任务试点，由对应岗位人员检查成果，再评估是否推广。这句话比任何宣传都实在。

#### 三句话总结
1. Kimi 用 K3.1 Pro + Kimi Code/Work + Godot/Blender/Unity/UE 插件，把玩法验证、美术、工程、运营四段串成一条 Agent 流水线，一次演示无人干预连跑 20 小时交出可继续开发的原生工程。
2. 它的差异点不在「生成一段代码或一张图」，而在**直接操作现有工程并交付可编辑文件 + 操作记录**，能嵌进团队既有流程。
3. 对 CODM 宣发团队：最直接可试的是**投放素材批量制作与效果比较**（控制引擎录实机画面 + 开源动效剪辑工具拼多版本开场/卖点，再汇总数据反选），以及**玩家反馈按类分桶并保留来源**——这两个都是当前人力密集、边界又足够清晰的场景，建议按官方建议先拿一个单任务试点。

### #2 ⭐ MIT CSAIL「权重空间编程」：GPT-6 Astra 改 0.016% 权重，小模型数学 7.9% → 48.1%

> **来源**：MIT CSAIL《Sparks of Weight-Space Programming》· [36 氪](https://36kr.com/p/4053239918728070) · 同花顺 / 微博技术社区 | **评分**：9.3/10 | **标签**：模型研究 / 权重编辑 / RSI

#### 核心事件
MIT CSAIL 团队公布一组实验，提出一个新说法：**权重空间编程（Weight-Space Programming, WSP）**——把神经网络的原始权重当成可读、可改的「代码」，用自然语言告诉前沿模型目标，让它直接在权重空间里定位、修改并验证。核心实验是让 **GPT-6 Astra** 检查 **Qwen3.5-0.8B** 的内部权重，找到它反复陷入推理循环的毛病，随后只修改约 **0.016% 的参数**：MATH-500 从 **7.9% 升到 48.1%**，小学数学 13.8% → 67.1%，指令遵循 21.0% → 62.3%，最高约 6 倍。**整个过程没有重新训练，没有梯度下降，也没有训练数据。**

#### 技术亮点 / 影响分析
- **读、改、写三层能力**：① **Read**——把 4 个架构/输入/动作完全相同的游戏策略网络权重逐个喂给 Astra，不给工具也不给选项，它 100% 说对了 Breakout、Pong、Pac-Man、Freeway；还能从 4 层 Transformer 的中间权重里认出训练语种、定位全部归纳头。② **Edit**——一个 PPO 汽车策略总卡在坡道，给出权重、场景和 1 条失败轨迹后，Astra 一次回复写出补丁（不用工具），只改 3.5% 权重，成功率到 100%。③ **Write**——给出 MinAtar 规则和代码，Astra 一次回复从零写出 Breakout 网络权重，零训练零工具，得分比训练 5 亿步的 PPO 高 20 倍；另一个例子是生成的游戏策略网络超过了训练 1 亿步 PPO 的模型。
- **和微调不是一回事**：传统梯度优化依赖训练数据、必须反向传播、目标由损失函数定义；WSP 是推理驱动、零数据可用、无需反向传播、目标用自然语言给。成本结构完全不同——改 0.016% 参数的代价，和做一轮 SFT 不是一个量级。
- **RSI 的新入口**：团队自己在博客里说，神经网络权重很快会由能主动推理权重的 LLM 原生优化，并正在构建评测基准和帮 LLM 探索、写入权重的 harness。这条路线和 Anthropic 同日在 S-1 里写的「可能很快触及 RSI 阈值」是同一枚硬币的两面。
- **需要保留的判断**：成绩由发布方自评，尚无独立实验室按同一提示、同一推理配置和同一评分流程复测；Astra 在练习问题上用了 50 次前向传播的预算。真正要看的是这套方法换一个模型、换一个毛病还成不成立。

#### 三句话总结
1. MIT CSAIL 提出权重空间编程：GPT-6 Astra 只读 Qwen3.5-0.8B 的权重、只改 0.016% 参数，就把 MATH-500 从 7.9% 拉到 48.1%，全程零梯度零训练。
2. 它把「优化模型」从「准备数据 → 反向传播 → 祈祷收敛」换成「自然语言描述目标 → 定位 → 打补丁 → 验证」，是 RSI 叙事里少见的、可复现的具体路径。
3. 对 CODM 宣发团队：短期用不上改权重，但思路可以直接借用——**把「反复出现的坏毛病」当 bug 定位而不是当风格接受**。比如某个生图模型总在同一个构图/手部/字体细节上翻车，值得先做一次「失败样本归因 + 定向 prompt/参数补丁」的小实验，比盲试 100 次有效。

### #3 腾讯混元 Hyra 2.0：科研 Agent 从「解题」转向「造工具」，HyInv 比 ProteinMPNN 快 57 倍

> **来源**：[腾讯混元官方公众号](http://mp.weixin.qq.com/s?__biz=MzkwODU2OTQyNQ==&mid=2247498763&idx=1) · [凤凰网科技](https://news.qq.com/rain/a/20261102A0CKD000) · IT之家 | **评分**：8.9/10 | **标签**：科研 Agent / 工具复用 / 开源

#### 核心事件
11 月 2 日，腾讯混元发布 AI 科研系统 **Hyra 2.0**。三个月前的 Hyra 1.0 驱动开源模型 Hy3 解决了加法组合学中悬置五十多年的开放问题（和集与差集的最优指数），是国产开源模型首次全自动解决数学开放问题。这一次团队把目标往上抬了一级：**不再让 Agent 直接解题，而是让它研发和升级科学模型、研究工作流与软件工具**，让一次研发的成果在后续研究中被反复使用——官方的说法是从「刷题抽卡」走向「造工具」，形成智能复利。

#### 技术亮点 / 影响分析
- **三层分工**：**Overall** 与人类研究者对齐目标、管优先级和关键决策；**Mission** 长期负责一个研究问题，定路线、组织 Worker、对结论负责，并判断哪些假设值得继续投、何时换方向；**Worker** 独立读代码、做实验、分析失败原因，**可以质疑 Mission**。不同 Worker 还能用不同模型，提供不同的分析和复核意见。
- **接进真实研发环境**：Hyra 2.0 接入企业微信（和研究者对齐需求）、计算平台（提交管理实验）、代码仓库（实现并验证改动）。任务进持久化队列后按优先级、依赖和资源上限调度；等待训练结果或人工审批时其他任务继续跑；Agent 还能设置下次唤醒时间。较大算力开销和共享知识同步**仍需人工审批**。
- **三套分离的记忆**：项目状态与 Research Board 记录协作；每个 Agent 维护分层记忆（当前认识、关键假设、已排除路线、下一步）；跨任务可复用经验进共享知识库 **Books**，分「观察 / 已验证 / 约定」三级，必须写清做法、理由、适用条件并附原始证据。项目复盘时把可迁移方法整理成 **skill**，本身就是 Hyra 造出的工具。
- **初步成果很硬**：**HyInv**（196 万参数 GNN 做蛋白质逆折叠，预训练/SFT/RL/推理优化全部由 Hyra 2.0 完成，还自己设计了「先起草、再改写」两步采样，比 ProteinMPNN 序列吻合度更好、快 **57 倍**）；**HyPLM-Flash**（6.5 亿参数蛋白质语言模型，只用 7260 亿训练 token，是 ESM-2 650M 的 0.73 倍、同类模型的五分之一到八分之一，12 个模型中推理最快、35 个评测平均第 3）；**HyFF**（原子级分子模拟基础模型，5 种规模 230 万–12 亿参数，覆盖 83 种元素，5 个模型**全部位于精度–速度帕累托前沿**，已跑通 6 万原子水通道蛋白膜体系 100 纳秒模拟）；**HyQEC**（构造并严格验证量子码 [488,123,22]，kd²/n 达 122.0，比 qLDPC Challenge 原榜首提升约 **48%**，还把原榜首码距上界从 95 收紧到 86）；**灵巧手**（自主发现五指「旋梯手」布局，DR5 仿真中物体旋转速度比论文最优设计快 **28.6%**，尚未真机验证）。
- **成果持续开源**：相关结果会持续公开到 GitHub `Tencent-Hunyuan/hyra-results` 供社区检验复用。

#### 三句话总结
1. 腾讯混元 Hyra 2.0 把科研 Agent 的目标从「解出一道题」改成「造出能反复用的工具」，用 Overall / Mission / Worker 三层分工加 Books 共享知识库支撑数天到数周的长期研究。
2. 已交付的成果包括比 ProteinMPNN 快 57 倍的蛋白质逆折叠模型 HyInv、全部落在精度–速度帕累托前沿的分子模拟模型 HyFF，以及刷新量子码纪录的 HyQEC。
3. 对 CODM 宣发团队：真正值得抄的不是科学模型，是**它的知识沉淀结构**——把踩过的坑按「观察 / 已验证 / 约定」分级存进共享库、并在复盘时固化成可复用 skill。宣发生图流程里的失败提示词、无效参数、被否风格，同样该这样存，而不是每次从零试。

### #4 ⭐ Anthropic 修订版 S-1/A：Q3 营收 170 亿由盈转亏，8954 亿算力账单排到 2045 年

> **来源**：SEC 修订版 S-1/A（11 月 2 日递交）· [财联社](https://www.toutiao.com/article/7703633710452589090) · 格隆汇 · [网易](https://www.163.com/dy/article/LAQ3L3OC0519VPHD.html) · WSJ | **评分**：9.5/10 | **标签**：资本与算力 / IPO / 财报

#### 核心事件
11 月 2 日，Anthropic 向 SEC 提交招股书修订稿 S-1/A，**首次补上 2026 财年第三季度（截至 9 月 30 日）的财务数据**。营收约 **170 亿美元**，环比上一季的 116 亿增长约 **47%**，同比去年同期的 14 亿增长逾 **1127%**——但增速明显放缓（Q2 环比是 144%）。更关键的是利润方向掉了头：GAAP 口径下**营业亏损 5.67 亿美元**，而上一季它刚实现首次经营盈利 **9.74 亿美元**；净亏损 **233 亿美元**（去年同期 121 亿），主体是可转债及衍生负债公允价值变动这类非现金费用。剔除这些项目和股权激励后，调整后营业利润约 **25 亿美元**，但利润率已从 **19% 降到 15%**。

#### 技术亮点 / 影响分析
- **为什么会由盈转亏**：Anthropic 通常提前 12–18 个月签长期合同锁定算力，但三季度用户需求增长超出预期，原定算力不够用，只能临时加购 **50 亿美元短期算力**，价格明显高于长期合同。结果是算力与基础设施支出环比**暴增 77% 至 99 亿美元**，每投入 1 美元算力与基础设施带来的收入从 **2.08 美元降到 1.72 美元**——这个指标首次下滑。另外新模型降价和合同折扣让收入少了约 6 亿，加上 20 亿美元员工捐赠配捐的非现金费用，利润被两头挤。

### #5 OpenAI 启动 Grid Protectors：算力园区电网紧张时削峰，佐治亚试点最高 1000 MW

> **来源**：[OpenAI 官网](https://openai.com/index/grid-protectors-program)（11 月 2 日）· 新浪财经 · Techmeme / BloombergNEF 引用 | **评分**：9.0/10 | **标签**：能源与基建 / 需求响应 / 数据中心

#### 核心事件

- **背景与对照**：OpenAI 援引美国数据中心容量预计到 **2030 年超过 100 吉瓦**。同一时间，从内华达到佐治亚，美国数十个县市的选民将就限制数据中心的政策公投（征税、监管乃至直接禁止），可能影响数千亿美元投资；OpenAI 也计划把数据中心重新包装为「AI 算力园区」。

#### 三句话总结
1. OpenAI 发布 Grid Protectors，让未来算力园区在电网紧张时主动降载，佐治亚 Effingham 园区试点，与 Georgia Power 的协议含最高 1000 MW 灵活需求响应，并承诺自付全部基建与供电成本。
2. 变化不在技术（需求响应是成熟工具），而在身份——一家 AI 公司主动把自己写进「可被调度负荷」名单，用可中断性换社区与监管的社会许可。
3. 对 CODM 宣发团队：这条离业务很远，但它定了一个基调——**AI 算力的外部性开始被明码标价**。将来云生图/生视频的排期如果碰到区域性算力紧张、限流或涨价，逻辑和这里的「削峰」是同一套，做集中投放期素材生产时值得留一点缓冲。

### #7 SemiAnalysis GDPx：206 项高价值专业任务，最佳模型只做到 12%，金融法律普遍 0 分

> **来源**：[SemiAnalysis](https://newsletter.semianalysis.com/p/gdpx-measuring-frontier-model-capabilities)（11 月 2 日）· 今日头条 / AISignal 转述 · Google CEO Sundar Pichai 转发 | **评分**：8.8/10 | **标签**：评测基准 / 趋势信号 / Agent 能力

#### 三句话总结
1. SemiAnalysis 联合 14 家伙伴推出 206 项任务、覆盖 11 个高价值专业领域的 GDPx，13 款前沿模型里最好的 Claude Opus 5.5 也只做到 12.0%，金融与法律普遍 0 分。
