### #1 ⭐ OpenAI 发布 GPT-6.2 Astra 与 Sol：Astra API 降价 20%、缓存砍 60%，ARC-AGI-3 适配器模式 100% 满分，首破「AI 自我改进」高风险阈值

> **来源**：[OpenAI 官方](https://openai.com/index/introducing-gpt-6-2-astra-sol/) · [凤凰网科技](https://tech.ifeng.com/c/8y7WiMENt8e) · [Artificial Analysis 评测（Clauday 转述）](https://clauday.com/article/6cf2151a-b38e-40ff-821d-f8bab6537c83) · [AI Socratic](https://aisocratic.org/news/openai-releases-gpt-6-2-astra-and-sol) | **评分**：9.5/10 | **标签**：旗舰降价 / 自我改进 / 3D 与工程 / P0

#### 核心事件
11 月 17 日 17:45 UTC，OpenAI 正式发布 **GPT-6.2 Astra** 与 **GPT-6.2 Sol**，同步上线 ChatGPT Work、Codex 与 API（模型名 `gpt-6.2-astra` / `gpt-6.2-sol`）。定价是这次最大的信号：**Astra 输入 8 美元 / 输出 40 美元每百万 Token，较 GPT-6 Astra 降 20%，缓存输入更是砍 60% 到 0.40 美元**；走量的 Sol 维持 2 美元 / 10 美元不变，但 Pro 200 套餐终于开放 Sol 的 Ultrafast 极速模式（降价 50%）。官方口径：Agents' Last Exam 上 Astra 比上代 +5.2 分、单任务成本不到 1/3，对 Claude Fable 5.2 领先 5.5 分而成本仅 5%；GDPval v2 +6.2 分同时输出 Token 少 22%；Harvey LAB-AA 法律基准通过率超 Fable 5.2 两倍、成本约 1/6。外部裁判 ARC Prize 用 OpenAI 适配器在 **ARC-AGI-3 拿到 100% 满分（成本 4100 美元，标准测试框架为 70.3% / 24200 美元）**。最受关注的是系统卡披露：**Astra 是 OpenAI 首个对外发布、达到「AI 自我改进」High 阈值的模型**，官方同步上线「控制室」监控系统。

#### 技术亮点 / 影响分析
- **价格本身成了发布主角**：把「输入价、缓存价、单任务成本」写进头条，标志旗舰竞争从「跑分」彻底转向「Cost per Task」——与 #2 微软 MAI 七连发是同一场价格战的两个身位。
- **3D 与工程能力是宣发侧最该盯的一格**：实测里 Astra 一句话直出 3D 鹈鹕骑车、1:1 复刻巴黎（50+ 地标可驾驶）、山路跑车底盘物理仿真、19 页带矢量图的商品提案 PPT——从文字简报到可交互 3D 样片的链路进一步缩短。
- ** Independent 评测的「降温」要写在旁边**：Artificial Analysis 智能指数 Astra 排第二（62）落后 Fable 5.2（65），编码 Agent 指数与上代持平、Sol 反降 3 分，AA-Omniscience 幻觉率最高 59%；Theo 实测让 Astra 压缩编译器 7 天反而慢了 56%。便宜与「偏科」是同一枚硬币。
- **查重说明**：GPT-6.2 在历史日报无命中（仅 04-14 期出现过 GPT-6 泛述），今日为 6.2 全新版本首发 + 完整定价 / 基准 / 系统卡，属新事件。

#### 三句话总结
1. OpenAI 11 月 17 日发布 GPT-6.2 Astra 与 Sol：Astra 输入/输出价降 20%、缓存降 60%，ARC-AGI-3 适配器模式 100% 满分，是首个触及「AI 自我改进」高风险阈值的外发模型。
2. 它把旗舰竞争的头条从跑分改写成「每完成一件事花多少钱」，但第三方评测显示编码 Agent 与幻觉控制仍有明显短板——便宜与偏科并存。
3. **对 CODM 宣发团队**：Astra 的「一句话出 3D 场景 + 带矢量图的成套 PPT」值得直接拿来做赛季武器 3D 预览、KV 场景粗模与提案页批量生成，Sol 低价适合字幕/规则文案初稿；但厂商自报的成本与分数须自测复核，100% 满分是适配器特定口径，对外物料仍标注「模型辅助生成」。

### #2 ⭐ 微软 Ignite 2026 甩出 MAI 七连发：Code 2 用 5% 价格达 Opus 5.5 的 96%、Cyber 2 Flash 成本不到 GPT-6 Astra 的 2%、Maia 200 每瓦吞吐 1.7 倍

> **来源**：[Microsoft AI 官方](https://microsoft.ai/news/microsoft-ignite-2026) · [himiao.ai](https://himiao.ai/en/news/2026-11-17-microsoft-mai-seven-models) · [ExplainX](https://www.explainx.ai/blog/microsoft-ignite-mai-code-2-seven-models-november-2026) · [Tech360.tv](https://www.tech360.tv/microsoft-prices-its-own-ai-models-under-its-partners) | **评分**：9.4/10 | **标签**：自研模型 / 价格战 / 全栈 / P0

#### 核心事件
11 月 17 日微软 Ignite 2026，纳德拉把 Copilot 定位成「工作操作系统」，同步推出 Microsoft IQ、Agent 365、Cobalt 200 VMs，Microsoft AI 则一次性发布**七款自研 MAI 模型**，全部主打「可扩展的性价比」：① **MAI Code 2**——四个企业编码基准平均达 GPT-6.1 Sol 的 98%（约 40% 价格）、Claude Opus 5.5 的 96%（仅 5% 价格），界面构建盲测 67-68% 胜率压过 GPT-6 Sol，已在 GitHub Copilot 全面可用；② **Code 2 Flash**——对标 GPT-6 Luna（65% 价格）/ Haiku 5.5（20% 价格）；③ **Cyber 2 Flash**——CyberGym-E2E 完成 92.3%（GPT-6 Astra 91.5%），单任务成本不到 2%，通过 Codename MDASH 定向提供；④ **MAI Image 2.7**——登顶 Artificial Analysis 图像编辑榜，约 GPT Image 2.6 Sunburst 的 1/5 价格；⑤ **MAI Realtime 1**——首个语音到语音模型，0.01 美元/音频分钟起，超越 GPT-Realtime 2.1；⑥ **Transcribe 2**——Dragon Copilot 底座，每月处理 1000 万次问诊、多语错误率减半；⑦ **Decision 1.1**——比 GPT-Sol 6.1 快 50 倍、便宜 79 倍。硬件侧第二代自研加速器 **Maia 200** 已量产，每瓦 token 数是上代 1.7 倍；另有 MAI Licensed Weights 让企业在自有 Azure 环境微调定制前沿模型。

#### 技术亮点 / 影响分析
- **「专业模型 + 自家渠道」的打法**：微软不去争通用旗舰分数，而是把编码/安全/图像/语音/决策做成专用 SKU，当天全部塞进 Copilot 与 Foundry，用 Azure + Copilot 的分发渠道绕开 OpenAI 的发版节奏——Suleyman 明说要拿 MAI Code 抢 Copilot 默认编码位。
- **自研芯片 + 自研模型的成本闭环**：Maia 200 每瓦 1.7 倍是这轮价格故事的物理底座，「第一方芯片 + 第一方模型」打包对 Azure 容量规划是直接卖点。
- **所有数字都是微软自测**：对标的是竞品已公布的基准结果，非同场独立测试，且 Code 2 的价格按 50% 促销价计算——「5% 价格达 96%」是有利于己方的比较，不是定论（官方也承认 Code 2 未针对基础科研与超长 Agent 任务调优）。
- **查重说明**：MAI / Ignite / Code 2 在历史日报零命中，属全新事件； cyber 模型与此前 MAI-Cyber 预览是同一条产品线的迭代新阶段。

#### 三句话总结
1. 微软 Ignite 2026 一次发布七款 MAI 模型 + Copilot「工作操作系统」升级 + Maia 200 芯片，编码 / 安全 / 图像 / 语音 / 决策全面用性价比对标 OpenAI 与 Anthropic。
2. 这套打法的本质是把模型做成专用 SKU、用 Azure 与 Copilot 自家渠道分发，让自研芯片的每瓦吞吐直接兑换成价格优势；但所有对标均为厂商自测且含促销价口径。
3. **对 CODM 宣发团队**：MAI Image 2.7 登顶图像编辑榜、Code 2 在 GitHub Copilot 免费/学生档可用，值得用来做**海报文案的批量图生图改稿与活动页前端原型**；Cyber 2 Flash、Realtime 1 暂走企业/安全渠道，普通团队先用 Image 2.7 与 Code 2 试水即可，性能数字进对外物料前仍需自测。

### #3 ⭐ 英伟达黄仁勋离任后首份财报：营收 1158 亿美元（+103%）、数据中心首破千亿、净利 653 亿创新高；同日董事会拒黄仁勋复职、SEC 调查、停售 H200 中国

#### 核心事件
美东 11 月 17 日盘后，英伟达发布 2027 财年 Q3 财报（截至 10 月 25 日）：**营收 1158 亿美元、同比 +103%、环比 +20%，连续 17 个季度超预期**；数据中心营收 **1076 亿美元首次站上千亿、同比 +110%、占总营收约 93%**；GAAP 净利 653 亿美元（+105%）；Q4 指引 1300 亿美元（±3%）、且不含任何中国数据中心收入。Vera Rubin NVL72 开始出货、为公司史上最快产品爬坡，上调 2028 财年营收增长预期至 75%（原 70%），云业务积压订单达 2.5 万亿美元。但财报的另一面同样密集：**这是黄仁勋辞任 CEO 后首份财报**，财报前数小时黄仁勋发声明「愿在董事会认为符合最佳利益时回归」，财报电话会上董事长哈维·琼斯却明确表示董事会**未考虑让其复职**、已聘海德思哲启动 CEO 遴选；SEC 正就披露是否误导投资者展开民事调查；公司宣布停售 H200 芯片至中国，并新设董事会级国家安全与出口管制监督委员会。财报后盘后股价一度涨超 4%，但年内仍跌超 17%，11 月以来至少 11 家券商下调评级。

#### 技术亮点 / 影响分析
- **「基本面炸裂」与「治理动荡」同台**：一边是数据中心单季破千亿、抬高 2028 预期，一边是创始人请愿复职被董事会当面拒绝、SEC 调查与出口收紧——英伟达的股价逻辑已从「增长能不能持续」变成「治理稳不稳」。
- **H200 停售 + 国安委员会是新变量**：此前 H200 对华出口是「需境内、缴 25% 关税」的斡旋通道，如今直接停售，Q4 指引索性不含中国收入，地缘因素正式计入财务模型（受影响收入预估 44–62 亿美元）。
- **对 Anthropic 的报价构成直接背景**： Anthropic IPO 最终定价要看 Nvidia 财报后市场反应（见 #4），两件事被华尔街绑在同一天。
- **查重说明**：1158 亿 / 财报在历史日报零命中；H200 历史 7 篇多为出口管制背景提及，今日为「主动停售 + 设国安委员会 + 黄仁勋请愿被拒」新动作；黄仁勋连续剧在此前多期已追踪，今日为财报季新一幕。

#### 三句话总结
1. 英伟达 Q3 营收 1158 亿美元（+103%）、数据中心首破千亿、净利 653 亿创新高，Vera Rubin 出货并上调 2028 财年增长预期至 75%。
2. 同一天董事会拒绝黄仁勋复职、SEC 启动民事调查、停售 H200 中国并设国安委员会——强劲基本面与治理动荡被压在同一张财报里。
3. **对 CODM 宣发团队**：算力仍在高歌猛进，意味着 AIGC 视频/3D/图生图的供给与价格在中期仍会继续下探，做 2027 年素材产能规划可适度乐观；但地缘与合规变量增多，涉及海外云渲染、跨境素材生成的流程要预留供应商替代与数据合规预案。
