> **来源**：OpenAI 官方公告 / IT之家 | **评分**：9.3/10 | **标签**：#AI Agent #Computer Use #Windows

#### 核心事件
5 月 31 日，OpenAI 发布 Codex 应用 26.527 版本，**Computer Use 视觉操作能力正式登陆 Windows 10/11**，支持屏幕识别与鼠标键盘控制，同步上线远程控制功能——用户可通过 iPhone 或安卓版 ChatGPT 应用远程启动 Windows 电脑上的 Codex 任务。

#### 技术亮点 / 影响分析

#### 三句话总结
1. OpenAI Codex Computer Use 终于跨出 macOS 舒适区，Windows 用户首次获得 AI 桌面操控能力
2. 手机远程控制功能让 AI Agent 从"桌面助手"进化为"全天候远程操作员"，但 Windows 版功能仍受限

### #2 ⭐ 何恺明团队首个扩散语言模型 ELF：不走 GPT 自回归老路

> **来源**：量子位 / 新浪AI热点 | **评分**：8.8/10 | **标签**：#扩散模型 #语言模型 #研究突破

#### 核心事件
何恺明（ResNet 一作、前 FAIR/Mask R-CNN 核心作者）带队发布首个**连续扩散语言模型 ELF（Embedded Language Flows）**，放弃 GPT 式的"预测下一个 token"自回归范式，转而采用在图像领域大获成功的扩散模型路线。

#### 技术亮点 / 影响分析
- **要点1**：ELF 仅 105M 参数，但架构完全不同于 GPT——用连续扩散替代离散自回归
- **要点2**：扩散语言模型在文本生成领域尚属前沿探索，ELF 验证了这条路径的基本可行性
- **要点3**：若扩散路线可 scale，可能绕过自回归模型的推理速度瓶颈，实现并行解码

#### 三句话总结
1. 何恺明团队将图像扩散范式引入语言模型，ELF 虽然参数量小但概念验证意义重大
2. 扩散语言模型若能 scale，可能在推理速度和生成质量上挑战自回归模型的统治地位
3. 对 CODM 宣发团队：关注扩散模型在文本+图像多模态融合的潜力，未来可能催生新一代创意生成工具

#### 核心事件
Open Envelope 是一个新发布的开放协议规范，旨在**标准化 AI Agent 团队的定义和交互方式**。类似 Agent 世界的"OpenAPI 规范"，定义了 Agent 角色、能力声明、任务分配协议和消息传递格式。

- **要点1**：统一 Schema 让不同框架（LangChain、CrewAI、AutoGen）构建的 Agent 可在同一团队中无缝协作

- **要点3**：Multi-Agent 互操作性是当前 Agent 生态的最大痛点，标准化有望加速生态成熟

#### 三句话总结
1. Open Envelope 为 Multi-Agent 互操作制定开放标准，是 Agent 生态的"HTTP 协议"时刻
2. Agent 从"各自为政"走向"标准化协作"，跨框架 Agent 编排成为可能
3. 对 CODM 宣发团队：未来可用标准化协议编排多个 AI Agent 协作（文案+设计+视频），宣发流水线全自动
