### #1 ⭐ 阿里 Wan3.0 视频生成大模型正式上线：30秒视频+文档输入+专业运镜

> **来源**：IT之家 / 36氪 / 上海证券报 | **评分**：9.5/10 | **标签**：`视频生成` `国产模型` `宣发`

#### 核心事件

阿里巴巴视频生成大模型 **Wan3.0** 8 月 24 日正式上线，是国内首个支持 **30 秒单次生成**的视频大模型，同时**首次支持 doc/xls/ppt/pdf/md 等文档格式输入**——在角色、道具、声音、空间关系、风格等维度可保持一致性，支持推拉摇移跟等专业运镜，**最多支持 20 份参考素材**。API 定价为 480P/720P/1080P 每秒 0.3/0.6/1.2 元，限时 7 折期 8 月 24 日至 9 月 23 日。公测期间已进入企业生产流程，应用于短剧、广告、文旅传播等场景。

#### 技术亮点 / 影响分析

- **"文档+视频"是宣发级的范式跃迁**：直接喂入剧本/PDF/PPT 就能生成 30 秒成片，对宣发团队而言是"一稿多版"生产力的数量级提升
- **20 份参考素材 + 一致性控制**：角色/道具/风格在多镜头中保持一致，告别"换镜头就换脸"的可灵/Runway 时代痛点
- **专业运镜内建**：推拉摇移跟直接是模型能力，不需要后期剪辑补救，**短剧/广告场景的生产链条被压缩一环**

#### 三句话总结

1. 阿里 Wan3.0 上线，单次生成 30 秒视频，首次支持 doc/ppt/pdf/md 文档输入，20 份参考素材一致性控制
2. 文档直出视频 + 专业运镜内建，把"剧本→成片"的中间环节压到最少；限时 7 折期至 9 月 23 日
3. 对 CODM 宣发团队：脚本/PDF 直接喂 Wan3.0 出 30 秒成片是当下可落地的提效路径，值得纳入 39.x 素材产线试点

### #2 ⭐ DeepSeek 发布 V4-Flash-Vision 多模态视觉模型：补齐视觉短板，1000图<20美分

> **来源**：DeepSeek 官方 / 算泥 | **评分**：8.5/10 | **标签**：`多模态` `DeepSeek` `Agent`

#### 核心事件

DeepSeek 上线实验性多模态视觉模型 **DeepSeek-V4-Flash-Vision-Exp**，通过 API 提供，**多模态 Agent 能力逼近 Opus-4.8**——1000 张图片分析成本不到 20 美分，约为 Claude Opus 的 **1/80**。同步上线 **Files API** 支持跨会话复用图片/文件资源，把视觉理解从"一次性调用"升级为"可持续 Agent 资产"。文本能力与 V4-Flash 文本版对齐，视觉能力在多模态 Agent 基准上有"主要提升"。

#### 技术亮点 / 影响分析

- **视觉补齐 = DeepSeek 全模态闭环**：之前 V4 系列纯文本/代码强、视觉弱，Flash-Vision 把"看图"补齐，Agent 场景里视觉+推理可一站式搞定
- **1/80 成本打开视觉 Agent 普惠**：1000 图 20 美分意味着视觉 Agent 可以进入"高频小任务"模式（每图 0.02 美分），视觉审计、批量素材归类等场景成本可忽略
- **Files API = 跨会话记忆**：图片/文档成为可复用资产，多轮 Agent 不再每次重新上传，宣发团队可建"视觉素材库"持久上下文

#### 三句话总结

1. DeepSeek 发布 V4-Flash-Vision-Exp 多模态视觉模型，1000 张图分析 <20 美分（Opus 1/80），Files API 同步上线
2. 视觉补齐后 DeepSeek 形成"文本+视觉+Files 持久化"全模态闭环，Agent 场景成本与可组合性显著提升
3. 对 CODM 宣发团队：批量 KV 素材归类、视觉一致性审查、视觉风格 Agent 化等工作流可低成本接入，建议先做小批量试点对比 Claude 视觉能力

### #3 ⭐ 智谱 GLM-5.3 编程专模发布：漏洞识别 84.5% 超 GPT-5.6，两周后开源

> **来源**：大器观察 / 智谱官方 | **评分**：8.3/10 | **标签**：`编程` `智谱` `开源`

#### 核心事件

智谱发布 **GLM-5.3 编程专模**：基于 GLM-5.2 基座通过后训练放大能力上限，编程能力较前代提升 **50%**，在 Terminal Bench 3.0 基准取得**开源模型第一**，性能接近 Claude Fable 5。**CyberGym 评测漏洞识别率 84.5%**（超 GPT-5.6 Sol 的 83.3%），DeepSWE v1.1 拿到 66.9（对手 62.7）。模型权重将在**两周后开源**，同步上线 ZCode、AutoClaw 配套开发工具；荣耀 YOYO Claw 虾虾大脑宣布率先接入 GLM-5.3 基座。

#### 技术亮点 / 影响分析

- **编程 Agent 国产替代实证**：在代码审查、漏洞挖掘两个企业最关心的场景，国产开源模型已能在分数上追平/超越 GPT-5.6，私有化代码审计不再只能选海外闭源
- **"编程专模"路径成熟**：GLM-5.3 不是又一个大一统基座，而是"基座 + 后训练放大 + 垂直场景"的窄化路线，对宣发/工程团队"模型选型按场景而非按总分"提供新参照
- **两周开源 + 终端接入**：荣耀终端率先接入，标志国产模型在端侧 Agent 生态的卡位进入"硬件级绑定"阶段

#### 三句话总结

1. 智谱 GLM-5.3 编程专模发布，漏洞识别 84.5% 超 GPT-5.6 Sol，DeepSWE 66.9 领先开源阵营，权重两周内开源
2. "基座 + 后训练放大 + 垂直场景"路径在编程/安全场景验证可行，国产模型在企业级代码审计上具备替换潜力
3. 对 CODM 宣发团队：若涉及脚本/Prompt 工程代码审计，可考虑 GLM-5.3 作为本地化备选；端侧模型生态成熟也将影响移动端宣发工具选型

### #4 MiniMax H3 生态集成索引发布：GB200 上推理提速 27.7 倍

> **来源**：MiniMax 官方 | **评分**：8.0/10 | **标签**：`视频模型` `MiniMax` `推理加速`

#### 核心事件

MiniMax 发布 **Awesome MiniMax H3 Integrations** 生态集成索引，收录围绕 H3 构建的各类集成：覆盖 24GB VRAM 本地 ComfyUI 部署到企业级 SGLang 与 vLLM-Omni 部署。同日披露：NVIDIA SANA 团队的 **Sol Engine** 把 H3 视频生成延迟大幅压缩——**单块 GB200 上 10s/768p 视频从 414s 降至 14.93s（27.7 倍加速）**，5s 视频达 22.2 倍加速。H3 已上线 5 天日均处理 8 万亿 token，是中国模型出海 OpenRouter 调用量第一。

#### 技术亮点 / 影响分析

- **"生态集成索引"= 模型即产品的范式**：从"卖模型权重"转向"卖部署工具链"，覆盖从消费级 GPU（24GB）到数据中心（GB200）的全栈路径
- **27.7 倍推理加速改变可用性门槛**：414s → 14.93s 意味着 10 秒视频从"批处理任务"变成"交互式生产"，视频生成进入"试错-迭代"工作流
- **OpenRouter 第一 = 国产视频模型出海标杆**：H3 与 Wan3.0 形成中国视频模型双子星，对全球开发者生态的中国权重有明显拉动

#### 三句话总结

1. MiniMax H3 发布生态集成索引（24GB 本地到 SGLang 企业级），GB200 上 10s 视频推理提速 27.7 倍（414s→14.93s）
2. "模型 + 部署工具链"成为新范式，推理加速让视频生成从批处理进入交互式生产
3. 对 CODM 宣发团队：H3 与 Wan3.0 构成中国视频模型双选，27.7 倍提速后单条 10s 视频可在 GB200 上交互式迭代，KV/动效素材生产成本与周期结构性下降

### #6 微软 Aion 智能体系统曝光：Copilot 为核心，无开始菜单的 AI 原生 OS

> **来源**：IT之家 / Windows Latest / DoNews | **评分**：8.0/10 | **标签**：`智能体OS` `微软` `企业`

#### 核心事件

微软 **Project Aion**（内部名 **CopilotOS**）曝光，定位为面向企业用户、没有开始菜单的 AI 原生系统，可在运行 AOSP、Win3 甚至 Windows 11 的 AI 专用设备上运行。系统基于 **Microsoft Edge 浏览器和 Web3 轻量化 Windows 代码库**构建，无传统开始菜单、桌面图标与任务栏应用——一切基于 AI 交互。点击 Copilot 按钮后看到以姓名开头的问候语，随后出现 3 张卡片（"Stay on Top"/"Create something new"/"News of the day"）；"My Stuff"区提供 Edge、Teams、Outlook、OneDrive、Microsoft 365、Figma、VS Code 等应用入口；"Ask me anything"输入框支持自动补全建议；每段对话都会变成独立应用并保存为"My Stuff"中的卡片。

#### 技术亮点 / 影响分析

- **"无开始菜单的 OS"是 AI 时代的范式宣言**：微软把"OS = 任务栏 + 桌面 + 文件管理器"这个 30 年前提彻底打破，OS 变成"对话 + 卡片 + 空间（Spaces）"
- **任务栏 = 对话内容**：示例中"鸡尾酒杯"图标代表毛伊岛餐饮对话、"日历"图标代表会议对话——**应用图标由语义生成**，OS 状态由对话内容动态决定
- **企业级 AI 入口卡位**：Aion 直接捆绑 Microsoft 365/Figma/VS Code 等企业级应用入口，等于在 AI OS 时代把企业生产力套件一次性圈定

#### 三句话总结

1. 微软 Project Aion（CopilotOS）曝光，AI 原生、无开始菜单，对话与卡片即 UI，支持企业级 AI 设备运行
2. "任务栏图标 = 对话语义生成"是 30 年来最激进的桌面 OS 范式重写，AI 时代的 OS 形态之争正式开打
3. 对 CODM 宣发团队：Figma/VS Code 被捆绑进 AI OS 入口，长期看设计/开发协作工具的"系统级可达性"会重排——关注 Figma 是否跟进类似"AI 空间"改造

1. OpenAI 下调 GPT-5.6 Sol API 价格 20-33%（输入 $4/输出 $20 百万 token），优惠持续至 11 月 21 日；同期 Gemini 3.7 Flash 降价约 50%
2. 美头部模型进入同步降价周期，"模型稀缺溢价"窗口关闭，AI 公司估值锚点向性价比漂移

### #8 Claude Code v2.1.243 发布：新增 /usage 循环统计、模型选择器与无密钥登录

> **来源**：Anthropic 官方 / GitHub Releases | **评分**：7.5/10 | **标签**：`ClaudeCode` `开发工具` `Anthropic`

#### 核心事件

**Claude Code v2.1.243** 8 月 24 日发布：新增 **/usage 的 Loops（循环）细分统计**、**可自定义的 modelPicker 设置**、**promptCacheTtl 与 subagentPromptCacheTtl 配置**，以及**组织级 modelPricing 管理**。同步支持**无密钥登录**流程（不再强制要求每次配置 API key），并对 subagent 行为做了稳定性修复。版本号小幅迭代（v2.1.243）但功能点密集，主要面向工程团队长期使用场景的"运营型"改进。

#### 技术亮点 / 影响分析

- **"/usage 循环统计" = 团队级成本可见性**：Loops 细分让团队 Leader 可以看到每个 subagent/每个项目循环的 token 消耗，把"用了多少"从个人级提到团队级——AI 工具的 FinOps 化进入 Claude Code
- **"无密钥登录" = 企业级接入门槛降低**：不再每台机器/每个新成员手动配 key，企业 IT 可统一走 SSO/OAuth 流程接入，AI 编程工具在大型组织的扩散阻力大幅下降
- **"modelPicker 可自定义" = 工具链解耦**：可指定团队默认模型 + 项目级 override，Claude Code 进一步脱离"绑定 Sonnet"的工具属性，向"AI 编程工作流调度器"演化

#### 三句话总结
