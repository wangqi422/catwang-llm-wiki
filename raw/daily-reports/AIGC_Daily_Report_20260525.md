### #7 ⭐ 微软研究院推出 Webwright：用终端代码替代逐点点击的 Web Agent 新范式

> **来源**：微软研究院（2026-05-25）| **评分**：8.0/10 | **标签**：`#Agent` `#开源`

#### 核心事件
微软研究院发布 **Webwright**，一种全新的 Web Agent 范式：不再逐点预测点击位置，而是给 AI 一个终端，让它通过编写 Playwright 代码控制浏览器。整个框架仅约 **1000 行代码**，GPT-5.4 测试在线任务准确率 **86.7%**。

#### 技术亮点 / 影响分析
- **要点1**：代码即操作——Agent 一次可链式执行多个网页交互，效率远超逐点点击
- **要点2**：生成的脚本可打包为可复用 CLI 工具，跨 Codex/Claude Code/OpenClaw 平台共享
- **要点3**：GPT-5.4 平均每任务成本 $2.37，产出可复用的 RPA 脚本

#### 三句话总结
1. Webwright 用"写代码"替代"点鼠标"，Web Agent 范式从逐步操作升级为编程式自动化
2. 1000 行代码 + 86.7% 准确率，极简架构却刷新 SOTA，证明 Agent 设计的"少即是多"
3. 可复用 RPA 脚本 + 跨平台共享——未来竞品数据采集、社媒发布等流程可一键自动化
