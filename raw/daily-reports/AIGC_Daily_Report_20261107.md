### #1 ⭐ AI 资本同日重定价：OpenAI 首批 110 亿美元到账、Anthropic IPO 估值下修、企业 AI 支出见顶信号

#### 核心事件
11 月 6 日（周五），彭博报道 **OpenAI 完成新一轮融资的首批约 110 亿美元资金到账，对应估值 1.25 万亿美元**；首批出资方包括 Coatue Management 与普信集团（T. Rowe Price），后续参与者有软银、红杉、Founders Fund、a16z 与一个阿联酋投资者财团，剩余部分预计未来数周内完成。本轮**总规模从最初 300 亿美元目标降到约 200 亿**，估值目标从 1.4 万亿降到 1.25 万亿（仍高于今年 3 月融资时的 8520 亿）。《纽约时报》DealBook 同日披露出资结构：**累计投入约 650 亿美元的软银本轮仅商谈数亿美元**，Coatue 也在数亿美元级，阿联酋财团预计成最大出资方。CFO Sarah Friar 称「一个好的 CFO 总会在能融资的时候融资」，强调**数据中心投资计划不变、仍推进 2027 年上市可能性**。

- **与 11-01 期要区分**：11-01 期报的是「融资目标从 300 亿砍到 200 亿、估值 1.4 万亿→1.25 万亿」的**传闻阶段**；今天是**首批资金实际到账 + 出资方削减结构曝光 + 估值下修扩散到 Anthropic**，属于从「谈」到「落地」的新事件，且与 11-03 期报道的 Anthropic S-1/A Q3 财报是不同维度（那是财务数据，今天是定价博弈）。

### #2 ⭐ 工信部印发《关于加强智能体终端设备进网管理的通知》：智能体进手机先过进网许可

> **来源**：[工信部 / 中证网](https://jnzstatic.cs.com.cn/zzb/htmlInfo/137494.html) · [中国新闻网](https://www.chinanews.com.cn/cj/2026/11-06/10727217.shtml) · [腾讯新闻·央视](https://news.qq.com/rain/a/20261106A0B6XF00) · [南方都市报](https://news.qq.com/rain/a/20261106A0FHT300) | **评分**：9.0/10 | **标签**：监管 / 进网许可 / 唯一身份码 / 用户选择权

#### 核心事件
11 月 6 日，工信部印发 **《关于加强智能体终端设备进网管理的通知》**，覆盖**预置安装智能体的手机、平板、可穿戴设备等电信终端**，部署四项任务：
① **智能体与终端适配**：开发者加强适配验证，须在**产品设置页公示适配验证列表**（已完成适配的终端型号与操作系统信息），上架应用分发平台前提交适配验证情况；
② **改进进网管理**：进网检测中开展智能体适配验证与风险评估，依法开展**涉诈风险安全评估与反诈能力前置性评测**；终端所用智能体须参考智能体互联系列国家标准**配备唯一身份码**；终端生产企业须保证获证前后一致性，重大变化要报备并重新检测；
③ **强化现网升级管理**：通过 OTA 推送智能体现网升级须**提交升级方案**（时间、规模、用户群、场景、服务内容、经营模式、网络与数据安全、反诈措施），升级结束提交报告，**经工信部组织专家评估、征求意见后方可正式提供服务**；
④ **健全分发管理**：应用分发平台推动 App 开发者通过**电子签名主动声明是否同意智能体调用，未经声明同意不得强制调用调取**；分发页公示适配验证列表，不得提供不兼容设备型号的智能体下载安装。
官方定调引导 AI 技术「**为人所用、为人服务、为人所控**」，建立适配验证→进网检测→现网升级→分发管理**全链条制度体系**；中国信通院将建设智能体版本与终端型号适配库、推进可信身份体系与管理平台建设。

#### 技术亮点 / 影响分析
- **与 11-05 期《智能体发展自律公约》要区分**：那是乌镇峰会中国信通院联合腾讯、阿里、蚂蚁等 20 家单位发布的**行业自律**（八条措施 + 身份注册与解析平台）；今天是**行政主管部门的进网许可制度**，具强制力，且把「唯一身份码」从倡议写进进网要求。
- **迭代节奏被纳入监管**：OTA 升级要报方案、交报告、过专家评估，意味着系统级智能体不再能像普通 App 那样「先推后改」，版本节奏直接受合规约束。
- **入口之争第一次有了明文边界**：「未经声明同意不得强制调用调取应用」直指手机厂商 / 超级 App 想让智能体跨应用代操作的野心，App 开发者第一次拿到明确的选择权，用户拿到知情权与选择权。
- **合规成本前置**：对终端预置、系统级助手与出海 AI 功能，适配验证、身份码、涉诈评估要在产品定义阶段就排进去，而不是投放前补材料。
- **边界**：通知为框架性部署，具体检测标准、适配库与身份体系仍在建设中，执行细则与时间表待后续文件；「重大变化」的判定口径尚未细化。

#### 三句话总结
1. 工信部印发通知，要求预置智能体的手机 / 平板 / 可穿戴过进网检测、配唯一身份码、OTA 升级报备并经专家评估，App 不声明同意智能体就不得强制调用。
2. 智能体治理从行业自律升级为行政进网许可，适配验证、身份标识、升级评估、分发声明被串成一条全链条制度。
3. **对 CODM 宣发团队**：未来若与手机厂商或系统级智能体合作「一句话生成海报」「游戏助手入口」「活动提醒」类能力，立项时就要确认适配验证列表、唯一身份码与 App 调用声明，别等投放前才发现入口不合规；涉及玩家数据的自动调用更要提前过一遍法务。

### #3 ⭐ Meta 无限期暂停商业网页抓取条款：挪威、巴西、英国三国监管同日夹击

> **来源**：[AI HOT 热点资讯 11-07](http://mp.weixin.qq.com/s?__biz=MzY4MjMyNjIyNQ==&mid=2247497480&idx=1&sn=ad7ccbf24d07209181e0bb246703eb6e) · [AI 科技日报 2026-11-07](http://mp.weixin.qq.com/s?__biz=MzY4MjMyNjIyNQ==&mid=2247489422&idx=1&sn=d5ec9a6e7bb1bb05e8ae6c2b58ecbe66) · [AI HOT 聚合池 s=73](https://aihot.news/) · Nieman Lab / Press Gazette / 404 Media | **评分**：8.7/10 | **标签**：数据合规 / 司法 / 授权链 / 文本水印

#### 核心事件
Meta 宣布**无限期暂停原定 11 月 20 日生效的商业条款更新**——该条款曾要求商业账号授权 Meta 抓取其关联网站内容，且**无退出选项**。压垮它的不是舆论而是司法：**挪威奥斯陆法院**应十家媒体申请颁布临时禁令、**巴西法院**禁止未经授权使用新闻内容、**英国竞争与市场管理局（CMA）**启动正式调查，美国参议员 Schiff 与 Blackburn 亦致信扎克伯格要求撤回。Meta 称将继续与各方磋商，**暂停不等于撤回**。
同日，**Anthropic 通知 API 客户：11 月 16 日起 Claude Opus 4.6 / 4.5、Sonnet 4.5、Haiku 4.5 陆续加入不可见文本水印**，以赶上**欧盟 AI 法案 12 月 2 日**的合规期限。水印为 DeepMind **SynthID-Text 变体**，通过选词统计模式嵌入，不增加 token、不含用户信息；但本轮四款模型**仅在默认采样参数下带水印**，开发者调整 temperature、top_p 等参数后水印可能失效。

#### 技术亮点 / 影响分析
- **与 11-02 期四巨头统一 robots.txt 退出信号是同一条主线的下一章**：那次是「站方可选退出」的企业协同，这次是「平台方被司法强制暂停」——训练 / 检索内容的来源可追溯性，正从自律条款变成法定义务。
- **授权链成为固定合规成本**：与 11-06 期 Anthropic × 美联社首份新闻内容授权协议连起来看，模型厂商从「先抓再说」转向「先谈授权 / 先加标识」，内容来源的可追溯性正在变成基础设施。
- **水印的缝隙要说清**：「默认参数才生效」意味着合规承诺与工程现实之间还有距离；调整采样参数是开发者常见操作，实际约束力需第三方验证。
- **边界**：Meta 是暂停而非撤回，CMA 调查与各国诉讼仍在进行；Anthropic 水印的覆盖率与鲁棒性尚无独立复测，不宜按「全面合规」解读。

#### 三句话总结
1. Meta 在挪威法院临时禁令、巴西法院裁定与英国 CMA 调查下无限期暂停原定 11-20 生效的商业抓取条款；Anthropic 同日宣布 11-16 起为四款旧模型加不可见文本水印以赶上欧盟 12-02 合规期限。
2. 内容授权链与生成物标识从企业自律推进到司法与法定义务，模型厂商的固定合规成本又多一层。
3. **对 CODM 宣发团队**：给 AI 素材建一份「参考来源可追溯」台账，尤其是含品牌角色、玩家 UGC、新闻图片与第三方字体的二创——平台抓取条款与欧盟合规期限会让「能不能用这张参考图」变成法务问题，而不只是审美问题；上线前顺手确认水印与来源标识是否会破坏成片。

### #4 ⭐ Perplexity 发布 Teammates：常驻工作智能体，内部 30 天跑出约一万个

11 月 5–6 日，两条世界模型进展同时落地。

其二，**NVIDIA 开源 4 个 Cosmos 3 世界模拟模型**（各 **16B 可训练参数**，基于 Cosmos 3 Nano 后训练，OpenMDW1.1 许可允许商用）：覆盖自动驾驶 **11 路相机同步视频 + 激光雷达**生成、流式交互仿真（车动场景响应）、**空间控制信号转真实感视频**（深度 / 分割 / 边缘 / 模糊布局 + 文本提示）、双臂机器人动作预测；同步发布 **VFlash 并行视觉解码框架**，利用边界框、轨迹等视觉图元的固定结构一次预测完整图元，在 Jetson Thor / DGX Spark 指定任务下**机器人推理最高提速 5.1 倍**，MolmoSpaces 四组任务平均成功率从 **62.6% 升至 70.2%**。

- **一个推体验、一个推可部署**：Frameboy 是云端实时交互（研究预览），Cosmos 3 是可下载、可商用、能适配自有相机组与机器人的开源权重，两条路线互补而非竞争。

3. **对 CODM 宣发团队**：Frameboy 这类实时摄影机最适合做**分镜预演与场景勘景**（换机位不用重渲染），Cosmos 3 的 Sim-Transfer 可把仿真器里的深度 / 分割 / 布局转成带材质光照的画面做 PV 场景草稿；但 15FPS 与云端成本决定它现阶段只能进预演环节，最终成片仍需传统渲染与人工终审。

## 编辑点评

八条其实在讲同一天里的两个方向：**钱开始挑项目，智能体开始常驻**。

**① 上半场是重定价（#1–#3）**。OpenAI 110 亿到账但出资方集体缩手、Anthropic IPO 估值被压到 1.2–1.3 万亿、工信部给智能体发「进网工牌」、Meta 被三国司法按住——资本与监管在同一天把「无限扩张」的假设收了回去。值得注意的是，**估值仍守在万亿以上，缩的是支票和节奏**，这不是泡沫破裂，而是从「信仰定价」转向「账本定价」。

**② 中间三条是常驻（#4–#6）**。Perplexity Teammates 让 Agent 变成 200 美元/月的「同事」，Meta 用 Active Memory 让它记得住，Google 用 Agent Substrate 让它挂得起、醒得快——产品层、记忆层、基础设施层是三家公司在同一天独立交出的三块拼图。配上 11-06 期 Kimi Hosted Agents 的运行环境，常驻 Agent 的技术栈第一次完整可见。

**③ 收尾两条回到宣发最实在的地方（#7–#8）**。Frameboy 把世界模型从「等渲染」推进到「推镜头」，Cosmos 3 把仿真权重开源到自有机房；Ling-3.2-flash 让模型看着自己的画面纠错，Krea Video 把生成 / 改片 / 音效收进一个工作台。前三条讲钱和规矩，中间三条讲「住下来」，最后两条讲「能不能少重跑一次」。

**今天最高分给到 #1 资本重定价（9.3 / P0）**：分量不在数字大，而在「估值守住、支票变小」这个转折第一次同时发生在两家头部实验室身上，且立刻传导到算力租约与企业 AI 支出预期。

**四条可以立刻执行的线索**：① 用 Frameboy / Viewfinder 试一次分镜预演（只做草稿，15FPS 与云端成本决定它不进成片）；② 在 Krea Video 开一条「同镜头多风格」试点，验 UGC 广告模板是否省掉来回导出；③ 给常驻 Agent 排期前先算清 200 美元/月 × 队友数与权限继承规则，避免越权读到未发布资产；④ 给 AI 素材与系统级智能体入口补一份「适配验证列表 + 调用声明 + 参考来源台账」的合规清单，把 #2 与 #3 的要求前置到立项阶段。
