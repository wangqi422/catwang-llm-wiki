## 1. 海外巨头 & OpenAI 终局发布

### 1. GPT-5.6 7/7-9 终局发布: Sol 创 Terminal-Bench 2.1 91.9% 新纪录 + Terra/Luna 同步

**关键信息**:
- **发布时间窗口**: 7/7-9 三天内分阶段发布, 美国政府要求错峰, Sol 旗舰版 7/7 优先开放, Terra 均衡版 7/8, Luna 轻量版 7/9
- **Terminal-Bench 2.1 新纪录**: Sol 在 Terminal-Bench 2.1 编程 Agent 基准上拿到 **91.9%**, 较 GPT-5.5 提高 4.2 个百分点, 编程 + Agent 推理新基准确立
- **DeepMind 主动让路**: Gemini 3.5 Pro 推迟至 7/17, 避开 7/7-9 的 OpenAI 焦点; 谷歌内部沟通"晚一周抢不到新闻头条"
- **企业版预审名单**: 美国国防部 / 国务院 / 财政部 / NIH 等 12 个联邦机构已通过 API 预览, 配套 Claude 4 同期被禁
- **同步开源版本**: OpenAI 同步推出 GPT-5.6-base 基础模型(无 RLHF), MIT 协议, Hugging Face 已开始镜像
- **价格体系**: Sol 定价 $15/M input + $60/M output, 与 GPT-5.5 持平; Terra $3/$15; Luna $0.3/$1.2

**来源**: OpenAI 官方 · Testing Catalog · 量子位 · X: @sama · X: @OpenAI · 财联社

**AIGC 速报解读**: GPT-5.6 Sol 是 OpenAI 一年内**最大版本动作**, Terminal-Bench 2.1 91.9% 意味着编程 Agent 推理正式突破"单任务 90%"线, 此前 88% 是行业天花板。**7/9 后是中美 AI 编程差距的关键校准点** — 阿里 7/10 卸载 Claude + Qoder + Qwen3.7-Max 替代方案的实战价值, 需要在 7/9 后用 GPT-5.6 Sol 做一次对比测试。

## 2. 国产 AI & 反击战

### 3. 阿里 7/10 全员卸载 Claude: 中国 AI 史上首次"反向封禁"美国头部 AI

**关键信息**:
- **禁令时间线**: 7/3 智东西独家, 7/10 正式生效, 全员硬性要求卸载, 覆盖 Sonnet / Opus / Fable / Claude Code 在内所有 Anthropic 产品
- **导火索**: 6/24 Anthropic 向美国参议院银行委员会递交信函, 指控阿里用 2.5 万个虚假账号对 Claude 实施 2800 万次对话"工业级模型蒸馏攻击"
- **阿里同步动作**: 6/24 在加州圣何塞联邦法院起诉美国国防部, 要求将其从"中国军事企业名单"(1260H 名单)移除; 7/4 阿里 Token Hub 事业群成立, 接管 1.6 万亿模型分发
- **替代方案**: 阿里推荐自研 Qoder 作为 Claude Code 替代, Sonnet/Opus/Fable 由 **Qwen 3.7-Max + GLM-5.2 + DeepSeek V4** 兜底
- **背景烧钱**: 阿里年初对外部模型使用实行大额报销政策, 不少程序员每周在 Claude 上烧数百美元, 替代后预计年省 6-8 亿元
- **行业连锁**: 腾讯 / 字节 / 美团内部已启动"非美 AI 工具切换 POC", 7/15 内部立项会

**来源**: 智东西(独家) · 太平洋科技 · 新智元 · China Daily Exchange · 天眼查 · 美团开源 1.6 万亿模型公告

**AIGC 速报解读**: 阿里这一刀是**中国 AI 史上首次"反向封禁"** — 之前都是美国封中国(华为/昇腾/1260H 名单), 现在是中国头部科技公司因"安全 + 国家名单"双重原因**主动封禁**美国头部 AI 产品。CODM 团队 7/10 后若还用 Claude Code, 需考虑合规风险 + 是否有自研替代(Qwen3.7-Max/GLM-5.2 已是 Qoder 主力), **宣发涉政/涉军事素材的合规成本会急剧上升**。

## 3. AI 跨界 & 芯片 + 电影

### 4. Anthropic×三星 2nm 芯片代工洽谈 + 挖角 OpenAI 芯片工程师 Clive Chan: 自研芯片进入实操

**关键信息**:
- **芯片代工洽谈(7/4 新发)**: Anthropic 与三星电子 Foundry 部门进入 2nm AI 芯片代工协议谈判, 计划 2027 Q3 首批流片, 2028 量产
- **核心团队挖角**: Anthropic 7/2 从 OpenAI 挖走**芯片架构首席 Clive Chan**, 此前在 OpenAI 主导 IPU/Inference 芯片架构; 团队同时挖走 OpenAI TPU 团队的 4 名核心工程师
- **战略意图**: Anthropic 自研芯片命名为 **"Claude Silicon"**, 用于降低 Claude Opus 4.8 推理成本(目标降 40-50%)+ 服务国防部 / NIH 等"主权 AI"客户
- **投资规模**: 三星 2nm 代工首批 5000-8000 片晶圆, 单价 $18,000-20,000, 订单总额约 1.0-1.6 亿美元
- **配套融资**: Anthropic 7/4 完成 G 轮 80 亿美元融资, 估值 1850 亿美元(较 F 轮 1380 亿涨 34%), 由 a16z / Google / 沙特 PIF 共同领投
- **台积电备选**: 若三星 2nm 良率不达标, 备选方案是台积电 A16(1.6nm)工艺, 但成本高 25%

**来源**: The Information(独家) · Reuters · 36氪 · X: @AnthropicAI · X: @sama · 智东西

**AIGC 速报解读**: Anthropic 自研芯片意味着**头部 AI 公司正进入"软硬一体 + 垂直深耕"阶段** — OpenAI 有 IPU, Google 有 TPU, Amazon 有 Trainium 3, Meta 有 MTIA v3, 现在 Anthropic 也要有自己的"Claude Silicon"。**4 亿美元做药 + 80 亿融资 + 自研芯片**, Anthropic 在 7/4 一天里完成"制药 / 资本 / 芯片"三线扩张, 这是"AI 公司 → 垂直行业操盘手"路径的最强信号。

### 7. Google DeepMind 投 7500 万美元入股独立电影厂 A24: 共建"AI 创作工具甲方"

**关键信息**:
- **投资金额**: Alphabet 向 A24 投资约 7500 万美元, 是 Google 首次以股权形式入股电影制片厂
- **合作模式**: 不是 IP 授权, 不是数据训练协议, Google 无权用 A24 电影训练模型; 资金专款专用, 不能挪作电影投资
- **资金去向**: 流向 A24 内部 20 人 Labs 团队(由前 Adobe 高管 / Behance 联合创始人 Scott Belsky 领衔), 首个方向: AI 生成的故事板 + AI 辅助剪辑优化 + 个性化推荐
- **战略意义**: DeepMind 需要"一个能说'这个工具不好用'的甲方", Sora 失败已证明光有技术不够, 必须有真实创作者反馈
- **配套产品**: DeepMind 同步推出 Veo 3 Long(90 秒长版), 与 A24 Labs 共建"创作者工作流沙盒"
- **对标对比**: 微软投资 OpenAI 是 130 亿美元 + 算力换股权, DeepMind 投资 A24 是 7500 万美元换"工具迭代反馈", 战略路径不同
