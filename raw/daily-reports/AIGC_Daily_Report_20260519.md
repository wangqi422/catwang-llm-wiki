### #8 ⭐ Karpathy 提出 "Agentic Engineering"：从 vibe coding 到代理工程

> **来源**：数位时代 / TheNewStack / TechTimes | **评分**：7.8/10 | **标签**：#方法论 #编程范式

#### 核心事件
Karpathy 在红杉 AI Ascent 2026 提出 **"Agentic Engineering"** 概念，标志着从 2025 年的 vibe coding 升级到更严肃的代理工程范式。核心观点：LLM 是"鬼魂"而非动物，唯一能影响它的是 prompt、context 与环境设计。

#### 技术亮点 / 影响分析
- **Software 3.0 范式**：prompt 即程序，context window 是控制 LLM 的指令
- **新 10x 人才**：能驾驭代理工程的人，加速幅度"峰值远不只十倍"
- **"思考"可外包，"理解"不可外包**：未来人才市场的隐形分水岭
- **CLAUDE.md 22 万星**：Karpathy 理念催生的配置文件已成 GitHub 最快增长仓库之一

#### 三句话总结
1. Karpathy 提出 Agentic Engineering，从 vibe coding 进化到代理工程，强调"理解"不能外包。
2. 新编程范式的核心是：人做审计和架构决策，Agent 做执行和迭代。
3. 对宣发团队启示：AI 可以执行素材生成，但品牌调性的"理解和判断"仍需人类把控。
