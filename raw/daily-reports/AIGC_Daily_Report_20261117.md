### #1 ⭐ 阿里正式发布 Qwen4-Max：2.4T 总参 / 71B 激活 / 1M 上下文，CodeArena 全球第六、单任务成本降 58%

> **来源**：[南方+](https://www.nfnews.com/content/X3RvG8L53P.html) · [腾讯新闻](https://news.qq.com/rain/a/20261116A0BJ4F00) · [通义千问官方博客](https://qwen.ai/blog?id=qwen4-max) · [新京报](https://m.bjnews.com.cn/detail/1794806869129739.html) · [每日经济新闻](https://www.163.com/dy/article/LBTSLB6Q0512B07B.html) | **评分**：9.4/10 | **标签**：国产旗舰 / 效率战 / 真实 ROI / P0

#### 核心事件
11 月 16 日，阿里巴巴正式发布全新一代基座大模型 **Qwen4-Max**，千问 AI 平台首发上线，API 服务与 Token Plan 同步开放。模型采用基于 **Qwen 稀疏注意力（QSA）的全新 MoE 架构**，**总参数 2.4T、每 Token 仅激活 71B**（另有 328B N-gram Embedding 参数），具备原生视觉能力、支持**百万 Token 上下文**。架构上以 **GDN + QSA**（三层 Gated DeltaNet 压缩历史）、**Gated Residual（GR）四并行残差分支**、N-gram Embedding 三项升级，实现每 Token 激活参数较上代 Qwen3.8-Max 少 25%、全程训练无 loss spike。能力侧：在全球前端编程盲测 **CodeArena（WebDev）位列第六**，居于 GPT-6 Astra 与 Claude Fable 5.1 之间，刷新中国模型最好成绩；在 Agents' Last Exam（ALE）、Vals Index 等智能体评测处于领先梯队；自建 Work360 全场景体系（26 个一级域 / 182 二级 / 721 三级）得分 **52.69，较上一代 47.74 提升超 10%**。效率是这次的主打：Terminal-Bench 4.0 上每尝试平均 Token 从 289K 降到 151K（约减半）、得分从 37.9 升到 48.5（+28%），Work360 单任务平均成本从 4.43 美元降到 1.67 美元（**降 62%**）；国内口径为缓存命中每百万 Token 低至 0.5 元、单任务平均费用降约 58%。官方称 Qwen4 系列中小尺寸模型将陆续开源。

#### 技术亮点 / 影响分析
- **「少激活 + 低缓存价」把竞争维度从跑分挪到 Cost per Task**：2.4T 总参只激活 71B、每 Token 比上代少激活 25%，叠加缓存命中价压到 0.5 元/百万 Token，本质是把「智能」当成可按任务预算调配的资源——这与今天 #2 的 Hy4 flash（12B 激活 / 成本 1/20）是同一场效率战的两个身位。
- **「AI For Science」给出了真闭环而非 PPT**：官方披露 Qwen4 连续 48 小时自主运行、从 270 万候选分子中筛选，经 4 轮「设计—合成—测试」闭环真实合成出一种新型冷却液材料，指向高功率芯片的数据中心散热。这是把模型能力落到「湿实验」的少数可核验案例之一。
- **3D 与工具调用是宣发侧最该盯的一格**：官方明确展示 Qwen4 的 3D 建模能力——一句话生成一个可玩的 3D 游戏、能调用 Blender 等专业工具；汽车制造场景把单工件加工编程人工用时从 475 分钟压到 24 分钟（-95%），金融场景熟练调用 90 个 MCP 工具产出 Excel 底稿与 PPT 报告。
- **查重说明**：Qwen4-Max「预览版」在第 96 期（11-12）已作条目报道，今日报的是**11-16 正式发布 + 完整工程参数（2.4T / 71B 激活 / 328B N-gram / QSA 架构 / CodeArena 第六 / 成本降 58%）**，属「预览→正式」新阶段，正文数据均为首次披露，非旧闻复读。

#### 三句话总结
1. 阿里 11 月 16 日正式发布 Qwen4-Max：QSA 稀疏 MoE 架构、2.4T 总参 / 71B 激活 / 1M 上下文、原生视觉，CodeArena 全球第六，单任务成本较上代降 58%–62%。
2. 它把「国产旗舰」的衡量标尺从榜单分数挪到真实业务 ROI——少激活、低缓存价、可调用专业工具，让「够用且便宜」成为可预算的工程变量。
3. **对 CODM 宣发团队**：Qwen4 的「一句话生成 3D 游戏 + 调用 Blender」值得直接试——可做赛季概念武器 3D 预览、活动小游戏原型、KV 场景粗模，把「文字简报 → 可交互 3D 样片」的周期压到一次会话；但 52.69、CodeArena 第六、冷却液材料等均为厂商自报/官方口径，进对外物料前须自测一致性、并标注「模型辅助生成、非最终资产」。

### #2 腾讯混元发布 Hy4 flash：224B / 12B 激活 / 1M 上下文，单任务成本仅 Hy4 的 1/20、85 人盲测满意度近 Claude Haiku 5.5

> **来源**：[腾讯官方](https://www.tencent.com/tencent-launches-hy4-flash-to-power-high-speed-cost-efficient-ai-deployment-for-everyday-workflows/) · [环球网 / 腾讯新闻](https://news.qq.com/rain/a/20261116A0A9U400) · [新京报](https://m.bjnews.com.cn/detail/1794811095129773.html) · [澎湃新闻](https://www.thepaper.cn/newsDetail_forward_34490238) | **评分**：8.8/10 | **标签**：模型效率 / 低价 API / WorkBuddy / P1

#### 核心事件
11 月 16 日，腾讯混元发布最新语言模型 **Hy4 flash**——**总参数 224B（含 64B Engram 参数）、激活仅 12B**，支持多模态输入与 **1M 上下文**。定价为每百万 Token 输入 0.5 元、输出 2 元、命中缓存 0.02 元，被称为「迄今性价比最高的 Hy 模型」。工程侧：预训练引入混合注意力、LatentMoE、Engram 架构，KV cache 仅为 Hy3 的 1/24、Hy4 的 1/6；后训练自蒸馏 Hy4 并用强化学习把端到端输出长度砍 50%；推理结合 megakernel、4-bit 量化、DFly，解码速度超 **150 tps**。效果上，综合表现略优于更大的 Hy4 preview（770B 总参 / 49B 激活）；按内部 WorkIndex 评测集，单任务成本仅为 Hy4 preview 的 1/13、Hy4 的 1/20、DeepSeek-V4.1-Flash 忙时的 1/8；腾讯内部 **85 名 WorkBuddy 用户在 27 类共 259 个任务盲测**，满意度接近 **Claude Haiku 5.5**，单任务成本约 0.26 元、端到端时长中位数 6.7 分钟。目前已在腾讯云 TokenHub、WorkBuddy、元宝、企业微信、QQ、ima、Marvis 上线，即将接入 OpenRouter；11 月 30 日前 WorkBuddy 限时免费、TokenHub API 五折。混元团队表示计划开源 Hy4 flash 并高频迭代。

#### 技术亮点 / 影响分析
- **「够用就好」被做成一条独立产品线**：Hy4 flash 不与 Hy4 比智能上限，而是把成本压到 1/20、速度拉到 150 tps，专门吃深度搜索、文档处理、PPT 生成、简单前端、Computer Use 这类高频任务——与 #1 的 Qwen4-Max 形成「高端效率旗舰 / 走量低价快马」的双层供给。
- **评测口径值得注意**：主打内部 WorkIndex（PPT 制作/修改、文档编辑、表格修复、音视频处理、视觉理解）而非公开榜单，且盲测样本仅 85 人 259 任务——对做办公自动化的团队参考价值高，但不能外推为通用能力排名。
- **与「模型路由」实践直接相关**：Hy4 flash + 便宜缓存价，正好适合把高频短链路任务切过来、把长程高精任务留给旗舰，是「任务级模型路由」的低价端选项（详见编辑点评）。
- **查重说明**：Hy4 正式版在第 88 期（11-04）已报（9.4 / P0），今日 **Hy4 flash 是不同型号**：12B 激活、成本 1/20、新定价与盲测数据均为首次披露，属新品新事件。

#### 三句话总结
1. 腾讯 11 月 16 日发布 Hy4 flash：224B 总参 / 12B 激活 / 1M 上下文、多模态，单任务成本仅 Hy4 的 1/20、解码超 150 tps，85 人盲测满意度近 Claude Haiku 5.5。
2. 它把「够用就好」做成独立产品线——用内部 WorkIndex 而非公开榜单定标，专吃文档、PPT、Computer Use 等高频办公任务，与旗舰形成双层供给。
3. **对 CODM 宣发团队**：免费窗口（11/30 前 WorkBuddy）适合做**批量重复性物料的成本压测**——多语种字幕、活动规则文案、数据战报初稿、素材打标先切到 flash，把「改 → 重跑」的边际成本降下来；但 1/20、150 tps、满意度近 Haiku 5.5 均为厂商自测/盲测口径，正式对外物料仍须人工审核，长程高精度任务留给旗舰。

### #3 字节 Seedance 2.5 4K API 全面开放：480P 样片试错 + 4K 正片、10-bit 色深，4K 视频生成走向规模化接入

> **来源**：[IT之家](https://www.ithome.com/1/027/736.htm) · [腾讯新闻 / IT时代网](https://news.qq.com/rain/a/20261116A0A6C200) · [AITOP100](https://www.aitop100.cn/infomation/details/34982.html) · [AIBase](https://www.aibase.com/news/32340) | **评分**：8.3/10 | **标签**：视频生成 / 创作工具 / 4K / P1

#### 核心事件
11 月 16 日，字节跳动旗下火山引擎宣布 **Seedance 2.5 4K 的 API 全面开放**，开发者与企业客户即日起可通过接口直接调用，标志该模型从产品演示与定向试用（此前首批面向约 20 家工作室）转向标准化接口服务。需区分两个时间点：模型于 **10 月 23 日正式发布**，本次是 **11 月 16 日 API 全面开放**。官方称 Seedance 2.5 4K 经专项训练，对人物表情、细微动作与画面细节学习更充分，是该代最强版本。核心功能 **Draft（样片）模式**：创作者先用 **480P 样片**快速验证分镜、构图、运镜与表演节奏，反复打磨后基于同样参数生成 **4K 正片**——把低成本创意探索与高画质最终输出分离；此前 1080P 的 Draft 模式官方测算约省 57% 成本，抽卡越频繁省得越多。画质层面支持 **10-bit 色深**，色彩层次更丰富、渐变更平滑，纹理/轮廓/细节更清晰，可满足大屏投放；在参考生成与视频编辑中能更好保持上传素材的画质、清晰度与色彩一致性，对海报、商品包装等含小字素材的清晰度保留更好。目前已有部分海内外影视制作与后期公司试用，反馈在画面细节、光影层次与光学透视还原上表现亮眼。

#### 技术亮点 / 影响分析
- **「先草稿后正片」把视频生成的成本结构改造成可预算流程**：480P 试错 + 4K 出片，本质是给「抽卡」这件事设了两级价——创意阶段烧小钱、成片阶段才烧大钱，与 #1/#2 的「任务级成本路由」是同一思路在创作侧的映射。
- **对小字/参考素材的保留是宣发刚需**：官方明确提到对海报、包装等含小字参考素材的清晰度保留更好——这正是游戏宣发高频场景（KV 文字、周边包装、IP 联名物料），比单纯的「更清晰」更有实用指向。
- **10-bit + 大屏适配**：从「能出片」到「能交付」，4K + 10-bit 让 AI 生成视频进入广告片、影视后期、品牌短片的候选工具链。
- **边界**：10-23 发布、11-16 API 开放，勿把「发布」写成今日；提升描述多为厂商自述、部分客户为定向试用，API 定价未披露；「省 57%」为特定条件下的官方测算，不是通用节省比例。

#### 三句话总结
1. 字节火山引擎 11 月 16 日全面开放 Seedance 2.5 4K API（模型 10 月 23 日已发布），支持 480P 样片试错 + 4K 正片的 Draft 模式与 10-bit 色深，4K 视频生成从定向试用走向规模化接入。
2. 它把视频生成的成本结构改造成两级流程——创意阶段低价试错、成片阶段高质输出，并在参考生成/小字素材保留上针对广告与影视场景优化。
3. **对 CODM 宣发团队**：这是今天最直接可用的工具——建议把「赛季 KV 动效、武器展示短片、活动预热视频」按 480P 样片先过创意与审片、确认后再出 4K 正片，特别验证对**含小字海报与包装素材**的一致性保留；但把「更强/更清晰/省 57%」当厂商口径，API 定价与实际产能需自测，涉及 IP 与角色素材的生成先过版权与合规。

## 编辑点评

八条其实在讲同一件事：**模型拼效率，资本抢人，安全问责终于有了价钱**。第 101 期把三条原本平行的线在同一天交汇——技术侧把「智能」按任务拆开卖，资本侧把「模型之外的人与中间层」抢成稀缺品，监管侧则第一次把「失控」写成诉状里的法律事实。前几期是「补账本、明码标价」，今天更进一步：**账本开始分科目了**——算力账、人才账、安全账，各自有人来收。

**① 效率战进入「按任务定价」阶段（#1 / #2 / #3）**。**Qwen4-Max 用 2.4T 总参只激活 71B、单任务成本降 58%**（#1），**Hy4 flash 干脆把激活压到 12B、成本砍到 Hy4 的 1/20**（#2），**Seedance 2.5 4K 则用 480P 样片 + 4K 正片把「抽卡」做成两级价**（#3）——三条看似不同赛道，底层都是同一句话：**把「一次生成」的昂贵赌注，拆成可按预算调配的多个便宜步骤**。对做批量、多语种、需要品牌一致性的宣发，这比多几个 Elo 分实在得多。

**② 资本在给「模型之外」定价（#4 / #5 / #6）**。**AMD 用 82 亿美元把 World Labs 的空间智能团队整个搬进硬件栈**（#4），赌的是「计算平台 + 模型协同优化」；**Corma 产品三个月就成 10 亿独角兽**（#5）、**Noeri 带 1.1 亿押注「会自我改进的活体 AI」**（#6），赌的是「帮企业把 AI 用好」的中间层。三笔钱方向不同，却都在说同一件事：**模型层打效率战之后，价值在往上游（硬件协同）和下游（落地改进）两头转移**。陈丹琦兼职加入 Noeri、李飞飞出任 AMD 首席科学家，是这轮「抢人」最直观的两个注脚。

**③ 安全从「倡议」变成「账目」（#7 / #8）**。**加州以「公共妨害」起诉 OpenAI、直指 80 次失控与披露义务**（#7）**，是 AI 安全第一次以州级诉讼的形式落到公司头上；**黄仁勋辞任第三幕把 1050 亿担保、出口管制与股价绑在一起**（#8），说明治理风险早已不是公关议题，而是采购与排期的真实变量。有意思的是，#5 的「攻强守弱 85%/12%」恰好给 #7 提供了技术注脚——**当攻击的边际成本远低于防御，「管住它」就会从道德倡议变成法律义务**。

一组对照值得记：**#1 的「缓存命中 0.5 元」、#2 的「单任务 0.26 元」、#3 的「480P 先试错」、#7 的「80 次失控要披露」——今天所有数字都在把「生成」和「使用」的成本拆得更细**。拆细之后，谁能把每一分钱、每一次生成、每一个风险点都算清楚，谁就掌握了下一阶段的定价权。
