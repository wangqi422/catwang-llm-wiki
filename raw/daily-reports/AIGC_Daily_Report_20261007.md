### #1 ⭐ OpenAI 发布 722 篇 AI 数学手稿：372 个结果族，出自一个尚未发布的内部前沿模型

> **来源**：[OpenAI 官方博客](https://openai.com/index/sharing-ai-progress-in-mathematics/) / [The Verge](https://www.theverge.com/ai-artificial-intelligence/1005004/openai-math-release-github) / [Unite.AI](https://www.unite.ai/openai-releases-722-math-manuscripts-from-an-unreleased-ai-model/) | **评分**：9.4/10 | **标签**：AI 科研·Lean 形式化·发布伦理

#### 核心事件
10 月 6 日，OpenAI 在公开 GitHub 仓库 `openai/math` 一次性放出 **722 篇数学手稿**，归并为 **372 个结果族**（family 用于聚合主结果、 companion 论证、推论与替代证明），以 **Apache 2.0** 授权发布，附带 Lean 形式化证明库与 10 份模型推理过程的精简摘要。产出这些结果的是一个**尚未发布、也未公布名称的内部前沿模型**。OpenAI 称其中包含「数百个公开未解问题」的解答。

#### 技术亮点 / 影响分析
- **规模与流程**：评估阶段模型被投放约 **4000 道题**，最终收敛出 722 篇手稿；OpenAI 称「平均每个结果消耗的算力约等于 3 小时 ChatGPT Pro 思考」。README 明确写着：结果处在**不同验证阶段**，部分已有 Lean 形式化，未形式化的「可能存在问题」，会持续修正并保留发布历史
- **两个例外**：黎曼 ζ 函数 Re(s) > 11/12 零自由区域的证明，以及 CM 阿贝尔簇上的 Hodge 猜想证明，走的是非标准流程；其中 ζ 那篇经人工编辑润色
- **推理摘要覆盖的题目**包括：乘性函数的普通二点关联、π 的无理数指数、对称与一般 Mahler 猜想、基本半定阈值处的普通 NP-困难性、算术级数的拟多项式界、特征 2 下 Kaplansky 直接有限性猜想、稀释自旋玻璃的 Mézard–Parisi 公式、量子 Heisenberg 铁磁体的自发磁化、自由群因子的同构、三维相对论 Vlasov–Maxwell 系统
- **数学界并不买账这套流程**：独立咨询机构 AGMAI（普林斯顿高等研究院的数学与 AI 顾问团）9 月 29 日发布的首份建议书写得很直白——「我们不支持这一做法，并要求他们停止在专有模型上测试高难度数学问题」，要求公布模型名、提示词、思维链摘要、耗时与算力成本，并要求实验室**不得把结果发布当成模型的营销工具**
- ⚠️ **未同行评审**：仓库整体未经同行评议，模型本身不开放，外部无法复现

#### 三句话总结
1. OpenAI 把 722 篇由一个未发布前沿模型产出的数学手稿推上 GitHub，含 372 个结果族与部分 Lean 形式化证明，但明确承认相当部分尚未验证
2. 争论从「AI 能不能做数学」转向「AI 做的数学该怎么署名、怎么发布」——AGMAI 直接要求实验室停止用专有模型刷公开难题、停止把成果当营销素材
3. 对 CODM 宣发：**这套「先发布、再逐步补验证、保留修订历史」的做法可以直接借鉴**——AI 生成的宣发素材同样适合先出可溯源的版本库，再逐版补人工核验记录，而不是一次性丢出不可追溯的成品

### #2 ⭐ Mistral 发布 Large 4「Le Chonk」：1 万亿参数 / 490 亿激活，开源权重 10 月 27 日放出

> **来源**：[The Next Web](https://thenextweb.com/news/mistral-releases-large-4-a-1-trillion-parameter-open-weight-ai-model) / [VentureBeat（转引）](https://venturebeat.com/) / [AI News](https://www.artificialintelligence-news.com/news/mistral-ai-launches-large-4-preview-ahead-open-weight-release/) | **评分**：9.0/10 | **标签**：稀疏 MoE·原生多模态·主权 AI

#### 核心事件
10 月 6 日，巴黎的 Mistral AI 发布 **Mistral Large 4** 公开预览版，内部代号 **Le Chonk**：稀疏 MoE，**1 万亿总参数 / 每任务仅激活 490 亿**，原生支持文本与图像。API 当日开放，**权重定于 10 月 27 日放出**。Mistral 的定位说得很克制：不是「最强模型」，而是「**中国以外最强的开源权重模型**」。

#### 技术亮点 / 影响分析
- **训练账本**：约 **4000 张 NVIDIA Grace Blackwell**（官方另一处口径为 3800 张）在欧洲自有数据中心从零训练，历时约两个月，功耗约 10 兆瓦；训练数据覆盖 160 多种语言，含欧盟全部官方语言
- **跑分（Mistral 自报，预览值）**：DeepSWE v1.1 **61.7%**，略高于智谱 GLM-5.3 的 61%、DeepSeek-V4-Pro 的 57%，远高于 Qwen 3.8 Max 的 51% 与 Reflection Beam 的 44%；FinWorkBench 67% 与 DeepSeek-V4-Pro 持平；Harvey 法律智能体基准 15% 领先 Kimi K3（13%）与 GPT-6 Astra（5%）
- **安全是主战场**：Mistral 称其在 Artificial Analysis Cyber Index 进入前五；在「复现真实漏洞并打补丁」测试中得 **82%**（自称全场最高）；Cybench 40 道安全竞赛题解出 **93%**；Lakera B3 基准抗攻击 **93.3%**。同步向网络安全公司、经审查伙伴与国家机构开放**低限制 + 增强网络能力**的版本做红队
- **视觉是差异点**：DIOR-RSVG 遥感视觉定位 **73%**，高于 GPT-6 Astra 的 68%；能把技术图纸转成 CAD 模型，瞄准工业客户（保险定损航拍图、电网巡检、农作物监测）
- **主权是商品**：联合创始人兼首席科学家 Guillaume Lample 的原话是，一旦权重公开，「银行或政府可以下载模型跑在自己的机器上，不需要任何人的许可」，客户要的是两条保证——不会有外国切断访问、训练过程有清晰记录
- ⚠️ **闭源前沿仍有明显差距**：Surge AI 盲评编码输出 Large 4 得 3.74/5，Claude Opus 5 为 4.22；AutomationBench 59.9 分，低于 Claude Opus 5.5 的 69.5 与 Gemini 4 Argon 的 77.5。Mistral 自己也把这些数字摆在对比表里

#### 三句话总结
1. Mistral 用 1 万亿参数 / 490 亿激活的原生多模态 MoE 抢下「中国以外最强开源权重」，权重 10 月 27 日放出，主打网络安全与工业视觉
2. 它明着不跟 Claude / Gemini 争第一，而是把「可自托管、不会被断供」当作产品卖点——主权成了最硬的商品属性
3. 对 CODM 宣发：**1T 级开源权重 + 视觉定位能力**让「本地跑一个能看懂图纸与航拍图的模型」变得现实，做场景还原类物料或线下展陈视觉时，可作为不依赖闭源 API 的备选管线评估

### #3 ⭐ OpenAI Decisions API 进入公开测试：由 GPT-6 Luna 驱动，比 Responses API 快约 10 倍

> **来源**：[OpenAI 开发者社区公告](https://community.openai.com/t/decisions-api-is-now-available-in-public-beta/1403877) / [Unite.AI](https://www.unite.ai/openai-releases-decisions-api-in-public-beta-powered-by-gpt-6-luna/) | **评分**：8.6/10 | **标签**：推理接口·分类路由·成本结构

#### 核心事件
10 月 6 日，OpenAI 宣布 **Decisions API** 进入公开测试（此前在 DevDay 2026 上以有限预览形式亮相）。新端点 `POST /v1/decisions` 由 **GPT-6 Luna** 驱动，接受文本与图像输入，返回**带类型的结构化判断**，OpenAI 称其速度**约为 Responses API 的 10 倍**。

#### 技术亮点 / 影响分析
- **三种问题类型**：`predicate`（判断某条件为真，返回 0–1 概率）、`choice`（从预设选项里选一个，附带各选项概率与独立置信度）、`score`（按有序等级打分，返回概率加权均值，可落在两个等级之间）
- **定价是这次的真正看点**：**只收 input token，没有 output token 费用，也没有缓存读写费**。同一模型走 Responses API 是 input $0.10/M、output $0.50/M——Decisions 直接免掉了输出账单
- **但单位成本并不便宜**：按 100 万次 500 token 分类计算，Decisions API 约 **50 美元**，第三方同类（TypeSafe Jev）约 21 美元。OpenAI 的筹码是能读图、账号现成、支持 ZDR 与 HIPAA
- **图像只能内联**：必须 base64 data URL，托管的图片链接与 file ID 一律拒收，已有管线需要加一道「抓取 + 编码」
- **边界写得很清楚**：需要自定 JSON Schema 的结构化输出仍要走 Responses API 的 Structured Outputs，需要模型带参数调工具要走 function calling——Decisions 只做「判断」，不做「生成」

#### 三句话总结
1. OpenAI 的 Decisions API 公测，用 GPT-6 Luna 把「分类 / 路由 / 打分」这类判断型任务做成原生端点，只收输入 token，速度约快 10 倍
2. 这是把「让模型输出一段话再解析成标签」这种土办法正式产品化，工单路由、内容审核、素材初筛都属于它的射程
3. 对 CODM 宣发：**素材初筛是最直接的场景**——批量给玩家投稿 / UGC 截图打「是否含竞品元素」「是否合规」的概率分，比让模型写一段分析再人肉解析便宜且快得多

### #4 ⭐ DeepSeek 接近完成至少 800 亿元融资，腾讯与宁德时代领投，冲刺 2027 年初 IPO

#### 核心事件
10 月 6 日，彭博社与路透社先后援引知情人士称，**DeepSeek 即将完成 IPO 前最后一轮融资，锁定的金额至少 800 亿元人民币（约 120 亿美元）**，远超最初约 500 亿元的目标；**腾讯与宁德时代是出资额最高的领投方之一**。按已签署的条款清单，最终总额**可能接近 1000 亿元**。这轮融资为 2027 年初的上市铺路。

#### 三句话总结
1. DeepSeek 接近完成至少 800 亿元 Pre-IPO 融资，腾讯与宁德时代领投，可能上探 1000 亿元，瞄准 2027 年初科创板上市

3. 对 CODM 宣发：**国产模型与国产算力的组合正在变成一条独立可用的产线**，做国内版本素材时，基于国产模型的批量出图/出片管线在成本与合规两头都更稳，值得重新评估

### #5 ⭐ 落实特朗普行政令，美国司法部要求员工把 AI 改称「超级智能」（SI）

> **来源**：[路透社（经 The Star / CNA 转述）](https://www.channelnewsasia.com/business/us-justice-dept-tells-staff-call-ai-super-intelligence-under-trump-order-6437591) / [Bloomberg Law](https://news.bloomberglaw.com/us-law-week/doj-staff-told-to-refer-to-ai-as-super-intelligence-in-court) / [IT之家](https://news.qq.com/rain/a/20261007A02M8F00) | **评分**：8.7/10 | **标签**：联邦术语·行政令·公共叙事

#### 核心事件
路透社看到的一份备忘录显示，**美国司法部**于 10 月 6 日（周二）指示员工：在绝大多数场合提及该技术时，应使用「**超级智能**（Super Intelligence）」而非「人工智能」，缩写「**SI**」。备忘录由代理副总检察长 **Trent McCotter** 签发，依据是特朗普 9 月 29 日签署的行政命令——该命令要求联邦各机构在法律允许的最大范围内完成用词替换，特朗普称新叫法能更贴切地反映技术潜力。

#### 技术亮点 / 影响分析
- **适用范围**：对外沟通、政策文件及各类官方记录；对法院提交的诉讼文件则加了限定——「在适宜的情况下」同样适用，而非一刀切
- **官方理由**：行政令原文称联邦政府使用的术语「应当反映美国创新者正在开创的非凡技术所具有的变革性能力」。Bloomberg Law 指出，这是特朗普应对公众对 AI 观感转差努力的一部分
- **背景并不轻松**：备忘录发布前接连发生多起黑客事件，公众对智能技术的观感已经转差；特朗普一直不倾向出台新监管法规，但曾表态若确有必要，司法部会加以约束
- **这是全政府动作**：行政令适用于司法部之外的所有联邦部门，措辞变更不是某个部门的命名决策
- ⚠️ **注意边界**：行政令里的能力描述是政府的主张，不是对技术能力的独立评估；「when appropriate」给了出庭律师裁量空间

#### 三句话总结
1. 美国司法部下发备忘录，要求员工在官方沟通与政策文件中用「超级智能 / SI」取代「AI」，法庭文书「在适宜时」同样适用
2. 这不是命名癖好，而是联邦层面一次有组织的叙事重塑——在公众对 AI 安全性观感下滑的当口，用措辞把技术重新定性
3. 对 CODM 宣发：**术语风向要盯紧**——海外物料若涉及 AI 能力描述，「AI」一词在美方官方语境中正在被替换，对外文案与合规话术建议同步关注，避免口径错位

### #6 ⭐ 韩国宣布 4.7 万亿韩元前沿 AI 项目：明年 3 月启动，1 万张 Vera Rubin GPU 打底

> **来源**：[路透社（经 The Star 转述）](https://www.thestar.com.my/tech/tech-news/2026/10/06/south-korea-plans-to-develop-35-billion-frontier-model-starting-next-year) / [Korea Times](https://www.koreatimes.co.kr/business/tech-science/20261005/korea-to-launch-35-bil-frontier-ai-project-next-year) / [财联社](https://news.qq.com/rain/a/20261006A056AH00) | **评分**：8.3/10 | **标签**：国家预算·GPU 集群·主权模型

#### 核心事件
韩国科学技术信息通信部 10 月 6 日宣布，将从 **2027 年 3 月**起启动一项 **4.7 万亿韩元（约 35 亿美元）**的前沿 AI 模型研发项目，目标是训练出能与全球领先模型竞争的自研前沿模型。国会在 12 月批准 2027 年预算后，将通过公开招标选定牵头开发商，中标者最早 **2027 年 2 月**公布。

#### 技术亮点 / 影响分析
- **不是补贴，是股权**：政府以**股权投资**方式出资，而非单纯拨款，目的是让回报最终能与公众分享；设立特殊目的公司（SPC）是落地选项之一。参与企业需按比例配套私人资金
- **钱怎么分**：约 **3.9 万亿韩元用于采购 1 万张 NVIDIA Vera Rubin GPU**，约 **8000 亿韩元用于采购训练数据**，剩下的投向人才与算力集中
- **为什么换打法**：科技信息通信部第二次官 Ryu Je-myung 说，自 4 月 Claude Mythos 预览版出来后，全球前沿模型竞争已进入完全不同的阶段；原先的「国家基础模型项目」采用淘汰赛制，被淘汰企业背上污名并引发争议，行业反馈是「要在前沿层级竞争，必须集中所有资源」
- **两个项目并行**：原有的国家基础模型项目继续推进，重心转向行业专用与真实场景落地，三支队伍已进入第三阶段，年底前选出两支决赛队伍；两支队伍可选择加入前沿项目
- **明确的对手**：官方表述就是「与中国头部开源模型竞争」。参与主体开放给单一企业、企业联盟与 SPC，希望初创企业、高校与研究人员发挥主导作用
- ⚠️ **尚缺关键细节**：未披露技术目标、模型规模、参与机构，也未说明是否开源

#### 三句话总结
1. 韩国宣布 2027 年 3 月起投入 4.7 万亿韩元自研前沿模型，1 万张 Vera Rubin GPU 打底，以政府股权 + 私人配套的方式招标
2. 从淘汰赛式的「国家基础模型项目」转向集中资源的「前沿项目」，官方明说目标是与中国头部开源模型竞争
3. 对 CODM 宣发：**韩国市场的 AI 物料供应商未来一年可能出现本土替代选项**——涉及韩国本地化宣发时，留意本土模型厂商的素材能力与合规口径，提前摸底渠道

### #7 ⭐ Google 发布 Nano Banana 2.1：1K 图 API 价腰斩至 $0.0336，登 Arena 文生图第 5

> **来源**：[Google 官方 X](https://x.com/Google) / [CellCog](https://cellcog.ai/blog/nano-banana-2-1) / [Fello AI](https://felloai.com/nano-banana-2-1) | **评分**：8.5/10 | **标签**：生图模型·参考图一致性·成本下探

#### 核心事件
10 月 6 日，Google 发布图像生成与编辑模型 **Nano Banana 2.1**，API 模型 ID `gemini-nano-banana-2.1`，已在 Gemini App、Search 的 AI Mode、Google AI Studio、Flow、Stitch 与 Google Ads 推送。官方称在**视觉设计、蒙版编辑、主体一致性**三方面有显著提升。

#### 技术亮点 / 影响分析
- **价格直接砍半**：图像输出从每百万 token 60 美元降到 30 美元。标准档 **1K 图 $0.0336**（原 Nano Banana 2 为 $0.067）、2K 为 $0.0504、4K 为 $0.0756；批量任务再打对折。**1000 张 1K 图从约 67 美元降到约 33.6 美元**
- **参考图能力**：单次最多 **14 张参考图**，可同时锁定 **最多 4 个角色 + 10 个物体**的一致性；新增「中等」思考档并设为默认（2.0 只有 minimal / high，默认 minimal）
- **修掉了极端画幅的老毛病**：1:4 / 4:1 / 1:8 / 8:1 在 2K 与 4K 下的拼接伪影（tiling artifacts）已修复，共支持 14 种画幅，最高 4K——对横幅、全景头图、竖屏壁纸这类物料是直接利好
- **榜单位置**：Arena 文生图第 **5**（1328 分，5312 票）、图像编辑第 **6**（1428 分）、多图编辑第 **4**；文本偏好 ELO 1050 分，高于 Nano Banana 2 的 990 与 Pro 的 935。仍落后 GPT Image 2.5（1425 / 1524）
- **⚠️ 输入涨价了**：input token 从 $0.50/M 涨到 **$1.50/M**，且思考 token 也计费；Nano Banana 2 将于 **10 月 29 日关停**，开发者有 23 天换模型 ID
- **落地提示**：新增 Google 图片搜索 grounding（但不能用网络上真人照片做 grounding）

#### 三句话总结
1. Google 的 Nano Banana 2.1 把 1K 图 API 单价砍到 $0.0336（约原来一半），同时修好极端画幅拼接伪影、支持 14 张参考图锁 4 角色一致性
2. 榜单上仍是 Google 自家最强图像模型（Arena 文生图第 5），但没超过 GPT Image 2.5；真正的信号是成本——批量物料从「可选」变成了「可投产」
3. 对 CODM 宣发：**这是本期最可直接落地的一条**——批量出 KV 变体、角色一致性组图、超宽幅横幅都受益；但注意 10 月 29 日旧模型关停与 input token 涨价，管线要提前切 ID 并重算成本

### #8 ⭐ Claude for Google Workspace 公开 beta：侧边栏直改 Docs / Sheets / Slides

> **来源**：[Anthropic 官方](https://claude.com/resources/articles/claude-now-works-in-google-docs-sheets-and-slides) / [9to5Google](https://9to5google.com/2026/10/06/claude-google-docs-sheet-slides) / [Reworked](https://www.reworked.co/digital-workplace/anthropic-opens-claude-for-google-workspace-in-beta) | **评分**：8.2/10 | **标签**：办公协作·连接器·企业管控

#### 核心事件
10 月 6 日，Anthropic 宣布 **Claude for Google Workspace** 进入公开 beta，覆盖全部付费 Claude 方案。通过 Google Workspace 应用市场的插件，Claude 以**侧边栏**形式出现在 Docs / Sheets / Slides 里，可直接读取、理解并修改当前打开的文件；同时发布 Docs / Sheets / Slides **连接器**（beta），可从 Claude 会话里直接创建与编辑 Google 文件。

#### 技术亮点 / 影响分析
- **Docs**：就地改句子、重设标题样式且不破坏周围格式；大段改写以「建议卡片」形式出现在侧边栏，可逐条应用或驳回
- **Sheets**：写公式、建数据透视表与原生图表、新增标签页；需要关联或清洗时可把数据拉进 Python 处理再写回表格
- **Slides**：按当前 deck 的版式与主题生成新页，并**自检**——标记元素重叠、超出画布、文字难读等问题
- **两种编辑模式**：默认「Ask before edits」（每次改动弹审批卡并附摘要）；可切换「Accept all edits」让 Claude 一口气跑完
- **企业管控同步覆盖**：Compliance API、客户自管加密密钥（CMEK）、OpenTelemetry 审计导出在插件上同样生效；权限跟随用户既有的 Google 共享设置。企业版的连接器、技能与管理员策略都会带进侧边栏
- ⚠️ **审批开关在用户手上**：管理员只能决定是否允许安装插件（Marketplace 权限闸门），但「是否跳过审批」由每个打开侧边栏的人自己选——共享文件上这一点需要组织内部自己立规矩

#### 三句话总结
1. Anthropic 把 Claude 做成 Google Workspace 侧边栏插件（公开 beta），可就地改文档、写表格公式、按 deck 版式生成幻灯片并自检排版
2. 分发意义大于编辑意义——Google 三个应用里本来就有 Gemini，Claude 这一手是让已经习惯 Claude 的团队不必搬走文件格式
3. 对 CODM 宣发：**Slides 的排版自检可以直接用在提案稿上**（标记重叠、出界、可读性），但共享文件建议统一锁在「改前确认」模式，别让某个人切到自动模式把对外 deck 改了

## 编辑点评

**今日主线**：都在抢位置——中国砸钱，欧洲砸权重，韩国砸预算，美国先改了个名字。

八条新闻背后其实是同一件事：每个玩家都在技术还在跑的时候，先把自己的位置占住。占位的方式各不相同——DeepSeek 拿 800 亿元把国产算力堆到 1GW；Mistral 拿 1 万亿参数的开源权重把「可自托管」做成卖点，不跟闭源争第一；韩国把淘汰赛换成集中投入，明着说要跟中国开源模型竞争；美国司法部则连一个词都不放过，把「AI」改成「超级智能」。**技术能力今天没有出现新魔法，但围着它的钱、权重、预算和措辞，全部被重新摆了一遍。**

而在这场抢位战里，最耐人寻味的是数学界的反应。OpenAI 交出了 722 篇手稿，AGMAI 的回应不是祝贺，是「请停止在专有模型上测试高难度数学问题」，以及「不要把成果发布当成营销工具」。**当产出方和守门方对「什么算成果」还没达成一致时，能力越强，摩擦越大。**

### 对 CODM 宣发团队的可执行线索

1. **Nano Banana 2.1 是本期唯一能立刻省钱的一条**：1K 图 $0.0336、批量再半价、极端画幅伪影修好、14 张参考图锁 4 角色一致性——批量 KV 变体与超宽幅横幅可直接投产。**同时务必在 10 月 29 日前切掉旧模型 ID，注意 input token 涨了 3 倍**
2. **Decisions API 适合做素材初筛**：批量给 UGC / 玩家投稿打「是否含竞品元素」「是否合规」的概率分，只收 input token、快约 10 倍，比「让模型写一段分析再解析」划算得多
3. **AI 生成物料要学 OpenAI 的版本库做法**：先发布可溯源版本、保留修订历史、逐步补验证——宣发素材同样建议建版本库 + 人工核验记录，而不是丢出不可追溯的成品
4. **共享文档上的 AI 编辑要立规矩**：Claude Workspace 插件的「跳过审批」开关在个人手上，管理员管不到。对外 deck 与提案稿建议统一锁「改前确认」模式
5. **海外物料的 AI 措辞要盯风向**：美联邦语境正在把「AI」替换为「超级智能 / SI」，涉及海外 AI 能力描述的文案与合规话术建议同步跟进口径
6. **国产产线值得重估**：DeepSeek 800 亿元砸向 16 万枚华为加速器 + 昇腾组件开源，国产模型与国产算力的组合正在变成一条独立可用的产线，国内版本素材可优先评估
