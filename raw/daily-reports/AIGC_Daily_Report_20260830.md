## §1 AI 模型 & Agent

### #1 ⭐ 腾讯开源 Tencent Hy4 Preview：770B 参数 MoE、1M 上下文、Apache 2.0

> **来源**：腾讯混元官方 / Simon Willison 博客 / Hacker News | **评分**：8.5/10 | **标签**：`模型` `开源` `MoE`

#### 核心事件

腾讯正式发布并开源下一代大语言模型 **Tencent Hy4 Preview**——总参数 **770B**、每 token 激活参数 **49B** 的旗舰 MoE 模型，上下文窗口达 **1M token**（此前 7 月的 Hy3 为 295B 总参 / 21B 激活 / 256k 上下文），Hugging Face 上权重体积达 1.56TB。模型采用 **Apache 2.0 协议**完全开源，原生集成 MTP 层支持投机解码，推理配置提供 "high"（默认）与 "no_think" 两档。在 163 位内部专家参与的 203 项真实工程任务盲测中，Hy4 Preview 平均分 **2.99**，优于 GLM 5.3（2.92）与 Kimi K3（2.94），定位编程、办公与科研等真实生产力任务，并已在 vLLM 中运行。

#### 技术亮点 / 影响分析

- **国产 MoE 旗舰的「上下文 + 激活参数」双跳升**：从 Hy3 到 Hy4，上下文 256k→1M 翻了 4 倍、激活参数 21B→49B 翻倍有余，且总参不变体量下「激活/总参」比更激进（49B/770B），走的是「更大稀疏度 + 更长上下文」的 MoE 路线
- **Apache 2.0 + vLLM 原生支持是真正的护城河**：权重、协议、推理栈三件套全开，社区可自由商用与二次微调，直接对标 GLM/Kimi 在开源中文模型上的争夺，对自建产线团队是「可私有化部署的旗舰级底座」新增选项
- **「high / no_think」双档推理 + MTP 投机解码**：把思考档位与投机解码做进首版，说明腾讯在「推理成本控制」上下了重注，1M 上下文 + 投机解码对长文档/代码库级任务尤其友好

#### 三句话总结

1. 腾讯开源 Tencent Hy4 Preview，770B 总参 / 49B 激活 MoE、1M 上下文、Apache 2.0 协议，盲测平均分 2.99 压过 GLM 5.3 与 Kimi K3，定位生产力任务
2. 相比 7 月 Hy3，上下文翻 4 倍、激活参数翻倍，且已原生支持 vLLM 与投机解码，是国产开源旗舰底座的一次实质性跃迁
3. 对 CODM 宣发团队：这是「可私有化部署的开源旗舰」新增选项——1M 上下文 + Apache 2.0 商用友好，适合评估用作宣发文案/策划案的本地长文档理解与批量生成底座，规避闭源 API 的数据外发与成本波动风险

### #2 ⭐ Google Gemini Omni 1.1 Flash：40 秒场景扩展 + 首尾帧控制 + 4K 放大

> **来源**：MarkTechPost / Gemini API | **评分**：8.2/10 | **标签**：`视频生成` `Google`

#### 核心事件

Google 发布 **Gemini Omni 1.1 Flash** 生产更新，视频生成能力进一步强化：场景扩展可读取最多 **10 秒先前上下文**并累计扩展至 **40 秒**，支持**首尾帧控制运镜**（首帧定起、尾帧定落，中间自动补全）；360p 草稿生成速度最高提升 **60%**、成本仅为 720p 的**三分之一**，成片可放大至 **4K**。模型通过 Gemini API 提供，Adobe、Figma Weave、GMI Cloud 与 Runway 已投入生产使用。

#### 技术亮点 / 影响分析

- **「首尾帧控制」是导演式创作的关键拼图**：从「文生视频」进化到「定头定尾、AI 补中间」，让镜头起落、转场节奏可控，是影视/宣发工作流从「抽卡」走向「可控」的重要一步
- **「低成本草稿 → 4K 成片」的阶梯生产范式**：360p 草稿快又便宜、成片再放大 4K，把「先粗剪看方向、再高清出片」的工业化流程做进了 API，直接降低试错成本
- **头部工具链已抢先接入**：Adobe、Figma Weave、Runway 等已投入生产，说明「40 秒场景扩展 + 首尾帧」这套能力已成为视频生成新基建的共识接口

#### 三句话总结

1. Google 发布 Gemini Omni 1.1 Flash，场景扩展累计至 40 秒、支持首尾帧控制运镜，360p 草稿提速 60%、成本仅 720p 的三分之一，成片可放大 4K
2. 「首尾帧控制 + 低成本草稿 → 4K 成片」标志着视频生成从「抽卡式」走向「导演式可控 + 工业化阶梯生产」，Adobe/Figma/Runway 已接入
3. 对 CODM 宣发团队：首尾帧控制是「转场/运镜可控」的关键——可评估用 Gemini Omni 1.1 Flash 做英雄技能小动效、活动预热短片的「低成本草稿试错」，把迭代节奏从分钟级压到秒级

2. 当前 50% 临时增幅将持续至 9/13，之后回落到永久 25%，相对当下实际额度减少约 17%，重度用户需提前规划

1. 索尼音乐+华纳查普尔起诉 Anthropic，指控其非法盗用版权作品训练 Claude，每件索赔最高 15 万美元、总额可达数十亿美元
