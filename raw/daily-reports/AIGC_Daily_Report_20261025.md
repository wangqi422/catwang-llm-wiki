## §1 模型 & Agent

### #1 ⭐ Anthropic 开源 sandbox-runtime（srt）：OS 级无容器沙箱，Claude Code 同款隔离层，装个前缀就生效

> **来源**：[Anthropic sandbox-runtime GitHub](https://github.com/anthropic-experimental/sandbox-runtime) / [npm @anthropic-ai/sandbox-runtime](https://www.npmjs.com/package/@anthropic-ai/sandbox-runtime) / [MarkTechPost](https://www.marktechpost.com) / [AI Weekly](https://aiweekly.co) | **评分**：9.3/10 | **标签**：智能体安全·OS 级沙箱·零容器·MCP 隔离·最小权限

#### 核心事件
Anthropic 把支撑 Claude Code「沙箱化 bash 工具」的那层隔离运行时单独开源出来，以 **@anthropic-ai/sandbox-runtime**（命令行名 `srt`）发布在 npm 上，当前版本 **v0.0.81**，包体约 **11.4 MB**，许可为 **Apache-2.0**，要求 Node.js ≥ 22.12。用法极简：全局安装后，把 `srt` 作为前缀加在任何命令前面，该进程及其**整棵进程树**（含脚本与子进程）即被限制在文件系统与网络的双重边界内。

关键设计是**不用容器**：macOS 上走 `sandbox-exec` + 动态生成的 **Seatbelt** 配置（只需额外依赖 ripgrep）；Linux 上走 **bubblewrap** 并剥离网络命名空间（额外依赖 socat、ripgrep）；Windows 版本目前是 **alpha**，由专门的 `srt-sandbox` 本地账户 + Windows Filtering Platform 出向围栏 + 显式 NTFS ACL 组成，并附带 `srt-win.exe`。

默认策略遵循最小权限：**读默认全放行（除非显式 deny）、写默认全拒绝（除非显式 allow）、网络默认全拒绝（除非域名进白名单）**。出网流量只能经由宿主机上的 HTTP / SOCKS5 代理，由代理执行 allowlist / denylist。README 列出的能力还包括域名通配、Unix socket 白名单、实验性 TLS 终止（可中间人检查 HTTPS）、环境变量与文件里的凭据掩码、以及 AWS SigV4 请求签名（密钥被掩码）。

对 MCP 用户最实用的一点：在 `.mcp.json` 里把某个 MCP 服务器的 `command` 从 `npx` 换成 `srt`、原命令作为参数传入，即可让该服务器在沙箱里运行，规则写在 `~/.srt-settings.json`。Anthropic 给出的自报数据是：内部启用该沙箱后，**Claude Code 的权限弹窗减少了 84%**。仓库同时标注这是「为 Claude Code 开发的研究预览，API 与配置格式可能变化」，并明确列出了 Windows 后端的已知缺口（基于 Schannel 的工具如 System32\curl.exe、Invoke-WebRequest、.NET HttpClient、winget 无法使用；经 Windows Update 等系统服务的流量会绕过 WFP 围栏）。

#### 技术亮点 / 影响分析
- **「隔离是基础设施，不是某个产品的功能」，这句话被做成了一个 npm 包**：Anthropic 先给自己造沙箱，再把它开源出来给所有人的智能体用。这个动作的信号价值高于工具本身——**它把「让 LLM 在你机器上跑 shell」这件事的默认姿势改成了「先关进笼子再跑」**
- **不选容器是一次明确的取舍**：Docker 太重，重到很多团队会直接跳过隔离。OS 原生原语（Seatbelt / bubblewrap）的启动成本极低，代价是**平台能力不对等**——Linux 与 macOS 是可用状态，Windows 标注 alpha 且自带已知绕过路径。**团队跨平台部署时必须先确认自己的操作系统落在哪一档**
- **「文件 + 网络」双边界缺一不可的逻辑讲得很清楚**：只有网络隔离，被提示词注入的智能体可以把 SSH 密钥外传；只有文件隔离，它可以先逃逸再自己开网。**任何只做一半的自建沙箱都等于没做**
- **MCP 生态会直接受益**：把 MCP 服务器丢进 srt 是目前成本最低的「第三方 MCP 服务器风险控制」方案——不需要审代码，只需要给它一份白名单。**在 MCP 服务器数量激增的当下，这几乎是一个必选项**
- **边界要说清楚**：84% 是 Anthropic 自报数据，不是第三方基准；v0.0.81 属早期研究预览；**Windows 后端明确列出了会绕过围栏的系统服务流量**，在这台机器上不要把它当作唯一防线

#### 三句话总结
1. Anthropic 将 Claude Code 底层的 OS 级隔离层开源为 npm 包 `@anthropic-ai/sandbox-runtime`（v0.0.81 / Apache-2.0），用 `srt` 前缀包裹任意命令即可施加文件与网络双重限制，无需 Docker 或容器，macOS 用 Seatbelt、Linux 用 bubblewrap、Windows 为 alpha
1. 关键设计是「读默认放行、写默认拒绝、网络默认全封且需域名白名单」，限制覆盖整棵进程树，且可直接把 `.mcp.json` 里 MCP 服务器的启动命令换成 `srt` 做免审代码的隔离；内部自报把 Claude Code 的权限弹窗减少了 84%
1. 对 CODM 宣发团队：**立刻给本地跑的宣发智能体脚本（批量生图、素材整理、自动剪辑、本地 MCP 服务器）套上 srt**——网络默认全封 + 只放行必要的模型 API 域名，把含未发布版本的素材目录写进 `denyRead`。**这比在提示词里写「不要外传素材」可靠一个数量级，前者是请求，后者是拿走能力**

### #2 Block 发布 Dessa：全球首个纯语音训练的全双工语音模型，单台 GB200 训出、MacBook 本地跑

> **来源**：[Block 官方 / Dessa 项目站](https://dessa.com) / [Jack Dorsey X](https://x.com/jack) / [TechCrunch](https://techcrunch.com) / [India Today](https://www.indiatoday.in) | **评分**：9.1/10 | **标签**：语音原生·全双工·纯语音训练·端侧推理·研究预览

#### 核心事件
Jack Dorsey 旗下的 Block 发布了语音模型 **Dessa**，官方定位是「迄今最真实的**全双工（full-duplex）语音模型**」。全双工意味着它可以**边听边说**——音频进、音频出，中间**没有转写层**，与 OpenAI 今年早些时候的 GPT-Live 属同一路线。

训练方式是最激进的部分：Block 称 Dessa **完全用人类语音从零训练，不使用任何文本，也不基于任何预训练模型**。模型通过「听」学会语言、口音、停顿、呼吸节奏、幽默与反讽，以及**什么时候该闭嘴**。算力上只用了一台 **NVIDIA GB200 NVL72**。官方博客给出的理由很直接：现有语音 AI「把你的声音转成文字，扔掉了大量文字承载不了的信息——世界上最强的 AI 也听不出你的感受，这很荒谬，会导致更差的体验，而且有潜在危险」。

演示层面，Block 放出了多段对话样本：说到自己上班累了的时候语气真的变疲惫；句中遇到好笑的地方会自然笑出来；用户说到一半卡住时它会像真人一样倒吸气、自然接话。团队还放出了一段 Dessa 与 ChatGPT Live 对话的演示。部署上，官方称推理**快于实时**，可在 **MacBook Pro M4 Max 及以上**的机器上本地运行，无需联网。

但目前状态是**研究预览**：**无参数量、无 API、无定价、无权重、无公开评测**，仅开放候补名单，并且只邀请一小批 **AI 安全研究者**先行测试。团队来自 2020 年被 Square（现 Block）收购的多伦多深度学习公司 Dessa，负责人为 Ragavan Thurairatnam。

#### 技术亮点 / 影响分析
- **「绕开文本」是一次路线级赌注**：所有主流语音助手都是 ASR → LLM → TTS 三段式，情绪靠 tag 驱动（ElevenLabs v4、Fish Audio Drama 3 均如此）。Dessa 主张情绪是模型内生出来的，**如果成立，这意味着一大类「情绪标签工程」会变得多余**
- **端侧可跑是商业上的关键**：语音是客服、点单、车载、陪玩这类场景的入口，而这些场景对延迟和云端成本极度敏感。**能在消费级笔记本上跑且快于实时，才让「每个门店一台本地语音代理」这类形态成立**
- **只邀请安全研究者测试，是这次发布里最诚实的部分**：一个「听起来像真人、能接话、能表达情绪」的模型，最先被滥用的方向就是电话诈骗与冒充。**先给安全研究者、再开发布，比反过来负责任得多**
- **证据强度要打折**：目前全部能力展示都是**公司自选自剪的 demo**，不是独立评测；参数量、数据集、基准全部未公开。**「语音的 GPT-3 时刻」是团队自己的说法，不是第三方结论**
- **知识来源存疑**：Block 称 Dessa 的知识来自「对话数据本身」，没有外接 LLM 做检索。**这意味着它在事实性问题上的可靠性未知，短期内不适合任何需要准确信息的场景**

#### 三句话总结
1. Block 发布全双工语音模型 Dessa，完全用人类语音训练、不经过任何文本与预训练模型，音频直进直出无转写层，由一台 NVIDIA GB200 NVL72 训成，可在 MacBook Pro M4 Max 及以上本地运行且快于实时
1. 目前处于研究预览：无参数量 / API / 定价 / 权重 / 公开评测，仅开放候补名单并先邀请 AI 安全研究者测试；所有能力展示均为官方自选自剪的 demo，非独立验证
1. 对 CODM 宣发团队：**短期不可用，但值得挂上观察列表**——如果「情绪内生」的路线成立，未来游戏角色语音、NPC 应答、语音客服都会从「配标签」转向「语音原生」。**当前可做的准备是把需要情绪表达的角色台词整理成带情境说明的短文本集，等这类模型开放 API 时能直接拿去做对比测试**

### #3 NVIDIA 发布 Nemotron 3.5 Bolt E4B 4GB：约 4GB 显存跑多轮工具调用，直指语音助手与游戏 NPC

> **来源**：[NVIDIA Research 官方技术报告](https://research.nvidia.com/labs/nemotron/NVIDIA-Nemotron-3.5-Bolt-E4B-4GB) / [Hugging Face 模型卡](https://huggingface.co) / [MarkTechPost](https://www.marktechpost.com) | **评分**：8.9/10 | **标签**：小语言模型·端侧智能体·游戏 NPC·开放权重·多轮工具调用

#### 核心事件
NVIDIA 于 **10 月 23 日**发布开放小语言模型 **Nemotron 3.5 Bolt E4B 4GB**，基于 Google 的 **Gemma 4 E4B** 做 Nemotron 后训练而成，总参数 **8B、有效参数 4B**，以 **Q4_K_M** 量化发布（GGUF 文件 6.18 GB），上下文 **64K**，支持 **35 种语言**（基座预训练覆盖 140+ 语言），许可为 **OpenMDW 1.1**，官方称可商用。

训练方式上有个反常识细节：NVIDIA 称**只用强化学习、不做监督微调**，理由是 SFT 会损害对话的自然度，工具链为 NeMo-RL + NeMo-Gym。面向智能体的功能包括：跨多轮的**工具调用**（含异步调用集成指引）、可切换的**对话模式**（生成简短、适合朗读的回复）、**可配置的推理强度**（可为满足延迟目标设置思考上限）。

部署目标是本地与边缘：GeForce RTX、Jetson、RTX Spark、DGX Spark。NVIDIA 实测（llama.cpp，batch=1，3K 输入 / 50 输出）：显存占用 **3.1–5.0 GB**；RTX 5070 12GB 上 **133.4 tokens/秒、首 token 548 毫秒**；Jetson Orin Nano 8GB 上降到 **15.5 tokens/秒、首 token 近 6 秒**。同场还发布了一个 **DFlash** 投机解码 drafter，称吞吐最高提升 **21%**。

性能方面，NVIDIA 称在关键对话智能体基准上比自家上代小模型平均高约 **40%**、比参评同侪高约 **10%**，开启推理时输出 token 最多少 **80%**；在 21 项基准中领先 15 项，IHEval 得 **84.8**（Gemma 4 E4B 67.0、Qwen3.5-4B 60.6）。**但官方表格也承认短板**：在考验客服任务完成度的 Tau2-Bench 上，Qwen3.5-4B 得 75.1，Bolt E4B 只有 55.1。所有数字均来自 NVIDIA 自测，其中 Brevity Bench 与 When2Call-MT 是 NVIDIA 自有且尚未公开的基准。

最值得注意的是场景定位：官方明确列出**设备与语音助手、虚拟与交互角色（游戏内 NPC、同伴角色）、嵌入式与工业智能体**三类，演示包含一个跑在 Jetson Orin Nano 8GB 上的 Reachy Mini 机器人，以及**一个游戏里的铁匠商人 NPC**——该 NPC 会先确认收款，再自主调用工具查配方、收集材料、打造物品并交付给玩家。分发渠道包括 Hugging Face、Ollama、LM Studio、Unsloth、Canonical、Jetson AI Lab、NIM，以及**面向游戏开发者的 In-Game Inferencing SDK**。

#### 技术亮点 / 影响分析
- **「会调工具」被压到 4GB，这条比分数重要**：过去端侧模型只能做「问答」，这次能跨多轮调应用 API、能开关推理强度、能切对话模式。**端侧智能体的能力门槛从「能说话」抬到了「能办事」**
- **游戏 NPC 被官方点名，且有配套 SDK**：NVIDIA 不是顺口提一句，而是给了 In-Game Inferencing SDK 和一个完整的商人 NPC 演示（收款 → 查配方 → 收材料 → 打造 → 交付）。**这是主流大厂第一次把「端侧小模型跑 NPC」做成开箱即用的路径**
- **短板同样写在官方表里**：Tau2-Bench 55.1 vs Qwen3.5-4B 75.1，说明它在**多步骤任务完成度**上明显落后。**它适合「维持人设、自然对话」，不适合「把一件复杂事办完」**——选型时要按这两类需求分开评估
- **边缘部署的延迟落差必须提前算**：同一模型在 RTX 5070 上是 548ms 首 token，在 Jetson Orin Nano 上接近 6 秒。**「4GB 能装下」不等于「在你的目标硬件上能用」**，原型阶段就要在真实设备上压测
- **所有基准均为厂商自测**，且有 2 个基准未公开。**引入生产前必须用自己的任务集复测**，尤其是人设一致性与品牌口吻约束这类 NVIDIA 不会替你测的维度

#### 三句话总结
1. NVIDIA 发布开放小模型 Nemotron 3.5 Bolt E4B 4GB（8B 总参 / 4B 有效、Q4_K_M、64K 上下文、OpenMDW 1.1 可商用），只用强化学习训练，支持跨多轮工具调用、可切换对话模式与可配置推理强度，显存占用 3.1–5.0GB

### #4 宾夕法尼亚州签署《人工智能欺骗性广告法》：AI 广告须加标识，罚款上限 3000 美元，12 月 21 日生效

> **来源**：[The Verge](https://www.theverge.com/ai-artificial-intelligence/1018187/pennsylvania-ai-deceptive-advertising-act) / [Loeb & Loeb 律所解读](https://www.loeb.com) / [宾州议会 SB 806 法案记录](https://www.legis.state.pa.us) / [IT之家](https://www.ithome.com) | **评分**：9.0/10 | **标签**：AI 广告披露·合成内容·合规标识·州级立法·虚假认知

#### 核心事件
宾夕法尼亚州州长 Josh Shapiro 于 **10 月 22 日**签署 **SB 806《人工智能欺骗性广告法》（Artificial Intelligence Deceptive Advertising Act）**，列为 **2026 年第 99 号法案（Act 99）**，**签署后 60 天生效，即 2026 年 12 月 21 日**。

法案约束的对象是「**合成内容**」——定义为「被人工智能显著修改或生成的信息，包括图像、视频、音频片段或文本」。触发披露的条件不是「用了 AI」，而是**使用方式让消费者对商品或服务的性质、来源或真实性产生错误认知**。满足该条件时，广告必须带「清晰且显著」的披露，说明「本广告包含经人工智能修改或生成的内容」。

标识需要同时满足三个位置要求：**在合成内容首次出现时就出现、与内容处于同一媒介、在技术上可行的前提下做到永久或极难移除**。视觉标识按尺寸、颜色、对比度、位置和停留时长判定；音频标识按音量与语速判定；且必须使用广告所面向的语言。

**豁免三类**：明显虚构的内容、戏仿/讽刺/评论/批评、以及纯文本内容。**不设「明知」要件**——参议院审议时删除了限定「明知、轻率或故意」的措辞。执行主体是州总检察长或相应地区检察官，可申请临时或永久禁令并提起民事诉讼，法院可处**最高 3000 美元**民事罚款并判付律师费与诉讼费；律所 King Spry 指出该法**不创设私人诉权**，但消费者依既有消费者保护法享有的权利不受影响，且披露本身不构成对其他法律责任的抗辩。

立法过程为跨党派：由民主党州参议员 Nick Pisciottano 提出，共和党参议员 Tracy Pennycuick、Elder Vogel 等联署；参议院 6 月 10 日 **48–2** 通过，众议院 10 月 7 日 **163–40** 通过。审议中曾有参议员质疑该法案「没说清『虚假』是相对什么而言」，但两院均未修改措辞。

#### 技术亮点 / 影响分析
- **这是美国州级 AI 立法从「管表演者」跨到「管全部合成内容」的一步**：此前纽约与加州的类似法律聚焦「合成表演者（synthetic performers）」，宾州这部把范围扩到了**图像、视频、音频与文本全媒介**。对任何做素材生成的团队，这意味着**判断对象从「有没有用 AI 人」变成「有没有用 AI」**
- **触发点是「欺骗」而不是「使用」，这是双刃剑**：好处是普通的 AI 生成背景不一定要标；坏处是**「什么算让产品看起来比实际更好」由检察官和法院判断**，法案本身没定义「虚假」的参照物。**在出现首个判例之前，合规边界是模糊的**
- **「首次出现即标注 + 同媒介 + 极难移除」三条对投放形式有实质影响**：信息流短视频要在**画面内**标注而非只在文案区；音频广告要在**音频里**念出来；任何「贴片几秒就消失」的做法都不满足要求
- **域外效力值得注意**：The Verge 明确指出，**即使广告是在别的州制作的，只要预期在宾州投放就要标注**。这意味着合规不是按制作地判断，而是**按投放地判断**
- **边界要说清楚**：这是州法，不是联邦法，仅约束宾州投放；豁免条款中的「明显虚构」尚未有解释；**罚款上限 3000 美元不算高，真正的风险在于禁令与诉讼成本，以及它与 FTC 法第五条和既有虚假广告责任的叠加**

#### 三句话总结
1. 宾夕法尼亚州 10 月 22 日签署 SB 806（Act 99），要求当 AI「显著修改或生成」的合成内容使消费者对商品性质、来源或真实性产生错误认知时，广告必须在合成内容首次出现处、以同一媒介、以极难移除的方式标注「含 AI 生成或修改内容」，12 月 21 日生效
1. 触发点是「造成错误认知」而非「使用 AI」；明显虚构、戏仿讽刺评论、纯文本三类豁免；删除了「明知」要件；由总检察长或地区检察官执行，民事罚款上限 3000 美元，不创设私人诉权，且**按投放地而非制作地判断适用范围**
1. 对 CODM 宣发团队：**本周内建立 AI 素材台账**——逐条记录哪张主视觉、哪段视频、哪句配音经过 AI 显著修改或生成，并准备「本广告包含经人工智能修改或生成的内容」的中英文标识模板（画面内标注 + 音频口播两个版本）。**判定原则是：凡 AI 让画面/音效比实拍更好看的，一律默认按需披露处理；戏仿与明显虚构的豁免不要套用在商业主视觉上**

### #5 瑞典政府办公厅 10 月 26 日起封禁办公电脑上的 ChatGPT 与 Claude，改用已签合同的 Copilot

> **来源**：[Sveriges Radio Ekot](https://sverigesradio.se) / [SVT](https://www.svt.se) / [Decrypt](https://decrypt.co) / [IT之家](https://www.ithome.com) | **评分**：8.7/10 | **标签**：政府采购·数据合规·影子 AI·模型无关治理·企业协议

#### 核心事件
据瑞典国家公共广播公司 Sveriges Radio（Ekot）**10 月 23 日**报道，瑞典**政府办公厅（Regeringskansliet，即首相府与各部的中央行政机构）**将从 **10 月 26 日（下周一）**起，禁止工作人员通过办公电脑直接访问 **ChatGPT 与 Claude 的网页版**，引导员工改用已获批准的 **Microsoft Copilot** 等服务。

关键细节是**这不是封模型，是封接入方式**：办公厅对 SVT 表示，ChatGPT 与 Claude 的网页界面将不可访问，**部分其他 AI 服务也会被关闭**，但员工仍可通过办公厅**自主开发的 AI 助手平台 Intric** 调用 ChatGPT 与 Claude 的模型。此外，微软 365 Copilot 本身也能调用 Anthropic 的 Claude 模型（Researcher、Copilot Studio 等功能），只是这些模型**被排除在微软的欧盟数据边界（EU Data Boundary）之外**，在欧盟/EFTA/英国地区默认关闭，需管理员主动开启——办公厅未说明是否开启。

这不是孤例：瑞典**税务局（Skatteverket）**与**国家机构管理局（SiS）**已采取类似封锁，**强制执行局（Kronofogden）**仍在研究中。瑞典交通管理局今年早些时候的内部审计发现，员工普遍使用**约 10 种 AI 服务**且存在风险，问题既涉及输入信息的敏感程度，也涉及对 AI 生成回答的处理方式。中国 DeepSeek 此前已在官方设备上受限。

#### 技术亮点 / 影响分析
- **「合同比模型重要」被讲成了最清楚的一次**：同一个 Claude，在浏览器里被禁、在 Intric 里放行、在 Copilot 里默认关闭。**判定标准不是「哪个模型更安全」，而是「这条通道有没有合同、配置和日志」**
- **两条风险被分开处理，这个分类值得抄**：一是**数据外泄**（输入内容按服务商标准条款处理，而非机构谈定的条款），二是**输出可靠性**（公务员可能把生成文本当作权威结论而不加核验）。前者靠合同解决，**后者只能靠培训、内部规则和问责**——这一点很多企业推进 AI 时都会漏掉
- **微软胜出不是因为它是欧洲公司**：微软同样受美国法律框架约束。Copilot 通过的原因是办公厅**已有企业协议、已在既有环境内完成审查、且能控制配置**。**采购状态决定准入，不是国籍决定准入**
- **影子 AI 是这次治理的真实对象**：交通管理局审计发现约 10 种 AI 服务在「广泛且有风险」地被使用——**生成式 AI 在绝大多数组织里是先由员工带进来、再由 IT 和法务补规则的**。瑞典各机构是在事后补这个缺口，多数企业也一样
- **边界要说清楚**：措施由政府办公厅这一中央行政机构实施，**不等同于瑞典全国禁令**；执行范围、受影响的员工数量、Intric 上的具体限制均未公开；且 Copilot 内是否启用了 Claude 模型办公厅未作说明

#### 三句话总结
1. 瑞典政府办公厅宣布 10 月 26 日起封禁办公电脑上的 ChatGPT 与 Claude 网页版，员工改走已签合同的 Microsoft Copilot，理由是使用未签协议的 AI 服务会影响信息安全；税务局与国家机构管理局已采取同类措施，强制执行局在研究中
1. 关键是被封的是**接入方式而非模型**：员工仍可通过政府自建平台 Intric 调用同样的模型；Copilot 通过的原因是已有企业协议、已审查、可配置，而非供应商国籍；交通管理局审计发现员工普遍在用约 10 种未受管 AI 服务
1. 对 CODM 宣发团队：**把「签约通道优先」写成内部硬规则**——未发布版本、未公开角色与剧情、合作方素材，一律只走已签约的企业级 AI 通道，禁止粘贴进任何个人账号的网页版对话。**同时别忽略第二条风险：给团队做一次「AI 输出必须核验」的培训，合同能管住数据外泄，管不住有人把生成内容当结论直接用**

### #6 信通院词元服务监测报告：6 月国内日均消耗约 500 万亿词元，归一化均价翻倍至 13.46 元

> **来源**：[中国信通院《大模型词元服务性能监测报告（2026 年）》](http://www.caict.ac.cn) / [澎湃新闻](https://www.thepaper.cn) / [财联社](https://www.cls.cn) / [IT之家](https://www.ithome.com) | **评分**：8.5/10 | **标签**：词元经济·MaaS·量价齐升·性能监测·上下文长度

#### 核心事件
**10 月 23 日**，中国信息通信研究院人工智能研究所、人工智能大模型及软硬件评测工业和信息化部重点实验室与中国人工智能产业发展联盟联合发布《大模型词元服务性能监测报告（2026 年）》。报告基于 **2026 年 1 至 8 月**的监测数据，围绕调用成功率、吞吐速度、首词时延、稳定性、价格、上下文窗口等维度，对国内外大模型词元服务展开分析。

核心数据是**量价齐升**：**2026 年 6 月国内词元日均消耗量约 500 万亿**，是 2025 年 12 月的**近 4 倍**；同期国内词元价格较 2025 年下半年**翻倍**，但**量的增长达到 3 倍**。归一化均价（把各家不同计价方式折算到统一口径）从 2025 年下半年的 **6.8 元**涨到 2026 年的 **13.46 元**，涨幅接近一倍；不过国外价格仍显著更高，2026 年以来发布的典型模型平均归一价格约 **117.8 元**。

性能侧：8 月国内各模型平均每秒输出词元数（TPS）达 **78.23 个**，较 2025 年均值 38.25 个翻倍；同期国外典型模型 TPS 均值 **112.82 个**，仍整体优于国内。时延侧：国内平均首词时延（TTFT）持续上升，8 月均值 **1.26 秒**，高于 2025 年平均的 0.78 秒；国外典型模型 8 月均值 **2.08 秒**（4 月为 1.04 秒）同样上升。报告解释，TTFT 上升**并非单纯的性能退化**，而是模型参数量、上下文长度、调用量同步增加的结果。

上下文长度变化剧烈：被监测模型中达到 **100 万（1M）词元**的占比已达 **47.8%**，20 万及以上合计 **95.7%**，较 2025 年底提升**超过 76 个百分点**。开源模型方面，8 月 **DeepSeek-V4-Pro 的 TPS 已达 DeepSeek-V3.2 的 2 倍**；报告还指出**同一模型在不同第三方平台上的表现存在差异，部分平台明显优于官方平台，TPS 差距最大可接近一倍**。

#### 技术亮点 / 影响分析
- **「降价周期结束」是这份报告最该被记住的结论**：经历两年价格战后，2026 年国内外模型服务价格**明显上涨**。任何按 2025 年单价做的 AI 预算都需要重算，**尤其是批量生图、批量剪辑这类高 token 消耗场景**
- **词元正在成为新的计量单位**：报告明确提出 MaaS 厂商越来越多地以公有云 API 方式供给词元服务，**词元成为服务计量与结算的基本单位**。对通信行业而言，网络承载对象正从传统数据流扩展为「模型请求—推理计算—结果返回」的端到端服务流
- **「同一模型不同平台性能差近一倍」是最实用的一条**：报告实测部分第三方平台明显优于官方平台。**选型时不能只看模型，必须测「模型 × 平台」的组合**，这一条能直接换算成成本

- **边界要说清楚**：报告监测的「500 万亿」是 **2026 年 6 月**的数据，报告本身基于 **1–8 月**样本，不是当月实时值；归一化价格为折算口径，与各家实际标价不同；**报告由信通院等机构发布，数据来自其自有监测体系，未经第三方复核**

#### 三句话总结
1. 中国信通院联合发布《大模型词元服务性能监测报告（2026 年）》：2026 年 6 月国内词元日均消耗量约 500 万亿（为 2025 年 12 月的近 4 倍），归一化均价从 6.8 元升至 13.46 元；8 月国内平均 TPS 78.23、首词时延 1.26 秒，1M 上下文模型占比已达 47.8%
1. 报告同时指出：国外典型模型归一价格约 117.8 元仍远高于国内，TPS 均值 112.82 亦优于国内；TTFT 上升主要源于参数量、上下文长度与调用量同步增长；**同一模型在不同第三方平台的 TPS 差距最大接近一倍**
1. 对 CODM 宣发团队：**把 AI 生图与批量剪辑的预算口径从「单价」改成「单任务成本」**——词元价格在涨、输出 token 也在涨，两者叠加会吃掉模型降价的红利。**具体动作：挑 3 个高频任务（一张主视觉、一条 15 秒剪辑、一份多语种文案），在同一模型下对比官方平台与至少两个第三方平台的实际耗时与账单，选组合而不是选模型**

### #7 两项研究称花哨 harness 只买账单不买通过率：单任务成本差 3–5 倍，分数落在重跑噪声内

> **来源**：[The Decoder](https://the-decoder.com/fancy-harnesses-make-coding-agents-more-expensive-but-not-better-study-finds/) / 山东大学论文《What Does a Harness Buy? Tokens, Mostly.》 / UC Berkeley Sky Computing Lab & Arena《HarnessTax》 / [AI Weekly](https://aiweekly.co) | **评分**：8.3/10 | **标签**：智能体评测·harness 税·成本治理·评测噪声·最小基线

#### 核心事件
山东大学研究者 Yangze Liu 与 Zhongyi Han 发表论文《**What Does a Harness Buy? Tokens, Mostly.**》，用 **5 个模型 × 3 个生产级 harness（Claude Code、OpenCode、mini-SWE-agent）**在 **SWE-bench Verified** 上做对照，随后**把同一配置重跑多次**，看什么都没变时分数会浮动多少。

结果分两层。**通过率**：在 447 题的池子上，Claude Code 与极简的 mini-SWE-agent 差距在 **2 个百分点以内**，作者称「在 5 个百分点误差范围内统计等价」；在 45 道最难题上，换 harness 与重跑不变配置导致的解题翻转比例都是 **13%**——**换 harness 带来的改变，和什么都不改变重跑一次差不多**。**成本**：同一模型、同一任务、同一价目表，**单任务成本最多差 3 倍**。GLM-5.3-Flash 下，Claude Code 单次 1.81 元、OpenCode 0.56 元。

成本差异的来源是**固定上下文**：每走一步都要重发系统提示与工具描述，论文实测这段「前缀」为 **Claude Code 16581 tokens、OpenCode 7025 tokens、mini-SWE-agent 829 tokens**。前缀设定了基线成本，步数再把它乘上去。缓存 token 的折扣会缩小差距，但不改变排序。

几个反直觉细节：DeepSeek 自家的 harness 配自家模型**并不比别人更好，反而最贵**；Claude Opus 5 在移除 Claude Code 的工具后结果**完全一致**；一年前的旧版本以不到一半的成本解出相似数量的任务，因为当时 Extended Thinking 默认关闭。**「思考」是唯一一个 harness 选择真正改变结果的维度**——关掉思考后 mini-SWE-agent 配 Qwen3.6 掉 11 分，而 Claude Code 与 OpenCode 只在噪声范围内波动。

另一项来自 UC Berkeley Sky Computing Lab 与 Arena 的 **HarnessTax** 研究，评估 7 个模型在 Claude Code、OpenAI Codex CLI 与仅有四个基础工具的极简开源 harness **Pi** 上的表现，结论一致：**harness 选择只让通过率变动几个百分点，却让推理成本最多放大 5 倍**。作者团队的结论是一句可以直接引用的话：「**我们能测到的每一个 harness 效应，都是一种『让模型本可以解出的任务失败』的方式，外加一张账单，而不是通过率。**」他们建议：任何 harness 对比都必须同时公布同配置的重跑结果。10 次同配置重跑的分数波动为 **2.2–6.0 个百分点**，比多数榜单用来排序的厂商宣称差距还大。

#### 技术亮点 / 影响分析
- **「harness 税」这个概念今年会被反复引用**：固定前缀每步重发，Claude Code 16581 tokens vs mini-SWE-agent 829 tokens，差 20 倍。**在一个长任务里，这个差距会随步数线性放大**
- **榜单上 2 个点的差距可能只是噪声**：10 次重跑波动 2.2–6.0 个百分点。**以后看到「某 harness 让某模型提升 2 分」的宣传，第一反应应该是问「重跑了吗」**
- **「自家 harness 配自家模型没优势」这条很打脸**：DeepSeek 的 harness 配自家模型既不更好也不更便宜。**厂商捆绑不等于优化**
- **思考开关是唯一实质变量**：关掉思考对不同模型的影响差异巨大且不可预测（有的掉 11 分，有的在噪声内）。**这说明「要不要开推理」必须按具体模型 × 任务组合调，不能沿用默认值**
- **边界要说清楚**：主研究以单一基准（SWE-bench Verified）为主，Terminal-Bench 2.1 的小样本交叉验证显示相同模式；闭源顶级模型 Opus 5 只在 Claude Code 里跑过；作者自承测试网格太小，无法解释「为什么」；**结论适用于编程智能体，不能直接外推到生图、剪辑等其他智能体场景**

#### 三句话总结
1. 山东大学与 UC Berkeley 两项独立研究得出同向结论：在同一模型同一任务下，换用更「花哨」的编码智能体 harness 最多让单任务成本涨 3–5 倍，而通过率差异与「什么都不改重跑一次」的波动（2.2–6.0 个百分点）相当
1. 成本来源被定位为固定系统提示与工具描述的每步重发（Claude Code 16581 tokens / OpenCode 7025 / mini-SWE-agent 829）；DeepSeek 自家 harness 配自家模型既不更好也不更便宜；「是否开启思考」是唯一真正改变结果的变量
1. 对 CODM 宣发团队：**在采购或自建任何智能体编排方案前，先拿极简基线跑一遍同样的任务做对照**——如果提升不足 5 个百分点，就别付那 3–5 倍的账单。**具体动作：给现有的批量生图 / 素材整理流程加一个「不开任何编排框架、直接调 API」的对照组，按「单任务成本 + 通过率」两项一起评估，而不是只看单价**

### #8 澳国脚 Volpato 独家授权 AI 数字分身：形象、声音、生物特征与表现数据打包给 Callandor

> **来源**：[Guardian Australia](https://www.theguardian.com/australia-news) / [SmartInfo](http://smartb.com.au) / [凤凰网科技 / IT之家](https://tech.ifeng.com) | **评分**：8.2/10 | **标签**：AI 肖像权·数字分身·体育营销·授权代理·合成内容治理

#### 核心事件
现年 22 岁、效力于意甲萨索洛的澳大利亚国脚 **Cristian Volpato** 于 **9 月中旬**与总部位于加州的 **Callandor** 公司签署协议，成为最新一位**把自己的 AI 肖像授权变现**的职业运动员。相关视频近日在社交平台传播：画面里的他走在宽敞中庭，随后**分身出四个数字分身**，分别出现在十二使徒岩海滩、巨型数字广告牌、镜子前等场景——**视频由 AI 生成，但获得了本人授权**。

协议内容是关键：Callandor **独家持有** Volpato 的**数字形象、声音、生物特征数据与赛场表现数据**，负责对接品牌合作、用他的 AI 肖像变现并抽取分成，同时**拦截未经他本人许可的相关内容**。联合创始人 **Michael Fisk**（前索尼影业、美高梅高管）把这个业务定义为制造「**合成双胞胎**」：球员一直在训练和比赛，会把有限的空闲时间留给家人朋友，因此会错过大量品牌合作机会；「**只要获得本人许可，品牌方就可以全天候、全年无休地使用数字分身**」。

Callandor 今年 2 月成立，目前签约运动员不多，包括巴西球员若日尼奥（Jorginho）与美国帆船选手 Chris Poole，项目仍处试点阶段。除传统广告外，公司在探索 AI 生成的多语种有声书旁白，以及让球迷与运动员数字分身建立专属互动的应用（例如由 Volpato 的数字分身实时指导用户踢球动作）。

背景是行业与监管的赛跑：**博彩公司、转播方与品牌方越来越多地在未经许可的情况下把运动员形象用于 AI 生成内容**。本月早些时候，澳大利亚橄榄球联盟（AFL）应球员工会投诉，要求合作博彩公司 Sportsbet 停止使用未经球员许可的 AI 生成球员形象。今年 6 月，巴西球星内马尔把自己的 AI 肖像授权给一家中资娱乐平台并在世界杯期间发布短视频。悉尼初创公司 Hyperknown 创始人 William Saunders 的说法概括了这个逻辑：运动员渐渐意识到，**如果自己不主动把 AI 肖像变现，别人就会擅自拿去牟利**。目前澳大利亚各大主流体育联赛的球员合同里**还没有任何与 AI 相关的条款**。

#### 技术亮点 / 影响分析
- **肖像权第一次被拆成四项资产来卖**：数字形象、声音、生物特征、表现数据，且是**独家**授权。这比传统的「肖像使用许可」细得多，**未来任何涉及真人形象的 AI 生成授权，条款都得按这个颗粒度谈**
- **「拦截未授权内容」被写进商业模式**：Callandor 不只是代理变现，还负责下架未经许可的合成内容。**这意味着「维权」正在从法务动作变成一项可外包的服务**
- **真实与合成的边界在手机上已经分不出来**：Fisk 自己承认，这些数字分身「在手机上看，观感和质感几乎看不出差别，想要分辨真假越来越难」。**这句话是这一条新闻里最值得警惕的部分**
- **监管明显滞后于商业**：澳各大联赛球员合同尚无 AI 条款，AFL 与 Sportsbet 的纠纷靠球员工会投诉推动，而非既有规则。**在规则补上之前，谁先签约谁先占据主动，这就是「这是一场赛跑」的含义**
- **边界要说清楚**：这是单一球员的商业授权，不构成行业通行规则；协议细节（期限、分成比例、审核权）未公开；**知识产权学者指出，现行著作权法保护人类创作的作品，并不自动延伸到 AI 生成的复制件**，运动员、AI 公司与品牌三方之间的法律基础仍不清晰

#### 三句话总结
1. 澳大利亚国脚 Cristian Volpato 于 9 月中旬与加州公司 Callandor 签署独家协议，授权对方使用自己的数字形象、声音、生物特征与赛场表现数据，由该公司对接品牌合作、抽取分成并拦截未授权内容；相关 AI 生成视频近日在社交平台传播
1. Callandor 今年 2 月成立、项目仍在试点，同时在探索多语种有声书旁白与球迷互动应用；背景是博彩、转播与品牌方越来越多地在未经许可下使用运动员形象，本月 AFL 已要求 Sportsbet 停止使用未授权的 AI 球员形象，而澳各大联赛球员合同尚无 AI 条款
1. 对 CODM 宣发团队：**凡涉及真人形象（代言人、主播、KOL、Coser）的 AI 生成或 AI 换脸内容，授权链条必须书面化到四项资产——形象、声音、生物特征、表现数据，并明确期限、审核权与分成**。**同时为「AI 生成的真人形象」准备内部标识规范：在手机端已经分辨不出真假的情况下，主动标注比事后被指认更划算**

## 📝 编辑点评

今天八条里，有一个词反复出现，值得单独拎出来 —— **边界正在被打包成产品**。

它今天同时以四种形态出现，而且每一种都可以被直接安装、引用或计价：

- **沙箱成了 npm 包**：Anthropic 把 Claude Code 的隔离层抽出来开源，装个包、加个 `srt` 前缀就能生效。**隔离从「要不要做」的架构讨论，变成了「做不做这一步」的操作动作**
- **披露成了州法**：宾夕法尼亚州把「使用了 AI」这件事写成了可引用的条款（Act 99），还给出了标识的三个位置要求。**合规从「原则上应该」变成了「第几秒、用什么语言、能不能被抹掉」**
- **权限成了采购条款**：瑞典政府办公厅封掉 ChatGPT 与 Claude 网页端，但同一个模型在 Intric 里照用。**被管的不是模型，是通道**——有没有合同、能不能配、有没有日志
- **词元成了计量单位**：信通院把「日均 500 万亿」这个数字摆出来，词元服务正在变成像流量一样可被监测、可被比较的商品

这四件事的共同点是：**AI 的边界不再靠共识维持，而开始靠可交付物维持。** 这是比任何一次模型发布都更实质的变化——因为它决定了接下来几年里，「用 AI」这件事的成本结构长什么样。

另一条暗线是**账单开始被认真对待**：

- 词元价格在涨（归一化均价 6.8 元 → 13.46 元），量的增长更快（3 倍 vs 价格 1 倍）
- harness 研究表明，**同样的模型、同样的任务，账单可以差 3–5 倍，而买到的通过率差异落在噪声里**
- 21% 的受访企业**没有任何自动手段去叫停自家智能体的 token 开销**

能力侧今天反而是「往小里走」的一天：NVIDIA 把会调工具的智能体压进 4GB，Block 把语音模型压进一台笔记本。**前沿在抢天花板，产业在抢地板**——前者决定能做什么，后者决定有多少人真的用得上。

### 给宣发团队的可执行线索

1. **本周内建立 AI 素材台账，并准备两套披露标识模板**：逐条记录哪张主视觉、哪段视频、哪句配音经过 AI 显著修改或生成；标识文案统一为「本广告包含经人工智能修改或生成的内容」，做**画面内标注**与**音频口播**两个版本，标注位置要求「首次出现即标注 + 同媒介 + 极难移除」。宾州法 **12 月 21 日生效**，判定原则是**按投放地而非制作地**
1. **给本地宣发智能体脚本套上 srt**：安装 `@anthropic-ai/sandbox-runtime`（需 Node.js ≥ 22.12），把网络设为默认全封 + 只放行模型 API 域名，把含未发布版本的素材目录写进 `denyRead`；本地 MCP 服务器直接把 `.mcp.json` 里的 `command` 换成 `srt`。**Windows 后端仍是 alpha 且有已知绕过路径，关键任务优先在 macOS/Linux 上跑**
1. **把「签约通道优先」写成内部硬规则**：未发布版本、未公开角色与剧情、合作方素材，只走已签约的企业级 AI 通道，禁止粘贴进任何个人账号的网页版对话。同时补一次「AI 输出必须核验」的培训——**合同能管住数据外泄，管不住有人把生成内容当结论直接用**
1. **把 AI 预算口径从「单价」改成「单任务成本」**：挑 3 个高频任务（一张主视觉、一条 15 秒剪辑、一份多语种文案），在同一模型下对比官方平台与至少两个第三方平台的实际耗时与账单。信通院实测**同一模型在不同平台的 TPS 差距最大接近一倍**
1. **任何智能体编排方案上线前先跑极简基线对照**：如果提升不足 5 个百分点，别付那 3–5 倍的账单；**看到「某框架让通过率提升 2 分」的宣传，先问一句「重跑了吗」**——10 次同配置重跑的波动是 2.2–6.0 个百分点
1. **试跑 Nemotron 3.5 Bolt E4B 做本地 NPC 原型**：用 Ollama / LM Studio 起服务，配 In-Game Inferencing SDK，适合展会可交互 NPC 与内部角色对话原型（离线、无云成本、不上传素材）。**只用它做人设化闲聊与台词，别让它跑多步任务**（Tau2-Bench 仅 55.1）；落地前在目标硬件实测首 token 延迟，Jetson 与桌面卡差距是 10 倍级
1. **把 Dessa 挂上观察列表，但不进生产**：目前无 API、无权重、无公开评测，仅有官方自选 demo。**现在可做的准备是把需要情绪表达的角色台词整理成带情境说明的短文本集**，等这类模型开放 API 时能立刻做对比测试
1. **凡涉及真人形象的 AI 生成内容，授权链条要书面化到四项资产**：数字形象、声音、生物特征、表现数据，明确期限、审核权与分成；并**为「AI 生成的真人形象」制定内部标识规范**——在手机端已经分辨不出真假的情况下，主动标注比事后被指认更划算
