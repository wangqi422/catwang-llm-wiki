1. 谷歌把 Computer Use 做进了轻量级的 Flash，意味着 Agent 操控电脑不再是前沿模型的专属能力
2. 跨端覆盖（网页/桌面/移动端）+ 70+ 轮连续执行，实用门槛大幅降低
3. 对 CODM 宣发团队：可探索用 Gemini Flash 自动抓取竞品官网 / 社交媒体更新素材，转化为素材监控 Agent
