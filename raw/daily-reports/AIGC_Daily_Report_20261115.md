### #2 ⭐ AMD 公布 MEXT 预测式内存引擎：DRAM 砍半保留 99% 性能，145 台已部署、2027 扩至 2000 台

> **来源**：[Tom's Hardware](https://www.tomshardware.com/pc-components/cpus/amd-shares-how-it-can-retain-95-percent-of-server-performance-with-just-half-the-dram-sidestepping-memory-shortages-with-mext-tech-powers-over-100-servers-already-running-with-plans-to-expand-to-2-000-servers-in-2027) · [The Register](https://www.theregister.com/systems/2026/11/11/amd-where-were-going-we-dont-need-as-much-dram/5308953) · [Wccftech / 东方财富财富号](https://caifuhao.eastmoney.com/news/20261114162125672104780) · [dev.to AI Daily Digest 11-15](https://dev.to/hiroki-ii-ai/ai-daily-digest-november-15-2026-opus-55-becomes-default-openai-publishes-372-math-results-1pm5) | **评分**：9.1/10 | **标签**：算力基建 / 内存降本 / 推理经济学 / P0

#### 核心事件
11 月 10–14 日，AMD 集中披露 **MEXT** 预测式内存引擎的技术细节与部署数据（技术来自其 2026 年 6 月收购的 Mext 公司）。做法是在服务器操作系统与物理内存之间加一层软件，**用 Transformer 模型预测哪些内存页即将被用到、提前从 NVMe 闪存预取回 DRAM**，把冷页透明地分层到闪存，让闪存「看起来像内存」——因为闪存比 DRAM 慢约 500 倍，这层预测是整个方案成立的关键。官方数据：按工作负载不同，**物理 DRAM 用量可减少 20%–75%**；Synopsys PrimeTime EDA 负载下内存从 512GB 降到 256GB 仍保留约 **95%** 性能；Azure 上 Spark TPC-DS 一半 DRAM 配置达到全 DRAM 基准约 **99%**；压到 25% DRAM + 75% 闪存时降到 80%。智能体负载下「DRAM 与 MEXT 闪存各半」的五智能体并发流程**每美元性能提升 90%**、偏吃内存的智能体应用提升 70%。落地：AMD 内部**已在 145 台服务器上以 50% DRAM 容量运行**，相对纯扩 DRAM 方案**节省约 83% 成本、避免约 490 万美元 DRAM 采购**；计划 **2027 年扩到 2000 台**，与 **HPE** 合作推「MEXT Ready」系统（第一阶段），Microsoft Azure 与 Oracle Cloud Infrastructure 列为扩展部署云主机；对外授权第二阶段尚无时间表。

#### 技术亮点 / 影响分析
- **它动的是「推理集群最贵那一块」**：AI 建设把内存需求推得比 DRAM 密度增长更快，内存已占推理机队成本的很大一块。把性能与「物理内存容量」解耦，等于给运营商一个此前没有的杠杆——少买 DRAM 通道，把差价换到加速器或电力上。
- **和 #1 的 2500 亿担保、11-14 期美联储的 6800 亿基建债务是同一条账本**：一头是资本端在给算力扩张重新定价、砍敞口，一头是硬件端在给单机成本做减法。行业从「堆料」转向「每美元性能」，MEXT 的 90% / 70% 口径正是这种转向的量化表达。
- **「预测准确率就是性能契约」值得抄进架构评审**：闪存延迟远高于 DRAM，一旦访问模式随机化、预取失手，99% 立刻回落。这类「用模型预测换硬件成本」的方案，必须把命中率做成可观测指标 + 降级预案，而不是只信厂商标称值。
- **边界**：所有基准均为 AMD 自家 Epyc 硬件上的内部测试，PrimeTime 与 Spark 恰好都是「吃大数据集但容忍一定延迟」的分层友好负载，**延迟敏感的实时推理数据 AMD 尚未公布**；83% 降本对应「可接受最大性能损失」的配置假设；145 台基线完全由 AMD 掌控，独立复测尚未出现。

#### 三句话总结
1. AMD 披露 MEXT 预测式内存引擎：Transformer 预测 + 闪存分层，DRAM 砍半在 Spark 负载保留 99% / PrimeTime 保留 95% 性能，内部 145 台服务器已部署、省约 490 万美元 / 83% 成本，2027 计划扩至 2000 台并与 HPE 合作。
2. 它把「每美元性能」而非「峰值算力」变成推理集群的新优化目标，用模型预测换硬件成本，是 AI 基建从堆料转向精细化运营的标志性工程。
3. **对 CODM 宣发团队**：批量出图 / 视频渲染 / 本地推理的机器选型与云预算，别再只按「显存 / 内存容量」下单，改为按目标负载的实测吞吐与单位成本比价；若引入任何「预测式 / 分层式」加速方案，先把命中率监控与降级回退写进验收清单，厂商标称的 99% 不能直接进对外承诺。

> **来源**：[南南南看 AI 11-14](http://mp.weixin.qq.com/s?__biz=MzYzNDk5MDA1Nw==&mid=2247486091&idx=1&sn=c1fc14e3b253fae070603409f46c2f47) · [国内科技要闻 11-14](http://mp.weixin.qq.com/s?__biz=MzUwOTg2NzYyNg==&mid=2247484916&idx=1&sn=0fdafa47c148096952abc8c04d653f04) · [kling.ai/dev/pricing](https://kling.ai/dev/pricing) · [火山引擎 / 火山方舟](https://www.volcengine.com/) · [证券日报](https://www.stcn.com/) | **评分**：8.1/10 | **标签**：定价透明 / 交付物口径 / 宣发成本 / P2

#### 核心事件
11 月 14 日，多家 AIGC 创作工具把价目表写细到「秒、张、首」，被行业媒体集中盘点成一次**交付物口径的集体显性化**：① **阿里「快乐虾米」APP**（11/13 上线 iOS / Android，虾米品牌以 AI 之名回归）做端到端整曲生成——作词 / 作曲 / 编曲 / 人声演唱一体，带「音乐配方」与「做同款」，**30 元/月含 150 首**（媒体折算约 0.2 元/首），但「一首」的**时长、音质、版权归属三项官方均未说明**。② **可灵 4.0** 官方 API：**720p 每秒 0.157 美元、1080p 每秒 0.235 美元**，**带参考视频按输出时长 ×2 计费**（10 秒片配 5 秒参考算 20 秒）。③ 字节 **Seedance 2.5 flash**：API 于 **11/15 14:00 在火山方舟开放**，720P 约 **0.99 元/秒**（较 2.5 低 34%），单段 ≤30 秒、最多 10 图 + 5 视频 + 5 音频参考，仅 480P / 720P。④ **MiniMax H3-Image** 4K 单张**五折到 0.03439 美元**（约 0.2261 元），**11/17 16:00 UTC 到期**。⑤ **Google Gemini 4 Hydrogen**：输出每百万 **7.50 美元**、输入 1.50 美元，缓存 0.075、Batch 半价、Priority 1.8 倍。⑥ **讯飞 SparkAudio 1.0** 上线 API，用原生语音大模型替代 ASR+LLM+TTS 级联、覆盖 **99 语种 / 202 方言**（全国产算力训练），未公布单价；ElevenLabs Scribe v3 Live 批版 0.20 美元/小时、实时 0.22 美元/小时。

#### 技术亮点 / 影响分析
- **「按首 / 按秒 / 按张 / 按 token」不是同一把尺，不能相加更不能互算**：南南南看 AI 的核心提醒很实用——只有「每首」这一格连分母都没写清。看到「每首 / 每条 / 每次」先问交付物写没写清，单位没定义就别进比价表。
- **带参考视频按双倍时长是最容易踩的坑**：可灵 4.0 的「10 秒片 + 5 秒参考 = 20 秒计费」意味着做「参考片驱动」的宣发二创，成本要按输出时长重算一遍，不能拿每秒单价直接乘成片长度。
- **与 #6 词元所、11-14 期 DeepSeek 全家桶 API 是同一条线**：整个行业把「能力」拆成可计价的原子单位，价格一旦可见，产品就得说清自己到底卖什么。对买方的直接好处是出片成本第一次能做进预算表，对卖方则是被迫补齐交付物定义与版权口径。
- **边界**：0.2 元/首为 30÷150 的媒体推算、非官方单价；Seedance「速度翻倍 / 效果最接近旗舰」为厂商自述、无独立测评（智东西 15 元 15 秒 480P 单次实测样本量 1、快节奏画面文字偶有乱码）；H3-Image 五折到期后价格翻倍；讯飞 SparkAudio 与 ElevenAI 均未定价 / 处于 preview，不得写成「已可用 / 已收费」；各家分辨率与规格不同，不按单价直接排名次。

#### 三句话总结
1. 11/14 多家 AIGC 工具把价目表写细：快乐虾米 30 元/月 150 首（时长/音质/版权三项空着）、可灵 4.0 720p $0.157/s 与 1080p $0.235/s 且带参考按双倍时长、Seedance 2.5 flash 11/15 14:00 上火山方舟 720P 约 0.99 元/秒、H3-Image 4K 五折 $0.03439/张（11/17 到期）、讯飞 SparkAudio 1.0 覆盖 202 方言未定价。
2. 它把「能力」拆成可按秒 / 张 / 首 / token 计价的原子单位，价格可见后倒逼厂商补齐交付物定义与版权口径，也第一次让出片成本能进预算表。
3. **对 CODM 宣发团队**：建一份统一比价表，逐列登记「单位 + 分辨率 / 时长 + 版权归属 + 到期时间」，把「按首 / 按次」这种没分母的报价单独标红不进表；做带参考视频的二创先按双倍时长重算成本；批量出图可排在 H3-Image 五折到期（11/17 16:00 UTC）之前，但厂商自述的速度 / 效果提升不写进对外承诺。

## 编辑点评

八条其实在讲同一件事：**没有一款新模型发布，全在给这轮震荡补账、标价和动手术**。周日的大厂集体静默，反而让 11-14 期那条「交出权和补账本」的主线走到了更实在的一层——昨天是系统开始向人要权限，今天是系统开始为自己算成本、定口径、拆组织。

上半场（#1–#3）全是英伟达那场人事地震的余波，但落点已经不是人：**12 万人请愿 + 国会 12/1–12/3 作证 + 市值跌破 4 万亿**把「一个人的离场」写成了治理与监管问题（#1）；**AMD 把 DRAM 砍半保住 99% 性能**则是硬件端第一次认真回答「每美元性能」（#2）；最妙的是 **#3** ——所有人都在担心「后黄仁勋时代的融资缺口」，资本却在同日把 Fractile、LangChain、Rhoda、Poolside 四笔大单砸了下去。钱没走，只是不再只押一条 GPU 供应链。

中段三条（#4–#6）是「把能力交出来」的三种姿势：**OpenAI 直接拆掉独立机器人团队**，赌通用模型能当机器人大脑（#4）；**Google DeepMind 把顶级气象模型的两套数据集按 CC BY 4.0 全量开放**（#5）；**百度词元所把「选哪家模型」做成有验真与征信的交易所**（#6）。一个交出组织边界、一个交出数据底座、一个交出选择权——都不是发布新模型，而是把已有能力变成别人能复现、能比价、能长期用的东西。

收尾两条最贴地气（#7–#8）：**Anthropic 用「成本降 78%」解释常驻智能体为什么现在才成立**，比任何「Agent 元年」的口号都可信（#7）；**AIGC 工具把价目表写到秒、张、首，却有一格连「一首多长」都没定义**（#8）。越自动化、越常驻，越要把单位、分母和版权先写清楚——这和 11-14 期「权限、口径与边界」是同一句话的下半句。

一组对照值得记：**#1 的 2500 亿担保被减半、#2 的 DRAM 砍半、#8 的价目表，都是「把模糊的东西变成可核对的数字」**。前者是给资本去杠杆，中者是给硬件去成本，后者是给创作去含糊。今天没有谁更聪明，比的是谁先把账算明白。

一句话：没有新模型的一天，全在给这轮震荡补账、标价和动手术

今天最高分给到 **#1 英伟达治理危机（9.4 / P0）**：分量不在人事本身，而在 48 小时内它同时触发了董事会正当程序、国会出口管制听证与表外担保敞口三条制度线，并给出「12/1–12/3 听证 + 2500 亿担保减半 + 跌破 4 万亿」这些能直接写进风险清单的日历与数字——这是 11-13 期「一个人的退场」之后，市场第一次为「一套系统怎么接住一个人的缺席」定价。

五条可以立刻执行的线索：**① 云渲染 / GPU 算力 / 长周期供应商合同的预算与排期，标注「12 月听证 + 出口管制」外部变量**，不把特定加速器供货与价格写死进对外承诺；**② 批量出图 / 视频渲染的机器与云选型，改按目标负载实测吞吐与单位成本比价**，引入任何预测式 / 分层式加速须把命中率监控与降级回退写进验收清单；**③ 建一份 AIGC 统一比价表，逐列登记「单位 + 分辨率 / 时长 + 版权 + 到期时间」**，「按首 / 按次」无分母的报价标红不进表，带参考视频按双倍时长重算；**④ 采购第三方模型 API 时把「模型是否与宣称一致、有无持续监测」列进供应商评估表**，平台自报数据不等于 SLA；**⑤ 若把舆情 / 巡检 / 日报做成常驻 Agent，先按「单位任务成本 × 日调用量」算清月账单再立项**，架构保留可暂停 / 可审计，凭据优先自托管或按环境隔离。
