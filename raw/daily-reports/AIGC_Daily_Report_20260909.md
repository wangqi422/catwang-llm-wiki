### #1 ⭐ Meta 发布个人智能体 Muse：扎克伯格站台，连接购物/订票/支付

> **来源**：IT之家 / TechCrunch / ai.meta.com | **评分**：8.6/10 | **标签**：`Agent` `个人智能体` `Meta`

#### 核心事件

9 月 9 日，Meta 正式发布个人智能体 **Muse**（内部代号 Hatch），定位「面向个人事务的常驻式主动智能体」，由最新长程智能体模型 **Muse Spark 1.3** 驱动，初期仅在美国上线。Meta 首席 AI 官 **Alexandr Wang（Scale AI 创始人）** 亲自站台，扎克伯格也公开谈了自己的使用方式。Muse 可自主完成发邮件、卖车、预订旅行、订餐、全网购物等任务，靠大量连接器接入 Gmail、Google 日历、Outlook、Spotify、1Password（登录）、Stripe（支付）等服务，并在应用关闭后持续工作。定价为免费基础版 + **每月 20 美元 / 100 美元**两档订阅，入口 `muse.ai`。

#### 技术亮点 / 影响分析

- **「个人智能体」从概念走向量产产品**：Muse 不是聊天工具，而是「运行在安全虚拟机里的常驻 Agent」——官方强调数据不用于广告、只用于「更好地服务你」，配合 1Password 登录继承、Stripe 支付授权，把「让 AI 替你办事」的信任闭环第一次在产品层面补齐
- **生态与分发是 Meta 的王牌**：对比同赛道的 Instinct 等竞品，Muse 拥有 WhatsApp、Instagram、Marketplace 等 Meta 原生集成，早期用户反馈「浏览器操作速度是我见过最快的」，Alexandr Wang 更晒出「Muse 对战 Instinct 4-1」——**分发能力 + 已有登录体系，是 Meta 切入个人智能体的最大差异化优势**
- **诚实的边界**：内部测试已暴露安全漏洞与运行故障，且 soul.md、Memory 等命名对普通用户不直观、信息流相关性不足；目前仅限美国，商业化刚起步

#### 三句话总结

1. Meta 发布个人智能体 Muse（Muse Spark 1.3 驱动，代号 Hatch），连接购物/订票/支付等，免费 + 20/100 美元订阅，仅美国上线
2. 这是「个人智能体」赛道从概念走向量产产品、并由 Meta 以生态分发能力入场的标志性事件，安全虚拟机 + 登录/支付继承补齐了「让 AI 替办事」的信任闭环
3. 对 CODM 宣发团队：**个人智能体正成为新的「用户触点」**——未来玩家可能通过这类常驻 Agent 完成「查版本、领福利、预约活动」，宣发侧应关注「把宣发物料/活动入口做成可被 Agent 调用」的方向；同时 Meta 靠「分发 + 已有登录」的打法，也提示我们**宣发的竞争优势同样在「触达能力 + 存量关系」而非单一内容**

### #2 ⭐ OpenAI 用 1 万智能体 88 小时求解 Navier-Stokes 千年难题

> **来源**：OpenAI / The Verge / Simon Willison | **评分**：8.8/10 | **标签**：`数学` `Agent` `里程碑`

#### 核心事件

OpenAI 官方博客宣布：用约 **10000 个并发 AI 智能体**，在 **88 小时**内给出了 Navier-Stokes 存在性与光滑性问题（**七大千禧年大奖难题之一**，单个奖金 100 万美元）的一个解。全程发送 **490 万条消息**、消耗约 **3000 亿输出 token**，并由 GPT-6 Astra 完成 **17 小时 Lean 形式化验证**。所求解使用 8 月 28 日开始训练、能力远超 GPT-6 Astra 的下一代内部模型，构造了「从静止出发、有限时间内发展出无界速度但动能有界」的解，对应 Fefferman 表述中的情形（C）与（D）。**OpenAI 表示不领取奖金**。

#### 技术亮点 / 影响分析

- **「万级智能体协作」首次逼近数学前沿**：不是单模型硬算，而是 10000 个 Agent 分工协作 + 17 小时 Lean 形式化验证兜底——把「智能体规模化协作」从实验推到了「解一道 90 年未解的数学难题」的真实场景，是 AI Agent 能力的一次里程碑式展示
- **争议同步爆发，且火药味十足**：陶哲轩公开点赞但担忧「AI 竞速正在摧毁数学界公开分享问题的传统」；NYU 数学家 **Tristan Buckmaster** 则指控 OpenAI 抢发并施压——他和 Anthropic 数学家 Levent Alpöge 已借助 Codex 与 Claude 模型对同一问题取得阶段性证明。**「谁先做出来、证明是否成立、是否该公开」成为同一天的舆论主战场**
- **形式化验证的价值被放大**：490 万条消息、3000 亿 token 的原始产出无法人工核对，17 小时 Lean 形式化验证成为「证明可信度」的关键闸门——**Agent 大规模输出的可信性，越来越依赖形式化/可验证的兜底机制**

#### 三句话总结

1. OpenAI 用 1 万智能体、88 小时、490 万条消息、3000 亿 token 求解 Navier-Stokes 千年难题，GPT-6 Astra 17 小时 Lean 形式化验证，宣布不领奖
2. 这是「万级智能体规模化协作」首次逼近数学前沿，但同步引爆「抢发」与「AI 竞速破坏数学传统」的双重争议，陶哲轩担忧、NYU 数学家指控
3. 对 CODM 宣发团队：**这条新闻的启示不是「AI 能解数学题」，而是「大规模 Agent 协作 + 形式化验证兜底」的范式**——未来宣发侧一旦跑「批量 Agent 流水线」，务必配「可自动校验的结果闸门」（脚本校验素材尺寸/文案合规/链接有效性），别让「产出快」掩盖「产出不可信」；「抢发争议」也提醒我们**在公开平台发布前先做好归属与授权声明**

### #3 ⭐ OpenAI 发布 ChatGPT Images 2.5：延迟降 50% + Sketch 涂鸦生图

> **来源**：OpenAI / The Verge / IT之家 | **评分**：8.4/10 | **标签**：`生图` `模型` `ChatGPT`

#### 核心事件

OpenAI 发布图像生成模型 **ChatGPT Images 2.5**，Sam Altman 官宣。相比 2026 年 4 月的 Images 2，**延迟最多降低 50%**，细节锐度、自然光照、纹理质感全面提升，多次编辑间细节保持一致；新增 **Sketch 涂鸦生图**（聊天框输入 `@Sketch` 弹窗手绘草图 → 依草图生成）、模板库、图片内评论式局部修改。官方透露模型已在 ChatGPT Images 与 API 中累计生成 **超 30 亿张图片**。衍生模型 Sunburst 与 Flare 登顶 Arena 三个图像榜单前两名。

#### 技术亮点 / 影响分析

- **「涂鸦→成图」把生图门槛进一步下探**：Sketch 让不懂 Prompt 的人也能用手绘草图表达意图，配合「图片内评论标注局部修改」，把生图从「文字描述」升级为「多模态意图输入」，更贴近设计师/非技术用户的工作方式
- **「一致性」成为新一代生图的核心卖点**：多次编辑间细节保持一致、参考对象保持、局部修改只动想改的地方——**这正是商用素材最痛的点**，直接对标「AI 生图能不能稳定出系列素材」的刚需
- **延迟降 50% 的工程意义**：30 亿张图的规模验证了推理链路的成熟度，速度提升意味着「边生成边调」的交互式工作流更流畅，批量化出图成本更低

#### 三句话总结

1. OpenAI 发布 ChatGPT Images 2.5，延迟降 50%，新增 Sketch 涂鸦生图、模板库、图片内评论式局部修改，累计已生成超 30 亿张图
2. 核心升级是「一致性」与「多模态意图输入」——多次编辑细节保持一致、涂鸦/评论即可改图，直击商用素材「稳定出系列」的刚需
3. 对 CODM 宣发团队：**这是最直接的生产力信号**——「涂鸦生图 + 局部评论式修改 + 细节一致性」正好覆盖宣发做 KV/海报/角色图时「从草图定方向、局部微调、保系列风格统一」的完整链路；建议第一时间在真机/API 上验证「同一角色多角度一致性」与「品牌色/logo 还原度」，把它纳入生图工具链的候选

### #4 Inception 发布扩散 LLM Mercury 2.5：智能提升 40%，1107 tok/s

> **来源**：Inception Labs / Hacker News | **评分**：7.5/10 | **标签**：`扩散LLM` `开源` `推理`

#### 核心事件

Inception 发布扩散大语言模型 **Mercury 2.5**，官方称其为「目前能力最强、规模最大的扩散 LLM」：智能较 Mercury 2 提升 **40%**，在 NVIDIA GPU 上达 **1107 tokens/s**，上下文 **260K tokens**。定价 **$0.20/百万输入、$0.75/百万输出**，发布期 8 折。官方对标 GPT-5.6 Luna（Low）、Gemini 3.5 Flash-Lite 和 Claude Haiku 4.5 这一「快速档」能力带。核心路线是**离散扩散（discrete diffusion）**，宣称实现 LLM 的无损加速。

#### 技术亮点 / 影响分析

- **扩散 LLM 从「实验」走向「对标主流」**：与自回归（AutoRegressive）主流路线不同，扩散 LLM 可并行解码、天然更适合高速生成；Mercury 2.5 直接对标主流「快速档」模型，是扩散路线成熟度的一次公开验证
- **「无损加速」是关键承诺**：过去扩散 LLM 常被质疑「提速牺牲质量」，Mercury 2.5 强调「智能 +40% 同时 1107 tok/s」，若成立意味着**速度与质量不再二选一**，对推理成本敏感的 Agent 场景尤其有价值
- **低价 + 高吞吐的落地信号**：$0.75/百万输出的定价 + 1107 tok/s，把「高速长文本生成」的成本大幅下探，适合批量、低延迟的生成类工作负载

#### 三句话总结

1. Inception 发布扩散 LLM Mercury 2.5，智能较 Mercury 2 提升 40%、1107 tok/s、260K 上下文，对标 GPT-5.6 Luna / Gemini 3.5 Flash-Lite / Claude Haiku 4.5
2. 信号是「离散扩散 LLM 从实验走向对标主流」，主打「无损加速」——速度与质量不再二选一，对推理成本敏感的 Agent 场景有直接价值
3. 对 CODM 宣发团队：**高速推理模型对「批量文案/多语言本地化/快速生成候选稿」最有价值**——宣发侧的批量文案生成、多语言本地化、素材描述批量打标等高频低延迟任务，可以关注这条「又快又便宜」的路线；但当前是「快速档」能力，重度创作仍建议走旗舰模型

### #6 蚂蚁百灵开源首个原生多模态 Ling-3.0-flash-VL：124B MoE

> **来源**：蚂蚁百灵（Ling）| **评分**：7.4/10 | **标签**：`多模态` `开源` `国产`

#### 核心事件

蚂蚁百灵发布并开源**首个原生多模态大模型 Ling-3.0-flash-VL**，基于 Ling-3.0-flash 的 MoE 架构，**总参数 124B、单次推理激活 5.5B**，**原生支持图像、文本与视频输入**，上下文窗口 **256K Token**。这是蚂蚁在「原生多模态（VL）」路线上的一次开源卡位，延续了其「MoE + 高激活比」的技术路线。

#### 技术亮点 / 影响分析

- **「原生多模态」而非「外挂视觉编码器」**：与「LLM + 视觉编码器拼接」的主流做法不同，原生 VL 让视觉与语言在统一的 MoE 架构内深度融合，理论上对「图文视频跨模态理解」更自然，是国产开源在多模态路线上的一次差异化尝试
- **「高激活比 MoE」的工程信号**：124B 总参、5.5B 激活，延续蚂蚁「大参数、低激活」的推理友好路线，配合 256K 上下文，瞄准「长视频/多模态长上下文理解」场景
- **开源生态继续补强**：继 Ling-3.0-flash 之后，蚂蚁把多模态版本也开源，国产开源在多模态赛道持续加码，给下游「私有化部署多模态理解」提供了新选项

#### 三句话总结

1. 蚂蚁百灵开源首个原生多模态 Ling-3.0-flash-VL（124B MoE、激活 5.5B、原生图像/文本/视频、256K 上下文）
2. 亮点是「原生多模态」而非外挂视觉编码器，延续「大参数低激活」推理友好路线，是国产开源在多模态理解上的差异化卡位
3. 对 CODM 宣发团队：**多模态理解模型是「视频/图文素材库自动化」的底座**——未来宣发侧可用它做「素材自动打标、竞品视频拆解、多模态内容检索」，尤其是原生视频理解能力对「拆解竞品 CG/宣发视频」很有价值；国产开源 + 可私有化部署，也解决了素材数据不出域的顾虑

#### 核心事件

Runway 发布 **Runway Plugins**，新面板可直接嵌入 **Adobe Premiere Pro 与 After Effects**，让用户在**时间线内**直接生成图像和视频、重绘片段并放置结果；配套 **Edit Studio** 可基于已有片段用 **Aleph 2** 模型按原始时长重新渲染。插件免费下载（macOS 与 Windows），生成功能面向所有付费计划并消耗现有额度。

#### 技术亮点 / 影响分析

- **AI 生视频「嵌入剪辑工作流」是结构性升级**：过去「AI 生成 → 导出 → 导入剪辑软件」的断裂流程，被「时间线内直接生成/重绘」打通——**创作者不用离开 Premiere/AE 就能用 AI 补镜头、改画面、重渲染**，这是 AI 视频工具「从独立应用走向专业软件内嵌」的关键一步
- **「重绘片段」直击剪辑师痛点**：基于已有片段按原时长重渲染（Aleph 2），意味着「拍废的镜头补一补」「换运镜」「改氛围」能在时间线里原地完成，把「返工」成本大幅压低
- **「免费下载 + 消耗现有额度」的渗透策略**：不设新门槛，直接借用 Runway 已有付费用户和额度，最大化渗透 Adobe 庞大的专业剪辑用户群

#### 三句话总结
