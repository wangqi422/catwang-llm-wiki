## §1 模型 & Agent

### #1 ⭐ Meta 发布首个前沿模型 Muse Wonder 系列，最强档不开放权重也不卖 API

> **来源**：[Meta 官方新闻室](https://about.fb.com/news/2026/10/introducing-muse-wonder-models/) / [TechCrunch](https://techcrunch.com/) / [VentureBeat](https://venturebeat.com/) / [腾讯新闻](https://news.qq.com/rain/a/20261013A02Y7X00) | **评分**：9.4/10 | **标签**：前沿模型·闭源·智能体·Active Memory

#### 核心事件
北京时间 10 月 13 日凌晨，Meta 超级智能实验室（MSL）发布 Muse Wonder 与 Muse Wonder Full 两款模型，内部代号「西瓜」（Watermelon），由俄亥俄州规模超 1 吉瓦的「普罗米修斯」（Prometheus）集群训练而成，距上一代 Muse Spark 1.3 仅约六周。这是 Meta 自去年 143 亿美元收购 Scale AI、任命 Alexandr Wang 掌舵 AI 研发以来推出的**首款前沿旗舰级模型**，也是这家靠开源 Llama 推动大模型普及的公司第一次为顶级模型引入**闭源托管机制**。

定价上，标准版 Muse Wonder 通过 Meta Model API 与 Muse Code 开放，每百万输入 / 输出 token 4 美元 / 20 美元，缓存输入降至 0.20 美元，大致与 GPT-6 Sol、Claude Opus 5.5 同档；更强的 **Muse Wonder Full 不开放 API，只向 Muse Code 付费订阅用户开放**，中文媒体报道其订阅上限约每月 200 美元。Zuckerberg 与 Wang 在访谈中暗示「已经在着手开发更高阶的产品」，模型开发「从现在起可能会明显提速」。

#### 技术亮点 / 影响分析
- **第三方跑分已进前沿梯队**：Artificial Analysis 智能指数（v4.3）给出 Muse Wonder **52 分**、Wonder Full **56 分**，较 Muse Spark 1.3 的 48 分分别 +4 / +8。Wonder Full 追平 Claude Sonnet 5.5（56），超过 GPT-6 Astra 与 Gemini 4 Argon（均 53）以及 Claude Fable 5.1（53），仅次于 Claude Opus 5.5（58）。Meta 自述在 14 项基准中有 8 项超过 Opus 5.5。
- **两个「Active」是产品定位核心**：Active Memory 负责跨对话保留个人与专业上下文、并在需要时召回细节，Meta 称其在 MemoryBench 上超过 Fable、Opus 与 Astra；Active Focus 负责任务变难时不放弃目标，能换路径、从错误中恢复，并在执行重要动作前先请示确认。两款模型接收文本 / 图像 / 音频 / 视频输入、输出文本，上下文约 100 万 token。
- **专门强调了「能查自己代码的漏洞」**：Meta 明确训练 Wonder 家族拒绝未经许可分享私人信息、拒绝协助有害行为，但**保留安全研究人员用它找代码缺陷的能力**——在安全与攻防之间划了一条很细的线。完整安全评估报告「即将发布」。
- **闭源转身的行业信号**：从 Llama 的开放权重到 Wonder 的「权重不下载 + 最强档不外卖」，Meta 的立场转向比分数更值得关注。对企业买家而言，最强能力被锁在 Meta 自家工具链里，数据治理与生产部署的选型成本都会上升。

#### 三句话总结
1. Meta 用 1 吉瓦集群和 14 个月重构换来了首个前沿模型，最强档 Wonder Full 拿到 AA 56 分、进入第一梯队。
2. 但两款模型都不开放权重，最强档还只给 Muse Code 订阅户——开源旗手正式转向闭源托管。
3. 对 CODM 宣发团队：Muse Wonder 支持图文音视频输入 + 100 万上下文 + 跨会话记忆，适合拿来做「长期品牌素材库 + 持续迭代的宣发智能体」；但要注意最强档只能走 Muse 订阅，API 侧只能用到标准版，做素材批量生成时的质量上限要按 Wonder（52 分）而不是 Wonder Full 来评估。

### #2 ⭐ AlphaProof Nexus 解出 9 个未解埃尔德什问题登《科学》，走完同行评审

> **来源**：[Google DeepMind（Science 论文）](https://www.science.org/) / [The Decoder](https://the-decoder.com/) / [腾讯新闻](https://news.qq.com/rain/a/20261013A03QWZ00) | **评分**：9.0/10 | **标签**：形式化证明·Lean·学术规范

#### 核心事件
Google DeepMind 于 10 月 12 日在《科学》（Science）发表 AlphaProof Nexus 的成果：系统从 353 个未解埃尔德什（Erdős）问题中解出 **9 个**，其中两个已悬置 **56 年**；此外证明了 OEIS 整数序列数据库中的 **44 个猜想**，回答了一个代数几何的开放问题，并改进了 min-max 优化中的一个已知界。关键在于它**走完了同行评审**——这与同期 OpenAI 把数百份 AI 生成的证明直接放到 GitHub、引来陶哲轩等牵头的「人类数学协会」抵制形成直接对照。

系统以 **Gemini 3.1 Pro** 为底座，用形式化语言 Lean 起草与修订证明，Lean 逐稿校验、把报错喂回下一轮，遇到难题时才调用专门的证明工具 AlphaProof。DeepMind 称即便不调用 AlphaProof，那 9 个埃尔德什问题也能解出。团队还公开了机器可读的 Lean 证明文件与失败案例的形式化，让外部研究者可以本地跑 Lean 自行核验。

#### 技术亮点 / 影响分析
- **「九」的分母是 353**：约 2.5% 的命中率说明这套方法只在开放问题的一个薄片上有效，另外 344 个仍未解出。这个边界让研究更可信，也划清了能力范围——不是「AI 能解著名猜想」，而是「在形式化良好、可机械校验的子集上能出结果」。
- **Lean 把「听起来对」变成「可机检」**：大模型写数学最大的风险是跨页的隐蔽逻辑错误，Lean 编译器逐稿校验让错误变成下一步搜索的反馈信号，机制上和编码智能体靠编译器 / 测试迭代是一样的。
- **发表时间点本身就是论点**：OpenAI 因跳过评审遭抵制、DeepMind 走完评审登刊，两者的发表伦理被摆在同一周对比。「发表规范」正在成为实验室之间的竞争维度，而不只是学术圈的洁癖。
- **值得注意的冷事实**：论文里用的是 2025 年 2 月发布的 Gemini 3.1 Pro，不是最新旗舰——谷歌把稳定可复现的上一代交给前沿科研。

#### 三句话总结
1. AlphaProof Nexus 解出 353 个未解埃尔德什问题中的 9 个（两个悬置 56 年），并证明 44 个 OEIS 猜想。
2. 成果经《科学》同行评审后发表，与 OpenAI 跳过评审遭数学界抵制形成鲜明对照。
3. 对 CODM 宣发团队：这套「生成器 + 机械校验器 + 报错回流」的闭环，正是 AI 批量出图 / 出视频时最该补的一环——先定可机检的验收规则（构图、配色、LOGO 安全区、字体版权），再让模型按报错迭代，比靠人眼挑图更可控。

### #3 ⭐ Grok、Cursor、X Premium 合并为 The X Subscription，五档 8 至 200 美元共享用量池

> **来源**：[xAI 官方（x.ai/news/x-subscription）](https://x.ai/news/x-subscription) / SpaceXSI 官方 X / [Cursor 官方](https://x.com/cursor_ai) / Lauren Tan / Eric Zakariasson | **评分**：8.9/10 | **标签**：订阅整合·入口·编码智能体

#### 核心事件
SpaceXSI 于 10 月 12 日推出 **The X Subscription**，把 Grok、Grok Bot、Cursor 与 X Premium 四条产品线合并成一个订阅，分 Free / Plus / Premium / Super / Ultra 五档，价格为 **0 / 8 / 30 / 100 / 200 美元每月**。付费档共享一个 Grok 模型用量池，横跨 Grok 应用、X 上的 Grok 标签页与 Cursor，一边没用完的额度可以挪到另一边。30 美元的 Premium 档打包了此前合计约 90 美元的 SuperGrok + Cursor Pro + X Premium+ 权益；Super 与 Ultra 则是 Plus 用量的 15 倍与 50 倍。

老用户不受影响——现有 SuperGrok、Cursor 与 X Premium 订阅的价格与权益原样延续，想迁移的用户会在账单设置里看到切换选项，并附按比例退款与限时升级优惠。团队与企业侧按同等单人价格提供 Premium / Super / Ultra，附带 SSO、管理后台、合并计费与 SOC 2 合规。

#### 技术亮点 / 影响分析
- **把「编码智能体」塞进大众社交订阅**：Cursor 是开发者最值钱的入口之一，把它并进一个面向大众的社交平台订阅，是相当反常规的一步。SpaceXSI 称每个 X Subscription 档位都包含至少两倍于同档 Cursor 计划的编码用量，第三方模型在 Premium 及以上仍可按 API 原价另计。
- **共享用量池是核心卖点**：跨产品共享额度让用户不必为「这个月写代码多还是聊天多」做预算决策，实质是把三条独立账单压缩成一条——对重度用户是实打实的简化，对轻度用户则是被抬到 30 美元门槛。
- **与 10 月 1 日 Grok Bot 编码工具扩展形成连续动作**：过去一个月 Grok Bot 一直在往 Cursor 里插得更深，这次订阅合并是同一条线的收口。
- **待观察**：官方只用「倍数」描述用量，没有给出 Plus 档具体对应多少请求或 token；App Store 与非美国地区定价是否不同也未说明。

#### 三句话总结
1. Grok、Grok Bot、Cursor、X Premium 合并为 The X Subscription，五档从免费到 200 美元，共享模型用量池。
2. 30 美元档打包了此前合计约 90 美元的三项订阅，Cursor 这个开发者入口被并进大众社交订阅。
3. 对 CODM 宣发团队：如果团队已在用 Cursor 或 Grok，合并订阅能省掉一份账单并把用量在聊天与编码之间调度；但要先算清「Plus 用量倍数」到底折合多少次生成，别按旧价格线性外推预算。

### #4 ⭐ 微软发布自研推理芯片 Maia 300，2027 年起多吉瓦部署成自家主力推理系统

> **来源**：[Microsoft 官方博客（Scott Guthrie）](https://blogs.microsoft.com/) / [Reuters](https://www.reuters.com/) / [CNBC](https://www.cnbc.com/) / [The Verge](https://www.theverge.com/) / IT之家 | **评分**：9.2/10 | **标签**：自研芯片·推理·去英伟达化

#### 核心事件
微软在 10 月 12 日于圣何塞开幕的 **OCP 全球峰会**上发布第三代自研 AI 芯片 **Maia 300**，并宣布从 2027 年起把 Maia 家族扩展到**多吉瓦级部署**、成为「微软产品与服务的主力推理系统」。云与 AI 执行副总裁 Scott Guthrie 表示，Maia 300 相比领先的 GPU 系统每兆瓦可多产出 **40% 的 token**；单机架 96 颗芯片、167 千瓦功耗，机架级 token 吞吐最高达 Maia 200 的 **7 倍**，性能功耗比提升超 2.5 倍。路透社报道称微软明年可能部署超过 100 万颗该芯片。

规格上，Maia 300 采用 chiplet 设计，计算芯片粒用台积电 **N2P** 工艺（上代 Maia 200 为 3nm），每颗配 **8 栈 HBM4**，峰值带宽 **18 TB/s**，容量 288 GB，整颗功耗 950 瓦；单机架聚合 27.6 TB HBM 容量与 1.7 PB/s 带宽，最多 128 个机架可通过以太网互联成 12,288 颗芯片的系统。芯片面向长上下文推理、低延迟对话与智能体多步任务，支持增强版 MXFP4 低精度与高速张量并行互联。

#### 技术亮点 / 影响分析
- **「数据搬运而不是算力」被点名为瓶颈**：Guthrie 的原话是「在大型推理系统里，高效搬运数据正日益成为瓶颈，而非原始算力」。设计上用软件定义数据流 + 片上 SRAM 作「软件管理的暂存区」+ AI 辅助内核优化，尽量少碰 HBM。
- **Maia 200 已在扛生产流量**：已在美、欧、澳部署，服务 Copilot、OpenAI 模型与微软自研 MAI 模型，GitHub Copilot 与 Microsoft Foundry 年底跟进；Guthrie 称其在 Teams / Copilot / Cowork 的内置 AI 功能上比领先 GPU 基础设施每瓦多产出最高 1.7 倍 token。
- **「不出租」是个关键差异**：与谷歌 TPU、亚马逊 Trainium 不同，Maia 不能按小时租给外部公司 —— 它是纯粹的成本项而非收入项。Evercore ISI 估计到 2027 年一季度 Maia 约占微软 AI 芯片支出的 10%。
- **对照信号**：同场峰会期间，英特尔 CEO 陈立武与博通 CEO 陈福阳双双警告**资金短缺**可能成为 AI 发展的最大瓶颈；SemiAnalysis 创始人则称算力需求仍远超供给、基础设施规模被低估。一边扩产一边喊钱不够，是本周基建叙事的一体两面。

#### 三句话总结
1. 微软发布 Maia 300（N2P 工艺、8 栈 HBM4、18 TB/s、950W），2027 年起多吉瓦部署并成为自家主力推理系统。
2. 设计目标是每兆瓦多产出 40% token、机架级吞吐为 Maia 200 的 7 倍，且不对外出租，纯为降本。
3. 对 CODM 宣发团队：推理成本直接决定 AI 批量出图 / 出视频的边际成本——云厂商自研芯片把 token 单价往下压，意味着明年同预算可支撑的素材产量会明显上升，值得在年度预算里预留这块弹性。

### #5 ⭐ Epic 对迪士尼项目下达「不再手写代码」AI-first 指令，漫威 × 星战射击游戏无限期延期

> **来源**：[Bloomberg（Jason Schreier）](https://www.bloomberg.com/) / [Ars Technica](https://arstechnica.com/gaming/2026/10/report-epic-games-goes-all-in-on-ai-for-disney-collaboration) / [Eurogamer](https://www.eurogamer.net/) / [Dexerto](https://www.dexerto.com/) / [Rock Paper Shotgun](https://www.rockpapershotgun.com/) | **评分**：8.8/10 | **标签**：游戏开发·AI-first·虚幻引擎

#### 核心事件
Bloomberg 10 月 12 日报道，Epic Games 对与迪士尼合作的那款未公开射击游戏下达了「**AI first**」生产指令：开发者被告知「**不再手写代码**」（no more hand-written code），全部美术资产「**用完整 AI 工作流生成**」，人类开发者转为管理与引导以 Claude 为代表的模型产出。这款融合漫威与星战角色的游戏原定 2027 年 3 月发售，现已**无限期延期**。Bloomberg 归因于 AI 转型叠加人手不足与开发进度慢于预期。

Epic 发言人 Jake Jones 对 Bloomberg 表示「我们正在拥抱 AI 加速开发，由 Epic 的开发者主导，他们是所有工作的愿景与创意驱动者」，对「AI first」的说法做了柔化。CEO Tim Sweeney 在 X 上称「Epic 正在进行一场大规模转向，重组开发者以最大化 AI 加速」，目标是「让每个人做得更多更好，而不是用更少的人做同样的事」，并把收益外溢到所有使用 Unreal 的团队。

#### 技术亮点 / 影响分析
- **这是行业最高规格的一次「AI 替换而非辅助」试验**：此前两年行业主流是人写、AI 辅助；Epic 把比例倒过来——机器产出、人类品控。GDC 前的调研显示 2300 多名从业者中 36% 已用生成式 AI，但多用于研究与头脑风暴（81%），用于代码辅助的仅 47%、原型 35%。
- **内部反弹与行业情绪**：报道称部分开发者在 10 月初的视频会议上当场质疑「AI 生成内容带来的错误怎么修」，也有人怀疑这套打法能否达到预期。Sweeney 的回应「房间里的很多人想回到 2016 年，但回不去了」在社区引发强烈反弹。背景是 Epic 3 月刚裁员超 1000 人，理由之一是 Fortnite 参与度下滑。
- **选了通用模型而非游戏专用系统**：内部消息点名的是 Anthropic 的 Claude——一个以编码与企业工作见长、而非游戏美术管线的模型。这说明 Epic 押注的是通用模型当生产中台，而不是自研游戏专用生成器。
- **对引擎厂商的外溢效应**：Epic 同时是 Unreal Engine 的提供者，其内部实践往往预示它准备给全行业塞什么工具。若这次试验能出可发售品质的成品，它会成为所有发行商引用的样板；若烂尾，则是反面教材。

#### 三句话总结
1. Epic 对迪士尼合作射击游戏下达「不再手写代码」的 AI-first 指令，全部美术走完整 AI 工作流，项目从 2027 年 3 月延期为无限期。
2. 这是头部工作室首次在旗舰项目上把 AI 从「辅助」翻转为「主要生产者」，人类转为品控，内部与社区均有明显反弹。
3. 对 CODM 宣发团队：这条最值得盯的是**验收机制**——Epic 的争议点恰恰是「AI 产出谁来验证」。宣发素材走 AI 全流程时，必须先建可量化的质检清单（品牌色偏差、字体版权、LOGO 安全区、人物一致性）并留人工终审位，否则效率换来的会是返工与合规风险。

### #7 ⭐ Arena 完成 2 亿美元 B 轮、估值 31 亿美元，同步推出智能体对齐指数

### #8 阿里千问发布 QwenGyre：面向超长程智能体的弹性强化学习框架

> **来源**：[Qwen 官方 X](https://x.com/Alibaba_Qwen) / [arXiv 论文](https://arxiv.org/) / [MarkTechPost](https://www.marktechpost.com/) / [IT之家](https://www.ithome.com/) | **评分**：8.2/10 | **标签**：强化学习·长程智能体·训练基础设施

#### 核心事件
阿里千问团队本周发布 **QwenGyre**，一个面向「超长程（XLong-horizon）」智能体任务的在线强化学习框架。它针对的场景是一次执行持续数小时、模型与环境数百轮交互、单次 rollout 累计消耗 **70 万到约 100 万 token** 的重型任务（如用自然语言规格生成整个代码仓库）。论文由阿里 Token Hub 与中国科学技术大学、清华大学合作，本周挂在 arXiv。

框架有两个核心机制：**Elastic Scheduler** 把 GPU 切成若干共享训练布局的计算单元，任务每结束一批、空出的单元就转入训练，仍在跑的任务不受打扰、KV 缓存经 RDMA 整体迁移不必重算；**Trajectory Processor** 把智能体压缩上下文、派生子代理、失败重试产生的分叉历史组织成共享前缀的**轨迹树**，去重后只展开被选中的路径，并对超时但部分完成的任务做 Partial Scoring 保留奖励信号。

#### 技术亮点 / 影响分析
- **实测数据**：在 Qwen 3.8 2.4T 上（192 节点、4 个各 48 卡的单元），48 步训练耗时 **75.42 小时**，对比 Colocate 的 91.47 小时与 Async 的 134.55 小时，端到端加速 1.21×~1.85×；NL2RepoBench 通过率从 **52.48% 提升到 58.54%**。在 Qwen 3.6 122B 上跨 DeepSWE、TerminalBench 等任务同样取得端到端提速。
- **角色切换成本低**：rollout 转训练平均 8.52 秒、反向 3.46 秒；每条执行最多保留 5 条轨迹，分数与不设上限持平，但前后向时间减少 25.2%。
- **对黑盒 harness 友好**：框架通过未经修改的黑盒 harness 工作，不需要为训练循环重写智能体脚手架——这对训练「Claude Code 这类改不动的外部工具」上的智能体是关键设计。
- **⚠️ 尚未开源**：论文未附公开代码、未披露许可证，也未说明 GPU 型号。同赛道的 veRL、AReaL、Agent Lightning 均为 Apache-2.0 或 MIT 开源——这是 QwenGyre 目前最大的短板，效率主张暂无法由第三方复现。

#### 三句话总结
1. 阿里千问发布 QwenGyre，用弹性 GPU 调度 + 轨迹树去重解决超长程智能体（单次 rollout 约 70 万 token）的强化学习训练效率问题。
2. 实测在 Qwen 3.8 2.4T 上比 Async 快约 1.78×，NL2RepoBench 通过率从 52.5% 提到 58.5%，但论文未开源。
3. 对 CODM 宣发团队：价值在于方法论而非直接用——「把长任务的分叉历史去重后再喂训练」和「超时但部分完成也给分」这两条，可直接迁移到宣发智能体的任务设计里，避免长流程素材生成因中途失败而整条作废。

## 编辑点评

今天八条里有三条在同一天做了同一件事：**把最好的东西收进自己的围墙**。Meta 的最强档不卖 API 只给订阅户，微软的推理主力要换成自研芯片且不对外出租，马斯克把三个订阅合成一个共享用量池。开放曾是这轮 AI 浪潮的默认姿态，现在它正在变成一种需要理由的例外。

围墙外面，「验收」被单独拎出来做成了一门生意：DeepMind 把 AI 证明送进《科学》走完同行评审，Arena 估值十个月翻倍到 31 亿并推出专查智能体「越权、谎报完成、错误归因」的对齐指数。前者在争学术规范的话语权，后者在卖企业侧的信任度量——它们指向同一个判断：**当产出变得廉价且量大，价值会向「可信的验收」转移**。

游戏这条最该被读出弦外之音。Epic 的「不再手写代码」不是效率新闻，是责任结构新闻：当生产主体从人换成模型，争议的落点永远是「谁来验」。

**四条可执行线索**：
1. **验收清单前置**：照抄 Arena 的三类失当（未授权行为 / 欺骗性完成 / 错误归因），给宣发智能体建一份可机检的交付清单——LOGO 安全区、品牌色 ΔE、字体版权、人物一致性，逐项过。
2. **闭环替代人眼**：参考 AlphaProof 的「生成器 + Lean 编译器 + 报错回流」，把宣发素材生成接上可机检规则（构图检测、OCR 文字核对、色值比对），让模型按报错自动迭代，而不是靠人一张张挑。
3. **按 Wonder 不是 Wonder Full 做预算**：Meta 最强档不开放 API，走 API 只能用到 52 分的标准版；素材质量上限要按标准版评估，别按发布会的 56 分规划排期。
4. **盯国产异构算力**：无问芯穹已覆盖 16 种芯片、异构混训利用率 97.6% 且有文娱游戏行业方案，可作为大批量素材生成迁到国产算力的备选路径，纳入技术选型观察。
