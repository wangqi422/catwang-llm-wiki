## §1 AI 模型 & Agent

### #1 ⭐ DeepSeek Harness v0.1 开源：24 小时狂揽 3.3 万星，「一切皆插件」改写 Agent 底座

> **来源**：DeepSeek 官方 / 每日经济新闻 | **评分**：9.3/10 | **标签**：`Agent` `开源` `中国AI`

#### 核心事件

北京时间 8 月 13 日晚，DeepSeek 正式发布并开源首个智能体运行框架 **DeepSeek Harness（DSH）开发者预览版 v0.1**，以 MIT 协议开放全部源码。官方将定位凝练成一句公式「模型 + Harness = Agent」——模型负责思考，Harness 负责执行。其核心设计哲学是「一切皆插件」：模型、工具、技能、会话、沙箱、存储、循环、调度、UI 等所有 Agent 能力均由插件组合而成，可自由替换、灵活重组。项目上线半小时 GitHub 星标破万，24 小时超 3.3 万星，Hacker News 单日 572 分，登顶 GitHub Trending 榜首。

#### 技术亮点 / 影响分析

- **基于 Cordis 元框架的「乐高式」架构**：Cordis 只负责插件的加载/卸载与依赖关系，Harness 所有业务组件都是独立插件，通过服务与事件机制协作，开发者无需改源码即可在配置层自由拼装
- **四种运行模式适配不同场景**：标准模式（完整工具集）、PTC 模式（程序化工具调用，模型生成代码编排多轮工具链）、极简模式（仅 shell + 文件编辑，用于最小环境基准测试）、创造模式（检查运行时、内存调试插件、自定义新模式）
- **「执行层」卡位战打响**：紧随 V4 Pro 正式版上线，DeepSeek 从单纯提供基座模型与 API，正式进入 Claude Code、Codex 所在的 AI 编程执行层竞争，且走「模型无关」的开放路线区别于 Codex 闭源黑盒

#### 三句话总结

1. DeepSeek Harness v0.1 以 MIT 协议开源，24 小时狂揽 3.3 万星，「一切皆插件」架构让模型/工具/沙箱/UI 全部可插拔重组
2. 基于 Cordis 元框架提供标准/PTC/极简/创造四种模式，补齐 Vibe Coding 入口，正式对标 Claude Code 与 Codex 的执行层
3. 对 CODM 宣发团队：MIT 协议的开源 Agent 底座意味着可自建「宣发素材批量生成/竞品监测」内部 Agent，不依赖单一闭源平台，二次开发门槛大幅降低

### #2 ⭐ 智谱 GLM-5.3 发布：基座没变靠后训练 Scaling，编程能力开源第一

> **来源**：智谱官方 / 钛媒体 | **评分**：9.0/10 | **标签**：`模型发布` `编程` `中国AI`

#### 核心事件

8 月 14 日，智谱正式发布新一代基座模型 **GLM-5.3**，总参数规模 7430 亿，在编程能力与复杂工程执行上取得突破，公开基准测试取得开源第一。最让人意外的是技术路径：官方明确表示「与 GLM-5.2 相比，基座模型没变，但通过极致的后训练 Scaling 大大提高了模型的智能上界」。此前 8 月 3 日 ZCode 官网曾短暂上线「ZCode for GLM-5.3」页面造成「意外泄露」，智谱股价当日涨超 8%，随后高盛上调其收入预期 35%。

#### 技术亮点 / 影响分析

- **「不重训基座、只做后训练」的激进路线**：在 7430 亿参数基座不变的前提下，通过数十倍的长程任务环境、更丰富的环境类型与超长后训练时间压出能力跃升，为「后训练 Scaling」提供了一次大厂级验证
- **编程 + 网安双突破**：白盒代码审查与漏洞推理等安全任务表现接近 Mythos 5，网络安全防御能力亮眼，Cybersecurity 能力成为开源模型的新竞争维度
- **开源第一的标杆意义**：继 GLM-5.2 拿下 Artificial Analysis 开源最佳后，5.3 进一步巩固「国产开源编程最强」心智，直接施压同档开源与闭源竞品

#### 三句话总结

1. 智谱 GLM-5.3 正式发布，7430 亿参数，基座不变靠极致后训练 Scaling，编程能力开源第一
2. 编程 + 网络安全双突破，白盒代码审查接近 Mythos 5，验证「后训练 Scaling」的可行路径
3. 对 CODM 宣发团队：GLM-5.3 的高性价比编程能力适合脚本化宣发任务与批量代码生成，可纳入内部工具链选型，降低外部 API 依赖

### #3 ⭐ OpenAI 预览 GPT-5.6 Sol Ultrafast：Cerebras 加持 14 倍速、750 token/s

> **来源**：OpenAI 官方 / 新智元 | **评分**：8.8/10 | **标签**：`模型发布` `推理` `前沿竞赛`

#### 核心事件

OpenAI 预览 GPT-5.6 Sol 的 **Ultrafast 模式**，借助 Cerebras 晶圆级硬件加速，推理速度最高提升 14 倍，生成速度可达 **750 token/s**，大幅压缩实时 Agent 工作流的响应延迟。该模式主要面向实时语音 Agent、客服、高频金融研究、自动化编码循环等对低延迟有刚性需求的场景，先向部分企业客户通过 OpenAI API 灰度开放，后续再扩大范围。同时 GPT-5.6 系列最小模型成本大幅下降，ARC-AGI-3 性能同步提升。

#### 技术亮点 / 影响分析

- **「推理速度」成为新的军备竞赛维度**：从拼参数、拼上下文转向拼「每秒吐多少 token」，750 token/s 意味着语音对话、实时交互体验接近人类反应速度
- **晶圆级硬件进入推理主战场**：Cerebras 的 wafer-scale 架构首次在 OpenAI 前沿模型推理侧大规模落地，「异构算力」从训练延伸到推理
- **「速度即体验」的产品逻辑**：Ultrafast 直指实时性强的企业应用，推理延迟的下降会直接改写 Agent 的可用性边界与用户留存

#### 三句话总结

1. OpenAI 预览 GPT-5.6 Sol Ultrafast 模式，借 Cerebras 晶圆级硬件实现 14 倍速、750 token/s 生成
2. 推理速度成为新竞争维度，晶圆级硬件从训练切入推理，实时语音 Agent、客服等场景率先受益
3. 对 CODM 宣发团队：实时性强的生成任务（语音互动、实时文案、直播辅助）将更划算，可关注低延迟推理带来的「实时 AIGC」宣发玩法

### #4 ⭐ Google Gemini 3.7 Flash 发布：Agent 主力模型降价 50%，DeepMind 换帅反击

> **来源**：Google DeepMind / 新浪财经 | **评分**：8.7/10 | **标签**：`模型发布` `Agent` `前沿竞赛`

#### 核心事件

8 月 14 日，Google 正式发布 **Gemini 3.7 Flash**，定位「编码与 Agent 的最智能主力模型」，支持 1M token 多模态上下文（文本/图像/视频/音频/PDF），配备可配置的三档思考模式（低/中/高），并支持函数调用、代码执行、computer use（预览）、文件搜索、结构化输出等 Agent 能力。为加速普及，年底前输入价格降至每百万 token 0.75 美元、输出 3.75 美元，仅为 Gemini 3.6 Flash 原价的一半。该发布距离 3.6 Flash 仅三周，背后是 DeepMind 史上最大规模领导层重组：哈萨比斯退居二线、科拉伊·卡武克丘奥卢接棒，联合创始人谢尔盖·布林亲自督战。

#### 技术亮点 / 影响分析

- **「workhorse」定位的务实转向**：官方口径「真实世界的工作跑在主力模型上」，谷歌优先补强量产的 Agent 中坚层，而非追逐前沿能力跳跃，承认在绝对前沿上暂时落后于 Anthropic 与 OpenAI
- **三档思考模式的可调节推理**：低/中/高思考档让开发者在延迟、成本与多步规划深度之间按任务复杂度取舍，是生产系统应对异构任务的关键杠杆
- **换帅 + 布林督战的战略信号**：领导层重组与联合创始人亲自下场，标志着谷歌从「防守」转向「反击」，Gemini 3.5 Pro 旗舰仍是市场检验其能否追平的关键标的

#### 三句话总结

1. Google 发布 Gemini 3.7 Flash，1M 多模态上下文 + 三档思考模式，定位编码与 Agent 主力模型，API 降价 50%
2. 距离上代仅三周，背后是 DeepMind 换帅 + 布林督战，谷歌从防守转反击，旗舰 Gemini 3.5 Pro 仍是关键考验
3. 对 CODM 宣发团队：Gemini 3.7 Flash 的多模态与 Agent 能力 + 半价，适合多模态素材理解与自动化工作流，可作为谷歌生态内的性价比主力选项
