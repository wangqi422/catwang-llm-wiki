## 1. 算力路标 & 巨头转向

### 1. NVIDIA Kyber NVL144 推迟 12+ 月到 2028 + NVL72x2 取消:Rubin Ultra 4-die 版砍掉,AMD MI500X/谷歌 TPUv8i 获窗口

**关键信息**:
- **核心延期**:SemiAnalysis 7/5 盘前 6 条连续推文披露,英伟达下一代旗舰机架 Kyber NVL144 推迟超过 12 个月至 2028 年;距 GTC 2026 展示仅 3 个月,直接打掉客户对 2026 内交付的预期
- **PCB 背板成卡点**:高速高密度大尺寸正交背板(Orthogonal Backplane)良率与量产能力不及预期,SemiAnalysis 称这是"工业可制造性"的硬瓶颈,不是设计问题
- **NVL72x2 取消**:原计划用两个 Oberon 机架背靠背纯铜方案扩大 NVLink 扩展域,因 CSP 集体反对"设计怪异 + 运维负担重"被取消
- **Rubin Ultra 缩水**:4-die 版被砍,仅保留 2-die 版,实际性能预计减半;CPO NVSwitch 路线图明确要等到 Feynman 世代
- **窗口期给到 AMD + 谷歌**:SemiAnalysis 点名 AMD MI500X 与谷歌 TPUv8i 在"纵向扩展域规模"上获得相对优势期
- **英伟达应对**:不砍出货,反而大幅增售现有 Oberon 架构 Rubin 机架"以量补质",供应链(内存/PCB/ODM)将受影响
- **来源** SemiAnalysis 7/5 / 雪球盘前 / 东方财富 / 华尔街见闻 / X: @SemiAnalysis_

**AIGC 速报解读**:这是 2026 H2 **最具结构性影响**的一条新闻。Rubin Ultra 4-die 版被砍 + CPO 推迟到 Feynman = 英伟达在 2026-2027 年内**没有成熟方案扩大 Rubin Ultra 的 scale-up 规模**,意味着所有押注"等 Rubin Ultra 落地再扩集群"的 AI 实验室都要重新规划训练计划。直接受益的是 AMD MI500X(2027 Q1 量产)与谷歌 TPUv8i(2027 中)——这两家的纵向扩展域(从 72 卡扩到 144/576 卡)在英伟达"跛脚"的窗口里获得至少 6-12 个月的相对优势。**对 CODM 团队**:如果使用 AMD GPU 训练 LoRA / 微调 SDXL / CogVideoX,2027 年起算力价格有望下降 20-30%;如果押注 NVIDIA 路线,需准备"双机柜 + Oberon 替代"过渡方案。

### 5. HBM 之父金正浩:AI 本质是内存,GPU 利用率仅 10-30%,10 年后 HBF 超 HBM,终极 100 层 3D 复合架构

**关键信息**:
- **核心断言**:韩国 KAIST 电气系教授金正浩(HBM1 2010 年起与 SK 海力士共同研发)7/5 受访《东亚日报》表示"AI 核心竞争力正从 GPU 转向内存"
- **GPU 利用率真相**:每次 AI 输出都要从 HBM 读数据 + 传 GPU 算 + 写回,就算部署 100 万块 GPU,真正用于计算时间仅 10-30%(行业普遍认知是 30-50%)
- **训练→推理范式转移**:训练时代 GPU 是核心,推理时代"决定性能的是一次能处理多少数据、多快处理",内存能力将直接决定 AI 性能
- **三阶段内存路线**:
  - 阶段一 HBM(当前):HBM4 开始不再是标准产品,客户定制化生产,卖方决定价格
  - 阶段二 HBF(10 年内):堆叠 NAND 闪存,容量超 HBM,适合视频/文档/长期记忆等冷数据
  - 阶段三 HBS(更远未来):高带宽 SRAM,比 DRAM 快 1000 倍
- **终极架构**:HBM 商场 + HBF 住宅 + HBS 缓存,组合成约 100 层的 3D 复合架构,GPU 在顶层负责散热
- **市场影响**:三星 + SK 海力士合计营业利润预计 500-600 万亿韩元(超英伟达),黄仁勋频繁访韩"坐立不安"
- **来源** 东亚日报 / IT之家 / 量子位 / 新浪财经

**AIGC 速报解读**:这是 **2026 H2 最重要的"范式判断"之一**——HBM 之父亲自宣告"AI 价值单位从 GPU 转向内存"。结合 7/5 同期发生的英伟达 Kyber 推迟(SemiAnalysis)和 SK 海力士 294 亿美元 IPO,**三件事形成完美因果链**:① Kyber 推迟 = 英伟达"卡脖子"做不出来 = 内存瓶颈是真的;② SK 海力士 IPO = 资本市场承认"内存即 AI 货币";③ HBM 之父受访 = 学术界盖章"未来是 3D 复合内存架构"。**对 CODM 团队**:① 2026 H2 起,采购 NVIDIA GPU 时,内存带宽(HBM3e / HBM4)比算力(FLOPS)更重要——推理侧业务(AI 客服 / NPC 对话 / 实时翻译)尤其敏感;② 关注 8-9 月三星电子 Q2 财报,如果 HBM4 业务首次披露,可能引发"内存股 vs GPU 股"估值再平衡。

### 6. Google 工程负责人 Addy Osmani 开源 agent-skills:24 个工程技能 + 7 阶段生命周期,GitHub 5.9 万星

**关键信息**:
- **项目身份**:agent-skills,Addy Osmani(Google Chrome 首席工程师,Google Cloud AI Director)开源,MIT 许可,6.30 公开后 6 天达 5.9 万 star
- **核心理念**:把"资深工程师的内隐判断"编码为 24 个结构化 skill,让 AI 编程 Agent 强制走"先写规格→拆任务→逐块构建→测试→审查→简化→上线"七阶段
- **6 阶段生命周期**:**DEFINE → PLAN → BUILD → VERIFY → REVIEW → SHIP**;8 个 slash 命令入口(/spec、/plan、/build、/test、/review、/code-simplify、/ship、/build auto)
- **反借口表格**:每个 skill 配"rationalization table",针对 AI 写代码时"这很简单不需要 spec / 写完再补测试 / 简单实现回头优化"等借口做反制
- **融合 Google 工程实践**:Hyrum's Law、测试金字塔、主干开发、doubt-driven-development(对抗性复盘高代价决策)、source-driven-development(要求框架决策引用官方文档)
- **兼容性**:Claude Code / Cursor / Gemini CLI / Codex / Windsurf / OpenCode / GitHub Copilot 全兼容
- **来源** X: @addyosmani / GitHub: addyosmani/agent-skills / slash-invest / 51CTO / colobu

**AIGC 速报解读**:agent-skills 不是"AI 帮你做事",而是"AI 怎么做事"——**反直觉设计**:大多数 skill 帮 AI 完成具体任务(写测试 / 调试 / 审查),agent-skills 强制 AI 跳过"用最短路径"默认行为,像资深工程师一样工作。这与 7/5 Anthropic 工具调用倒退(Opus 4.8 + Sonnet 5 在非主流 schema 上更不可靠)、7/5 SemiAnalysis"harness 本质是上下文编排"形成呼应——**AI 编程赛道的下半场是"工程纪律 / Harness 治理 / 反自我欺骗"**,不是"模型更强"。**对 CODM 团队**:① 把 agent-skills 作为标准插件装到 Claude Code / Cursor,7-8 月起所有 AI 生成代码都强制走 7 阶段;② 关注 8 月 Claude Code v2.2 是否内置类似"工程纪律"——如果内置,agent-skills 可能演化成"Claude Code 官方版"。

### 7. Amazon Mechanical Turk 7/30 起停接新客户:21 年众包平台进入"维持模式",33-46% 工人已被 LLM 替代

**关键信息**:
- **平台落幕**:Amazon 7/5 宣布 Mechanical Turk(MTurk)7/30 起不再接受新客户,现有客户可继续使用,但 AWS 不再开发新功能,平台进入"Services in Maintenance"内部清单
- **21 年历史**:MTurk 2005 年 11 月上线,曾用于 CAPTCHA / 情感分析 / 调查问卷;2018 年被并入 SageMaker 作为 AI 训练数据标注流水线
- **数据完整性崩塌**:2023 年学术研究显示 MTurk 上 33-46% 工人已使用 LLM 完成"人类智能任务",意味着平台本身已成为"数据污染源"
- **关联事件**:7/1 Uber 裁掉 AI 数据标注部门 Uber AI Solutions 两位资深领导(Naga Kasu / Pankaj Kamat),Scale AI 因与 Meta 关系受质疑
- **替代方案**:AWS SageMaker Ground Truth(亚马逊自营,审核更严) + Scale AI + Surge AI 等"可审计"数据标注服务
- **Reddit 高赞评论**:"这平台好几年前就死了"
- **来源** TechCrunch 7/5 / X: @rohanpaul_ai / mezha.net / 网易科技 / startupfortune

**AIGC 速报解读**:MTurk 落幕是 **AI 时代最具讽刺意味的"劳工范式转移"**——一个靠"真人假装成 AI"完成任务维持运转的平台,最终被"真人用 AI"反噬;同时它自己曾为 AI 训练提供数据,现在它自己已无法产生"干净的人类数据"。结合 7/2 扎克伯格"AI 智能体没我想的快"、7/1 Uber 裁数据标注部门、Scale AI 因 Meta 投资受质疑——**整个 2025-2026 "人类数据标注"产业链正在快速崩塌**,高质量 RLHF / DPO 数据被推到"专业 + 可审计"少数供应商手中。**对 CODM 团队**:① 如果 CODM CG / PV 制作依赖 MTurk 类平台做"群众演员表情 / 多语种台词标注",8 月起需切换到 Scale AI / Surge AI 等更严的供应商;② CODM 内部若用 RLHF 微调专属模型(如代言人音色 / 角色语气),需评估"训练数据来源是否会被自己训练的模型污染"。
