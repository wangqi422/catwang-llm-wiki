### #1 ⭐ OpenAI 首款自研芯片 Jalapeño 首秀：吞吐/能效/延迟全面超英伟达 GB300

> **来源**：OpenAI 官方 / SemiAnalysis / IT之家 | **评分**：9.5/10 | **标签**：`自研芯片` `推理` `硬件`

#### 核心事件

OpenAI 在 Hot Chips 大会上公布首款自研推理 ASIC **Jalapeño** 首批实测成绩，与博通（Broadcom）联合开发，在吞吐、能效、延迟三项指标上**全面超越英伟达 GB200 与 GB300**。Jalapeño 标称功耗仅 **700W**（约为 GB300 1400W 的一半），采用台积电先进制程 + HBM4（216 GiB / 15.4 TB/s 带宽）。在 SemiAnalysis 的 InferenceX 基准上：GPT-OSS 120B 单用户出词速度 **1459 tokens/s**（GB200 的 2.7 倍）；DeepSeek R1 670B 端到端延迟 **1.65 秒**（GB300 的 5.99 秒）；三款模型整体**每瓦 AI 吞吐提升 1.5~1.9 倍**。从设计到流片仅用 **9 个月**，过程中大量使用 Codex 辅助设计——SIMD 单元面积减少 8%、矩阵引擎面积减少 10%。

#### 技术亮点 / 影响分析

- **英伟达 CUDA 护城河首现裂缝**：这是头部 AI 客户用自研芯片公开挑战英伟达推理垄断的第一次，SemiAnalysis 直言"它击败了我们能测到的每一款英伟达/AMD/谷歌芯片"，算力格局进入"GPU + ASIC 多路线并存"时代
- **700W 打 1400W = 每瓦效率的碾压**：Jalapeño 每芯片每小时总拥有成本约 1.56 美元，与 H100 持平、远低于 Vera Rubin 的 3.61 美元——推理成本是决定性变量
- **AI 造 AI 芯片的闭环成型**：Codex 参与内核编写与优化，部分注意力/MoE 模块 AI 生成的内核比人类专家快 1.5~1.8 倍，9 个月流片周期显著短于业界 18-36 个月

#### 三句话总结

1. OpenAI 首款自研推理芯片 Jalapeño 首秀，700W 功耗下吞吐/能效/延迟全面超英伟达 GB300，DeepSeek R1 延迟 1.65s vs 5.99s
2. 英伟达 CUDA 护城河首次被头部客户自研 ASIC 公开挑战，算力进入"GPU + ASIC 多路线并存"时代；量产预计 2027 年，下一代已进入制造
3. 对 CODM 宣发团队：推理芯片每瓦效率跃升意味着 AI 素材生产成本的中长期下探；"AI 辅助造芯片"的 9 个月流片闭环，也印证宣发产线"AI 提效 AI 工具"的可行性

### #2 ⭐ OpenAI 曝完成 Bel 模型预训练：超 10T 参数，冲击 AGI 阈值

> **来源**：IT之家 / DoNews / 新浪（X 消息源 @synthwavedd） | **评分**：8.0/10 | **标签**：`AGI` `模型` `传闻`

- **10T 参数是"暴力美学"路线的极致**：对照 GPT-4 约 1.8T、Anthropic Fable 5 约 5T 参数，10T 若属实将刷新基座模型规模纪录；但若为 MoE 架构，激活参数才是能力关键

#### 三句话总结

1. OpenAI 曝已完成 Bel 模型预训练，总参数超 10T，定位 GPT-6 之后的基座、冲击 AGI 阈值（官方未确认，属传闻）
2. Jalapeño + Bel + 全场景 Agent 构成 OpenAI"底层芯片 + 基座模型 + 应用层"全栈自研的 AGI 押注
3. 对 CODM 宣发团队：前沿模型"规模军备竞赛"加速，短期不影响工具可用性，但提示需持续关注"模型能力越强、创意上限越高"的素材产线机会；传闻类信息谨慎采信

### #3 ⭐ 字节「豆包工作」Agent 正式发布：与飞书深度打通，桌面 Agent 元年

#### 技术亮点 / 影响分析

- **"桌面 Agent 元年"集团军正面交锋**：字节豆包工作、腾讯 WorkBuddy、阿里千问三巨头齐刷刷把枪口对准办公桌面；易观数据显示 6 月国内 17 款桌面端 AI 办公智能体月访问量突破 6000 万次（3 月仅 2000 万，三个月翻两倍）
- **"飞书上下文"是差异化壁垒**：豆包工作与一般 Agent 的本质区别在于对工作上下文的深度理解——飞书账号登录后完整继承企业知识，共创内容沉淀回飞书，形成"企业知识飞轮"
- **C 端流量能否反哺 B 端待观察**：豆包 6 月月活 3.82 亿（断层第一），但豆包与飞书是两套账号体系，缺乏微信→企业微信那种自动完成组织级账号迁移的通道

#### 三句话总结

1. 字节发布「豆包工作」Agent，自主拆解任务 + 调用工具 + 推进复杂流程，与飞书深度打通企业上下文
2. 字节/腾讯/阿里三巨头正面交锋"桌面 Agent 元年"，国内桌面 AI 办公智能体三个月访问量翻两倍
3. 对 CODM 宣发团队：Agent 办公工具进入"集团军阶段"，宣发团队可试点用豆包工作/WorkBuddy 承接周报、排期、竞品信息归集等流程性工作，关注其与企微/飞书的上下文打通差异

### #4 MiniMax-M3 智能体任务成本 0.018 美元，真实任务榜单最低

> **来源**：界面新闻 / 固件更新中 / MiniMax 官方 | **评分**：7.5/10 | **标签**：`智能体` `MiniMax` `成本`

#### 核心事件

MiniMax 旗舰模型 **M3** 在一项真实世界智能体基准测试中引发关注：仅需 **0.018 美元**就端到端完成了"创建收件箱、撰写并发送商务邮件"的完整任务，在同类测试中**成本居榜单最低**，且确实完成了任务。M3 总参数 428B、激活 23B，采用自研 MSA 稀疏注意力架构，支持 1M tokens 超长上下文，输入定价每百万 token 2.1 元、输出 8.4 元。测试方评价"这就是高效智能的样子"。

#### 技术亮点 / 影响分析

- **"低成本 Agent 部署"路径跑通**：0.018 美元完成一个完整智能体任务，意味着"高频小任务"型 Agent（批量处理、信息归集、自动化邮件）进入可忽略成本区间
- **稀疏注意力架构 = "够用且便宜"的国产样本**：428B 总参但仅激活 23B，用"筛出相关内容再计算"的方式在适中规模下支持超长上下文，是国产模型在智能体成本上的务实路线
- **与头部降价的行业共振**：叠加 OpenAI/Gemini 密集降价，模型"性价比规模"取代"能力稀缺"成为竞争主轴的信号进一步强化

#### 三句话总结

1. MiniMax-M3 以 0.018 美元端到端完成智能体任务（创建收件箱+发送邮件），真实任务榜单成本最低
2. 428B 总参/23B 激活的稀疏注意力架构，验证"够用且便宜"的国产智能体成本路线
3. 对 CODM 宣发团队：批量素材归类、竞品信息自动化归集等高频小任务可低成本接入 M3，作为智能体工作流的性价比备选方案

### #7 Claude 记忆机制统一：跨 Chat 与 Cowork 打通记忆功能

> **来源**：Anthropic 官方 / IT之家 | **评分**：7.5/10 | **标签**：`记忆` `Claude` `产品`

#### 核心事件

Anthropic 更新 Claude 记忆机制，**打通 Cowork 与聊天的记忆功能**——用户在 Claude 聊天中沉淀的记忆，可以在 Cowork（工作空间）中复用，反之亦然。此前记忆能力分散在不同产品线，这次统一让"Claude 记住你"跨场景生效，正在向部分用户逐步推送（Morning Brief 等功能也同步灰度）。这是 Claude 从"单次会话工具"向"长期协同伙伴"演化的产品级动作。

#### 技术亮点 / 影响分析

- **"统一记忆"是 Agent 长期价值的地基**：跨聊天/工作空间复用记忆，意味着 Claude 从"无状态调用"转向"有状态伙伴"，企业场景下用户画像与项目上下文可持续积累
- **与 DeepSeek Files API 形成行业共振**：昨日 DeepSeek 上线 Files API（跨会话复用文件），今日 Claude 统一记忆——"持久上下文"正成为头部模型的产品标配
- **对团队协作的价值**：个人记忆跨产品线打通后，团队级知识沉淀的连贯性提升，减少"每次重新交代背景"的损耗

#### 三句话总结

1. Anthropic 统一 Claude 记忆机制，打通 Chat 与 Cowork 的记忆功能，实现跨场景复用
2. "持久上下文"成为头部模型产品标配（呼应 DeepSeek Files API），Agent 从无状态调用转向有状态伙伴
3. 对 CODM 宣发团队：Claude 记忆统一后，项目背景、品牌规范、竞品信息可持续沉淀复用，减少重复交代；建议团队统一用 Cowork 沉淀宣发项目上下文
