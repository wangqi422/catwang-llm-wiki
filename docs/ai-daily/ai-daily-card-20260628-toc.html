i. Infra & Chips 2 items
🚀 基建 & 芯片
开源推理加速 + 自研 AI 芯片双线突破
1 DeepSeek × 北大开源 DSpark 推测解码框架：速度+85% 🔥 重磅
DeepSeek 联合北大开源 DSpark 推测解码框架（梁文锋署名），单用户生成速度 60%-85% 提升，高并发吞吐 51%-400%。同步开源 DeepSeek-V4-Pro-DSpark 模型权重与 DeepSpec 训练代码。半自回归架构 + 置信度调度 + 硬件感知前缀调度，破解"草稿长度-准确率"权衡。这是 500 亿元融资后首个开源动作，MIT 协议。
2 OpenAI × Broadcom 联合发布 Jalapeño 首款自研推理芯片 🔥 硬件
OpenAI 首款自研 AI 推理芯片 Jalapeño（Intelligence Processor）正式亮相，9 个月从设计到流片，被官方称为"高性能 ASIC 领域最快开发周期"。Broadcom CEO 透露成本相比 GPU 降低 50%，每瓦性能优于当前 SOTA。已交付 Sam Altman/Greg Brockman 工程样片，2026 年底微软数据中心吉瓦级部署。
ii. Geopolitics & Tools 2 items
🌐 地缘 & 工具

3 Anthropic 指控阿里 Qwen 实施 28.8M 次蒸馏攻击 🔥 地缘
Anthropic 6 月 10 日致信美国参议院银行委员会，指控阿里 Qwen 实施史上最大规模蒸馏攻击：约 25,000 个虚假账户在 4/22-6/5 期间生成 2,880 万次与 Claude 的交换，规模是此前 DeepSeek 案（16M）的 4 倍。攻击针对性蒸馏 Mythos Preview 强项能力（软件工程、长程任务）。Alibaba 未公开回应。
4 Mistral AI 发布 OCR4：170 语言，OmniDocBench 击败 GPT-5.5 Pro 🔥 工具
法国 Mistral AI 发布专精文档识别模型 Mistral OCR 4，170 种语言跨 10 大语族，OmniDocBench 拿到 93.07 分（人类评审 vs GPT-5.5 Pro 胜率 66.4% / vs Gemini 3.1 Pro 70%）。每个文本块返回边框坐标 + 类型标签 + 置信度评分，单容器自部署满足数据主权合规需求。4 美元/千页，批处理 5 折。
iii. Agent & Trends 4 items
🤖 Agent & 趋势
Karpathy 军规 + Agent 视频开闸 + 微博 MCP 原生
5 Karpathy 内部 Claude.md 军规泄露：10 条实战规则碾压 GitHub 18 万星 🔥 Agent
Karpathy 5 月 19 日入职 Anthropic 后，5 周内迭代的内部 Claude.md 配置文件意外流出——10 条实战军规（GitHub 18.3 万星社区版只有 4 条）。标题《CLAUDE.md: Field Notes on Getting a Language Model to Write Code You Will Not Rewrite》，副标题"看够同样错误犯两遍才攒出的规则"。社区评价"它解决了我们几乎所有当前的任务"。
6 OpenMontage：GitHub 周榜第一的 Agentic 视频制作系统 🔥 趋势
calesthio/OpenMontage 拿下 GitHub Trending 周榜第一（3.7k stars 周增长），世界首个开源 Agentic 视频制作系统：12 pipelines × 52 tools × 500+ agent skills。把 AI 编程助手变成完整视频制作工作室，与 Claude Code / Codex / Cursor 无缝集成。Agent 视频赛道正式开闸。
7 Anthropic 停招初级工程师双重警告：增长伴随失业 行业警报
Anthropic 联合创始人 Jack Clark 公开表示已停止招聘初级软件工程师，只招"高级直觉"型资深员工。同时警告 AI 可能带来"远超趋势的 GDP 增长"+"只有衰退期才会出现的失业率飙升"——两端同时拉满的危险悖论。"AI 替代潮"将影响大学 CS 入门课程与企业初级岗位。
8 微博 weibo-cli 正式上线：70+ API + MCP 协议，国内首个 Agent 原生 CLI 🔥 MCP
微博开放平台 6 月 22 日上线官方 CLI 工具 weibo-cli——国内主流社交平台首个面向开发者的官方 CLI，专为开发者和 AI Agent 设计。封装 70+ API，支持 MCP 协议（Model Context Protocol）即插即用。5 档订阅：Free / 29元（基础）/ 69元（Plus）/ 299元（专业）/ 899元（Ultra）。AI Agent 可端到端操控微博账号。
