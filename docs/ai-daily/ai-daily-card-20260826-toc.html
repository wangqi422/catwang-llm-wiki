i. Models & Agents 4 items
🧠 模型 & Agent
OpenAI 自研芯片 Jalapeño 首秀超英伟达 GB300，曝 Bel 模型 10T 预训练完成，字节豆包工作 Agent 发布，MiniMax-M3 智能体成本最低
1 OpenAI 首款自研芯片 Jalapeño 首秀：吞吐/能效/延迟全面超英伟达 GB300 🔧 自研芯片
OpenAI 在 Hot Chips 公布首款自研推理 ASIC Jalapeño 首批实测，与博通联合开发，在吞吐、能效、延迟上全面超越英伟达 GB200 与 GB300。标称功耗仅 700W（约为 GB300 1400W 的一半），台积电先进制程 + HBM4（216 GiB / 15.4 TB/s）。InferenceX 基准上：GPT-OSS 120B 单用户出词 1459 tokens/s（GB200 的 2.7 倍），DeepSeek R1 670B 端到端延迟 1.65 秒（GB300 的 5.99 秒），整体每瓦 AI 吞吐提升 1.5~1.9 倍。设计到流片仅 9 个月，Codex 辅助设计让 SIMD 面积减 8%、矩阵引擎减 10%——英伟达 CUDA 护城河首现裂缝，算力进入「GPU + ASIC 多路线并存」时代。
2 OpenAI 曝完成 Bel 模型预训练：超 10T 参数，冲击 AGI 阈值 🚀 AGI
X 消息源爆料，OpenAI 已完成代号 Bel 的新一代大模型预训练，是 Doug 模型的直接继任者，总参数量超过 10 万亿（10T），定位 GPT-6 之后的基座模型，甚至可能成为达到 AGI 阈值模型的底座。Doug 经强化学习后预计成为 Astra 和 GPT-6 的基础。爆料称 Anthropic 因算力限制暂无应对 Astra 的方案。注：OpenAI 官方未确认，属传闻。10T 若属实将刷新基座规模纪录（GPT-4 约 1.8T、Fable 5 约 5T）；Jalapeño + Bel + 全场景 Agent 构成 OpenAI「芯片 + 模型 + 应用」全栈 AGI 押注。
3 字节「豆包工作」Agent 正式发布：与飞书深度打通，桌面 Agent 元年 🤖 Agent
字节跳动 8 月 25 日正式发布生产力 Agent 产品与品牌 「豆包工作」，可自主拆解任务、调用工具、持续推进复杂工作流程，并与飞书深度打通——授权范围内调用飞书聊天记录、文档、会议纪要、日程等企业上下文。获授权后跨软件操作浏览器和电脑，长任务可调用云电脑继续执行（本地关机不中断），支持多 Agent 组队。飞书（7/30）、TRAE 与扣子（8/24）团队已先后并入豆包。字节/腾讯/阿里三巨头正面交锋「桌面 Agent 元年」，国内桌面 AI 办公智能体三个月访问量翻两倍。
4 MiniMax-M3 智能体任务成本 0.018 美元，真实任务榜单最低 💡 智能体
MiniMax 旗舰模型 M3 在一项真实世界智能体基准测试中，仅需 0.018 美元就端到端完成「创建收件箱、撰写并发送商务邮件」的完整任务，成本居榜单最低且确实完成任务。M3 总参数 428B、激活 23B，采用自研 MSA 稀疏注意力架构，支持 1M tokens 超长上下文，输入每百万 token 2.1 元、输出 8.4 元。「低成本 Agent 部署」路径跑通——高频小任务型 Agent（批量处理、信息归集、自动化邮件）进入可忽略成本区间。
ii. Industry & Infrastructure 2 items
🏭 行业 & 基础设施
Anthropic 拟披露 30 万亿美元 TAM 冲击史上最大 IPO，Stability AI 7600 万美元 B 轮获三大音乐巨头 + EA 参投
1 Anthropic 拟披露 30 万亿美元 TAM：目标估值 2 万亿、募资最高 1000 亿 💰 IPO
《华尔街日报》援引知情人士报道，Anthropic 将在 IPO 招股书中提出超 30 万亿美元的潜在市场规模（TAM），打破 SpaceX 28.5 万亿美元的纪录，成商业史上最庞大市场叙事。目标估值约 2 万亿美元（高于 SpaceX 1.77 万亿），拟募资最高 1000 亿美元（高于 SpaceX 860 亿），预计最快 9-10 月上市。底气来自财务：2026 Q2 单季营收 116 亿美元，首次实现调整后营业利润为正，预计 2028 年收入 1900~2000 亿美元。AI 进入「估值兑现」高峰期。
2 Stability AI 7600 万美元 B 轮：环球/索尼/华纳音乐 + EA 参投 🎮 融资
Stable Diffusion 母公司 Stability AI 完成 7600 万美元 B 轮融资，累计融资 2.32 亿美元。投资阵容极具战略色彩：环球音乐、索尼音乐、华纳音乐三大音乐巨头 + 游戏巨头艺电（EA），另加 AMD Ventures 与 Pacific Alliance Ventures。资金用于完善音乐/视频/图像「创意生产」产品套件。资本表即战略宣言——三大音乐 + EA 既是财务投资方也是共同开发与分发伙伴，Stability 从「卖模型」转向「共建专业创意工具」；EA 直接下场投 AI 创作工具，是游戏行业 AI 原生化的明确信号。
iii. Trends & Tools 2 items
📈 趋势 & 工具
Claude 记忆机制统一跨 Chat 与 Cowork 打通，Claude Code v2.1.246 修复通配符权限等问题
1 Claude 记忆机制统一：跨 Chat 与 Cowork 打通记忆功能 🧠 记忆
Anthropic 更新 Claude 记忆机制，打通 Cowork 与聊天的记忆功能——在 Claude 聊天中沉淀的记忆可在 Cowork 工作空间复用，反之亦然。此前记忆分散在不同产品线，这次统一让「Claude 记住你」跨场景生效，正向部分用户逐步推送。「统一记忆」是 Agent 长期价值的地基，Claude 从「无状态调用」转向「有状态伙伴」。呼应 DeepSeek Files API，「持久上下文」正成为头部模型的产品标配。
2 Claude Code v2.1.246 发布：修复 Bash 通配符权限、全屏模式等问题 🛠️ 开发工具
Claude Code v2.1.246 发布，主要修复多项工程问题：Bash 通配符权限处理、全屏模式、后台会话等 bug。相比昨日 v2.1.243（/usage 循环统计、modelPicker、无密钥登录）的功能密集版，本次是小版本修复。Anthropic 保持「功能 + 修复」双线高频发版（隔一天一发），AI 编程工具迭代进入企业级稳定阶段；「通配符权限」修复关乎安全边界，反映其在企业级安全合规上的投入。
