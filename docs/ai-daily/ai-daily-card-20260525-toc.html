i. Funding & Models 3 items
💰 融资 & 模型
Anthropic 碾压式一周：融资 + 模型 + 盈利三连击
1 Anthropic 本周完成 $300 亿融资，估值破 $9000 亿超越 OpenAI 9.5
Anthropic 即将完成超 300 亿美元新一轮融资，投后估值突破 9000 亿美元，正式超越 OpenAI 登顶全球 AI 独角兽。Q2 预计营收 109 亿美元，有望实现首次盈利，下月年化收入将突破 500 亿美元。红杉资本、Dragoneer、Altimeter 和 Greenoaks 联合领投，各出资约 20 亿美元。
来源：彭博社 / 每日经济新闻 · 2026-05-25
2 Anthropic 三大模型同日曝光：Opus 4.8 + Sonnet 4.8 + Mythos 1 9.3
开发者在 Google Vertex AI 后台发现 claude-opus-4.8 模型标识；同日代号 Mythos 1 的安全专用模型短暂现身；加上 51 万行泄露代码剧透的 Sonnet 4.8，Anthropic 三大杀手锏一口气全曝光。Sonnet 4.8 跳过 4.7 版本，重点升级视觉理解、代码生成、指令遵循。
来源：新智元 / Google Vertex AI · 2026-05-24
3 GPT-5.6 与 Claude Sonnet 4.8 或在 6 月同时发布 9.1
据 Pankaj Kumar 爆料，GPT-5.6 内部测试标签 iris-alpha / ember-alpha / beacon-alpha 曝光，或分为 GPT-5.6 和 GPT-5.6 Pro，方向包括多步推理、Agent 工作流、前端生成。Claude Sonnet 4.8 来自 51 万行泄露 source map。6 月还将迎来 Gemini 3.5 Pro——三巨头贴身肉搏正式开打。
来源：Pankaj Kumar / 央视财经 · 2026-05-25
ii. Platforms & Agents 3 items
🤖 平台 & Agent
苹果 AI 大招前奏 + 微软浏览器 Agent + DeepSeek 逆向操作
4 苹果注册 genai.apple.com，WWDC 2026 前释放 AI 大招信号 8.8
苹果在 WWDC 2026（6 月 9 日）前夕注册全新子域名 genai.apple.com。iOS 27 将搭载完全重建的 Siri，15 年来首次恢复独立 App 形态，支持多轮对话、文件分析、全局手势唤起。底层由 Apple Foundation Models + Google Gemini 双驱动。库克或发表任期最后一次 WWDC 主题演讲。
来源：MacRumors / 新浪财经 · 2026-05-24
5 微软发布 Fara 1.5 浏览器智能体，任务成功率 72% 超越 OpenAI Operator 8.5
微软研究院发布 Fara 1.5 系列浏览器智能体，含 4B / 9B / 27B 三个版本。Fara 1.5-27B 在 Online-Mind2Web 取得 72% 任务成功率，超越 OpenAI Operator（58.3%）。基于 Qwen3.5，采用"观察—思考—行动"循环，配套沙盒界面 MagenticLite。缺个人信息 / 不可逆操作时主动暂停询问用户。
来源：微软研究院 / IT之家 · 2026-05-23
6 DeepSeek V4-Pro 永久降价 75% + 组建 Code Harness 团队 8.3
DeepSeek 官宣 V4-Pro API 折扣永久化，价格直降 75%（输入 3 元 / 输出 6 元每百万 tokens）。同时在北京组建 Code Harness 团队，聚焦 AI Coding 方向，引入量化交易老兵崔添翼。创始人梁文锋正推进约 700 亿元首轮融资，DeepSeek 从纯模型公司转型为 AI 基础设施核心节点。
来源：硅基研究室 / 腾讯新闻 · 2026-05-25
iii. Research & Trends 2 items
🔬 研究 & 趋势
新范式与行业大数
7 微软 Webwright：用终端代码替代逐点点击的 Web Agent 新范式 8.0
微软研究院发布 Webwright，不再逐点预测点击位置，而是给 AI 一个终端让它编写 Playwright 代码控制浏览器。框架仅约 1000 行代码，GPT-5.4 测试在线任务准确率 86.7%。生成的脚本可打包为可复用 CLI 工具，跨 Codex / Claude Code / OpenClaw 平台共享。GPT-5.4 平均每任务成本仅 $2.37。
来源：微软研究院 · 2026-05-25
8 国内备案 AI 大模型数量突破 868 款，两年增长超 10 倍 7.8
国内备案 AI 大模型数量已突破 868 款，两年增长超 10 倍。恒生科技指数季检纳入 MiniMax 和智谱 AI，AI 公司加速登陆资本市场。AI 数据中心电力需求催热 A 股电力设备板块，5 月以来 42 家电力设备公司获机构密集调研。苹果市值站上 4.5 万亿美元创历史新高。
来源：AI 科技日报 · 2026-05-25

📝 编辑点评

今日最大信号是 Anthropic 的全面碾压态势：300 亿融资 + 9000 亿估值 + 三大模型同日曝光 + Q2 首次盈利，Karpathy 加盟后的"人才飞轮"正以肉眼可见的速度转动。与此同时，GPT-5.6 与 Claude Sonnet 4.8 的 6 月对决将成为今年最关键的模型之战。

对 CODM 宣发团队而言两大利好：① DeepSeek 永久降价 + AI Coding 赛道竞争白热化，用 AI 辅助素材制作成本将持续下降；② 浏览器 Agent（Fara 1.5 / Webwright）进入"可用"阶段，竞品监控、社媒发布等重复性工作自动化有了现实路径。建议下周试用 Fara 1.5 做一次竞品素材自动采集的 PoC。
