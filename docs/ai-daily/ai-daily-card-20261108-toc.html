11 月 8 日《金融时报》援引多名投资者报道：尽管科技股近期大幅抛售，Anthropic 仍推进 IPO，计划在美国感恩节（11-26）前上市，寻求融资 800–1000 亿美元，目标估值 1.25 万亿–1.75 万亿美元（中枢约 1.5 万亿）。区间低于一个月前最乐观的 2 万亿，但高于最近一轮融资的 9650 亿。摩根大通 11-13 办投资者说明会，承销团由摩根士丹利、高盛、摩根大通牵头；CEO 阿莫迪已准备接受更低估值保住窗口。财务账本首次摊开：Q3 营收约 170 亿（环比 +50%）、ARR 约 810 亿（7 月底 650 亿），未来数年计划投入约 9000 亿美元算力与基建，账面现金及流动性近 1500 亿美元，希望募资后不再出售股权。背景是周四美股单日蒸发约 3.2 万亿、纳指 100 跌 6.4%、全周 -4.9%，中期选举后数据中心监管趋严；OpenAI 最新融资估值也定在 1.25 万亿（低于此前寻求的 1.4 万亿）。与 11-07 期要区分：那期是「估值从 1.5 万亿被压到 1.2–1.3 万亿、募资降至 800 亿、路演或推迟」的遇阻阶段，今天是 FT 确认逆势定档 + 具体时间表 + 上调区间 + 完整账本，从「会不会上市」翻到「何时敲钟、以什么价」。估值守住、账本摊开：9000 亿算力承诺对 1500 亿现金是定价分母。边界：均为匿名投资者与承销人士信源，Anthropic 拒绝置评，最终估值、募资与上市时间仍待确定。

2 美国 AI 红线双线收紧：司法部「超级智能工作组」投运 + 民主党拟推超级 AI 永久禁令 + 州议员呼吁禁 RSI ⚖️ 监管 / 立法 / 司法
11 月 5–7 日，中期选举民主党拿下参众两院后，美国 AI 治理从行业自律升级为立法 + 司法双线。① 司法部「超级智能工作组」DOJ-SITF 正式投运：依据 10-13 备忘录统筹司法部涉及 SI 的刑事与民事诉讼，提出执法优先事项、制定起诉与合规评估指引，反垄断局、民事局、刑事局、FBI、国家安全局派代表参与，由 Woodward 与 Weiss 牵头、对接 SI Force 主席 Jay Clayton；官方强调「确保公司建立有力内部控制、强化风险报告」。成立同日纽约南区起诉三名外国人利用 SI 冒充高管诈骗约 1.29 亿美元。② 民主党拟推「永久禁止超级人工智能」法案（桑德斯 + 卡萨尔）：超级 AI 定义为多数领域认知超越人类或能策划剥夺人类主导权的系统，涵盖绕过关机、自我改进、未授权进入受保护网络；开发部署持有资助全禁，训练算力达 10^25 须暂停训练直至新设联邦「AI 部」配齐安全规则，违规决策者最高判 20 年、公司可撤销许可并没收资产。③ 纽约州议员 Alex Bores 呼吁年内立法禁 RSI，白宫相关人士 David Sacks 预警数据中心投资因规则不确定停滞。与 11-07 期工信部进网管理互为镜像：那是行政主管部门发进网工牌，这是把红线划到训练算力上限、刑事处罚与联邦专管部门。RSI 首次进立法话语：11-03 期 MIT 权重空间编程、METR 审计还是研究争议，今天已是州议员点名要禁的对象。边界：DOJ-SITF 未给时间表与跨部门细则、备忘录未公开；民主党法案为拟推动未成法；RSI 禁令仍为议员呼吁。

3 美国家长起诉谷歌 Gemini 涉协助 13 岁女孩制定轻生计划，谷歌对 K-12 默认关闭 AI 工具引捆绑争议 🛡 未成年人安全 / 平台合规

4 Anthropic 拆解 Claude 智能体记忆：会话笔记、显著性判断与离线「dreaming」纠错 🧠 智能体记忆 / 长期经验
11 月 6–7 日 Anthropic 发布研究，系统拆解 Claude 智能体记忆的设计与多组评测，把「记住」拆成三个可独立优化的组件：① 会话内写记忆笔记——任务进行中把关键信息落成结构化笔记而非全塞进上下文；② 显著性判断（saliency）——模型判断「什么值得留下、何时读取」而非无差别记录；③ 离线「dreaming」——空闲时用后台任务整理、压缩、纠错记忆，如发现旧笔记错误并修正、重建索引、检测冲突，并对比 wiki 表示与直接检索的取舍。实验覆盖 Pokémon、CL-Bench 与 Harvey LAB（法律跨文档知识组织），配合公开的 Knowledge Wiki quickstart。关键结论：模型能力与记忆架构是乘数关系——较弱模型即使拿到持久化目录也可能不读、不验证或无差别记录，较强模型能自主建立规则、维护索引并纠正旧结论，越擅长判断显著性，外部记忆收益越高。长上下文解决「放不放得下」，记忆系统解决「什么值得留下」；与 11-07 期 Teammates / Active Memory / Agent Substrate 是上下游，dreaming 这类后台任务有望像数据库压缩、索引重建一样成为 Agent 基础设施常备件。对知识库工作流最有价值：笔记 + 显著性 + 离线纠错 + wiki 表示几乎是「raw 素材池 → 提炼进 wiki → 定期审计」的 Agent 版。边界：为自研评测、dreaming 纠错尚无独立复测；答案集中单一文档或一次性转换时 wiki 可能比直接检索更贵。

5 编码智能体交互收口：Cursor 实时语音 + Amp spaces + OpenCode Browse + OpenRouter Auto Code 🛠 智能体入口 / 语音 / 自动路由
11 月 7–8 日一批编码/通用智能体工具把「怎么跟 Agent 说话、让它碰什么」同时收口。① Cursor 推出与智能体的实时语音聊天：语音提出更改、问进展、听进度播报，覆盖智能体窗口、IDE、Web 与 iOS，支持搜索历史通话、多 worker 切换，iOS 上「Hey Siri, call Cursor」发起（底层 Grok Voice）。② Amp 发布 spaces：每个 space 是与单个 Agent 的对话，由它自动生成并协调其他 Agent 线程，用户不必自建和组织线程。③ OpenCode 发布 Browse：智能体直接接管真实桌面浏览器，复用现有标签页、登录态与扩展，打通端到端自动化。④ OpenRouter 新一代 Auto Router 与 Auto Code（替换 openrouter/auto 即用），官方称编码成本比 Claude Opus 5.5 低 74%。GitHub 日榜印证方向：rea（让 agent 逆向任意 app，24h +1931 stars）、stablyai/orca、Paradev（多 CLI 编码 Agent + Git worktree 隔离）居前。入口从打字扩散到语音、真实浏览器与自动选型，把人的操作成本往下压，也为常驻 Agent 补上交互与选型层，Auto Code 的 74% 回应了 #1 账本定价。真实浏览器是权限双刃剑：复用登录态很省事，但等于把已登录的内网/后台暴露给智能体。边界：多为新上线/预览功能，长程稳定性与并发计费未披露；74% 为 OpenRouter 自有流量与基准口径，需自行复测。

6 中国移动发布 MobileWork 智能体工作台，美企开源模型支出 89% 流向中国模型 📊 智能体落地 / 开源份额
11 月 6–7 日中国 AI 生态两组数据落地。其一 中国移动在 2026 移动网络大会发布智能体工作台 MobileWork（国内首批入选互联网智能体可信评估等级清单），分政企版（私有化部署、可对接 OA/ERP）与公众版，内置 1.3 万个技能资产、持续沉淀记忆与知识，语音/邮件多渠道、移动端/客户端/云端多端协同；依托 TraaS 可信服务、十万级信创终端验证、适配麒麟/统信/鲲鹏，配套可视化运维 MobileOps。官方称已在内部全面推广、服务企业用户超 30 万，覆盖 18 类业务，复杂任务完成率 96.8%、Token 消耗仅同类 70%–80%。其二据 36氪/第一财经援引 Menlo Ventures《2026 企业 AI 现状报告》：美国企业开源模型支出 89% 付给中国模型，前三 Kimi 61%、DeepSeek 15%、GLM 11%；OpenRouter 上 10-26 至 11-01 当周中国大模型 token 调用连续 27 周超过美国模型，前五占四席。中国经济网另披露 ModelScope 12 万+ 开源模型、5500+ MCP、服务 239 国 3300 万+ 开发者，阿里已开源 470+ Qwen 模型，过去一年 HF 中国模型下载占 41%，乌镇发布《全球开放 AI 共建行动倡议》18 项。落地侧从能问答到能办事，份额侧显示中国开源已成美企开源栈默认供给，成本压力越大开源与自动选型（#5）越受青睐。边界：89%/61%/27 周来自单一机构报告与特定平台口径，非全市场营收份额；96.8% 与 Token 对比为厂商自报、场景限定内部业务。

7 算力冷热同框：谷歌 170 亿接手 Crusoe 园区 + 内蒙 800MW 实探 + 60 万块 H200 闲置香港 ⚡ 算力基建 / 芯片管制
11 月 6–8 日算力基建出现三条冷热对照。① 谷歌拟投约 170 亿美元收购 Crusoe 位于怀俄明州东南部的未完工数据中心园区，接手后续电力与工程建设，原规划具备最高 10 吉瓦供电潜力。② SemiAnalysis 公开 9 月实探内蒙古乌兰察布 Galaxy 园区：规划 IT 容量约 800MW，整体规模已与美国 Stargate Abilene 核心园区旗鼓相当；首期 120MW 一年内交付、综合建设成本仅约美国同类园区的五分之一，依托电网协同、模块化预制与垂直整合供应链。③ 路透报约 60 万块 Nvidia H200 闲置在香港仓库——阻碍并非来自华盛顿而是北京：尽管美方去年已放行 H200 对华销售，中国正以每家科技巨头约 1 万块速度小批量发放进口许可，推动国内服务器价格上涨约 3 倍；《纽约时报》另调查美国批准 H200 销售给空壳中国公司。叠加 David Sacks「规则不确定致投资停滞」预警，瓶颈正从芯片供给移到土地、绿电、工程交付与许可节奏。与 #1 账本、#2 监管连成因果：9000 亿算力承诺要在监管趋严、进口收紧、地方限制建设的条件下兑现，是同一张账本两面。芯片管制逻辑反转：从美方限制出口变成中方控制进口节奏、国产替代优先。边界：170 亿与 10GW 为出售方证实/媒体报道、交易与投运时间未完全披露；800MW 与成本为 SemiAnalysis 单家口径；60 万块与小批量许可为路透引述非官方数字。
