1 xAI Grok Build 扩大 Beta + Grok V9 1.5T 模型预告 🔥 9.2
xAI 将 Grok Build 从早期访问扩大到更广泛 Beta，支持 Plan Mode（自动拆解任务）、CLI 工具、文件读写。Elon Musk 预告 Grok V9 将是 1.5 万亿参数级别模型，SuperGrok Heavy 订阅 $300/月直指企业级 Agent 市场。
宣发启发：Grok Build 的 CLI + Plan Mode 可探索用于自动化素材生产流水线编排
xAI Official · The Verge · May 25-26
2 支付宝 AI Wallet + Token Pay — 全球首个 AI 原生支付体系 🔥 8.8
蚂蚁集团上线 AI Wallet（智能钱包）及 Token Pay。AI Wallet 允许自然语言完成转账/查询/理财；Token Pay 是面向 AI Agent 的加密支付协议，让 AI 可在授权范围内自主完成交易——标志着支付行业从"人操作 App"到"AI 代人操作"的范式转变。
宣发启发：Token Pay 的 Agent 支付能力未来可用于自动化采买广告位/素材分发
蚂蚁集团 · 36氪 · May 26
3 天工 AI SkyClaw-v1.0 — 百万 token 上下文 Agent 模型 8.5
昆仑万维发布 SkyClaw-v1.0，支持 100 万 token 上下文窗口（约 75 万字中文），原生支持 Function Call + 多工具编排，面向复杂 Agent 工作流设计。开源权重即将释放，有望成为国内 Agent 开发基础模型。
宣发启发：长上下文模型可处理完整策划方案/竞品报告，辅助长文档分析
昆仑万维 · 量子位 · May 26
4 微软 Win11 Ask Copilot 任务栏 AI — 文档确认 mid-2026 发布 8.3
微软支持文档确认 Windows 11 将在 mid-2026 推出"Ask Copilot"，直接集成在任务栏。用户可在任何应用中调起 AI 助手，跨应用上下文理解——AI 从应用层下沉到 OS 基础设施层。
宣发启发：OS 级 AI 助手意味着未来宣发素材触达用户的方式可能变化
Microsoft Docs · The Verge · May 26

5 美团发布"跑腿 Skill"— AI 助手生态开放 8.0
美团将跑腿服务封装为 AI Agent 可调用的标准化 Skill 接口。任何 AI 助手都可集成美团跑腿能力，实现"AI 帮你下单跑腿"。与支付宝 Token Pay 形成互补——AI Agent 从"能做"到"能买"的闭环正在形成。
宣发启发：Skill 化思路可借鉴——将宣发流程各环节封装为可组合 AI Skill
美团官方 · 36氪 · May 26
6 Runway Aleph 2.0 + Edit Studio — 改一帧全片生效 🔥 8.2
Runway 发布 Aleph 2.0 及 Edit Studio。Edit Studio 支持帧级编辑——修改某一帧后，AI 自动将变化传播到全片，保持时间一致性。这是从"一次生成"到"迭代优化"的关键能力跃迁，交互方式类似传统 NLE 降低专业创作者迁移门槛。
宣发启发：帧级编辑+自动传播可直接用于视频广告素材精修和版本迭代
Runway Blog · The Verge · May 21
7 可灵（Kling）分拆拟 IPO — 200 亿美元估值 7.8
快手旗下 可灵（Kling）推进分拆独立运营，目标估值约 200 亿美元。AI 视频赛道首个独立超级独角兽，分拆后将拥有更灵活的融资和人才机制，与 Runway/Sora 竞争。
宣发启发：可灵 IPO 后产品力可能加速，需持续关注其与游戏行业合作动态
Bloomberg · 36氪
8 AI 视频三国杀 — Seedance 8 成份额 vs Kling vs HappyHorse 8.0
AI 视频市场格局初定：Seedance 2.0 占据约 80% 国内份额；Kling 海外市场差异化发力；阿里 HappyHorse 正式入局，主打电商视频场景。三足鼎立意味着技术迭代和价格竞争将加速。
