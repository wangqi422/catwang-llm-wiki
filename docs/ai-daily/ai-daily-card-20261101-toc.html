1 OpenAI 12 月起 ChatGPT 与 Codex 共享统一 Token 额度，Instant 聊天不计费 🎟️ 订阅策略
10 月 31 日深夜至 11 月 1 日凌晨，OpenAI 官方支持页面上线新文档《理解 ChatGPT 与 Codex 使用限制》，宣布从 12 月开始，随着把 ChatGPT Work 的智能体能力并入 ChatGPT 主体验，Plus、Pro、Business 三档订阅在 ChatGPT 与 Codex 之间共享同一份使用额度。计费口径同时切换：不再按「几小时内能发多少条消息」计数，而是统一按 Token 计量，实际消耗速度取决于所选模型与任务复杂度——调用更高级的模型、执行更复杂的推理和长代码任务，消耗更快。官方给了唯一的豁免：Instant Chat（即时聊天）不占额度，仍然无限量供应。额度耗尽后只有三条路：等待自动重置、升级到更贵档位、增购 Credits。官方承诺「绝大多数用户等待重置的频率不会高于此前」，但并未公布各档位的 Token 总盘子与跨模型折算表——这正是社区质疑「是否变相缩水」的焦点。配套动作几乎同时发生：OpenAI 上线了严厉的「设备绑号上限」，一台设备绑定过多付费账号会被直接封锁。背景值得注意：此前一个月内 Codex Pro 额度刚经历「先降后恢复」的运营反复，叠加 IPO 预期下的算力成本压力，这次合池被普遍解读为成本侧的必然动作。usage 面板将在设置中统一显示合并后的剩余额度与下次重置时间。

2 商汤开源 SenseNova Loop-9B-Preview：32 层权重跑出 56 层计算，9B 对标 27B 🔁 循环架构
10 月 30 日晚，商汤开源日日新 SenseNova Loop-9B-Preview，权重与代码分别上 Hugging Face 与 GitHub，Apache 2.0 许可——可商用、可修改、可再分发。核心思路是 Looped Transformer：模型共 32 个独立解码器层，首尾各 4 层正常跑，中间第 4–27 层共 24 层共享权重执行两遍（写作 B(B(h))），一次前向完成约 56 次层计算，却只需存 32 层权重。规格上：总参数约 9B、推理时实际参与计算约 14.6B，训练上下文最长 262,144 token，文本 + 图像输入、文本输出。mHC（流形约束超连接）是为防第二遍循环把信号洗糊加的关键设计：两条残差流 + Sinkhorn 归一化的可学习映射（迭代 20 次）负责路由与融合；注意力每 4 层一组，3 层线性 + 1 层全注意力，循环边界正好对齐整组。实测（厂商自报）：对 Qwen3.5-27B，BIRD-Dev 71.38 : 69.84、WorkBuddy Bench 66.89 : 60.53、RaccoonPPT 70.70 : 59.08、TeamBench 48.89 : 44.44 均反超；但 Terminal Bench 2.1 40.45 : 47.19、T³-Banking 18.56 : 19.59 落后。mHC 消融：GPQA Diamond +4.42、TeamBench +13.34。代价要说清：省的是显存里的参数，不是每个 token 的算力——56 次层计算照样跑，首 token 延迟更高、长文本吞吐吃亏；技术报告仍标 TBD，RaccoonPPTBench 是商汤自研评测集。部署上 BF16 权重接近 18GB，单张 24GB 显卡可跑，加载需 trust_remote_code=True，10 月 31 日登上 HF 趋势榜。

3 DeepSeek 开源 Super-agent：Router + Worker 双层架构，多任务耗时砍半 🤖 Agent 架构
10 月 31 日晚，DeepSeek Harness 团队发布《Super-agent 设计探索：迈向更自主的 Agent 系统》，并开源研究原型 dsh-superagent-prototype（MIT 协议，当晚接近 1095 star）。它不是新产品，而是一套把调度与上下文同步从人手上移到系统层的架构。问题定义很实在：一个人通常只能同时跟进 3–5 个活跃会话——瓶颈已经不在模型，而在人的注意力。Router 层是常驻全局节点，统一接群聊 / GitHub / 邮件入口消息，只分派不干活（甚至可以连 Bash 工具都不配），用轻量模型即可；上一轮推理期间积压的事件会自动合并批处理，单个决定分摊的推理时间从 6.4 秒降到 1.6 秒。Worker 层各自独立上下文、挂完整工具、配最强模型，负责复现问题 / 代码审查 / 功能开发；Worker 不直接对人说话，只向 Router 汇报，由 Router 统一回复。订阅与直通是省钱的关键：Worker 创建后直接订阅对应 Thread，后续事件程序直通、不再绕 Router；实测取消直通后 Router 决策次数增加约 30%，缓存读取 token 从 2323 万涨到 3177 万（+37%）。投机执行借鉴分支预测：有人反馈 Bug，Agent 先在后台复现、分析、找简单修复，确认有价值才提交，否则保持安静。配合两级事件过滤（程序规则 Fast Path 先筛噪音，LLM Slow Path 再判）、存算分离（执行在云端、状态存数据库、本地只留轻量 daemon，关机不停）与外部 Watchdog。实测数据：模拟 300 条消息 / 20 个工作请求环境，Super-agent 任务完成时间中位数 12.4 分钟、95 分位 15.7 分钟；传统单 Session + Subagent 方案 95 分位为 29.5 分钟——快了近一倍，代价是 Token 消耗上升。

4 OpenAI 融资目标砍 100 亿至 200 亿美元，估值从 1.4 万亿降到 1.25 万亿 📉 资本纪律
10 月 31 日，据 FT 与彭博援引知情人士：OpenAI 把最新一轮融资目标从 300 亿美元下调至约 200 亿美元，削减 100 亿（降幅 33.3%）；对应估值目标从 1.4 万亿美元下调至 1.25 万亿美元，缩水 1500 亿（降幅约 10.7%，约合人民币 1.06 万亿元）。公司此前把这笔交易宣传为「明年 IPO 前最后一次入场机会」。更关键的是结构变化：OpenAI 已设定出资承诺截止日（周五），部分投资者缩减认购额度，首次交割预计到位资金不足 200 亿，后续还需靠面向高净值个人的零售配售补足。目前已获约 110 亿美元承诺。为什么缩：科技股集中抛售（纳斯达克 100 当日跌 3.5%、纳指跌 2.9%、较 10 月 6 日高点回撤约 7.8%、10 月创去年 3 月以来最差单月）+ 市场对 AI 支出规模与回报周期的担忧 + Anthropic 即将上市分流同一批机构资金。谁在出钱：阿联酋财团（含国有科技基金 MGX）预计为最大参与方，OpenAI 同时获得在该地区租赁新建算力的选择权；Founders Fund、Coatue、红杉、a16z 与软银计划跟投，各方均拒绝置评。估值路径：今年 3 月上一轮融资后 8520 亿美元 → 7 月后一度喊到 1.4 万亿 → 现在 1.25 万亿。行业信号：不是 AI 需求被下调，而是风险定价被重校——融资照做，但「少拿一点、价格低一点、交割稳一点」，从估值驱动转向资本纪律。传导链条是融资 → 资本开支 → 设备订单，产业链需要重新区分「确定性订单」和「估值预期订单」。

5 Anthropic IPO 招股披露近 9000 亿美元隐性债务，黑石只给投机级评级 🧾 表外义务
Anthropic 于 10 月 26 日向 SEC 提交 IPO 注册文件（有望成为人类史上最大 IPO，市场预期估值约 1.5 万亿美元）。彭博 10 月 31 日报道：招股文件显示公司计划通过远期履约义务，在服务器、建筑与电力等领域投入近 9000 亿美元（约合人民币 6 万亿元）——是账面负债的近 8 倍。账面口径是负债 1175 亿美元、现金 1120 亿美元，真正的故事全在财务报表附注里。拆解表外义务：表外采购协议规模从去年 12 月到今年 6 月翻至四倍、达 2656 亿美元，多数绑定云托管与基础设施合作，期限最长 20 年；尚未起租的租约总额 3210 亿美元；其余算力安排（含租约与修订协议）远期支出 2450 亿美元；另有 210 亿短期合作项目、8 亿数据中心开发成本担保；7 月向 AMD 采购 GPU 及相关硬件超 200 亿美元。为什么看不见：公司正从「租算力」转向「自建数据中心」，德克萨斯大学会计学教授 Patrick Badolato 指出这让业绩与前几年不再可比。Zion Research 分析师 Ravi Gomatam 直言：「无论公司能不能赚到收入，这些承诺款项都必须支付。」估值预期同步下调：部分投资者讨论的上市估值已从约 2 万亿降到约 1.5 万亿美元。评级预警：刚参与一笔 630 亿美元 AI 算力设备融资交易的黑石向投资者表示，预计 Anthropic IPO 后可能拿到 BB 区间信用评级——属投机级（俗称垃圾级）中较高档。招股书自述风险：GPU 价格、未来电价、燃油附加费都可能波动，部分协议含可变成本很难锁定最终金额；社区对数据中心耗水耗电的抵制、低成本开源模型的竞争，都可能让收入覆盖不了成本。

6 Roblox 财报：AI 游戏突破 7 万款，9 月时长 Top 100 超 80% 用 AI 辅助开发 🎮 游戏行业
Roblox 在 2026 财年 Q3 报告中披露：平台内使用 Build 工具创建的 AI 游戏总数已超过 7 万款；9 月游玩时长排名前 100 的游戏里，超过 80% 使用了 AI 辅助开发。本季度有 2 款几乎完全由 AI 创作的游戏进入平台同时在线玩家排行前 20。Roblox 在股东信中称，近三个月「游戏行业的 AI 采用与内容生成出现拐点」。量级来自哪里：Build 功能 2026 年 7 月底才推出（移动端优先），已有超 50 万用户使用；过去五个月平台新增约 7 万款游戏，折合每月约 1.4 万款，而 Build 尚未向全部用户开放。工具侧增速更陡：自 Q2 以来，头部创作者使用 AI 工具（含 Build、Studio Assistant 及通过 MCP 接入的外部 AI）的时长增至原来的 3 倍；每天使用其 MCP 服务器的创作者数量增长近 5 倍。门槛与限制：Build 面向年满 9 周岁且完成年龄验证的用户开放，已发布的 AI 生成游戏仅面向 16 岁以上用户。平台的下一步是分发：Roblox Everywhere（让 Roblox 游戏走出平台运行）+ Universal Player（用 AI 把任意已有主机 / PC / 移动游戏导入 Roblox），目标是把平台做成面向全体开发者的分发入口。用户结构：Q3 日活中 18–34 岁占 26%，未满 18 岁占 18%。股东信的战略判断值得抄下来：AI 让创作门槛下降后，分发、用户聚合、变现、发现与安全成为更关键的环节——护城河从「能不能做出来」转移到「能不能被看见」。背景上，该平台此前曾被指抓取大量三维资产用于 AI 训练。

一手把 3D 建模压成一句话并输出能改的工程文件，一手给「不许复刻具体游戏」划下第一条 AI 与游戏 IP 的边界 —— 提速和立规发生在同一天
7 Kimi 上线 3D Make：一句话或草图 → 云端跑 Blender 脚本，输出可编辑工程文件 🧊 3D 内容生产
10 月 31 日，月之暗面随 Kimi K3.1 Pro 上线 3D Make 模块：给模型一段文字描述、一张草图或一张参考图，它先推断物体的形状、比例与空间关系，再自主编写 Blender、FreeCAD 等专业软件的可执行脚本，上传到云端运行——相当于让 AI「远程操控」建模软件完成建模。产出文件可下载、可在线预览，用户还能用自然语言让它修改尺寸与几何形状，模型重新计算生成，支持多种格式导出。关键不在精度，在输出形态：官方演示中一句话可生成带材质分层的室内场景，产出的是可编辑的 .blend 工程文件而非静态网格——这意味着它塞进的是现有 DCC 工作流，而不是另起一套。路径值得抄下来：自然语言 → 推断几何 → 写脚本 → 云端执行 → 回传工程文件。用可执行脚本当中间层，比端到端生成网格更能保证结构可控、可改。官方给的场景包括组装场景、开发游戏资产——这是国产模型在 3D 内容生产方向少见的工程化落地。行业坐标：Kimi、ChatGPT 等模型都在向 CAD 建模延伸，但行业普遍反映「所写非所得」——后台难以真正理解用户意图，距离成熟可用尚远。冷静看：效果与描述不吻合的情况仍然常见；脚本路线依赖 Blender / FreeCAD 的能力边界，复杂拓扑与绑定仍要人接手。

8 Anthropic 收紧 Claude：新增「不许复刻现有游戏」规则，逆向工程请求被拦 ⚖️ 版权护栏
多名开发者发现 Claude Code 与 Opus 5.5 开始拒绝复刻游戏机制、重建现有游戏。X 用户 Chasm 找到 Claude Code 规则中新增的一条（列于 tengu_heron_brook 之下）：「可以构建原创游戏、某一类型下的游戏，以及基于用户自身设计与素材的游戏。不要构建对某一特定现有游戏的复刻，即使它被改名或被称为原创。」Anthropic 技术团队成员 Addy Osmani 随后确认：「我们在 Opus 5.5 的 Claude Code 提示词里加了两句话，让它避开复刻别人的具体游戏，因为用 Claude 侵权违反我们的使用政策。」为什么是现在：近几个月「AI 克隆游戏」已形成小规模家庭作坊式产业——《堡垒之夜》《辐射》克隆、玩家自制主机移植版本层出不穷；Steam Next Fest 展示的 demo 数量比上届翻倍，增量大部分来自 AI 辅助游戏，Valve 已承认 Steam 存在 AI 灌水问题。多款游戏 demo 被威胁「在你发布前克隆成完整游戏」，已有工作室因此取消公开 demo 计划。误伤已经发生：Claude 的 GitHub 页面涌现大量 issue——有开发者报告它连自己项目早期成果都拒绝复刻，仅因后续开发需要相似机制；Reddit 用户报告影响超出游戏领域，连「Reverse Engineer Anything」这类能力也被拒，而后者此前被用于破解智能电视厂商锁定、给汽车信息娱乐系统加功能、把游戏重新编译到其他平台。安全研究也被波及：有开发者在构建反作弊系统、分析 Windows 崩溃转储、做常规代码安全审查时遭到拒绝。时间线关联：这批限制与 Anthropic 10 月 6 日上线的 Cyber Verification Program（把前沿模型的高级网络安全能力限制在 Project Glasswing 覆盖的实体内）时间上重合，但官方未确认二者直接相关。Osmani 的补充：「原创游戏、类型游戏、基于你自己设计的游戏应当继续可用。我们会持续迭代以找到合适的平衡。如果 Claude 拒绝了本属于你的东西，发给我。」外溢效应已经出现：部分开发者开始讨论转向中国模型与开源权重模型以绕过商业过滤。

编辑点评

今天 8 条新闻串起来是同一件事：AI 的钱在变贵，而 AI 的效率在变便宜——两件事第一次同时发生在一个星期天。

三条主线同时展开：① 收紧的全是入口（OpenAI 把 ChatGPT 与 Codex 并成一个 Token 池，聊天从此要跟写代码抢预算；融资目标砍掉 100 亿、估值降 1500 亿，首次交割还可能不足 200 亿；Anthropic 招股书里 9000 亿表外义务是账面负债的 8 倍，黑石只给 BB 投机级）—— 钱与算力两笔账同时被重排。② 放量的全是效率（商汤 32 层权重循环出 56 层计算，把 27B 级能力压进一张 24G 显卡；DeepSeek 用 Router + Worker 把多任务完成时间从 29.5 分钟压到 12.4 分钟；Roblox 上 7 万款 AI 游戏、Top100 超八成用了 AI，Kimi 3D Make 把建模压成一句话）—— 不靠更多算力，靠把同一份算力用得更深、调度得更聪明。③ 收紧的尽头必然是护栏（Anthropic 给 Claude Code 加了两句话：不许复刻任何具体存在的游戏）—— 当产量被打到地板价，规则就必须跟上，AI 与游戏 IP 的第一条边界今天被划下。

今天最高分给到 #4 OpenAI 融资缩水（9.3/P0）—— 它的重要性不在少了 100 亿美元，而在于「估值驱动」这个持续两年的叙事第一次被公开市场叫停，融资照做，但价格由买方说了算。

四条可以立刻执行的线索：① 重排 AI 额度预算（12 月起 ChatGPT 与 Codex 共池，把聊天与产出分开记账的做法要作废；建议把额度集中给「出片 / 出脚本 / 出素材」类任务，日常问答改用 Instant）；② 先跑一轮 Kimi 3D Make（它输出的是可编辑的 .blend 工程文件而不是静态网格，可以直接接进现有 Blender 工作流；建议先拿简单道具 / 白模验证，再上复杂场景与材质分层）；③ 评估本地私部署（商汤 Loop-9B 是 Apache 2.0 + 单张 24G 卡可跑，适合做不出内网的文档 / PPT / 多步 Agent 流水线，先跑一轮 RaccoonPPT 类任务验证）；④ 把日报与竞品监控改成常驻 Agent（DeepSeek Super-agent 的 Router + Worker 正是这类流水线的标准形态——一个常驻调度入口 + 多个并行 Worker，而不是每天手动开七八个会话窗口；同时留意 Claude 逆向工程类请求正在变紧，需备好开源 / 国产模型的备选链路）。
