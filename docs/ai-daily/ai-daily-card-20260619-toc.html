i. AI Agent & Platform 4 items
🤖 AI Agent & 平台
今日最重磅的 Agent 与平台动态
1 OpenAI Codex 全产品线开放第三方大模型接入 🔥 P0
OpenAI 宣布 Codex 移除对自家模型的强制依赖，开发者可接入任意第三方大语言模型。新模型需适配 Responses API 接口规范，标志着 AI 编程平台从"模型锁定"走向"开放竞争"。开发者可自由选择 Anthropic、Google、DeepSeek 等模型驱动 Codex Agent。
2 NVIDIA ENPIRE：8 智能体协作机器人自主实验，完全开源 🔥 P0
NVIDIA 推出 ENPIRE 项目，8 个智能体操控双机械臂完成全流程物理实验，配备本地 RTX 5090 显卡，实现7 天无人值守运行。该框架将完全开源，全球开发者可基于此搭建自主研究系统。AI Agent 从虚拟走进物理世界。
3 苹果 Xcode 27 深度集成 AI 智能体，CoreAI 框架开放第三方 P1
苹果发布 Xcode 27，开发者可用自然语言对话完成代码修复与构建。引入 CoreAI 框架调用端侧模型，兼容 Anthropic、OpenAI 等第三方大模型。Siri 独立成 App + 第三方 Agent 接入，苹果 AI 战略从"落后者"转向"平台聚合者"。
4 Claude Code 深度用户周均 20 小时，AI 承担 80% 代码执行 P2
Anthropic 公布数据：深度用户每周使用 20 小时 AI，AI 承担 80% 代码执行操作，人类从"写代码"变成"审代码"。Design 协同工具首周 100 万用户注册，AI 编程从开发者扩展到设计师群体。
ii. Industry & Business 2 items
💼 行业 & 商业
值得关注的商业信号
5 DeepSeek 上线识图模式，V4.1 多模态版本本月发布 🔥 P1
DeepSeek 正式上线网页版识图模式，数学题可自主验算。计划本月发布 V4.1 多模态版本，整合视觉+文本+代码三模态。完成 510 亿元首轮融资，估值近 4000 亿元，创始人梁文锋个人出资约 200 亿元。
6 Midjourney 跨界医疗：发布全身声学计算断层扫描仪 行业事件
Midjourney 发布 "The Midjourney Scanner"全身体声学计算断层扫描仪，宣称成为 MRI 的继任者。通过数千传感器发射声波+AI 算力处理 PB 级数据，将声波信号转化为高精度图像。AI 公司从"生成虚拟内容"转向"解析物理世界"。
iii. Open Source & Tools 2 items
🔓 开源 & AI 工具
开源生态与 AI 创作工具动态
7 GitHub 6 月趋势：Claude Skills 生态爆发，编码智能体白热化 P1 开源
GitHub 6 月榜单呈现 AI 工程化转向：Claude Skills 模块化生态成最大爆点，mattpocock/skills 月增 55K 星。编码智能体（Coding Agent）成为增长最快子类别，OpenClaw 以 37.4 万星领跑。Token 压缩赛道由 headroom 带动，宣称裁剪 60-95%。
8 Grok Imagine Video 1.5 正式 GA：6 秒视频 25 秒出 P1 工具
xAI 宣布 Grok Imagine Video 1.5 结束预览正式上线。Fast 模式下 6 秒 720P 视频仅需约 25 秒（前代 40 秒+），主打音画同步、运动真实性和生成速度升级。已在 xAI API 以 grok-imagine-video-1.5 模型名称提供，开发者可调用。
