i. AI Agent & Platform 3 items
🤖 AI Agent & 平台
今日最重磅的 Agent 与平台动态
1 OpenAI Codex Computer Use 正式登陆 Windows，手机可远程操控电脑 9.3
OpenAI 发布 Codex 26.527，Computer Use 视觉操作能力正式登陆 Windows 10/11，支持屏幕识别与鼠标键盘控制。同步上线手机远程控制功能——ChatGPT App 可远程启动电脑任务，AI Agent 从"桌面助手"进化为"全天候远程操作员"。Windows 版仍缺锁屏操作等 macOS 专属能力。
2 何恺明团队首个扩散语言模型 ELF：不走 GPT 自回归老路 8.8
何恺明带队发布连续扩散语言模型 ELF（Embedded Language Flows），仅 105M 参数但架构完全不同于 GPT。放弃"预测下一个 token"的自回归范式，采用扩散模型路线生成文本。若扩散路线可 scale，可能绕过自回归的推理速度瓶颈，实现并行解码。
3 软银拟 750 亿欧元在法建 5 吉瓦 AI 数据中心，欧洲史上最大 8.5
软银计划投入至多750 亿欧元在法国敦刻尔克等地建设总功率最高5 吉瓦的数据中心，首期力争 2031 年提供 3.1 吉瓦算力。法国凭借核电低价电力成为欧洲 AI 算力中心首选地，全球 AI 基建竞赛进入"吉瓦级"时代。
ii. Security & Protocol 3 items
🛡️ 安全 & 协议
Agent 从"能做什么"转向"如何安全规范地做"
4 Deno 开源 Claw Patrol：AI Agent 安全防火墙 8.3
Deno 团队发布专为 AI Agent 设计的开源安全防火墙 Claw Patrol。基于 Deno 安全沙箱架构，拦截和审计 Agent 所有系统调用，支持自定义安全策略、白名单和实时告警。轻量高性能，适合集成到 LangChain、CrewAI 等各类框架。
5 COMPUTEX 前瞻：英伟达 N1 PC 芯片 + Vera Rubin 机架下周亮相 8.2
COMPUTEX 2026 将于 6 月 2-5 日举行，黄仁勋周一主题演讲。N1/N1X PC 芯片（英伟达 GPU + 联发科 Arm CPU）正式亮相，微软同步推出本地 Agent 执行软件。Vera Rubin 机架内存成本较 GB300 飙升 435%，英伟达+微软+Arm 联手定义"PC 新世代"。
6 Open Envelope：定义 AI Agent 团队的开放协议规范 8.0
Open Envelope 旨在标准化 AI Agent 团队的定义和交互方式——类似 Agent 世界的"OpenAPI 规范"。统一 Schema 让不同框架（LangChain、CrewAI、AutoGen）构建的 Agent 可在同一团队中无缝协作。Multi-Agent 互操作性的关键一步。
iii. Models & Optimization 2 items
⚡ 模型 & 优化
推理经济性与架构多元化
7 智元 GE 2.0 仅 2B 参数登顶 WorldArena 世界模型榜单 7.8
智元机器人发布GE 2.0 世界模型，仅 2B 参数便登顶 WorldArena 榜单。核心创新在于新型时空注意力机制和物理约束训练策略，"四两拨千斤"——精心设计的小模型在特定领域可超越大模型，降低世界模型部署门槛。
8 小米 MiMo 推理系统全链路优化，成本最高降 99% 7.6
小米首次公开 MiMo 推理系统全链路优化技术细节：多级缓存、动态批处理、自适应并行度调整，推理成本最高降低 99%。覆盖模型量化到服务层加速全流程，原本 1 元推理可降至 0.01 元，推理经济性进入"分钱时代"。
