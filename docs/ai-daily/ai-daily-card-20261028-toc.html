1 Google DeepMind 发布 Genie 4 世界模型：一句话生成可交互虚拟世界并同步原生音频 🌍 世界模型
Google DeepMind 发布交互式世界模型 Genie 4 研究预览版，支持一句话生成可交互虚拟世界并同步原生音频，用户可实时操控环境并即时编辑提示词。CEO Sundar Pichai 称其为「迄今最逼真、最具互动性」的世界模型；Demis Hassabis 亲自转发。Ethan Mollick 现场用它跑了 DOOM 演示，实时生成游戏环境体验流畅。Logan Kilpatrick 预告 Genie 4 即将登陆 API。The Verge 报道称可生成「更长更真实的交互体验」，Ars Technica 评价「人物更真实、物理模拟更精确」。「原生音频 + 实时编辑」是 Genie 4 相比前代最大的跃迁：Genie 3 只能生成无声世界，Genie 4 把音频当作世界模型的一等公民——脚步声、环境音、物体碰撞全部同步生成，意味着世界模型第一次逼近「完整感官体验」而非「可视化沙盒」。实时提示词编辑打破「生成即固定」：用户可以在体验过程中即时修改描述（如「把白天改成夜晚」「加一场雨」），世界实时响应，这把世界模型从「生成一段视频」变成了「持续运行的可编程环境」。即将登陆 API 是最关键的信号：Genie 3 发布时无 API 计划，Genie 4 明确预告 API，意味着开发者很快就能把「一句话生成可交互世界」嵌入自己的产品。

2 蚂蚁百灵发布灵光 2.0 并开源 Ling-3.1-flash-base 与 Ling-3.1-flash-1019 🇨🇳 国产模型
蚂蚁百灵发布灵光 2.0，同步开源 Ling-3.1-flash-base 与 Ling-3.1-flash-1019 两个模型权重。Artificial Analysis 评测显示 Ling 3.1 Flash 1019 提升至 44 分。卡兹克实测灵光 2.0 接入 15 个国民级 App（米家、钉钉、支付宝等）打造个人 Personal Agent，展示「国产 personal agent 整合米家钉钉支付宝等应用」的实际体验。「开源权重 + Personal Agent 产品」双线并行是蚂蚁的差异化打法：大多数国产厂商要么只开源模型（DeepSeek 路线）要么只做产品（豆包路线），蚂蚁同时推进——开源建生态、产品做体验，两条腿走路。接入 15 个国民级 App 是灵光 2.0 最有传播力的点：不是「能调 API」而是「已经接好了你每天在用的 App」，从模型能力到用户可感知的价值之间，蚂蚁把最后一公里走通了。Personal Agent 赛道正在升温：本周 Sentient OS（YC F26）发布端侧 AI 读取个人数据生成 markdown，加上灵光 2.0 接入国民 App，「个人智能体管你数字生活」从概念变成产品。

微软 AI 发布 MAI Image 2.7 Preview 图像编辑模型，登上 Arena 图像编辑榜第 3 和 Artificial Analysis AA-Image-Editing v2.1 第 2。Mustafa Suleyman 宣布 MAI-Image 升至全球图像编辑模型第二。Testing Catalog 报道模型已上线 MDASH 平台。微软在图像编辑赛道的排名爬升速度惊人：从 MAI-Image-Flash 到 2.7 Preview，一年内从「没进榜」到「AA 第 2」，说明微软自研图像模型已经跨过从「能用」到「能用且好用」的门槛。「Preview」标签说明还有上升空间：2.7 是 preview 版本而非 GA，正式版大概率还会在指令遵循、细节一致性上继续优化。图像编辑 vs 图像生成的赛道分化：Arena 和 AA 都在单独做「编辑」榜，说明行业已经把「改图」（inpainting / style transfer / object replacement）从「生成」中独立出来当作一个能力维度评测。

4 NVIDIA 与 Oracle 将 OCI Superclusters 扩展至多吉瓦规模并上线 Vera Rubin NVL72 🏗️ 算力基建
NVIDIA 与 Oracle 宣布将 OCI Superclusters 扩展至多吉瓦规模，并上线 Vera Rubin NVL72 与 Vera CPU。这是继上周 Meta 950 亿募资、SpaceX Apollo 400 亿 GPU 租赁之后，AI 算力基建的又一重磅动作。「多吉瓦」是算力规模的新计量单位：过去说「多少块 GPU」，现在说「多少吉瓦电力」，说明 AI 算力竞争已经从芯片数量竞争升级为能源规模竞争。Vera Rubin NVL72 上线意味着下一代架构开始交付：Blackwell 还在放量，Vera Rubin 已经进 Supercluster，NVIDIA 在用代际交替保持对 AMD / 自研芯片的领先窗口。Oracle 从「数据库公司」变成「AI 算力供应商」：OCI 在 AI 算力赛道的存在感越来越强，上周 OpenAI 也被曝将使用谷歌云 TPU，云厂商格局正在被 AI 算力需求重写。

5 Anthropic 收购一人公司 Mithril Medicine：创始人用 Claude 推进肌肉萎缩症疗法 💊 AI 制药
Anthropic 收购一人公司 Mithril Medicine，创始人用 Claude 推进肌肉萎缩症疗法研究。Yuchen Jin 评价这是「真正的单人十亿美元公司范式」。Anthropic 同时分享 Claude 支持药物研发的早期成果，已用于 6 家药企的真实药物研发项目。「一人公司被收购」是 AI 时代组织形态的标志性事件：一个人 + Claude 做出被大厂收购的成果，说明 AI 让「个人产出」与「组织产出」的差距急剧缩小。Anthropic 收购 Mithril 的战略意图：不是买技术（一人公司技术有限），而是买「Claude 在药物研发中的实战验证案例」——这是 Anthropic 向投资者证明 Claude 在垂直领域价值的最有力叙事。6 家药企真实项目是比收购本身更重要的信号：AI for Drug Discovery 从论文走向真实管线，意味着模型能力已经跨过「能辅助」到「被信任用于真实决策」的门槛。

6 Liquid AI 发布 LFM3 系列：一个 1.7B 底座衍生六个 2B 级多模态开源模型 📦 开源权重
Liquid AI 发布 LFM3 系列开源权重模型：以 1.7B 文本底座衍生出六个 2B 级多模态模型，1.7B 文本模型超越前代 2.6B。全部开源权重，覆盖文本、视觉、音频等多模态任务。「一个底座衍生六个模型」是高效的模型家族设计：不是训练六个独立模型，而是共享 1.7B 底座 + 各自的模态适配层，训练成本和推理成本都大幅降低。1.7B 超越前代 2.6B 说明小模型效率仍在快速提升：参数更少、能力更强，端侧部署的经济性持续改善。LFM3 的定位是「设备端 + 嵌入式」：2B 级模型可以在手机、IoT、车载等场景本地运行，与 NVIDIA Nemotron Bolt E4B（上周报道）形成端侧小模型赛道的竞争格局。

7 面壁开源 MiniCPM-OCR 1.0 + 百度开源 Unlimited OCR 2：OCR 赛道同日双开源 📄 OCR
面壁智能开源 MiniCPM-OCR 1.0 及校验模型 MiniCPM-OCR Jev；百度开源 Unlimited OCR 2，核心创新 SR-SWA（Sparse Region-Selective Window Attention）让超长文档解析的注意力开销尽量不随页数上涨，支持几十到几百页文档解析。同日两条 OCR 开源发布，赛道竞争白热化。SR-SWA 解决的是「长文档 OCR 的注意力爆炸」问题：传统 ViT 处理 100 页文档时注意力矩阵是 O(n²) 增长，SR-SWA 通过稀疏区域选择让开销接近线性，这是「能处理整本书」而非「能处理一页」的技术基础。同日双开源说明 OCR 是被低估的热赛道：Agent 时代文档解析是前置能力（读 PDF、读合同、读财报），OCR 精度直接决定下游 Agent 的信息质量。面壁 + 百度同日发布是国产 OCR 生态的集体信号：不是巧合，而是 Agent 应用爆发带来的文档解析需求倒逼模型层供给。

8 Cursor design mode 新增 Annotate 标注功能并开始将 Bot 纳入团队 🤖 AI 编码
Cursor 发布 design mode Annotate 功能，支持在设计模式中直接添加标注；同时 CEO Michael Truell 宣布 Cursor 开始将 Bot 纳入团队管理。Grok Bot 也分享了销售团队共享机器人的用法。「Annotate」补齐了 design mode 的协作闭环：过去 design mode 只能看不能标，现在可以像 Figma 一样在界面上加注释，让「设计 → 开发」的沟通成本进一步降低。「Bot 纳入团队」是 Cursor 从工具走向平台的信号：不只是「你用 Cursor 写代码」，而是「Cursor 里的 Bot 是你的团队成员」，AI 编码工具正在从 IDE 变成协作平台。与本周微软 Agent 365 的方向一致：巨头和独角兽都在把 AI 从「辅助工具」重新定义为「团队成员」，组织形态正在被重新设计。

编辑点评

今天 8 条新闻串起来是同一件事：世界模型从 demo 走向产品，端侧模型从论文走向国民 App。

三条主线同时展开：① 世界模型产品化（Genie 4 原生音频 + 实时编辑 + 即将开放 API）—— 「一句话生成可交互世界」从论文 demo 变成可嵌入产品的能力。② 端侧与垂直模型加速（蚂蚁灵光 2.0 接入 15 个国民 App、Liquid LFM3 一个底座衍生六个模型、面壁+百度 OCR 同日双开源）—— 模型能力正在被拆解成场景专用的小模型，部署成本持续下降。③ 组织形态被重新定义（Anthropic 收购一人公司、Cursor 把 Bot 纳入团队）—— 「一个人 + AI」的产出能力已经能被大厂收购，「Bot 是团队成员」从比喻变成产品功能。

今天最高分给到 #1 Genie 4（9.3/P0）—— 原生音频 + 实时提示词编辑让世界模型第一次逼近「完整感官体验」，即将开放 API 意味着开发者很快就能把「一句话生成可交互世界」嵌入自己的产品。

四条可以立刻执行的线索：① 世界模型 + 品牌场景（Genie 4 API 开放后，可关注「一句话生成战场环境」的互动体验，优先在概念预告片或互动 H5 中试点）；② 图像编辑能力独立评测（MAI Image 2.7 登榜说明「改图」已是独立能力维度，军事题材素材的武器替换、场景改天气/时间可优先试用）；③ OCR 作为 Agent 前置能力（竞品截图文字提取、历史素材归档检索、合同/排期文档自动解析可关注百度 Unlimited OCR 2 的多页表现）；④ 「一人 + AI」组织实验（团队内部哪些环节可以由「一个人 + AI」完成，减少协调成本）。
