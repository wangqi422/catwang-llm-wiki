11 月 23 日，Anthropic 宣布推出 Claude Ship（beta）——把代码提交后「审查—修复—批准」整段流水线交给 AI，面向 GitHub 的 Claude Team 与 Enterprise 团队，按 token 计费。三件套：Code Review（已正式可用）负责审查；PR Steward（beta）处理 CI 失败、合并冲突与审查反馈，每次推送后说明改了什么、必要时如何撤销；Claude Approvals（beta）依据团队写进仓库、可用自然语言编写的审批策略执行批准，并综合 Code Review 结果与企业分类器信号。Anthropic 强调 PR Steward 本身不批准或合并、审批权限受策略限制；因仍处 beta，建议先以「观察模式」运行（只出判断不执行）、先单仓库试点、设每月支出上限。目标是把交付速度拉到接近编写速度。查重：零命中；与 11-20 Codex 性能工厂、11-23 Claude Code 撼 IDE 不同域。

7 OpenAI 携手思科开源安全运行时 Shirudo：用 eBPF 为运行中的 Linux 提供「无需重启」的临时漏洞防护，Codex 生成的盾成功拦截 Elasticsearch 上的 Java4Shell 攻击 🛡️ 开源 / AI 安全 / P1
11 月 23 日，OpenAI 与思科联合开源安全运行时 Shirudo（日语「盾」），目标是在永久补丁到位前就能自我保护——基于 eBPF 技术，可在不重启系统前提下向运行中的 Linux 加载名为「shield」的临时防护，阻断漏洞利用而不影响合法请求。四大能力：实时防护（生效前可先观察）、机器速度防御（AI 智能体调查漏洞、写盾并验证）、可信部署（shield 加密签名 + eBPF 验证器校验）、硬件支撑验证（用 TPM 记录加载/移除）。在受控测试中，OpenAI 用 Codex 生成的 shield 为 Java Base64 解码器加入输入检查、直接挂到运行中的 Elasticsearch 进程，成功拦截针对「Java4Shell」的攻击且服务不中断，对近期一个 PHP 漏洞也完成拦截。项目以 BSD 2-Clause 开源、BPF 程序 BSD/GPL 双许可。查重：零命中；与 11-14 Cursor 安全事件、11-22 ARTEX 攻击框架不同——今日为防守侧开源基础设施。

8 谷歌 DeepMind 用多个 Gemini 4 智能体团队 + Lean 形式化验证优化量子算法：反正弦电路最高提速 290 倍、聚变算力降 11.8 倍，Lean 库与验证方案全部开源 ⚛️ AI4S / 形式化验证 / P1
11 月 23 日，谷歌 DeepMind 与 Google Quantum AI 发布联合研究：让多个 Gemini 4 智能体团队协同优化经典量子算法、生成高效量子电路，并用形式化定理证明器 Lean 对每个结果做数学验证——因资源密集的量子电路无法在经典计算机或现有量子处理器上实测，只能靠数学证明正确性。成果覆盖多个「人类重大挑战」场景：惯性约束聚变关键属性计算算力成本降 11.8 倍（纠错量子比特从 5650 降至 4338），光敏分子模拟成本降约 8 倍，细胞色素 P450 酶模拟性能提升 2.5 倍（内存 481→333 量子比特），基础算法 Grover 提速 2.57 倍、反正弦（arcsin）子程序最高提速 290 倍。团队把 Lean 函数库（基于 Lean 4、扩展 Mathlib/Physlib，Apache 2.0）、问题规格与经形式化验证的解法全部开源至 GitHub；智能体协调系统仍为内部专有。需注意：即便优化后，科学模拟所需算力仍超出第一代纠错量子计算机能力——成果是「资源需求降低」，不等于现有硬件已能跑通。查重：与 11-21/23 黎曼证明同属 AI+形式化验证主线，但学科不同（量子电路优化 vs 数学猜想）。

编辑点评

今天这批 8 条，被两股力量同时拽着：一边是权力与资本的重新结算——英伟达把辞任仅 11 天的黄仁勋请回王座、股价一天涨回近万亿，Sierra 靠「按结果收费」把估值半年翻倍到 300 亿，CrowdStrike 用 439 亿买下 Zscaler 把端点与零信任并成一张网；另一边是 AI 开始接管交付与安全——GLM-5.4 用「循环深度」换智能、GPT-6.2 Sol 补上日常聊天、Claude Ship 把 PR 从审查到批准一条龙包干、OpenAI 与思科用 eBPF 给未打补丁的 Linux 装临时盾、Gemini 4 智能体把量子算法提速 290 倍还附上数学证明。

① 王座 · 账本 · 架构（#1–#3）。黄仁勋全票复职（#1）与调查委员会同步推进，是「信任」与「合规」的双轨补位；Sierra 300 亿估值（#2）把「按结果收费」变成可核验的定价范式；GLM-5.4（#3）则在「扩参数」之外走出「循环深度换智能」的第三条路。三件事的共同点是：老规则都被重画了一遍。

② 模型 · 交付 · 版图（#4–#6）。GPT-6.2 Sol 补上 Chat 入口（#4），把模型能力沉淀成日常体验；Claude Ship（#5）把 AI 从「写代码」推到「批准代码上生产」；CrowdStrike 439 亿收购 Zscaler（#6）则用并购把「AI 安全」从概念做成版图。能力、交付、资本在同一条线上收束。

③ 自防御 · 科研（#7–#8）。Shirudo（#7）给未打补丁的 Linux 装「不用重启」的临时盾，把 AI 从「发现漏洞」延伸到「先挡住攻击」；Gemini 4 智能体配合 Lean 验证优化量子算法（#8），展示了「AI 搜索 + 机器可证明正确」的科研闭环。两者都在回答同一个问题：AI 交出的活，怎么让人放心。

今天最该拎出来的，是「交权」与「护栏」同步这条暗线——所有把权力交出去的动作，都配了一道可核验的护栏：复职配调查委员会、AI 批代码配观察模式、临时盾配人类批准、智能体搞科研配 Lean 验证。交出去的是活，攥在手里的是规矩。

说到底：王座上的、账本上的、流水线上的位置今天都被重新标了价，而我们要做的是——把「谁来背书、如何复核」写进每一份交付里。

一句话：王座迎回旧主，资本给智能体标价，AI 学会给自己打补丁

今天最高分给到 #1 黄仁勋全票复职（9.6 / P0）：单日近万亿市值回升 + 半导体全线反弹，说明市场把这轮治理震荡的核心不确定性视为解除；但调查未结、12·3 听证会未至，「信任」与「合规」的双轨补位才刚开始，仍是观察 AI 巨头治理走向的关键样本。

五条可执行线索：① 危机公关节奏——核心人物/合作方风波靠「制度补位 + 权威背书 + 明确时间表」关住不确定性，别只用一句「无事发生」；② 按结果对账——与 AI 素材/代运营团队合作用可核验的业务结果（转化、留存、采用率）结算，而非「产出多少张图」；③ 规则文件定边界——借鉴 Claude Ship 的「AI 出活 + 策略文件定边界 + 人签字放行」三级结构做内容审核流；④ 可逆的临时开关——线上漏洞/配置错误先上可撤销的临时止损方案再修根因，呼应 Shirudo 的临时盾；⑤ 机器初筛 + 独立复核——凡涉及数值、榜单、规则的对外物料建立双保险，「模型说对」不等于「事实对」。
