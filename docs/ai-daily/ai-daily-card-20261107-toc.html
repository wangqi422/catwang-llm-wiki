1 AI 资本同日重定价：OpenAI 首批 110 亿美元到账、Anthropic IPO 估值下修、企业 AI 支出见顶信号 💰 融资 / IPO / 资本纪律
11 月 6 日彭博报道 OpenAI 完成新一轮融资首批约 110 亿美元到账，对应估值 1.25 万亿美元；首批出资方为 Coatue 与普信集团，后续有软银、红杉、Founders Fund、a16z 与阿联酋财团，剩余部分预计数周内完成。本轮总规模从最初 300 亿目标降到约 200 亿、估值目标从 1.4 万亿降到 1.25 万亿（仍高于今年 3 月的 8520 亿）。《纽约时报》DealBook 同日披露：累计投入约 650 亿美元的软银本轮仅商谈数亿美元，Coatue 也在数亿美元级，阿联酋财团预计成最大出资方。CFO Sarah Friar 称「好的 CFO 总会在能融资的时候融资」，强调数据中心投资计划不变、仍推进 2027 年上市可能性。同一天 Anthropic IPO 潜在估值从 1.5 万亿下修至 1.2–1.3 万亿（部分投资人认为接近 1 万亿），募资拟从最高 1000 亿降到约 800 亿，路演或延至 11-16 当周甚至推迟；招股书显示前九个月营收约 332 亿美元、同比约 +1200%，但 S-1 里 10 月营收一栏留空。Ramp 数据显示企业 AI token 支出增长放缓；彭博另报微软逐步关停从甲骨文租用的部分算力并不再续签。与 11-01 期要区分：那期报的是「300 亿→200 亿、1.4 万亿→1.25 万亿」的传闻阶段，今天是首批资金实际到账 + 出资方削减结构曝光 + 估值下修扩散到 Anthropic。估值守住，支票变小：两家估值都还在万亿以上，但投资人从愿付任何价转为要折扣、要营收数据。触发点是 11-05 美股 AI 股 19 个月最大单日跌幅（纳指 -5.52%、市值一日蒸发约 2.5 万亿美元）与中期选举后 41 项地方公投 40 项倾向限制数据中心。边界：均为匿名信源与媒体报道，两家公司未公开确认，本轮尚未 close，最终规模与估值仍可能变化。

2 工信部印发《关于加强智能体终端设备进网管理的通知》：智能体进手机先过进网许可 📋 监管 / 进网许可 / 身份码
11 月 6 日工信部印发 《关于加强智能体终端设备进网管理的通知》，覆盖预置安装智能体的手机、平板、可穿戴设备等电信终端，部署四项任务：① 智能体与终端适配——开发者加强适配验证，须在产品设置页公示适配验证列表（已完成适配的终端型号与操作系统信息），上架分发平台前提交验证情况；② 改进进网管理——进网检测中开展适配验证与风险评估，依法开展涉诈风险安全评估与反诈能力前置性评测，终端所用智能体须参考国标配备唯一身份码，生产企业保证获证前后一致性；③ 强化现网升级管理——OTA 推送智能体升级须提交方案（时间、规模、用户群、场景、经营模式、数据与反诈措施），升级结束提交报告，经工信部组织专家评估、征求意见后方可正式提供服务；④ 健全分发管理——应用分发平台推动 App 开发者通过电子签名主动声明是否同意智能体调用，未经声明同意不得强制调用调取，不得提供不兼容设备型号的智能体下载安装。官方定调引导 AI 技术为人所用、为人服务、为人所控，建立适配验证→进网检测→现网升级→分发管理全链条制度；中国信通院将建设智能体版本与终端型号适配库、可信身份体系与管理平台。与 11-05 期区分：那是乌镇峰会 20 家单位的《智能体发展自律公约》（行业自律八条 + 身份注册平台），今天是行政主管部门的进网许可制度，具强制力，并把唯一身份码从倡议写进进网要求。迭代节奏被纳入监管：OTA 升级要报方案、交报告、过专家评估，系统级智能体不再能先推后改。入口之争第一次有明文边界：未经声明不得强制调用，直指手机厂商与超级 App 让智能体跨应用代操作的野心。边界：通知为框架性部署，具体检测标准、适配库与身份体系仍在建设，执行细则与「重大变化」判定口径待后续文件。

3 Meta 无限期暂停商业网页抓取条款：挪威、巴西、英国三国监管同日夹击 ⚖️ 数据合规 / 司法 / 授权链
Meta 宣布无限期暂停原定 11 月 20 日生效的商业条款更新——该条款曾要求商业账号授权 Meta 抓取其关联网站内容且无退出选项。压垮它的不是舆论而是司法：挪威奥斯陆法院应十家媒体申请颁布临时禁令、巴西法院禁止未经授权使用新闻内容、英国竞争与市场管理局（CMA）启动正式调查，美国参议员 Schiff 与 Blackburn 亦致信扎克伯格要求撤回。Meta 称将继续与各方磋商，暂停不等于撤回。同日 Anthropic 通知 API 客户：11 月 16 日起 Claude Opus 4.6 / 4.5、Sonnet 4.5、Haiku 4.5 陆续加入不可见文本水印，以赶上欧盟 AI 法案 12 月 2 日合规期限；水印为 DeepMind SynthID-Text 变体，通过选词统计模式嵌入，不增加 token、不含用户信息，但本轮四款模型仅在默认采样参数下带水印，开发者调整 temperature、top_p 后可能失效。与 11-02 期四巨头统一 robots.txt 退出信号是同一条主线的下一章：那次是站方可选退出的企业协同，这次是平台方被司法强制暂停——训练与检索内容的来源可追溯性正从自律条款变成法定义务。授权链成为固定合规成本：与 11-06 期 Anthropic × 美联社首份新闻内容授权协议连起来看，模型厂商从先抓再说转向先谈授权、先加标识。水印的缝隙要说清：默认参数才生效意味着合规承诺与工程现实仍有距离，调整采样是开发者常见操作。边界：Meta 是暂停非撤回，CMA 调查与各国诉讼仍在进行；Anthropic 水印覆盖率与鲁棒性尚无独立复测，不宜按全面合规解读。

4 Perplexity 发布 Teammates：常驻工作智能体，内部 30 天跑出约一万个 🛠 常驻 Agent / 订阅产品
11 月 6 日 Perplexity 推出 Teammates，把 AI 助手从会话内写提示词改成给目标后常驻在岗。用户只需描述高层目标，Teammates 便跨营销、销售、客服、运营等场景持续监控项目进展、主动汇报异常与待办，可主动联系用户、同事与其他智能体，并复用 Perplexity 既有项目、技能与记忆，不必反复给指令。每个 Teammate 运行在隔离环境、沿用主账号的权限与访问控制，避免越权读取数据。先面向 Max 订阅（200 美元/月） 网页版研究预览开放，随后上 iOS 与桌面原生应用。Perplexity 称内部工作区 30 天内已跑约 10000 个 teammates（约为员工数 20 倍），前一日约 1000 个活跃；CEO Aravind Srinivas 预计组织最终会为每名员工运行数百个队友。官方点名强项是深度研究、数据分析、QA、工单分诊与代码评审，对标 OpenAI Dots 与 Anthropic Claude Duet。交互范式变了：从一问一答变成带目标的持续代理，常驻 Agent 第一次被明码标价为 200 美元/月的高端订阅商品，而非免费聊天附赠功能。与 11-06 期 Kimi Hosted Agents 是上下游：那边把 Harness 做成 7×24 云托管环境，这边卖住在环境里的员工；再配本期 #6 的 Agent Substrate，产品层 / 运行环境层 / 隔离调度层同一天拼齐。10000 与 20 倍要留判断：厂商自报的内部数据，与 11-05 期 Uber 3.2 亿订单只有 4 单来自 AI 智能体形成对照——企业内部 Agent 密度与外部消费端落地仍不在同一曲线。边界：The Verge 指其明显贵于同类 agent，仍处研究预览，长程稳定性、并发计费与跨 Agent 失败恢复无第三方验证。

5 Meta Muse 三连发：Spaces 自定义空间 + Active Memory / Active Focus + 实时语音虚拟形象全美开放 🛠 智能体记忆 / 生成式 UI
11 月 6 日 Meta 一次性推进三条。① Muse Spaces：用户无需写代码，用一段文字描述想要的工具，生成式 Agent Muse 便在侧边栏搭出可复用的个性化空间（旅行规划器、健身追踪、项目看板），可接入第三方应用，并能在后台持续更新数据——演唱会日期变动、机票降价、储蓄进度自动刷新，目前小范围测试。② Active Memory / Active Focus：扎克伯格宣布 Muse 与 Meta AI 接入基于 Muse Wonder 训练的专用模型，前者跨时间保留相关信息，后者在遇障碍或条件变化时继续完成目标；Meta 测试称 遗忘关键信息的可能性降至约 1/2.4，应对变化约束的表现提升 67%。③ Muse Realtime Voice / Realtime Avatar 全美开放：移动端、网页、Mac 可与动画虚拟角色实时语音 / 视频对话，表情手势随对话情绪变化，支持随时打断、纯语音 / 侧栏 / 全屏三种形态，还能一边讲话一边让 Muse 处理已授权后台任务，后续进入 AI Glasses 与 Muse Charm；官方技术演示 25FPS、约 870ms 首个音视频响应延迟。三条指向同一件事：把 AI 从对话框搬进用户高频入口 + 长期记忆 + 后台自更新。与本期 #4、#6 是同一天三条独立路线：Perplexity 让 Agent 常驻工作区，Meta 让 Agent 常驻个人入口与记忆，Google 让 Agent 常驻基础设施——住下来不是一家公司的选择，而是行业动作。生成式 UI 对营销侧最有价值：活动数据看板、玩家问答位、素材进度追踪可按需生成而非排开发档期。边界：Spaces 为小范围测试，记忆与专注提升为 Meta 自测，Realtime Avatar 仅美国开放且模型不看见用户，25FPS / 870ms 是官方指定系统条件下的演示值。

6 Google 向 CNCF 捐赠 Agent Substrate / gVisor / OpenRL，Agent Substrate 在 GKE 正式可用 🛠 智能体基础设施 / 隔离调度
11 月 6 日 Google 将 Agent Substrate、gVisor 与 OpenRL 捐赠给 CNCF Sandbox，并宣布 Agent Substrate 在 Google Kubernetes Engine（GKE）正式可用。该基础设施面向智能体运行与隔离：闲置会话可在 500 毫秒内恢复，容器密度提升 10 倍，每秒支持超过 500 次挂起与恢复，为常驻 Agent 提供运行时与隔离层。同日 Google Antigravity 向所有付费个人订阅开放远程智能体：可在独立云虚拟机执行用户提交的任务，用户通过移动设备管理权限，之后获取测试结果与代码合并请求；并支持在同一项目连接 GitHub 仓库与 Google Drive 文件夹，跨网页与移动应用处理代码与文档。常驻 Agent 的经济性瓶颈在挂起 / 恢复而非模型推理：#4 里每名员工数百个队友能不能成立，取决于闲置时占多少资源、唤醒要多久，500ms 恢复 + 10 倍密度正是把这道门槛往下压。三层栈在同一天拼齐：产品层（Perplexity Teammates）→ 运行环境层（11-06 期 Kimi Hosted Agents）→ 隔离与调度基础设施层（Agent Substrate / gVisor）。捐给 CNCF 的信号：智能体运行时正从厂商私有能力变成行业标准件，后续多云 / 自建部署有了可复用底座，降低被单一云锁定的风险。边界：CNCF Sandbox 属早期项目阶段，规范与生态仍在演进；密度与恢复耗时为 Google 自测，未披露多租户真实成本；Antigravity 远程智能体的并发与计费口径尚待确认。

7 世界模型同日双响：World Labs Frameboy 实时 15FPS 探索 + NVIDIA 开源 4 个 Cosmos 3 与 VFlash 🎬 世界模型 / 实时交互 / 开源仿真
11 月 5–6 日两条世界模型进展同时落地。其一，李飞飞联合创办的 World Labs 发布 Frameboy 研究预览：基于约两个月前发布的自回归世界模型 Atlas（原生处理文本 / 图像 / 视频 / 3D，全部输入合并进一个共享空间上下文），用户在浏览器中控制摄影机，云端 GPU 依据镜头位置与朝向逐帧生成新视角画面，以最高 15FPS 流式传回；输入可以是单张图片，也可以是真实地点的多视角照片，官方 Demo 借用掌机与游戏卡带形象呈现像玩游戏一样探索。实时能力已接入封闭内测的 Viewfinder（逐帧搭场景 → Frameboy 叠加层实时进入探索）。这是 9 月 AMD 宣布约 82 亿美元收购 World Labs 后团队交出的首个技术成果。其二，NVIDIA 开源 4 个 Cosmos 3 世界模拟模型（各 16B 可训练参数，基于 Cosmos 3 Nano 后训练，OpenMDW1.1 许可允许商用）：覆盖自动驾驶 11 路相机同步视频 + 激光雷达生成、流式交互仿真、空间控制信号转真实感视频（深度 / 分割 / 边缘 / 模糊布局 + 文本提示）、双臂机器人动作预测；同步发布 VFlash 并行视觉解码框架，利用边界框、轨迹等视觉图元的固定结构一次预测完整图元，在 Jetson Thor / DGX Spark 指定任务下机器人推理最高提速 5.1 倍，MolmoSpaces 四组任务平均成功率从 62.6% 升至 70.2%。试错成本几乎归零：过去调一次机位要等几十秒到几分钟渲染、发现角度错了再拖回去重来，Frameboy 改成推镜头即出画面，正是分镜预演与勘景最需要的一步。一个推体验、一个推可部署：Frameboy 是云端实时交互研究预览，Cosmos 3 是可下载可商用、能适配自有相机组与机器人的开源权重。与 11-05 期乌镇世界模型区分：那批主打 4D 高斯资产与国产昇腾底座，这两条主打实时流式生成与开源仿真数据生成。边界：Frameboy 仍需高性能云端 GPU、成本高于本地渲染，15FPS 低于现代游戏常见 30 / 60FPS；Cosmos 3 公告未给出流式变体质量与速度数据、未说明最低显存要求；两者都不是可交付成片工具。

编辑点评

八条其实在讲同一天里的两个方向：钱开始挑项目，智能体开始常驻。资本与监管在同一天把无限扩张的假设收了回去，产品侧却让 AI 从你问它答变成它一直在岗。

① 上半场是重定价（#1–#3）。OpenAI 110 亿到账但出资方集体缩手、Anthropic IPO 估值被压到 1.2–1.3 万亿、工信部给智能体发进网工牌、Meta 被三国司法按住。值得注意的是估值仍守在万亿以上，缩的是支票和节奏——这不是泡沫破裂，而是从信仰定价转向账本定价；11-05 美股 19 个月最大单日跌幅与中期选举后 41 项公投 40 项限制数据中心，把算力能不能落地、电费谁付直接塞进了估值模型。

② 中间三条是常驻（#4–#6）。Perplexity Teammates 让 Agent 变成 200 美元/月的同事，Meta 用 Active Memory 让它记得住，Google 用 Agent Substrate 让它挂得起、醒得快——产品层、记忆层、基础设施层是三家公司在同一天独立交出的三块拼图。配上 11-06 期 Kimi Hosted Agents 的运行环境，常驻 Agent 的技术栈第一次完整可见：产品层 → 运行环境层 → 隔离调度层。

③ 收尾两条回到宣发最实在的地方（#7–#8）。Frameboy 把世界模型从等渲染推进到推镜头，Cosmos 3 把仿真权重开源到自有机房；Ling-3.2-flash 让模型看着自己的画面纠错，Krea Video 把生成、改片、音效收进一个工作台。前三条讲钱和规矩，中间三条讲住下来，最后两条讲能不能少重跑一次。

今天最高分给到 #1 资本重定价（9.3 / P0）：分量不在数字大，而在估值守住、支票变小这个转折第一次同时发生在两家头部实验室身上，且立刻传导到算力租约与企业 AI 支出预期。

四条可以立刻执行的线索：① 用 Frameboy / Viewfinder 试一次分镜预演（只做草稿，15FPS 与云端成本决定它不进成片）；② 在 Krea Video 开一条同镜头多风格试点，验 UGC 广告模板是否省掉来回导出；③ 给常驻 Agent 排期前先算清 200 美元/月 × 队友数与权限继承规则，避免越权读到未发布资产；④ 给 AI 素材与系统级智能体入口补一份适配验证列表 + 调用声明 + 参考来源台账的合规清单，把 #2 与 #3 的要求前置到立项阶段。
