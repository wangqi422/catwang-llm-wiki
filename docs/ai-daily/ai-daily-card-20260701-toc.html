i. Global Giants & Platforms 3 items
🌍 海外巨头 & 平台
Anthropic / AWS / 谷歌 三大平台同日发新
1 Anthropic Claude Sonnet 5：性能逼近 Opus 4.8，API 价格砍 60% 🔥 头条
Anthropic 7/1 发布 Claude Sonnet 5，SWE-bench Pro 跑分 63.2%（逼近 Opus 4.8 的 69.2%）。API 优惠价 $2/$10 每百万 token（8/31 前），比 Opus 4.8 便宜 60%。Cursor 即时上架 + CursorBench 3.1 = 57%，是"高能低耗"主力模型。Anthropic 借 470 亿美元年化营收 + 9650 亿美元估值冲刺 IPO。
2 AWS 10 亿美元成立 FDE 部门 · 45 天派驻工程师帮企业部署 Agent 🔥 企业服务
AWS 7/1 宣布 10 亿美元成立 FDE（前置部署工程）部门，数千名工程师每次派驻 45 天驻场帮企业部署 Agent AI。核心指标"45/45/45"：45 分钟构思 + 45 小时验证 + 45 天部署。首批客户 NBA + 理光。FDE 岗位招聘一年涨 729%（643 → 5330），云厂商竞争已从"模型能力"转向"承接企业 AI 落地后支出"。
3 谷歌 Nano Banana 2 Lite + Gemini Omni Flash：4 秒出图 + 对话式视频编辑 🔥 多模态
谷歌 7/1 双发：Nano Banana 2 Lite 4 秒出图 + 千张 $0.034（约 0.23 元）；Gemini Omni Flash 视频生成 + 对话式编辑（自然语言换角色/调光线/换场景），每秒视频 $0.10、当前 10 秒。两模型支持联动，图→视频工作流在谷歌生态内闭环，搭配 Stitch 工具做"自然语言 → UI 原型"。

🇨🇳 国产 AI & 政策
全国产算力跑通万亿模型 · AI 全学段教育写进十五五
4 美团 LongCat-2.0 正式开源 · 1.6 万亿参数 + OpenRouter 全球前三 🔥 开源旗舰
美团 6/30 正式发布 LongCat-2.0 并全栈开源——业界首个全国产算力（5 万卡）完成训练+推理全流程的万亿参数大模型，总参 1.6 万亿 / 激活 480 亿 / 1M 上下文。OpenRouter 匿名"OwlAlpha" 接入后 总调用量跻身全球前三，Hermes / Claude Code / OpenClaw 三大 Agent 场景全部位列前 3。SWE-bench Pro 59.5 / Multilingual 77.3 / Terminal-Bench 70.8，国产模型首次在 Agent 战场正面击败美国旗舰。
8 国务院《教育发展"十五五"规划》· AI 全学段教育写入国家战略 政策红利
国务院 6/29 印发《教育发展"十五五"规划》明确推进人工智能全学段教育，提升学生 AI 素养。北京已 1400+ 中小学开设 AI 通识课（≥8 课时/学年），目标 2030 构建"纵向贯通、横向联通"的全学段 AI 教育体系。同步建设国家 AI（教育）应用中试基地 + 完善国家智慧教育公共服务平台 + 构建 AI 开源创新生态——2 亿学生+2000 万教师入口级市场，**国产 AI 模型最大政策红利**。
