🖌️ 代码即画笔 · 确定性视觉产出
Fable 5.2 用 70 万笔触画购物车、1.4M 纯 HTML 算出 3D 世界、HyperFrames / cinecode 把视频变成可版本控制的确定性渲染 —— 视觉产出正从「采样」往「计算」迁移
1 Claude Fable 5.2 不调用图像模型，用 Python 代码逐笔作画：约 70 万笔触画照片级购物车、111 笔画日出鸟、落笔不可撤销 🖌️ 确定性创作 / 代码画笔 / P0
11 月 15–16 日，Anthropic 员工集中展示 Fable 5.2 一种「异类生图」能力并刷屏中文科技媒体：不调用任何扩散 / 图像生成模型，而是编写 1000–2000 行 Python 在虚拟画布上模拟刷毛纹理、颜料湿度与画布质感，把画面拆成大量独立笔触坐标逐笔执行。开发者 Jake Eaton 要求「画一幅尽量接近照片」，最终得到停车场里的购物车、约 70 万次模拟笔触，无外部图像模型、无预渲染底图，整幅画本质是一段可运行的 Python 程序。工程师 Michael Graczyk 做了更硬的实验：画「日出时的鸟」时每一笔单独输出为坐标、落笔后不能撤销，21 秒视频共 111 笔，第一笔用 #30346a 色号、90px 笔宽、5 个抖动路径点，模型自述约 7px 摆动是刻意的「人的手臂画不出绝对直线」；另一幅 280 笔黄昏场景里，后期光照糊掉桌上颜料管，模型主动用新笔触重画。这是「生成式」之外的第二条路，而且天然可编辑：扩散模型改一个细节得整张重抽，代码作画是逐笔可寻址的程序——改坐标重跑即可，确定性、可版本控制、可局部重绘，正好补上商业化物料最被诟病的一致性缺口。no-undo 约束把每一步变成不可回退的决策，是一次完整的 agentic loop。边界：70 万笔 / 111 笔 / 1000–2000 行均为开发者自报的演示元数据、非产品规格；逐笔输出坐标极耗 token；RoboDojo Sim 报 64.9% 但真实机械臂测试中对手更快，仿真强 ≠ 物理精细控制强。查重：模型本身 11-09 发布，今日报的是 11-15/16 集中曝光的能力与工程复现方法，属新事件。

2 1.4M 纯 HTML 3D 游戏走红：约 700KB 是打包的 Three.js，其余全程序化生成、零图片零模型，卡兹克给出提示词模板与自查迭代法 🎮 程序化生成 / 单文件交付 / P1
11 月 16 日 aihot.news 热度榜第 2 位，一个近期疯传的 1.4M 单文件纯 HTML 3D 游戏被「数字生命卡兹克」拆解：其中约 700KB 其实是打包进 HTML 的 Three.js 库，剩下部分全部由代码程序化生成——没有图片、没有 3D 模型、没有录音，场景、材质、几何体、交互逻辑都在一份文件里由 JS 现场算出。文章还给出可直接复用的提示词模板与「自查 → 迭代」的调试方法，把「一个能跑的 3D 场景」降维成「一段可让模型反复改的 HTML」。它和 #1 是同一件事的两个尺度：Fable 5.2 用代码算出一幅静态画，这个用代码算出可交互 3D 世界，#3 用代码算出一段视频——今天最清晰的信号不是某个模型更强，而是视觉产出正从「采样」往「计算」迁移，只要能写成代码就能确定、能复现、能 diff。单文件交付是被低估的分发优势：一个 .html 双击即开、无需构建 / CDN、可离线、可直接塞进落地页或企微 H5，对轻互动宣发物料 / 小游戏试玩 / 活动页这类短周期、强传播场景比整套资源包轻得多。真正值钱的不是这个游戏，而是「怎么让模型一次性生成可运行场景、跑不通时怎么让它自己读报错修」的工作流。边界：1.4M / 700KB 为拆解者口径；程序化生成在写实贴图、大体量资产上仍远不及现成资源，适合几何 / 风格化 / 概念验证；单文件含第三方库时注意许可证与体积合规。

3 代码化视频工具链成形：HeyGen 开源 HyperFrames（网页→确定性 MP4 / Apache 2.0）、cinecode 再登 GitHub 趋势榜、Remotion Agent Skills 30 分钟出片 🎬 视频基建 / 智能体原生 / P1
11 月中旬，「把视频变成可调用的代码原语」在同一周集中成形：① HeyGen 开源 HyperFrames（Apache 2.0），把任意用 HTML + CSS + JavaScript 写的场景，经 Puppeteer 渲染 + FFmpeg 编码 + GSAP / Lottie 动画本地渲染成 MP4，主打逐帧确定性——同样输入必得同样输出，agent-native、无需 API key，可与 Claude Code 等编码智能体直接配合，GitHub 月榜显示已约 84.7K stars。② 开源技能包 cinecode（MIT，11-03 建仓、11-15 再登 GitHub 趋势榜约 2.5K）让 Claude Code / Cursor「从代码导演整部电影」：五阶段 Plan → 剧本分镜 → 用 Canvas 2D / three.js 把每帧写成时间的纯函数 → Headless Chrome 逐帧捕获 → Web Audio 离线混音到 -14 LUFS 再 mux 成 MP4，不用视频模型、不用渲染队列、不烧积分，还带「先出两张静帧 + 低清草稿、留两轮改稿」的审批闸。③ Remotion Agent Skills 演示用 4–5 轮提示、约 30 分钟产出一条完整宣传片。三者拼出一条完整替代链：#1 静态画、#2 可交互 3D、这一条成片，共同点是「不调用生成式视频模型，改用代码确定性渲染」，收益是可编辑、可版本控制、可批量改价改字改结尾，恰好打中扩散视频「改一处全片重抽、角色脸会变」的老大难。「确定性」才是能进流水线的关键：批量本地化要求同一模板稳定复现，HyperFrames 的逐帧一致与 cinecode 的「改代码重渲染」把视频拉近软件工程 CI 范式。审批闸值得抄：在昂贵全片渲染前先给静帧 + 低清草稿，是把人工审片前置到最便宜的时刻。边界：案例均为作者自述、非独立评测；擅长信息流广告 / 数据可视化 / 倒计时 / Motion Graphics，复杂叙事与写实人物仍要专业剪辑介入。

4 美团开源 LongCat-2.5 权重：1.6 万亿 MoE / 约 48B 激活，全程昇腾训练未用英伟达 GPU，194 块 Atlas A2 部署、W4A4 吞吐 +43% 🧱 国产算力 / 开源权重 / P0
11 月 15 日 The Decoder 集中报道，把美团 LongCat-2.5 权重开源推成「年度最重要开放权重发布之一」。模型为原生多模态 MoE、总参 1.6 万亿、每 token 激活约 48B，面向长程 Agent / 软件工程，API 支持 100 万 token 上下文、单次输出 12.8 万 token，图像被转成离散 token 与文本同一 backbone 处理，同时兼容 OpenAI / Anthropic 两种 API 格式、可直接插进 Claude Code / Codex 等 harness。最硬的看点是硬件栈：美团称训练与微调全程跑在国产 AI 加速器上、没有任何英伟达 GPU，用 W4A4（权重 + 激活 4-bit）让国产芯片跑原生 INT4，相较 W8A8 基线 prefill 吞吐 +43.3%、decode +42.77% 且精度基本持平；自托管指南给出的参考集群是 194 块华为昇腾 Atlas A2（2 块图像 token 化、64 块 prefill、128 块 decode），完全没有英伟达配置选项。自报 Terminal Bench v2.1 88.4、DeepSWE v1.1 从上代 9.7 跃至 64.6；强化学习任务取自真实 GitHub PR、沙箱断网抹掉 Git 历史与构建缓存、并用 LLM 裁判反 reward hacking。权重按 MIT 放出，11-10 官方正式宣布、11-15 因报道再度发酵。这是「预告 → 兑现」的新阶段，不是旧闻复读：归档 11-02（第 86 期）报的是「模型亮相」，今天报的是权重真正放出 + 昇腾训练与部署栈首度完整披露——首次证明万亿级开源智能体模型可在纯国产算力栈完成训练与自托管。和 #6 是同一天的因果两面：一边把云端远程租算力也纳入许可，一边给出一份可复现替代方案。评分表要会读：88.4 是美团 in-house 跑分（模型卡明确未标星号的均为内部测试），更难的 Terminal Bench v4.0 只有 38.5；1.6T 为官方口径、safetensors 元数据约 1.78T 的差额官方未解释；194 块昇腾与「未用英伟达」是媒体表述，模型卡只说「国产 NPU 平台」——写进对外物料须按「厂商 / 媒体自报」标注，独立第三方复测尚未出现。

5 华为云 MaaS 上线 openPangu-2.1-Pro：主攻 Agent 开发 / AI 编码 / 推理优化，深挖鸿蒙操控与昇腾算子生成，权重开放下载 🧩 国产生态 / 软硬协同 / P1
11 月 15 日晚，华为云宣布开源盘古 openPangu-2.1-Pro 正式上线其 MaaS（Model-as-a-Service）平台，权重开放下载。升级集中在三条线：Agent 开发、AI 编码、推理优化，官方点名的增强场景包括深度研究、鸿蒙系统操控、鸿蒙 APP 开发、昇腾算子生成、推理链路优化；模型将接入华为云「智果 AgentArts / 码道 CodeArts / 国办 OfficeAce」，并由「华为小艺 Celia Work」首发集成。官方公告未给出参数量、上下文长度与跑分。同期背景：华为云 11-01 已公告 openPangu-2.0-Flash / 2.0-Pro 将于 11-30 停售下线，并建议存量客户迁移到 DeepSeek-V4.1-Flash 与 GLM-5.3。增量在「软硬协同与场景」，不在榜单：没有参数 / 跑分，却把场景钉死在鸿蒙操控、鸿蒙 APP 开发、昇腾算子生成上——把模型和自家 OS、芯片、开发工具绑成一条闭环，走「场景反哺模型」而非「刷榜」路线，与 #4 的国产算力栈是同一套叙事的上下游。「算子生成」是最实在的一格：让模型写昇腾算子，本质是用 AI 补国产芯片软件生态最缺的人力密集环节，若跑通等于给「去 CUDA 化」补上工具链。停旧推新 + 建议迁到友商模型是个不常见但诚实的信号：说明 MaaS 在把「平台」做成中立货架、把自研模型放在特定场景里竞争，对采购方选型更灵活，但也意味要重新评估存量集成的迁移成本。边界：无参数 / 上下文 / 基准，能力无法与 #4 或闭源旗舰直接对比；「鸿蒙 Agent 场景率先起量」目前是战略意图而非已验证结果，别把「上线 MaaS」写成「全面可用」。

6 美国国会推进把三项芯片出口管制塞进 NDAA：Remote Access / MATCH / AI OVERWATCH，连「云端远程租算力」也要纳入许可 📜 出口管制 / 云端算力 / P1
11 月 15 日，众议员 Carlos Gimenez 在电视访谈中称必须消除「第三国分销与云端漏洞」，让受管制 AI 处理器无法经数字网络被远程租用；同日 CBS《Face the Nation》播出众院中国特别委员会主席 John Moolenaar 专访，明确「接下来几周的重点就是把出口管制写进《国防授权法》（NDAA）」。立法组合为三项：Remote Access Security Act（H.R. 2683，2026-01-12 众院以 369:22 通过） 修订 2018 年《出口管制改革法》，把「刻意的境外远程访问」定义为可管辖的技术转移、授权 BIS 对远程服务器连接发许可证、要求云厂商做 KYC 与最终受益人核验；MATCH Act 收紧半导体制造设备管制并促盟国跟进；AI OVERWATCH Act 让国会获得审查 / 否决高端 AI 芯片出口许可的权力、并将部分旗舰芯片直接列入禁运。触发点：11-13 众院三委员会联名致函，要求就 Megaspeed 等中间商把受控加速器转至境外、以及东南亚 / 中东 GB200 云租赁出席说明；两院协商目标是在 12 月会期休会前敲定 NDAA 文本，商务部同月须提交远程算力监控的执法方案。管制对象从「实体芯片」扩到「算力使用权」：现行规则管物理跨境运输，新法案把「在中立司法辖区远程租一台 GB200 集群训模型」也定义为需许可的转移——不是「机器在哪」，而是「谁在用它、最终受益人是谁」。与 #4 / #5 构成同一天的因果闭环：一边把云端算力也锁进许可，一边放出 194 块昇腾跑通万亿级的替代栈。日历风险比法条本身更该盯：12 月 NDAA 协商 + 商务部执法方案 + 已排定的 12/1–12/3 三场听证，意味着 12 月是特定加速器供货与报价的高波动窗口。边界与克制：三项法案尚在协商、尚无最终成文文本，相关表态均为议员 / 媒体口径而非立法结果；本条只记录立法进程与合规口径变化对产业供应链的影响，不对各方立场作评判，对采购的实际影响以正式生效文本与企业法务口径为准。

11 月 14–15 日，三份口径完全不同的 AI 就业 / 投资数据同框：① 澳大利亚央行研究称 AI 冲击集中落在年轻劳动者上，软件开发与客服岗位降幅最大——被替代的不是「低端重复劳动」的旧叙事，而是入行门槛岗与可被结构化的白领任务。② Gartner 预测到 2030 年 AI 将使全球净增约 170 万个工作岗位，强调净效应为正、只是结构重排。③ 斯坦福 AI Index 新数据揭示 AI 投资突破万亿，与公众情绪、就业体感之间存在明显落差。同期 Hugging Face CEO Clement Delangue 重申「权力集中才是 AI 最大风险」、呼吁更强的开源。三份数据不矛盾，是三把不同的尺：澳央行量的是分布（谁先受影响、哪类岗位）、Gartner 量的是净总量、斯坦福量的是投入与体感的落差——净增不等于均匀分布，总量为正不代表过渡期无痛。对内容 / 宣发岗的直接含义：软件开发与客服「降幅最大」指向的正是可被模板化、可被 Agent 化的产出，这恰好解释了今天 #1–#3 的价值——当「会写网页 / 会出图」变成可调用原语，人的位置往「定义约束、审片、把关品牌与合规」上移。边界：澳央行结论基于单一经济体研究、Gartner 是 2030 年长期预测、斯坦福为指数口径，三者样本 / 方法 / 时间尺度均不同，不能相加、不能互算、不按数字直接排名次；均为媒体转述摘要，正式引用须回原始报告。

8 中科院自动化所 × 美团等发布 LLM Agent 递归自我改进（RSI）综述：Prompt / Memory / Skill / Harness 四主线、40 项研究、七步生命周期 🔁 Agent 架构 / 经验复利 / P2
11 月 15 日，中国科学院自动化研究所联合美团、山东大学、中国人民大学、中科院微电子所、上海交通大学、理想汽车等单位发布 LLM Agent 递归自我改进（RSI）综述《When, Where, and How Experience Becomes Structure》。核心命题：模型权重不变，Agent 也能积累能力——把一次任务里留下的工具调用记录、执行结果、用户纠正、失败修复，转化为下次能用的结构。综述沿 Prompt 优化 / Memory 进化 / Skill 进化 / Harness 进化四条主线，用三个问题（何时该改、改哪里、怎样把经验变成经得起验证、能长期复用的改进）与七步生命周期串起框架，选取 40 项代表性研究绘制全景、对 20 项研究的具体更新闭环做对照分析。同期 GitHub 11-15 趋势榜被概括为「AI 生产力与 Agent 协作的接口之战」：Univer 开源面向人与 AI Agent 的 Office SDK、AG-UI 定义智能体—前端交互协议、腾讯 LoopForge（Go、自托管）编排多个 coding agent 并带人工审批闸、plannotator 登顶。它给「越用越强」提供了工程语法：改一句 Prompt、存一条 Memory、固化一个 Skill、调整 Harness 的工具接口与检查逻辑，且强调「经得起验证」而非「改了就算改进」。Harness 进化与「人工审批闸」是今天最实用的一格：#3 的 cinecode 在昂贵渲染前留两轮改稿、腾讯 LoopForge 在编排里放人工审批，本质都是把「验证」做成流程节点而非事后补救。边界：这是综述 / 框架而非新模型或新基准，不含可直接跑的实现与实测提升；40 项研究的对照多为定性归纳，「自我改进」在开放环境下的稳定性、错误累积与回滚仍是开放问题。

编辑点评

八条其实在讲同一件事：不调模型调代码，不靠 CUDA 靠昇腾，都在把创作与算力从别人定价的地方挪回自己手里。第 100 期恰逢周一，大厂集体没发新旗舰，反而把这两条「去依赖」的路亮得格外清楚——前几期是「补账本、明码标价」，今天更进一步：不只要算清成本，还要把生产资料的控制权换回来。

① 上半场（#1–#3）是「代码即画笔」的三个尺度。Fable 5.2 用 70 万笔触画购物车（#1）证明不调图像模型也能出照片级作品，而且每一笔是可寻址坐标；1.4M 纯 HTML 3D 游戏（#2）把同样的思路推到可交互世界，还附赠提示词模板；HyperFrames / cinecode / Remotion（#3）补齐成片，把视频变成可版本控制的确定性渲染。三者共同点不是「更强」，而是确定、可复现、可局部改——改 logo 不用重抽卡，改价格不用重拍片。

② 下半场（#4–#6）是「国产算力栈」的因果闭环。美团把 1.6T 的 LongCat-2.5 权重放进 MIT，并首次完整披露「全程昇腾、194 块 A2、无英伟达选项」（#4），是 11-02「亮相」之后的兑现新阶段；华为云同晚上线 openPangu-2.1-Pro（#5），用鸿蒙场景与昇腾算子生成补齐工具链；而美国国会正把三项管制写进 NDAA、连云端租算力都要许可（#6）。一边锁、一边自建，两件事摆在同一天——但也要克制：88.4 是厂商自报、法案尚无成文文本，两个都不能写死进对外承诺。

③ 收尾两条（#7–#8）是账本与复利。澳央行 / Gartner / 斯坦福三份数据彼此对撞（#7），提醒「净增 170 万」与「年轻软件岗先受冲击」并不矛盾，是三把不同的尺；RSI 综述（#8）则把「Agent 把经验变成结构」拆成 Prompt / Memory / Skill / Harness 四层。#7 说被结构化最深的恰是模板化白领产出，#8 就给出「把每次修复沉淀成可复用结构」的方法——今天这两条其实是一问一答。

一组对照值得记：#1 的「落笔不可撤销」、#3 的「静帧审批闸」、#8 的「人工审批 + 经验证才叫改进」，都在做同一件事——把「验证」前置到最便宜的时刻。逐笔作画不许反悔，所以每一笔都得预判；全片渲染前先出草稿，所以改稿不烧钱；经验要先通过验证才配沉淀成 Skill。今天没有谁更聪明，比的是谁先把「不可逆」的成本管住。

一句话：不调模型调代码，不靠 CUDA 靠昇腾，都在把创作从最贵的供应链上挪开

今天最高分给到 #1 Fable 5.2 代码逐笔作画（9.4 / P0）：分量不在「画得像照片」，而在它给出了生成式之外的第二条可商业化路径——每一笔是可寻址坐标、整幅画是可运行程序，确定性、可版本控制、可局部重绘，正好补上扩散模型在品牌一致性物料里最被诟病的缺口；且与 #2 / #3 连成画、3D、视频的完整光谱，是今天唯一一条能直接改写宣发工作流的线索。

五条可以立刻执行的线索：① 用一下午做「单文件 HTML 概念小场景」试玩页，嵌进 H5 或企微卡片；② 把模板化短片迁到「改数据重渲染」的确定性工具链，并把「静帧 + 草稿、留两轮改稿」的审批闸写进自动化出片 SOP；③ 云渲染 / 批量出图 / 长周期 GPU 合同标注「12 月 NDAA + 出口管制 + 12/1–12/3 听证」外部变量；④ 所有厂商自报数据一律标「演示 / 自报、未经第三方复测」；⑤ 把 RSI 四主线做成常驻 Agent 自检表，以「30 天内是否被再次调用」衡量沉淀价值，并给所有自动化发布流程保留人工审批与合规审片节点。
