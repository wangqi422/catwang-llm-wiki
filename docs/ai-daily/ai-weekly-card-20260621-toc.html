4 Karpathy 四原则 · 任务成功率 59%→97% 方法论
Karpathy 在 22 万星 GitHub 项目中更新了 AI 编程四原则，核心思路：AI 能做的远多于它应做的——克制即智慧。四条规则：① 先想再写 ② 先求简单 ③ 外科手术式改动 ④ 目标驱动。实测 Bug 引入率从 22% 降到 3%。
四原则
先想再写 / 先求简单 / 外科手术 / 目标驱动
实测效果
成功率 59%→97% / Bug 22%→3%
∘ @karpathy
5 AI-First 四层架构 · 从"用 AI"到"AI 驱动" 架构
AI-First 工作流四层架构模型：Intelligence（模型选型+Prompt）→ Orchestration（Agent 编排+工具调用）→ Knowledge（RAG+知识库+记忆）→ Development（CI/CD+自动化测试）。四层同时设计，缺一不可。
Intelligence
选主力模型 + 统一 Prompt 规范
Orchestration
单 Agent 起步，稳定后加 fan-out
Knowledge
Markdown 先行，验证后上向量库
∘ @swyx @amasad
6 Make + AI Agent 三级进阶 · 不要跳级 自动化
Make 更新 AI Agent 集成指南，三级进阶：Level 1 — 单步自动化（触发器→AI→输出）；Level 2 — 多步链式（3-5 个 AI 模块+条件分支）；Level 3 — Agent 自主编排（AI 自行决定调用工具和顺序）。

单步 / 半天上线
Level 2
链式 / 一周搞定
Level 3
自主 / 一个月打磨

7 Claude Fable 5 提示词逆向 · 12 万字里的 7 个可抄技巧 Prompt 工程
Claude Fable 5 系统提示词被完整泄露（约 12 万字），提炼出 7 个可立即使用的 Prompt 技巧：① 正反清单法 ② 硬编码规则（ALWAYS/NEVER） ③ 搜索决策流程 ④ 分阶段输出 ⑤ 自检清单 ⑥ 上下文窗口管理 ⑦ 工具调用协议。
// 综合技巧 1+2+4 的 Prompt 模板 你正在执行 [任务描述]。 必须遵循 (ALWAYS) - [规则1] - [规则2] 绝对禁止 (NEVER) - [禁止1] - [禁止2] 执行阶段 1. 思考：复述需求 + 列出关键约束 2. 规划：输出执行步骤（≤5 步） 3. 执行：按规划输出最终结果

8 DeepSeek 隐藏玩法 · 角色+思维链三段式 技巧
社区总结出 DeepSeek 两个高效用法：角色+思维链三段式（事实层→分析层→结论层）和费曼学习法摘要（用初中生能懂的话解释→找反直觉要点→给"如果…那么…"建议）。DeepSeek 的思维链是"可设计的"，不是让它自己想，而是你规定它怎么想。
三段式
事实层 → 分析层 → 结论层
费曼摘要
初中生话 → 反直觉 → 如果…那么…
∘ @deepseek_ai 社区
9 反直觉 Prompt 逆向论证 · 先问"为什么不该做" 方法论
在让 AI 执行任务前，先让它论证"为什么不应该做这件事"。解决 AI 最常见的两个问题：① 过度执行（不该做的也做了）② 缺乏边界意识（不知道在哪停）。AI 的错误 80% 来自"做了不该做的事"。
// 逆向论证 Prompt 模板 任务：[描述你要做的事] 在执行前，请先回答： 1. 这个任务有哪些潜在风险或副作用？ 2. 在什么情况下不应该执行？ 3. 如果只能做 50%，最该保留/砍掉哪部分？ 确认以上后，再执行任务。
∘ @swyx @karpathy
