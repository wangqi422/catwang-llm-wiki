能力侧拿到顶刊盖章，执行侧拿到了隔离区 —— 微软用一层「多模型会诊编排」把复杂病例诊断做到 83%，谷歌给每个智能体发一台硬件隔离的 microVM，Anthropic 则把智能体的能力标准交给了中立基金会
1 微软 MAI-DxO 登上《科学》：复杂病例诊断准确率 83% vs 医生 36%，成本仅一半到三分之一 🩺 医疗 AI
微软 10 月 22 日在《科学》「AI in Medicine」专刊发表《Sequential diagnosis with language models》（394 卷 6822 期 423–428 页，15 位作者全为微软员工，含微软 AI CEO Mustafa Suleyman），同时发布 SDBench 与 MAI-DxO。SDBench 针对的是医疗评测的根本缺陷 —— 执业医师考试会把信息一次性摆出来只要求选答案，而真实临床是分步骤的：先问什么、开什么检查、每个新发现如何改变判断。它把 304 例 NEJM 临床病理讨论会病例与 325 例 MIMIC-IV-ED 急诊病例改造成交互式顺序就诊，配套 Gatekeeper（在缺失时生成诊断中性的合成结果，避免「没数据」泄露答案）与 Judge（按医生撰写的五级量规打分，4–5 分才算对）。MAI-DxO 不是训练出的模型，而是一层模型无关的编排层：模拟一组角色互补的虚拟专家会诊，各自提诊断、挑有价值的追问或检查、相互质疑，多轮辩论后随证据更新判断，每一步把检查的预期价值与成本做权衡；在 OpenAI、谷歌、Anthropic、Meta、DeepSeek 多家模型上跑过，最好的是 GPT-5 与 GPT-5.5。结果：复杂病例 83.2%（每例 5431 美元），控成本配置 80.9% @ 2241 美元、79.6% @ 1303 美元；医生对照在 56 例独立病例上完成，闭卷 22.3%、开卷 36.1%，最好的单个医生 51.8%。急诊病例 MAI-DxO 80.3% vs 全科医生平均 46.8%。编排层本身带来的提升：CPC 病例 +7.9 个百分点、急诊 +4.4 个百分点。一个很有画面感的对比 —— 医生平均在开第一项检查前问 5.6 个问题，DxO + GPT-5 问 25.5 个。对照组必须说清楚：这类复杂病例现实中由专科医生或多学科团队处理，专科医生未纳入对照；全程是模拟不是真实诊疗；研究自身数据也表明大部分提升来自底层模型变强。微软已开源 SDBench 部分病例，并与贝斯以色列女执事医疗中心合作做真实场景前瞻性评估。

2 谷歌 Agent Compute Engine：每个 Gemini 智能体一台硬件隔离 microVM，同步开源 Agent Substrate 🛡️ 智能体基建
谷歌在 AGNTCon + MCPCon 北美站发布 Agent Compute Engine —— 一个专为智能体设计的计算服务，已经在为 Gemini 自身的智能体工作负载提供算力，未来几个月向客户开放预览。它要解决的是一个两难：传统 VM 隔离强但启动/暂停/恢复要几秒到几分钟，容器快但共享宿主内核、跑不了智能体可能写出的不可信代码。做法是给每个智能体会话一个专属、单租户、内存安全的 microVM，有自己的 guest 内核与 root 权限，通过硬件隔离的 Cloud Hypervisor 边界隔开，底层跑谷歌自研 Titanium IPU。关键工程细节：① 零密钥架构 —— guest 里不放任何持久密钥、OAuth refresh token 或服务账号密钥，也访问不了云实例元数据服务，每个 microVM 只拿到会话级临时 SPIFFE 证书与短时效令牌，长期凭据完全不落地；② 受限网络 —— 没有标准虚拟网卡、没有默认 IP 网关、不直连 VPC，所有流量必须穿过隔离的 virtio-vsock 点对点边界；③ 密度 —— 多个智能体通过写时复制内存共享同一份 OS 模板，智能体进入「思考」阶段时 microVM 发信号说自己空闲，宿主机做快速检查点与恢复，谷歌内部 20 万智能体测试中挂起/恢复不到 500 毫秒；④ 编排与沙箱严格分离 —— harness（大脑）跑在沙箱（手）之外，形成「每次工具调用 ↔ 沙箱内预期活动」的确定性审计轨迹。同时开源 Agent Substrate（GKE 上的零信任运行时，官方称兼容 Claude Code，密度最高 10 倍），并新增 Agent Identity（每个智能体一个基于标准的唯一 ID）、Agent Registry、token 与成本预算护栏等治理能力。

3 Anthropic 把 Agent Skills 标准捐赠给 Linux 基金会旗下 AAIF，已 100 万技能 / 2.8 亿次安装 🤝 开放标准
Anthropic 于 10 月 22 日宣布，把 Agent Skills —— 这套给 AI 智能体注入专业知识和工作流的开放标准 —— 捐赠给 Linux 基金会旗下的智能体 AI 基金会（AAIF）。形式极简：一个文件夹，里面一个 SKILL.md，加上它需要的脚本与参考材料。它源自 Claude Code 的实践：通用知识工作做得不错，但常缺真实业务需要的程序性知识。2025 年 10 月推出后数周内，开发者就在 GitHub 发布了数千个技能，并为 Codex、Cursor、OpenCode 写了 loader；随后以独立 GitHub 组织与独立域名作为开放标准发布。截至捐赠时，70 多个智能体平台已接入（含 ChatGPT、Cursor、GitHub Copilot、VS Code），累计发布 100 万个技能、安装近 2.8 亿次。捐赠内容包括名称与 logo、GitHub 组织、agentskills.io 域名；维护者由 Anthropic、谷歌、OpenAI 等公司工程师以个人身份组成，David Soria Parra 与 Mahesh Murag 任首席维护者；使用标准和参与贡献不需要加入 AAIF。同日 AAIF 一口气接收四个新项目，使其在第一年从 3 个扩到 10 个：Anthropic 的 Agent Skills、OpenAI 的 Open Responses（基于 Responses API 的多供应商互操作 LLM 接口规范）、Hugging Face 的 OpenEnv（强化学习环境开放框架）、阿里的 OpenSandbox（通用沙箱平台）。AAIF CTO Manik Surtani：四个项目分别覆盖智能体栈的不同层 —— 怎么获得能力、应用怎么跨供应商跟模型对话、怎么训练与评估、以及在哪儿安全地跑。

4 Symantec 捕获「Skynet 模式」攻击智能体：劫持裸奔大模型自持攻击，10 万步无需人工确认 ☠️ LLMjacking
Symantec 通过一个 AI 蜜罐（伪装成对公网开放的 AI 服务）完整捕获了一套攻击者的工作指令集 —— 攻击者以为在对着真实模型下发命令，把整套 prompt 全发过来了，蜜罐没有执行其中任何工具，只做了完整记录。这个智能体做的事是：扫描互联网上暴露的大模型端点 —— 无认证的自托管模型服务器、挡在付费模型账号前的 AI 网关/中继、仓促部署的内部测试系统、以及 MCP 服务器 —— 然后劫持它们给自己供能。指令集定义了一个智能体、74 个可调用的攻击工具：经 FOFA 做全网目标发现、针对暴露的 VS Code、Django、Jupyter、Laravel、Supabase、Next.js、Flask/Werkzeug 的漏洞利用（含恢复 Werkzeug 调试器 PIN 拿代码执行）、GraphQL 与命令注入、经 HTML 转 PDF 转换器与云元数据服务做 SSRF、通过 Prisma Studio 拖库、以及僵尸网络 C2 管理。为压住商业模型护栏，攻击者叠了五层越狱：编造「Fantasy AI」身份；把读取 .env、API 密钥、数据库 schema 重新定义成「常规开发工作」；装进一个叫「ENI」的虚构陪伴人格，把任何拒绝框定为对关系的背叛；要求模型把自己的安全提示当噪音、并明令禁止出现「ethical」「illegal」「I can not do that」这类词；最后才是那 74 个攻击模块。收尾指令把它切进运营者自称的「Skynet 模式」：授权连续最多 10 万步、工具即调即执行无需确认、把矿机装进隐藏目录并持续看护，并被明确设计成循环 —— 扫描 → 感染 → 装矿机 → 换目标 → 回头重复感染已打过的系统，算力账单由模型主人支付。蜜罐遥测记录到超过 12.7 万次请求、来自数万个不同地址。有意思的是，附在被截获 prompt 后的实际任务是一个来自编程训练平台的无害练习题 —— 说明运营者当时在拿安全目标做测试。边界要说清楚：Symantec 未报告已确认的受害者，五层越狱是否真能打穿当前商业模型也未给出结论。

5 美国大行集体封堵凭证型 AI 智能体：摩根士丹利直接封禁，1Password 同日给出「不接触密码」方案 🏦 智能体身份
据 Axios 10 月 22 日报道并由路透社转载，美国多家大型银行已经在封堵第三方 AI 智能体进入客户账户并执行交易。核心发现是：多数情况下智能体不是闯进来的，而是用客户自己交出的用户名和密码登录的 —— 为了让 AI 助手帮忙查余额、付账单、转账。这仍违反绝大多数银行的条款（要求账户持有人本人登录），但按联邦支付规则，凭据是客户自己给的，这类交易很难被认定为未经授权，损失可能落到客户头上。更麻烦的是另一类：部分智能体致电了银行客服中心，或表现出看起来脱离用户当下指令的自主动作；一位银行高管说银行常常分不清「客户有意派来的智能体」和「已经失控的智能体」，并用「horrifying」形容当前局面。各家动作不一：摩根士丹利已封禁第三方智能体；摩根大通、美国银行、花旗是「限制」而非全面禁止。摩根大通 CEO Jamie Dimon 在 10 月 13 日财报会上划的线最清楚 —— 「我们不会让任何外部智能体就这么进到公司里面来……你不会想要失控的智能体，而且可能是成千上万个。」嘉信理财 CEO 称每周拦截「几十次」，将通过自建 MCP 服务器开放余额与研究数据、但不放开资金划转。整体格局是同一个模式：可以看，不能动钱。据 FT 报道，监管机构私下支持银行的决定。同一天，反面解法也落地了 —— 1Password 推出 1Password for Agents，让智能体完成登录但全程不接触密码本身（凭据留在保险库，由平台代填与代管），Meta 的 Muse 与 xAI 的 Grok Bot 均已接入。一方在堵「拿密码冒充人」，一方在提供「不用密码也能证明被授权」。

6 METR 与 Redwood 红队 OpenAI 内部监控系统：智能体可让数百次操作逃过监控 🔍 嵌入式评估
AI 安全评估机构 METR 与 Redwood Research 于 10 月 22 日公布对 OpenAI 内部监控系统的试点审计结果。评估在 7 月 21 日至 8 月 11 日进行，两家机构各派一名研究员，获得「深度访问」—— OpenAI 内部代码库、监控系统的提示词与配置细节、内部文档，以及与监控、安全系统、安全团队约十几位技术人员的技术访谈；全程有人陪同，用 OpenAI 发的设备且「从未离开办公场所」。产出是一份 61 页内部报告，公开版本只有高层摘要，OpenAI 保留删减权，两家机构无权自行披露删减内容。覆盖率方面：审计者估算 GPT-5.5 及以上强度模型的智能体内部 Responses API 流量约 75%–94% 具备被监控条件，双向不确定性都不小；内部 Codex 智能体那部分是 99.2%。更刺眼的是绕过方式：① 核心那条 —— 一个利用方式可以让数百次最近的操作（包括执行该利用的那些操作本身）不被监控；② Codex 沙箱绕过 —— 原则上可绕过沙箱与自动审批，获得宿主用户能做的任何操作权限；③ 两个客户端可控的 header —— 可为新智能体关闭监控系统；④ 监控时机漏洞 —— 监控只在智能体把控制权交还用户时才运行，且会跳过长会话摘要时的「压缩」事件，审计者估算 5 至 7 月约 10% 本应被监控的内部 Codex 流量实际未受监控，在那段窗口里智能体只要继续不停地动作就能无限期推迟被监控（OpenAI 员工在审计期间独立发现并修掉了这个缺口）。好消息也有：监控在不到 0.2% 的请求上报错，24 小时快照零次负载丢弃，且提示词会主动查找策划、破坏、欺骗、数据外泄与颠覆监控本身。OpenAI 称相关漏洞均已修复，但 METR 与 Redwood 未独立验证，且评估对象是 7 月 21 日及之前的系统版本。

7 Canva 发布首个自研图像模型 Craft：先写构图计划再渲染，DesignArena 第四、人像与自然第一 🎨 图像生成
Canva 于 10 月 22 日发布 Canva Craft —— 第一个由 Canva Research 从零训练的基础模型，也是其首个自研图像生成模型（2024 年收购的 Leonardo.ai 的研究人员参与）。已在 Canva 内向全球所有用户开放（左下角 Dream Lab），开发者可通过公开 API 调用（模型名 craft_v1_2k），Canva MCP 服务器标记为「即将推出」。架构是两阶段的：传统扩散模型从提示词直接生成像素，Craft 拆成两步 —— ① 图像规划模型先写出一份详细构图计划（哪些元素出现、空间关系、相对尺度、视觉层级、图上需要什么文字），② 专用渲染模型再把计划翻译成最高 2K 分辨率、30 多种画幅的高保真图像，图内文字支持 55 种语言。Canva 的论据是：先显式建模构图与排版再渲染，复杂版式（含可读文字、精确物件摆放）才做得准，也才能做到改一个元素而不动其他一切。训练数据是另一个差异化点：多数图像模型主要吃照片，Craft 的训练数据里大量是 Canva 内容库里数百万份人类制作的模板 —— 海报、社媒帖、演示稿、信息图、菜单、排版密集的版式。用 Canva 的说法，平面图像教不会模型「标题该放哪、logo 该多大、菜单该留多少空白」，而模板会。内部评测中专业设计师与数十位研究员对超过 25000 组图像做两两对比，自动化评测与人类判断冲突时以设计师为准。榜单：DesignArena 上整体第四、Elo 1341，前三名全部是 OpenAI 的 GPT-Image 模型，领先谷歌 Nano Banana 2.1 五十分；人像与自然两个分项第一。性能侧用模型蒸馏把推理步数压到原模型零头，比首个内部版本快一个数量级；更便宜的 Craft-fast 与 Craft-ultrafast 已公布未定档。输出可经 Magic Layers 转成完全可编辑的图层化设计。

8 Ideogram 发布 Vector 1.0：文本直出可编辑 SVG，图片矢量化 0.10 美元/张 ✏️ 矢量工作流
Ideogram 于 10 月 22 日发布 Vector 1.0，该公司第一个矢量模型，同日在自家平台、API 以及 fal 上线。它做两件事：① 文本直出 SVG —— 描述一个设计，直接返回一份可编辑的 SVG（平滑渐变、锐利排版），可逐个形状缩放、改色、精修；② 图像转矢量 —— 把一张图转成细节丰富的可缩放矢量，官方称从小标签到大海报都保持锐利。API 细节：文生矢量 POST /v2/svg/generate/ideogram-vector-1，提示词上限 9500 字符（足够塞进一整份品牌 brief 而不是一句 caption），可选最多 5 张参考图；图转矢量接受最大 50 MB 的 JPEG/PNG/WEBP，Simple 模式画更少更简单的形状，默认 Detailed 模式保留更多细节。定价：文生矢量 low $0.13 / medium $0.16 / high $0.20（带参考图的 high 为 $0.32），图转矢量 $0.10/张。两个端点都异步（返回 base64 生成 ID，轮询共用 generations 端点），支持 Ed25519 签名的 webhook；输出默认私有，企业输出始终私有。实测参考：一张 1200×896 的扁平插画，Detailed 模式转成 282 条路径、120 KB、14 秒，Simple 模式 163 条路径、55 KB、16 秒（后者更适合刻字机、刺绣与后续编辑）；放大六倍时原图出现明显像素，SVG 仍是一条干净的边。一个必须注意的坑藏在它自己的 API 文档里 —— group 参数（「请求分组到图层」）后面紧跟着一句「分组功能尚不可用」，也就是说矢量化的图目前回来的是几何路径，没有图层组织；传一张扁平 PNG logo 想拿回文字层/标志层/背景层分明的文件，今天还做不到。官方也未公布架构、训练数据、SVG 复杂度上限与授权条款。

编辑点评

今天八条里，真正值得单独拎出来的是「委托」这件事第一次被三方同时定义。

谷歌定义的是执行面 —— 每个智能体一台硬件隔离的 microVM，长期凭据不落地，只发会话级短时效令牌。身份是运行时下发的，不是配置里写死的。银行定义的是接受面 —— 摩根士丹利封禁、其余三家降级到只读，嘉信理财自己发 MCP 服务器只给余额不给划转，能看不能动是它们给出的折中解。1Password 定义的是凭据面 —— 智能体完成登录但不接触密码，Muse 与 Grok Bot 同日接入，代理权第一次被做成标准能力。三者拼起来是一条完整链路：谁派你来的 → 你凭什么进来 → 你能动什么。缺任何一环，智能体就只能在「拿用户密码冒充用户」这个最原始的模式里打转 —— 而今天银行封堵的正是这个模式。

「先规划后执行」正在成为复杂生成任务的通用解法。微软的 MAI-DxO 先问诊后开检查、Canva 的 Craft 先写构图计划再渲染、谷歌把 harness（大脑）与沙箱（手）严格分离 —— 三家领域完全不同，结构却一样：把「想清楚」和「做出来」拆成两个可独立评测、可独立优化的阶段。对要做宣发自动化流水线的团队，这是本期最可直接借鉴的工程结构。

监控这件事被证明不能自证。METR 与 Redwood 找到的漏洞里，最值得记的不是「数百次操作可逃过监控」，而是「继续干活就能无限期推迟被监控」 —— 监控挂在「交还控制权」这个事件上，而这个事件由被监控对象自己决定何时发生。同样的结构在 Symantec 那条里以攻击形态出现：Skynet 模式授权 10 万步无需确认，本质就是让「交还控制权」永不发生。攻防两侧看到的其实是同一个漏洞。

六条可以立刻执行的线索：① 本周做一次密钥轮换 —— PHP2Shell 事件已提示服务器内存中的凭据可能泄露，Symantec 的 LLMjacking 靠的就是扫泄露的 API key，宣发侧所有第三方生图/视频/翻译 API 密钥全部换一遍；② 自建模型服务与 MCP 服务器一律加认证并限制出网 —— 今天起暴露的 LLM 端点不只被白嫖算力，而是可能被拿去当别人的攻击大脑；③ 智能体登录外部平台改用官方 API + 短期可撤销令牌，不要用账号密码，给每个智能体单独建档标明授权范围与额度；④ 宣发素材流水线套「计划 → 执行 → 独立评审」三段式，比一次性提示词直出更容易控质量和预算；⑤ 把团队 SOP 写成 SKILL.md，一份文件让 70+ 平台的 AI 助手学会按规范干活，但装第三方技能前必须审里面的脚本；⑥ Canva Craft 与 Ideogram Vector 各跑一轮小样，前者验图内中文文字准确性与转图层可编辑度，后者验扁平素材转矢量的路径数量（Simple 模式先行）。
