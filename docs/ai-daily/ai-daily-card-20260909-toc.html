i. Models & Agents 3 items
🧠 模型 & Agent
Meta 发布个人智能体 Muse，OpenAI 用 1 万智能体求解 Navier-Stokes，ChatGPT Images 2.5 生图延迟降 50%
1 Meta 发布个人智能体 Muse：扎克伯格站台，连接购物/订票/支付 🤖 个人智能体
9 月 9 日 Meta 正式发布个人智能体 Muse（内部代号 Hatch），由长程智能体模型 Muse Spark 1.3 驱动，Meta 首席 AI 官 Alexandr Wang 亲自站台，初期仅美国上线。Muse 可自主发邮件、卖车、订餐、全网购物，靠连接器接入 Gmail、Google 日历、Spotify、1Password（登录）、Stripe（支付）等，应用关闭后仍持续工作。定价免费基础版 + 20/100 美元/月订阅，入口 muse.ai。它以「安全虚拟机 + 登录/支付继承」补齐「让 AI 替你办事」的信任闭环，Alexandr Wang 更晒出「对战 Instinct 4-1」。
2 OpenAI 用 1 万智能体 88 小时求解 Navier-Stokes 千年难题 🧮 数学
OpenAI 宣布用约 10000 个并发智能体、88 小时给出 Navier-Stokes 存在性与光滑性问题（七大千禧年大奖难题之一，奖金 100 万美元）的一个解，全程发送 490 万条消息、消耗约 3000 亿输出 token，并由 GPT-6 Astra 完成 17 小时 Lean 形式化验证，宣布不领奖。所用模型是 8 月 28 日开训、能力远超 Astra 的下一代内部模型。这是「万级智能体协作」首次逼近数学前沿，但同步引爆争议：陶哲轩点赞却担忧「AI 竞速摧毁数学公开分享传统」，NYU 数学家 Tristan Buckmaster 指控 OpenAI 抢发。
3 OpenAI 发布 ChatGPT Images 2.5：延迟降 50% + Sketch 涂鸦生图 🎨 生图
OpenAI 发布图像模型 ChatGPT Images 2.5，Sam Altman 官宣。相比 4 月的 Images 2，延迟最多降 50%，细节锐度、自然光照、纹理质感提升，多次编辑间细节一致；新增 Sketch 涂鸦生图（输入 @Sketch 手绘草图 → 依草图生成）、模板库、图片内评论式局部修改。官方透露已累计生成 超 30 亿张图片，衍生模型 Sunburst 与 Flare 登顶 Arena 三个图像榜单前两名。「涂鸦→成图 + 局部评论修改 + 一致性」正好覆盖商用素材「稳定出系列」的刚需。
ii. Industry & Infrastructure 3 items
🏭 行业 & 基础设施
Inception 发布扩散 LLM Mercury 2.5，Cognition 480 亿美元估值融资，蚂蚁开源原生多模态 Ling-VL
1 Inception 发布扩散 LLM Mercury 2.5：智能提升 40%，1107 tok/s 🧬 扩散 LLM
Inception 发布扩散大语言模型 Mercury 2.5，官方称「目前能力最强、规模最大的扩散 LLM」：智能较 Mercury 2 提升 40%，NVIDIA GPU 上达 1107 tokens/s，上下文 260K，定价 $0.20/百万输入、$0.75/百万输出。对标 GPT-5.6 Luna（Low）、Gemini 3.5 Flash-Lite、Claude Haiku 4.5 的「快速档」能力带。核心是离散扩散（discrete diffusion）路线，宣称实现 LLM「无损加速」——速度与质量不再二选一，对推理成本敏感的 Agent 场景最有价值。
2 Cognition（Devin）以 480 亿美元估值融资 20 亿美元 💰 融资
AI 编码智能体 Devin 开发商 Cognition 宣布以 480 亿美元估值融资 20 亿美元，由 Andreessen Horowitz、Accel、Founders Fund、General Catalyst、Avenir 领投，距上次 260 亿美元估值融资仅四个月、近乎翻倍。信号是「AI 编码」成为最吸金的 Agent 落地场景——「能产出可交付代码」是最容易量化 ROI 的一类，且顶级机构同下注说明赛道「非赢家通吃」，多家共存的预期反过来推高差异化工程能力的估值。
3 蚂蚁百灵开源首个原生多模态 Ling-3.0-flash-VL：124B MoE 📦 多模态
蚂蚁百灵发布并开源首个原生多模态大模型 Ling-3.0-flash-VL，基于 Ling-3.0-flash 的 MoE 架构，总参数 124B、单次推理激活 5.5B，原生支持图像、文本与视频输入，上下文窗口 256K Token。亮点是「原生多模态」而非外挂视觉编码器，视觉与语言在统一 MoE 架构内深度融合；延续「大参数低激活」的推理友好路线，瞄准长视频/多模态长上下文理解，国产开源在多模态赛道持续加码。
iii. Trends & Tools 2 items
📈 趋势 & 工具
Runway 发布 Adobe 插件直入 Premiere/AE，DeepSeek Flash 系列输出降至每百万 Token 4 元
1 Runway 发布 Adobe 插件：Premiere/AE 时间线内直接生图生成视频 🎬 视频编辑
Runway 发布 Runway Plugins，新面板直接嵌入 Adobe Premiere Pro 与 After Effects，在时间线内直接生成图像和视频、重绘片段并放置结果；配套 Edit Studio 用 Aleph 2 按原始时长重渲染。插件免费下载（macOS/Windows），生成功能面向所有付费计划、消耗现有额度。这是 AI 视频工具「从独立应用走向专业软件内嵌」的结构性升级——打通「生成→剪辑」断裂流程，直击剪辑师「补镜头/改运镜/换氛围/返工」的痛点。
2 DeepSeek Flash 系列降价：输出每百万 Token 4 元 📉 价格战
DeepSeek 开放平台公告，9 月 10 日 12 时起调整 Flash 系列定价：空闲时段输入缓存命中每百万 Token 0.02 元（降 60%）、缓存未命中 1 元（降 33.33%）、输出 4 元（降 11.11%），高峰时段价格翻倍。信号是国产推理价格战继续下探，「空闲/高峰」分时定价代表推理服务进入精细化「削峰填谷」运营；缓存命中价近乎归零，对 Agent 多轮、长上下文复用场景是隐性利好。

编辑手记

今天是 AIGC 日报第 45 期，主线是「Agent 的规模化兑现」：#2 的 OpenAI 用 1 万智能体 88 小时攻破 Navier-Stokes 千年难题，把「万级 Agent 协作 + 形式化验证」从实验推到真实数学前沿；#1 的 Meta 用 Muse 把「个人常驻智能体」做成可量产产品——一个在「协作极限」上炫肌肉，一个在「落地入口」上抢生态，共同指向：Agent 正在从「能做」走向「规模能用 + 可信可用」。

行业侧是「资本与价格的持续加码」：#5 Cognition 四个月估值从 260 亿飙到 480 亿美元（AI 编码最吸金），#8 DeepSeek Flash 输出打到 4 元/百万 Token（推理价格战继续下探），#6 蚂蚁开源原生多模态 VL——资本在往「能产出可交付成果」的 Agent 场景重仓，算力成本持续松动，国产开源在多模态上加码，宣发侧「批量自动化」的性价比天花板在被不断抬高。

工具侧两条（#3 Images 2.5 生图 / #7 Runway 入 Adobe）都直击宣发刚需：前者用「涂鸦生图 + 局部评论修改 + 细节一致性」覆盖了做 KV/海报的完整链路，后者用「时间线内直接生视频/重绘」打通了剪辑的断裂流程——一个解决出图，一个解决出片，且都强调「一致性与可返工」这个商用落地的关键。

落到宣发工作，本期五条可执行线索：① 生图链路 → 验证 Images 2.5 的「同角色多角度一致性 + 品牌色/logo 还原度」，纳入 KV/海报工具链候选；② 视频剪辑 → 验证 Runway 插件在 Premiere/AE 内「Aleph 2 重渲染」的成片质量，把「补镜头/改运镜/换氛围」做成剪辑标配；③ Agent 落地 → 记住 #2 的「形式化验证兜底」，批量 Agent 流水线务必配「可自动校验的结果闸门」，优先选「产出可直接验收交付物」的任务；④ 个人智能体 → 关注 Muse 代表的「新用户触点」，思考宣发物料/活动入口「可被 Agent 调用」的形态；⑤ 成本杠杆 → 非实时批量任务挪到空闲时段跑，吃 DeepSeek 分时定价的红利。
