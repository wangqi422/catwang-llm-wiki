⚡ 高效工作流
3 套改变日常的工作方式
5 Every「复利工程」· 单人维护 5 款产品的秘密 方法论
媒体软件公司 Every 公开「复利工程」方法论，用单人工程团队维护 5 款产品。核心不是写代码更快，而是 80% 时间花在 Plan 和 Review，只有 20% 写代码。
Plan
AI 生成实现计划、任务列表、测试策略
Work
按 plan 执行，每个改动后跑测试
Review
14 个专项审查 agent 并行检查
Compound
把解法写入 CLAUDE.md 和 docs/solutions/
∘ @xiaohu, Every Engineering · github.com/everydotai/compound-engineering
6 Claude Code 四种 Agent 循环模式 Claude
Anthropic 官方定义了四种 agent 循环类型：Turn-based（用户触发）、Goal-based（/goal 设定完成标准）、Time-based（/loop 定时重复）、Proactive（事件驱动自动运行）。
/goal
设定可验证完成标准与最大轮次
/loop
按时间间隔重复执行
/schedule
移至云端定时运行
∘ @ClaudeDevs · claude.com/blog/getting-started-with-loops
7 Claude Design 系统提示词开源 MIT 协议
Anthropic 旗下 Claude Design 的反向工程系统提示词在 GitHub 以 MIT 许可证开源，包含 20 章提示词和 14 项技能，覆盖内容纪律、美学、无障碍（WCAG）、交互状态、系统思维等。
∘ Hacker News · github.com/Trystan-SA/claude-design-system-prompt

8 Anthropic 提示词工程实战心法 Margot Van Laar
Anthropic 应用 AI 工程师 Margot Van Laar 核心观点：我们很少从零写提示词，大部分时间在调试和维护已有生产提示词。两个实战场景：客服机器人维护（XML 结构化、移除旧模型遗留指令）、零售排班 Agent 从零构建（拆成生成-评估-修复三个简单提示词）。
核心心法
评估（Eval）是唯一严谨方式，没有评估就是碰运气
模型选择
复杂逻辑选用更强推理模型（Opus）
∘ @berryxia · Code with Claude
9 shot-scraper video · 让 AI 智能体录制演示视频 Simon Willison
shot-scraper 1.10 新增 video 命令，支持通过 storyboard.yml 定义操作步骤，利用 Playwright 录制浏览器视频。把 --help 输出设计得足够详细，可使编码 Agent 直接利用该命令生成演示视频。
# 安装并录制演示视频 pip install shot-scraper shot-scraper video storyboard.yml
