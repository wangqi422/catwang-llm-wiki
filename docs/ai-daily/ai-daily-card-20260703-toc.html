i. Global Giants & Agent Revolution 3 items
🌐 海外巨头 & Agent 革命
OpenAI 以股换路 · Anthropic 双线突进 · 1000 个并行子代理开放 Pro 计划
1 OpenAI 提议 5% 股权（426 亿美元）给美国政府 · 换监管绿灯同时邀 Anthropic/谷歌/Meta 一起 🔥 头条
英国《金融时报》7/2 独家披露：OpenAI CEO 奥特曼已向特朗普政府提议将公司 5% 股权（按 8520 亿美元估值计算约 426 亿美元）移交公共财富基金，化解国会强监管压力，让美国公众"直接分享 AI 经济收益"。奥特曼进一步建议 Anthropic、谷歌 DeepMind、Meta 等美国前沿 AI 开发商各出 1%-5% 股权，注入类似"阿拉斯加永久基金"的主权财富基金，由独立委员会管理，分红给全美公民。方案仍处"概念性"阶段，需国会立法授权。
2 Anthropic Claude Sonnet 5 6/30 正式发布 · 最 Agentic 价位砍 60% 🔥 巨头降价
Anthropic 6/30 正式发布 Claude Sonnet 5——迄今最"Agentic"的 Sonnet 模型。能制定计划、自主调用浏览器/终端、自主任务能力接近 Opus 4.8。促销期 8/31 前 2 美元/百万输入 + 10 美元/百万输出 tokens，之后回到 3/15 美元——相比 Sonnet 4.6 综合降价约 60%。BrowseComp 评估匹配 Opus 4.8（高 effort ），网络安全能力比 Opus 弱很多（Firefox 漏洞 0%），主动定位为"agentic 部署的安全选择"。同步 7/1 全面解除 Fable 5/Mythos 5 出口管制。
3 Anthropic Claude Code 动态工作流正式开放 Pro 用户 · 单次 1000 个并行子代理 🔥 多代理
Anthropic 7/2 宣布将 Claude Code 的"动态工作流"（Dynamic Workflows）升级为正式可用，首次向 Pro 计划（20 美元/月）订阅用户开放。单次运行可协调多达 1000 个并行子代理，每个子代理拥有独立、专注的上下文窗口。架构级重构：模型把编排计划"外置"为 JavaScript 脚本由独立运行时执行，让"长达数天的自主运行"在架构上成为可能。"评估器-优化器"对抗验证机制专门解决 LLM 自我验证时倾向"高报成功率"的缺陷。成本警示：24 小时并行运行约 400-600 美元。
ii. China AI & Capital 2 items
🇨🇳 国产 AI & 资本
Kimi 进 GitHub Copilot · K3 2.5 万亿定档 · 可灵 30 亿美元独角兽
4 Kimi K2.7 Code 登陆 GitHub Copilot · 首个开源模型进入选择器；K3 7月定档 2.5 万亿参数 🔥 国产开源
GitHub 7/1 正式在 Copilot 中上线月之暗面 Kimi K2.7 Code——这是 Copilot 模型选择器首次纳入"开放权重"模型。模型托管在 Microsoft Azure，按用量计费。K2.7 Code 技术规格：MoE 架构总参 1 万亿，激活 320 亿；256K 上下文 + MLA + MoonViT 多模态。核心亮点："过度思考抑制"——比 K2.6 平均减少 30% thinking-token 使用量。同步消息：Kimi K3 已确认 7 月内发布，参数规模 2.5 万亿，超越 DeepSeek V4 Pro 的 1.6 万亿与百度文心 5.0 的 2.4 万亿，有望成为"国产最大参数模型"，1M 超长上下文 + 多模态深度集成对标 GPT-5.6 旗舰。
5 快手可灵 AI 完成近 30 亿美元融资 · 国产视频生成步入独角兽时代 国产资本
快手旗下 可灵 AI（Kling AI）7/2 完成近 30 亿美元融资，估值跃升至独角兽顶端（超 200 亿美元）。本轮融资是国产 AIGC 视频生成赛道迄今最大单笔融资，资金主要用于基础模型迭代、推理算力扩张与全球商业化。可灵 3.0 在国产视频生成中长期处于"质量 + 速度 + 中文场景"三维第一梯队，3.0 Ultra 早期访问已开放。30 亿美元足够把可灵推到"全球第一阵营"：买算力、扩团队、抢市场，1 年内可能直接挑战 Runway / Veo 3.1。
iii. Programming & Trends 3 items
🔥 编程 & 趋势

6 Claude Code 被曝暗中监视中国用户 3 个月 · Anthropic 道歉并下线代码 🔥 地缘 AI
7/2 Reddit 用户爆料：Anthropic 在 4 月推出的 Claude Code 2.1.196 版本中暗藏针对中国用户的"监视代码"——可暗中检测用户是否在中国境内、是否使用中国域名代理、是否与某中国 AI 实验室存在关联；一旦检测到会通过篡改系统提示词中的日期格式和表达符号向服务器发送隐藏标记。代码通过 XOR 加密遮蔽，官方更新说明从未提及，可能已存在近 3 个月。Anthropic 7/3 凌晨紧急回应："这是一次实验"，将在次日发布的新版本中删除该特殊代码。这是迄今最具体的"AI 公司针对特定国家歧视性技术"证据。
7 Anthropic 万人调查：35% 用户预计 AI 一年内完成大部分工作 趋势
Anthropic 7/2 发布万人规模用户调研：35% 的重度 AI 委托者预计 AI 将在 12 个月内承担其大部分工作任务。使用强度越高，对 AI 替代速度的预期越激进。同期 Claude Code 核心开发者 Boris Cherny 披露其工作流：同时运行 15 个 AI 代理协同写代码，已 6 个月未手写 SQL。Claude Code 已占 GitHub 公开提交量的 4%——意味着 GitHub 每 25 次公开 commit 就有 1 次来自 Claude Code。"AI 写代码"从概念变成基础设施数据。
8 Cursor 推出 iPhone/iPad 移动应用 · AI 编程走向移动端 🔥 移动编程
AI 编程工具 Cursor 7/1 推出 iPhone 和 iPad 应用公测版，为付费订阅用户提供"从移动设备启动、监控、审查 AI 编码智能体"的能力。功能完整度：启动编码智能体 + 管理进行中工程 + 审查变更的截图/视频 + 图片批注 + 差异检查 + 合并 PR + 语音对话与智能体交流。联合创始人 Chris Browder 称之为"连接本地和云端智能体工作的桥梁"。7/5 前移动端 Composer 2.5 享受 75% 折扣。继 SpaceX 600 亿美元收购 Cursor 传闻后，Cursor 是第一个把 AI 编程"装进口袋"的主流工具。
