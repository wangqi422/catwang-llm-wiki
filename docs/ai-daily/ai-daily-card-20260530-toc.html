Opus 4.8 自愈 + DeepSeek 永久降价 75% · 今日 AI 双重冲击波

🤖 AI 模型 & Agent · 🏗️ 行业 & 基础设施 · 📊 趋势 & 工具 · 2026.05.30
i. AI Model & Agent 3 items
🤖 AI 模型 & Agent
今日最重磅的模型与 Agent 动态
1 Claude Opus 4.8 发布：Dynamic Workflows + 自愈黑科技 🔥 P0 9.5
Anthropic 发布旗舰模型 Opus 4.8，同步推出两项行业首创：Dynamic Workflows（数百子代理并行自主执行复杂任务，上限 16 并发/1000 agents）和 Claude Code 自愈功能（自动检测修复 6 大开发噩梦场景，调试时间骤降 74%）。代码缺陷漏报率较前代降低约 4 倍，欺骗行为和偏差率显著下降。Mythos 级模型路线图同步披露，将在未来几周向所有客户开放。
2 DeepSeek V4-Pro 永久降价 75%，登顶全球性价比榜首 🔥 P0 9.2
DeepSeek 宣布 V4-Pro API 价格在 5/31 限时优惠结束后永久降至原价 1/4，降幅 75%。Artificial Analysis 确认其登顶全球性价比榜首——执行同等任务成本仅为 GPT-5.5 的 1/12、Opus 4.7 的 1/19。OpenRouter 平台 V4-Flash 周调用量 3.43 万亿 Token 首次登顶全球。社区共识："Codex/Claude 定上限，DeepSeek 定斩杀线"。
3 MiniMax 启动 A 股 IPO，大模型双雄有望同步上市 🔥 P0 8.8
MiniMax 于 5/29 与中信证券签署辅导协议，正式启动 A 股 IPO。智谱已于 2 月签约科创板上市辅导，港股市值一度达 8800 亿港元。双雄同步上市标志中国大模型产业从"融资驱动"进入"资本市场验证"阶段。同期月之暗面完成 140 亿元融资，DeepSeek 首轮估值约 3000 亿元。

🏗️ 行业 & 基础设施

4 苹果用 Gemini 训练端侧 AI，部分 Siri 请求转向谷歌云 P1 8.5
据 The Information，苹果计划在 WWDC 全面发力端侧 AI，正利用谷歌 Gemini 训练轻量化模型（模型蒸馏）。端侧无法处理的复杂需求已批准在谷歌云中使用英伟达 Confidential Compute 隐私保护技术。苹果还在寻求收购边缘 AI 初创公司，Liquid AI 曾为潜在目标。
5 Xcena 融资 1.35 亿美元：MX1 芯片将 KV 缓存管理搬进内存模块 P1 8.2
AI 芯片初创 Xcena 完成 1.35 亿美元 B 轮，估值 5.7 亿。核心创新 MX1 芯片将 KV 缓存管理从 GPU 软件层下沉到内存模块，直击 AI 推理"内存墙"瓶颈。代表从"堆 GPU"到"优化内存"的范式转换。
6 Liquid AI 开源 LFM2.5：8B-A1B MoE 模型，38T Token 训练 P1 8.0
Liquid AI 开源 LFM2.5：8B 总参数、1B 活跃参数的 MoE 架构，在 38 万亿 Token 上训练。非 Transformer 架构（Liquid Foundation Model），推理成本极低，适合端侧和边缘部署。苹果曾将其列为潜在收购目标。

7 Epoch AI 报告：开源与闭源模型差距扩大至 4 个月 P2 7.8
Epoch AI 最新分析：自 2026 年 1 月以来，开源与闭源模型平均差距为 8 个 ECI 点（约 GPT-5 与 GPT-5.5 之差），从 3 个月扩大至 4 个月。DeepSeek-R1 曾短暂缩小差距，但闭源迭代速度更胜一筹。AI 能力"民主化"面临现实挑战。
8 阿里云百炼全面 CLI 化并开源 + MuleRun Agent 海外发布 P1 7.5
阿里云百炼平台全面 CLI 化并开源，60+ 云产品 Skill/MCP/CLI 化。同步海外发布 Qwen Cloud、Agent 产品 MuleRun（多 Agent 协作）、编程平台 Qoder 1.0（9 个月 500 万用户）及桌面智能体 QoderWork。Qwen3.7-Max 首个非美模型原生 MCP + Messages API 兼容。
