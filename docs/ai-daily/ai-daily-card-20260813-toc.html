DeepSeek 与 Grok 同日亮剑，微信 WeLM 首曝双模型，Agent 赛道全面开火
1 DeepSeek V4 Pro 正式版深夜上线，DeepSWE 从 7.3 飙到 62.7 逼近 Fable 5 🇨🇳 模型
北京时间 8 月 13 日凌晨，DeepSeek 官网 API 文档悄然更新，模型版本切换至正式版 DeepSeek-V4-Pro-0813，调用模型名不变。新版本大幅增强 Agent 能力，支持 1M 上下文、最高 384K Token 输出，兼容 Responses API、Codex 接入与 OpenAI/Anthropic 双格式。最亮眼的是智能体编程基准 DeepSWE 从预览版 7.3 跃升至 62.7，直接反超 Claude Opus 4.8，Terminal Bench 达 87.9 逼近 Fable 5 的 88.0，多项 Agent 评测反超 Fable 5。价格暂未上调，但官网已预告「近期整体上调定价、涨幅较大」。
2 Grok 4.6 发布：主打长时任务 Agent，多基准登顶与 GPT-5.6 Sol 持平 🚀 模型
北京时间 8 月 12 日晚间，SpaceXAI（xAI）正式发布 Grok 4.6，重点强化长时运行 Agent 与复杂交互、视觉工作。在 Artificial Analysis Intelligence Index 上以 61 分与 GPT-5.6 Sol 持平，CursorBench 3.2 达 69.9%、DeepSWE 1.1 达 65.9%，多项智能体基准登顶。训练引入 Agentic RL，覆盖知识工作、编程、内核优化、Web 开发、CAD 等真实多步任务，并强化「自我测试/验证」能力。发布即上线 Cursor、Grok Build、API 及 OpenRouter/Vercel/Cloudflare，首周 2 倍额度。
3 微信公布 WeLM 双模型：80B 已驱动「小微」，617B MoE 开发中 💬 中国
微信团队正式公布自研大语言模型 WeLM，主打资源利用效率：WeLM-80B（800 亿总参数、30 亿激活）已部署于微信原生 AI 助手「小微」，负责聊天搜索、调用微信原生功能与小程序服务；更大的 WeLM-617B（6170 亿总参数、230 亿激活，MoE 架构）仍在开发，将面向智能小程序开发与小微工具生成。腾讯同日 Q2 财报披露「小微」已在微信内小范围灰度测试。MoE 架构把单次推理成本压到极致，正是十亿级用户高频调用场景的底层刚需。

4 LiteLLM 遭供应链攻击：43.4 万 CI/CD 凭据泄露，波及微软/亚马逊/英伟达 2500+ 组织 🚨 安全
安全机构 CloudSEK 与 Hudson Rock 披露大规模供应链攻击：开源 AI 网关 LiteLLM 被攻陷，两个恶意版本 1.82.7 与 1.82.8 被上传至 PyPI，在约 40 分钟窗口期内被大量下载，导致约 43.4 万条 CI/CD 流水线凭据泄露，波及微软、亚马逊、英伟达、思科、三星等超 2500 家组织。攻击链起点是漏洞扫描器 Trivy 的 GitHub Actions 流水线被攻破，进而窃取 LiteLLM 的 PyPI 发布 token——安全工具本身成了攻击跳板。恶意载荷借 `.pth` 启动钩子执行，静默窃取云密钥、SSH、Kubernetes token 与 AI 供应商凭据。
5 腾讯 Q2 资本开支 528 亿元（+176%），混元 Hy4 在路上，AI 投入重塑现金流 ⚡ 算力
腾讯发布 2026 年 Q2 财报：营收 2047.9 亿元（+11%），Non-IFRS 经营利润 756.4 亿元（+9%）。最受关注的是 资本开支 527.8 亿元，同比大增 176%、环比 +65%，自由现金流因此转负。混元 Hy3 已接入 WorkBuddy、元宝、ima、搜狗输入法，计划近期推出更大参数的 Hy4；WorkBuddy PC 端 6 月访问量超 2000 万，TokenHub 日 Token 调用量超 25 万亿、两个月增 5 倍。管理层透露「看到机会就加大投入」，算力订单转售可较采购价高出 30%——AI 资本开支正变成可交易资产。
6 Cerebras Q2 云业务 +287%，硬件收入下滑拖累股价盘后跌 17% 💻 硬件
AI 芯片公司 Cerebras Systems 公布 2026 年 Q2 财报：核心收入 2.099 亿美元（+103%），其中核心云及其他服务收入 1.277 亿美元，同比激增 287%，主要受 OpenAI 部署扩大推动。但硬件收入同比下滑 23%，拖累 GAAP 营收，盘后股价一度跌约 17%。云业务暴涨与硬件收入失速形成鲜明反差——推理需求爆发，但客户更倾向按需租用而非自购芯片，头部客户集中度也成估值扰动源。

📈 趋势 & 工具
Agent 能力跨端迁移，开源模型监管逻辑生变
7 Claude Chrome 侧边栏升级为 Cowork 会话，跨桌面/网页/移动端同步 🛠️ 工具
Anthropic 升级 Chrome 版 Claude 扩展，侧边栏带来完整 Claude Cowork 会话体验：浏览器内的任务与对话可跨桌面端、网页端、移动端无缝同步，历史记录互通，并自动继承账户已配置的 Agent Skills 与 Connectors。侧边栏能查看当前网页，利用浏览器登录状态执行点击、跳转、填表等操作。面对提示词注入攻击风险，Anthropic 对重大操作（提交表单、发消息、购买、共享数据）增设单独审查与人工确认，企业可限制访问域名。即日起面向 Max 与 Team 开放，Pro 数周内上线。
8 白宫拟将前沿开源模型纳入发布前安全测试，监管从「开闭源」转向「性能门槛」 📋 政策
据 WIRED 引述知情人士，白宫准备修改前沿 AI 安全测试框架，将开源模型纳入发布前政府测试。现行框架仅覆盖 OpenAI、Anthropic 等闭源前沿模型；未来一旦开源模型达到与 Mythos 级或 GPT-5.6 相当的「前沿能力」水平，也将接受发布前测试（预计最长 30 天），框架目前仍属自愿。这是美国 AI 监管逻辑的重要变化——监管边界从「开源/闭源」转向「性能门槛」，Meta 及美国开源生态面临新的监管不确定性，中国开源模型在美部署也可能受波及。

编辑手记

今天是 AIGC 日报第 26 期。今天最戏剧性的画面是DeepSeek 与 Grok 在同一个夜晚背靠背亮剑——V4 Pro 正式版与 Grok 4.6 在 2 小时内先后发布，且都把主战场压到了「长时任务 Agent」上。这不是巧合，而是 2026 年模型竞赛方向的集体转向：跑分内卷到头了，谁能把一件多步骤的活从头干到尾，谁才是下一阶段的王。

DeepSeek 的 DeepSWE 从 7.3 飙到 62.7是本期最反直觉的数字——一个接近十倍的增长，说明预览版到正式版的差距根本不是「打磨」，而是「重做」。对开源生态而言，这意味着闭源模型「Agent 能力」的护城河正在被快速追平，而 DeepSeek 偏偏选在「预告涨价」的档口放出这个成绩，商业上的意图再明显不过：能力先到位，价格随后跟上。

真正的警钟来自 LiteLLM 供应链攻击——43.4 万条 CI/CD 凭据、2500+ 组织、攻击入口居然是一个「漏洞扫描器」。这件事最值得记下的一句话是：你为了抓漏洞而装的安全工具，本身可能就是最大的漏洞。对任何把 AI 网关、扫描器塞进流水线的团队，本周该做的第一件事是核对版本、轮换密钥，而不是继续追新模型。

腾讯 528 亿资本开支则是国内侧的信号——自由现金流转负也要加码算力，WorkBuddy 月访 2000 万、TokenHub 两个月涨 5 倍，说明「模型 + 应用」的双轮在国内大厂同样跑通了。对 CODM 宣发团队，这直接意味着内部 AI 工具链会越来越强、越来越便宜。

落到宣发工作，本期三条可执行线索：① DeepSeek V4 Pro / Grok 4.6 的长时 Agent 能力，适合承载竞品情报归纳、素材批量分析这类「多步骤重活」，趁涨价前把技术方案定下来；② LiteLLM 教训提醒我们，任何接入宣发流水线的第三方 AI 工具都要先做供应链来源审查；③ 微信「小微」灰度，是私域运营与玩家服务自动化的新变量，值得持续跟踪开放节奏。
