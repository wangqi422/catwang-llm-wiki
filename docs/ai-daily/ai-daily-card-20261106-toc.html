🧱 开放权重与运行环境
今天交出来的不是参数表而是能直接跑的东西 —— 百度放 280B 基座权重、Thinking Machines 承诺下周开 594B 全量权重、月之暗面把 Harness 做成 7×24 云托管
1 百度开源 ERNIE 5.5 Flash Base：280B MoE / 每 token 激活 14B，33.5T tokens 预训练，推理支持 1M 上下文 🧱 开源基座 / 国产模型
11 月 5–6 日，百度正式开源最新基座模型 文心 ERNIE 5.5 Flash Base 的预训练终点权重，FP8 与 BF16 两版已上线 Hugging Face。稀疏 MoE 架构，总参数 2800 亿、每 token 仅激活 140 亿，用 33.5 万亿 tokens 从零预训练；预训练上下文 128K，微调与推理阶段最长支持 100 万 token。官方自报 MMLU 93.3、MMLU-Pro 78.4、HumanEval+ 82.3、MBPP+ 81.5，宣称同尺寸 SOTA，超过 DeepSeek-V4-Flash-Base、Hy3-preview-Base 与 MiMo-V2.5-Base。效率是设计目标而不是堆参数：43 层中 37 层采用每 128 个 token 只缓存一条的压缩注意力，共 512 个路由专家、每 token 选 10 个；训练侧用 Muon 优化器 + FP8 混合精度 + 自研 FlashMask-4 算子，把长文本的显存与计算一起压下来。开源的是基座不是助手：纯预训练权重，未经中训练与后训练，下载后不能当成熟聊天机器人用，定位是给开发者做指令微调、领域适配与强化学习；采用自定义许可证，商用前需单独核对条款。与昨日形成对照：11-05 期讲的是 65B / 276B 的小而快编码模型，今天这条把超大容量与每 token 只算 14B 同时做进一个可自部署的国产底座。需要保留的判断：跑分均为厂商自评，评测环境与验证脚本不统一，跨实验室横比只作参考；后训练版本官方称将随后推出。

2 Thinking Machines 发布 Inkling 2 Small：594B MoE，AA 指数 31，下周 Apache 2.0 开放全量权重 🧱 模型发布 / 开放权重
11 月 5 日，Mira Murati 的 Thinking Machines Lab 发布第二代模型 Inkling 2 Small：594B 总参 / 17B 激活的稀疏 MoE（48 层、每 token 路由 8 of 384 专家），原生支持图像输入与 variable effort，上下文最长 1M tokens。Artificial Analysis Intelligence Index v5 得分 31（官方模型卡列 30.6），远超第一代；Code Arena WebDev 约 1654 分被列为美国开放权重模型第一。当前先通过 Tinker 平台以闭源权重提供微调、采样与 Playground 试用，官方明确承诺下周完成外部安全测试与红队后以 Apache 2.0 开放全量权重，届时 checkpoint 可下载。训练方法比参数更值得看：更高效预训练 + 一次大规模统一 RL，在数十万条长程编码任务上跨多种 agent harness 与上下文压缩策略训练；奖励不再只有单元测试，很多任务配了 agentic RL grader 评估模型怎么解题而不只是代码是否跑通。视觉自检闭环：能读视觉反馈迭代搭建与精修网站、游戏、3D 设计——官方演示包括用 Three.js 无素材生成整座可运行的城市模拟器、用 Python 写出能启动 Linux 内核的 PC 模拟器、在 Blender 里改水面与烟囱。autoresearch 已跑通：模型自主在 Tinker 上训练 Qwen3.5-4B 做时序预测，自己写评估器、试数据集与 SFT / RL 配方，4.5 小时、426 美元把预测分翻了一倍以上。与昨日是连续剧不是重复：11-05 期的 Cognition SWE-2 Flash 正是基于 Thinking Machines 的 Inkling-Small，今天底座正式官宣并给出开放时间表。需要保留的判断：官方明确仍落后闭源模型（对齐评测低于 GPT-6.1 Sol），AA 指数 31 低于 Gemini 3.8 Flash 的 36.5；美国开放权重第一是在尚未开权重阶段的榜单表述，能否如期放出取决于外部安全测试。

3 月之暗面发布 Kimi Hosted Agents：把 Agent 的 Harness 做成 7×24 云托管服务 🧱 托管智能体 / 企业服务
11 月 5 日，月之暗面正式发布 Kimi Hosted Agents（托管智能体），把支撑 Agent 运行的 Harness 框架作为云端服务提供给企业与开发者。企业无需自建代码执行环境，也不必自己处理上下文管理、工具调用、权限控制、任务中断恢复，即可获得 7×24 小时托管环境，支持长程任务执行与多智能体协作。服务提供独立沙箱、网络权限控制、随时中止会话与审计导出，配套 140+ Skills 与 30+ 插件，可接入自有工具与数据源；配合 Kimi Inference Hook 可在每次推理前按企业规则拦截敏感数据。首批提供 8 个金融 Agent 模板，目前仅向企业认证用户开放。计费由模型 token + 沙箱运行时长 + 插件调用次数三部分构成。卖的东西变了：从卖模型推理 API 上移到卖智能体运行环境，竞争维度从评测分数转向生态厚度与信任半径；官方称企业自建一套可靠 Harness 常需数月并持续投入维护。与前三天的连续剧：11-03 期报 Kimi 游戏开发方案（Agent 直操 Godot / Blender / Unity / UE，20 小时无人干预），11-05 期已标注 K3.1 Pro 完整权重按 10-24 承诺放出并获昇腾 0Day 适配（本期不重复展开），今天补上运行环境托管这一层——模型、方案、环境三段拼齐。成本要拆开算：token、沙箱时长、插件调用次数分别计价，长程任务的账单形态与单纯 API 调用不同。短板也清楚：AWS、阿里云等云厂商已有同类托管服务且企业客户关系与基础设施纵深更深；Kimi 优势在模型与 Agent 框架原生协同，短板在云基础设施。

4 Google 发布 Gemini Omni 1.2 Flash：15 秒原生视频、降价 30% 至 $0.07/秒、多轮对话式改片 🎬 视频生成 / 宣发工具
11 月 5 日，Google 发布并全量开放 Gemini Omni 1.2 Flash，覆盖 Gemini API、Google Cloud、Google Vids、Gemini for business、Flow 与 AI Studio，同步上线 OpenRouter 与 fal。原生视频生成与编辑上限从 1.1 的 10 秒提升到 15 秒，可按一秒步进指定 3–15 秒；720p 价格较 1.1 下调 30% 至 $0.07/秒。新增多轮对话式编辑：换产品、换背景、调光照、改天气、切画幅都不用重生成整段。参考图遵循显著增强，可组合角色 / 产品 / 风格图、最长 3 秒运动片段与音频线索，让人脸、服装、包装字体与品牌色跨机位保持一致。推荐工作流是 360p / 720p 出草稿 → 对话改细节 → 放大到 1080p / 4K；输出带不可见 SynthID 水印，企业可配 Provisioned Throughput，Arena 文生视频榜登顶。账单从重生成换成重编辑：改一处细节不再整段重跑，为不同受众、不同版位出多版广告的成本结构被直接改写。正好补昨天的短板：11-05 期 Images 2.6 的 GIF 实测里背景与手部逐帧漂移、品牌资产需单独过合规是主要痛点；1.2 Flash 官方点名包装字体与品牌色跨帧锁定，等于把一致性做进模型侧。与 1.1 不是同一事件：往期报道过 Omni 1.1 Flash 的 40 秒场景扩展与 4K 放大；1.2 是原生时长、降价、对话式编辑与参考遵循的版本升级，且首次在企业栈全量可用。边界要说清：官方承认快速体育动作、频繁改脚本与复杂物理仍在改进；音频参考需白名单；15 秒仍不是长片；发布时点尚无第三方质量复测。

5 可灵 Kling 4.0 Flash 全面开放并接入 Adobe：PS / PR / AE 官方插件 + MCP / CLI / API 🎬 视频工具 / 剪辑工作流
11 月 4 日晚，可灵 AI 官宣 Kling 4.0 Flash 面向全球所有用户全面开放，支持官网与 API 调用，并新增 MCP、CLI 与第三方 AI 插件接入；最关键的是打通 Adobe 专业影视软件——创作者可在 Photoshop、Premiere Pro、After Effects 内通过可灵官方插件直接调用 Flash 生成素材。Flash 是 Kling 4.0 家族的速度 / 性价比版本，生成 3–20 秒 720p 片段，支持文生视频、图生视频与 Omni Reference。完整版 Kling 4.0 已于 10 月 15 日全量开放（单次最长 30 秒、最多 10 个关键帧），Flash 于 9 月 28 日先小范围开放；本次是扩到所有人 + 扩到 API 与插件，不是新模型首发。入口变化大于能力变化：从浏览器生成、导出、导入时间线，变成在剪辑台内直接生成草稿与试镜头，省掉来回导出，官方定位是打通从创意构思、素材生成到精细剪辑的完整链路。可被 Agent 调用：API + MCP + CLI 意味着生成能嵌进既有自动化流水线、由智能体按指令触发，不必人工开网页点按钮——与本期托管 Harness 正好构成上下游。分工清楚：Flash 管快速迭代与高频创作，多关键帧、长镜头控制与高规格成片仍归完整版，本次未改变 Kling 4.0 的能力上限。需要保留的判断：本次未公布 API 定价与各插件版本的确切可用范围；部分聚合站流传的 4K@30fps / 8K@24fps / 23ms 每帧 / 13GB 显存 / 每月 5 万次免费调用等参数与可灵官方文档口径不一致，不作为事实引用，排产前以官方页为准。

6 Runway 公开 57B 实时视频推理系统：8 → 4 张 H100 跑通 24fps 对话式数字角色 🎬 实时生成 / 算力
11 月 5–6 日，Runway 发布技术论文，首次详细披露实时视频对话产品 Runway Characters 背后的推理系统：一款约 57B 参数的自回归视频扩散 Transformer，能把一张静态图变成可实时交流的 AI 虚拟角色（真实人像、卡通或虚构角色均可），输出 704×1088 / 24fps，根据对话内容实时生成面部表情、嘴唇动作与头部运动。单会话需约 2.24 PFLOP/s 有效算力，超过单张 H100 的密集 FP8 理论峰值。团队通过缓存管理、计算流程与 GPU 间通信优化，在 4 张 H100 上把单步耗时从 240.9ms 降到 159.3ms（提速 1.51×，持续 24.5fps），再引入计算与通信融合降到 147.4ms（整体 1.63×），把单会话所需 H100 从 8 张砍到 4 张。实时视频不能靠批处理摊薄：与语言模型不同，每位用户需要独立的实时生成服务，增加第二个会话几乎让计算耗时翻倍，因此优化必须落在单会话内部。166.7ms 是硬门槛：24fps 要求每 166.7ms 产出一组四帧且整个对话持续维持，147.4ms 是压进这条线里的工程结果，缓存管理是其中关键改进。门槛砍半决定能不能排期：8 → 4 张 H100 直接决定数字人 / 虚拟主播能否从演示走进可预算的直播与互动投放。边界：论文为厂商自述，未披露商用定价与多会话并发的真实成本；704×1088 仍非广播级分辨率，长时间一致性未给出量化结果。

7 腾讯混元 Hy4 上线 WorkBuddy 后调用激增，推理集群紧急扩容十倍，Hy3 限免延至 11-15 📐 模型落地 / 真实用量
11 月 6 日，腾讯披露混元 Hy4 于 11 月 4 日在 WorkBuddy 首发接入后调用量激增，上线首日即有大量用户触及额度；团队已将 Hy4 推理集群紧急扩容十倍并提高免费体验额度，但受高端算力总量与高峰并发所限，个别时段仍可能限额。官方建议非紧急需求切换 Hy3 或错峰到晚间使用，Hy3 在 WorkBuddy 的限免延长至 11 月 15 日 23:59。同期 Arena Agent Arena 榜单显示 Hy4 登顶中国模型第一。与 11-04 期要区分：11-04 期报的是 Hy4 正式版发布（770B、首次引入视觉与电脑操作、进游戏引擎）；今天这条是发布后的运营侧事件——接入 WorkBuddy 后的调用洪峰与集群扩容，不是模型重复报道。从发布到被用的实测：11-05 期还在讲 Uber 3.2 亿订单只有 4 单来自 AI 智能体，一天之后国内办公 / Agent 场景就出现首日触及额度、集群扩容十倍——消费端冷现实与企业生产力场景的真实调用量并不在同一条曲线上。容量不等于无限：官方明确高端算力总量与高峰并发仍有限额，并给出降档到 Hy3、错峰到晚间的具体建议，等于把容量约束写进产品公告。成本口径同步变化：腾讯云积分抵扣文档显示，Hy4 preview 套餐内档在 11 月 4 日 00:30 由 66 积分（3.3 元）调到 105 积分（5.25 元），同一模型隔一天套餐内贵近四成，批量任务需按新价重算。

8 能生成 ≠ 能交付：Anthropic 与美联社签首份新闻内容授权；Google PLE 实测 91% 单项正确率只换来 41.3% 可行设计 📐 内容授权 / 落地边界
11 月 5 日两条信号同时落地。其一，Anthropic 与美联社（AP）达成首份新闻内容授权协议，这是该公司在与音乐出版商、书籍作者的版权诉讼之外，第一次与新闻机构建立正式内容授权关系。其二，Google 与 Mercor 联合发布 PLE 测试，量化工程 Agent 的正确率泡沫：共同创作任务中平均满足 91% 的单项约束，但满足全部硬性安全与可行性要求的设计项仅 41.3%；Claude Opus 5.5 在 56 项隐藏测试中仅得 48.3%。研究指出复杂工程里约束彼此耦合，解决一个问题常常导致另一个问题失败。两条指向同一件事：素材能不能用（授权链）与方案能不能落地（全部硬约束同时满足），才是能生成之后真正的门槛。91% 到 41.3% 的落差：单点评测会系统性高估 Agent 在真实项目里的可用度；营销物料的审校不能只看每条要求都过了，要看整份成品是否同时过合规、品牌、法务与版位。授权正在变成基础设施：Anthropic 从被诉方转向付费授权方，说明训练 / 检索内容的来源可追溯性正成为模型厂商的固定合规成本项，与 11-02 期四巨头统一 robots.txt 退出信号是同一条主线。边界：PLE 为 Google / Mercor 自评基准，隐藏测试集未公开；AP 协议的金额、范围与期限均未披露，不宜按全面和解解读。

八条其实在讲同一个动作：交付物从参数表变成了能跑起来的东西。前三名分别是开源基座、下周开权重的模型、把 Harness 做成云服务的厂商，第七条则是被真实调用量压着扩容十倍——模型侧第一次集体不再比谁更大，而是比谁能被拿去用。

① 上半场交的是环境，不是分数。百度把 280B 容量、14B 激活与 1M 上下文一起放进可私有化部署的国产底座；Thinking Machines 更直接，先上 Tinker 试用、承诺下周完成外部红队后以 Apache 2.0 开全量权重，还演示了 4.5 小时 / 426 美元自主训练一个小模型；月之暗面把上下文管理、工具调用、权限控制与中断恢复打包成 7×24 托管服务。共同点是：拿到手就能接进流水线，而不是先读一遍论文。

② 中间三条把生成工具推进了剪辑台。Omni 1.2 Flash 把时长拉到 15 秒、价格降 30%，并用多轮对话式改片把「重生成」的账单换成「重编辑」的账单，还首次把包装字体与品牌色跨帧锁定写进官方能力；可灵 Flash 钻进 Photoshop / Premiere / After Effects 插件，试镜头不再来回导出；Runway 用缓存与通信融合把实时数字人从 8 张 H100 压到 4 张、跑通 24fps。这三条都在回答同一个问题：能不能少重跑一次。

③ 最后两条给这份乐观标了刻度。Hy4 扩容十倍说明企业生产力场景的真实调用量与昨天 Uber 3.2 亿订单只有 4 单的消费端冷现实并不在同一条曲线上；而 PLE 测试的 91% → 41.3%，加上 Anthropic 与美联社那份新闻内容授权协议，提醒我们能生成和能上线之间还隔着授权链、品牌规范、法务与版位同时满足的整体验收。单点跑分不再是可用度证明。

今天最高分给到 #1 百度 ERNIE 5.5 Flash Base（9.3 / P0）：分量不在跑分，而在把超大容量、每 token 只算 14B 与 1M 上下文同时做成一个可私有化部署的国产底座。对宣发团队而言，这条和 #4 恰好构成一组必须同时做的动作——一边用对话式改片把产能拉满，一边把授权链与整份终审补齐。

四条可以立刻执行的线索：① 用 Gemini Omni 1.2 Flash 开一条同素材对话式出多版位试点（重点验品牌色与字体跨帧是否稳，复杂动作镜头仍人工终审）；② 在 Premiere 里试一次可灵插件的镜头草稿（先确认插件版本与 API 定价再排产，不采信聚合站流传的规格）；③ 批量生成排期错峰到晚间（WorkBuddy 扩容后高峰仍可能限额，按 11-04 调整后的积分单价重算预算）；④ 给 AI 素材补一份整份终审清单（授权链 + 品牌规范 + 法务 + 版位同时满足）。
