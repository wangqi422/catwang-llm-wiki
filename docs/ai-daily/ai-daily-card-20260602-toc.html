i. AI Model & Agent 3 items

AI 模型 & Agent

Anthropic 上市竞速 + Qwen Agent 化 + MiniMax M3 开源三合一

1 Anthropic 递交保密 IPO 申报，抢先 OpenAI 上市 #Anthropic #IPO
Anthropic 已向美国 SEC 递交保密上市申请，在 IPO 进程上抢先竞品 OpenAI。刚完成 650 亿美元融资，投后估值升至 9650 亿美元超越 OpenAI。年化营收突破 470 亿美元（4 月仅 300 亿），Claude 代码编程模型成企业端增长引擎，与 OpenAI 上演资本竞速。9.5/10
2 Qwen3.7-Plus 多模态 Agent 模型发布 #Qwen #Agent
阿里千问发布 Qwen3.7-Plus，统一视觉语言能力并具备完整 Agent 能力。支持 GUI/CLI 双界面操作，可通过阿里云百炼 API 调用，在千问 Studio 中体验。国产多模态 Agent 能力追平海外前沿，补齐与海外模型的差距。9.2/10
3 MiniMax M3 正式发布：MSA 架构 + 1M 上下文 + 超越 GPT-5.5 #MiniMax #开源
稀宇科技发布 MiniMax M3，采用自研 MSA 稀疏注意力架构，1M 上下文下每 token 计算量仅为前代 1/20。SWE-Bench Pro 59.0% 超越 GPT-5.5 和 Gemini 3.1 Pro，国内首个三合一模型（1M 上下文+原生多模态+顶级编程），10 天内开源权重。9.0/10
ii. Industry & Infrastructure 3 items

行业 & 基础设施

微信 AI 入口革命 + Claude 稳定性修复 + NVIDIA 进军 PC 芯片

4 腾讯微信 AI 助手即将上线，右滑呼出 #腾讯 #微信AI
腾讯即将在微信内嵌入 AI 助手，用户在主界面右滑呼出聊天窗口，零学习成本触达 13 亿用户。不只是聊天，可在微信内协助完成任务（订餐、打车、支付等），AI Agent 首次深入超级 App，重新定义移动端 AI 交互。8.8/10
5 Claude 修复 Opus 4.8 并行调用异常，重置 Pro/Max 限额 #Claude #修复
Claude 官方为所有 Pro 和 Max 计划用户重置 5 小时及周限额，修复了 Opus 4.8 的并行请求处理异常导致额度被过快消耗的缺陷。Opus 4.8 动态工作流上线后负载激增暴露稳定性问题，此次修复提升整体使用体验。8.5/10
6 NVIDIA RTX Spark 进军 PC 芯片，3nm 工艺联合联发科 #NVIDIA #AI PC
英伟达发布面向 PC 的 RTX Spark 超级芯片，3nm 工艺联合联发科打造，适配 Arm 架构 Windows。戴尔、联想、华硕 2026 秋季搭载，PC 行业 40 年最大底层变革。市场震动：英伟达 +6.25%，英特尔 -4.67%，高通 -8.78%。8.3/10

趋势 & 工具

通用数字工作者 Agent + 编程专精 MoE 模型

7 Perplexity Computer 发布通用数字工作者 Agent #Perplexity #Agent
Perplexity 发布 Computer——通用数字工作者 Agent，用户描述目标后自动部署子 Agent 浏览、研究、创建并连接工具。连接 Gmail/Slack/Notion/Calendar 等数百个应用，可运行数小时甚至数月，从聊天机器人进化为真正的数字员工。8.0/10
8 JetBrains 发布 12B MoE 架构模型 Mellum 2 #JetBrains #编程模型
JetBrains 发布 12B 参数 MoE 架构编程模型 Mellum 2，仅激活部分专家推理效率高。深度集成 IntelliJ/PyCharm 等 JetBrains IDE，针对代码补全、重构、调试场景优化，IDE 内代码辅助体验大幅提升。7.8/10
