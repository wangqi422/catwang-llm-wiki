i. Models & Agents 4 items
🧠 模型 & Agent
Wan3.0 文档直出 30 秒视频，DeepSeek V4-Flash-Vision 补齐视觉，GLM-5.3 编程开源第一，MiniMax H3 GB200 提速 27.7 倍
1 阿里 Wan3.0 视频生成大模型正式上线：30秒视频+文档输入+专业运镜 🎬 视频生成
阿里巴巴视频生成大模型 Wan3.0 正式上线，是国内首个支持 30 秒单次生成的视频大模型，同时首次支持 doc/xls/ppt/pdf/md 等文档格式输入——角色、道具、声音、空间关系、风格等维度可保持一致性，最多 20 份参考素材，支持推拉摇移跟等专业运镜。API 定价 480P/720P/1080P 每秒 0.3/0.6/1.2 元，限时 7 折期 8 月 24 日至 9 月 23 日。公测期间已进入企业生产流程，应用于短剧、广告、文旅传播等场景——"剧本→成片"链条被压到最少，对宣发团队是"一稿多版"生产力的数量级提升。
2 DeepSeek 发布 V4-Flash-Vision 多模态视觉模型：补齐视觉短板，1000图<20美分 👁️ 多模态
DeepSeek 上线实验性多模态视觉模型 V4-Flash-Vision-Exp，多模态 Agent 能力逼近 Opus-4.8——1000 张图片分析成本不到 20 美分，约为 Claude Opus 的 1/80。同步上线 Files API 支持图片/文件跨会话复用，把视觉理解从「一次性调用」升级为「可持续 Agent 资产」。视觉补齐后 DeepSeek 形成「文本+视觉+Files 持久化」全模态闭环，Agent 场景成本与可组合性显著提升，1/80 成本打开视觉 Agent 普惠。
3 智谱 GLM-5.3 编程专模发布：漏洞识别 84.5% 超 GPT-5.6，两周后开源 🛡️ 编程
智谱发布 GLM-5.3 编程专模：编程能力较前代提升 50%，在 Terminal Bench 3.0 取得开源模型第一，性能接近 Claude Fable 5。CyberGym 漏洞识别率 84.5%（超 GPT-5.6 Sol 的 83.3%），DeepSWE v1.1 拿到 66.9。模型权重两周后开源，同步上线 ZCode、AutoClaw 配套工具；荣耀 YOYO Claw 虾虾大脑宣布率先接入。「基座 + 后训练放大 + 垂直场景」路径在编程/安全场景验证可行，国产模型在企业级代码审计上具备替换潜力。
4 MiniMax H3 生态集成索引发布：GB200 上推理提速 27.7 倍 ⚡ 推理加速
MiniMax 发布 Awesome MiniMax H3 Integrations 生态集成索引，覆盖 24GB VRAM 本地 ComfyUI 部署到企业级 SGLang 与 vLLM-Omni。NVIDIA SANA 团队的 Sol Engine 把 H3 视频生成延迟大幅压缩——单块 GB200 上 10s/768p 视频从 414s 降至 14.93s（27.7 倍加速），5s 视频达 22.2 倍加速。H3 已上线 5 天日均处理 8 万亿 token，是中国模型出海 OpenRouter 调用量第一。「模型 + 部署工具链」成为新范式，视频生成从批处理进入交互式生产。
ii. Industry & Infrastructure 2 items
🏭 行业 & 基础设施
DeepSeek 启动 IPO 拟科创板 710 亿美元估值，微软 Aion 智能体 OS 曝光无开始菜单的 AI 原生系统
1 DeepSeek 启动 IPO 筹备，拟科创板上市：估值 710 亿美元 💰 IPO
DeepSeek 启动 IPO 筹备，计划于年内向科创板递交上市申请，预计 2027 年正式挂牌。新一轮融资投前估值约 710 亿美元（约合 5000 亿元人民币），首轮募资据报突破 500 亿元。投资方名单涵盖腾讯、宁德时代、京东、网易以及国家人工智能产业基金。四个月内估值从约 100 亿美元上涨至 5000 亿元（约 5 倍跳涨），已被视为「基础设施级」资产——DeepSeek API 价格策略与开放程度可能受 IPO 节奏影响。
2 微软 Aion 智能体系统曝光：Copilot 为核心，无开始菜单的 AI 原生 OS 🤖 智能体OS
微软 Project Aion（内部名 CopilotOS）曝光，定位为面向企业、没有开始菜单的 AI 原生系统，可在运行 AOSP、Win3 甚至 Windows 11 的 AI 专用设备上运行。系统基于 Microsoft Edge 浏览器和 Web3 轻量化 Windows 代码库构建，无传统开始菜单/桌面图标/任务栏应用——一切基于 AI 交互。点击 Copilot 按钮后看到 3 张卡片（"Stay on Top"/"Create something new"/"News of the day"）；任务栏图标由对话内容动态生成（示例中「鸡尾酒杯」代表毛伊岛餐饮对话），Figma/VS Code 等企业级应用被捆绑进 AI OS 入口。
iii. Trends & Tools 2 items
📈 趋势 & 工具
OpenAI GPT-5.6 降价 20-33% 美头部进入价格战，Claude Code v2.1.243 团队级 FinOps + 无密钥登录
1 OpenAI 下调 GPT-5.6 Sol API 价格超 20%：输入 $4/输出 $20 持续至 11月 💸 降价
OpenAI 自 8 月 21 日起将面向开发者的 GPT-5.6 Sol 基准价格下调逾 20%：输入价格下调 20%，输出价格下调 33%。新价格为每百万输入 token 4 美元、输出 20 美元，该优惠至少持续至 11 月 21 日。同期，谷歌同步下调 Gemini 3.7 Flash 定价约一半——美头部 AI 模型 8 月密集降价，「模型稀缺溢价」窗口正式关闭。市场解读为 OpenAI 在 Anthropic IPO 关键期用价格战对冲对手的「高端叙事」。
2 Claude Code v2.1.243 发布：/usage 循环统计、模型选择器与无密钥登录 🛠️ 开发工具
Claude Code v2.1.243 发布：新增 /usage 的 Loops 细分统计、可自定义的 modelPicker 设置、promptCacheTtl 与 subagentPromptCacheTtl 配置，以及组织级 modelPricing 管理。同步支持无密钥登录流程（不再强制每次配置 API key），并对 subagent 行为做了稳定性修复。团队级 FinOps + 无密钥登录 + 模型选择解耦，是 AI 编程工具向「企业级基础设施」演进的标志性版本。

编辑手记

今天是 AIGC 日报第 32 期，AI HOT 聚合 100+ 条近 30h 动态，信息密度极高。主线非常清晰：「中国 AI 三线齐发：Wan3.0 视频 + DeepSeek 多模态 + GLM-5.3 编程 + DeepSeek IPO」vs「海外头部降价与新 OS：Aion + GPT-5.6 降价 + Claude Code」。今天的八条，正是这两条线的浓缩。

最值得宣发团队关注的是 #1 阿里 Wan3.0。文档直出 30 秒视频 + 20 份参考素材一致性 + 专业运镜内建，是当下可直接落地的提效路径——脚本/PDF 直接喂 Wan3.0 出 30 秒成片，把"剧本→成片"中间环节压到最少。限时 7 折期至 9 月 23 日，建议在 39.x 素材产线做试点。配合 #4 MiniMax H3 GB200 上 27.7 倍提速（10s 视频从 414s 降至 14.93s），KV/动效素材的生产成本与周期都结构性下降。

行业级信号是 #5 DeepSeek IPO。710 亿美元估值、5 倍跳涨、腾讯/京东/宁德/网易/国家 AI 产业基金全谱系背书——中国大模型进入"估值兑现"窗口。叠加 #2 V4-Flash-Vision 视觉补齐（1/80 Opus 成本）与 #3 GLM-5.3 编程开源第一，DeepSeek + 智谱 + 阿里构成中国 AI 的「模型 + 多模态 + 编程 + 视频」全栈矩阵。

海外侧的范式重写在 #6 微软 Aion。"无开始菜单的 OS"是 30 年前提的彻底打破——任务栏图标由对话内容动态生成，OS 变成"对话 + 卡片 + 空间"。Figma/VS Code 被捆绑进 AI OS 入口，长期看设计/开发协作工具的"系统级可达性"会重排。#7 GPT-5.6 降价 20-33% 则标志"模型稀缺溢价"窗口关闭，AI 公司估值锚点向性价比漂移。

落到宣发工作，本期六条可执行线索：① Wan3.0 30秒视频+文档输入，直接喂脚本出成片（39.x 素材产线试点）；② DeepSeek V4-Flash-Vision 视觉 1/80 Opus 成本，视觉 Agent 化工作流可低成本接入；③ GLM-5.3 编程专模作为本地化代码审计备选；④ H3 GB200 27.7 倍提速，单条 10s 视频进入交互式迭代；⑤ GPT-5.6 Sol 降价 20-33%，长输出场景成本可重算；⑥ Claude Code v2.1.243 团队级 FinOps 与无密钥登录，工具在企业 IT 接入阻力下降。
