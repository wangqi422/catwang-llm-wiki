2 英伟达拟至少 5 亿美元收购扩散模型公司 Inception：Mercury 3 每秒 1068 token，补 Nemotron 与机器人物理 AI 🧩 并购 / 扩散模型 / 物理 AI / P0
The Information 援引三位知情人士报道，英伟达正接近以至少 5 亿美元收购成立仅两年的扩散式大语言模型公司 Inception，交易含 30 多名员工的业绩激励，条款仍可能变动。公司由斯坦福、UCLA、康奈尔三位教授创办，核心路线是扩散式文本生成——不像 GPT/Claude 逐 token 输出，而是从噪声草稿起步、多轮并行去噪精炼整段回答。旗舰 Mercury 3（10 月发布）自称在英伟达 GPU 上达 每秒 1068 token、首字延迟低于 300ms、吞吐较传统模型高 5–7 倍、单任务成本最高降 70%，上下文扩至 100 万 token（均为公司自测、未经第三方验证）。收购意图明确：把扩散技术并入开源 Nemotron 家族（已被 Palantir、美国多机构用作中国模型替代），并延伸到机器人等物理 AI。谈判在黄仁勋 11/12 辞任 CEO 前已启动，微软此前也表达过兴趣。查重：Mercury 2.5 产品（9-09）、微软 10 亿洽购（5-14）已报，今日为英伟达正式进入后期谈判、三创始人加盟的新阶段。

彭博与路透 11 月 20–21 日报道，AI 编码智能体公司 Cognition 正洽谈按 750 亿美元估值融资，拟募资 20 亿美元以上。这家以「能直接替代工程师写代码」的 Agent 闻名的公司，估值曲线极陡：今年 5 月约 260 亿，约两个月前（9 月）以 480 亿完成 20 亿 E 轮，如今再抬至 750 亿——半年接近三倍、两个月近乎翻倍；公司此前披露年化收入已突破 10 亿美元。在二级市场连续杀跌 AI 股的同一周，一级市场反而给「能干活」的软件开出更高报价，资金正从「买算力」向「买能交付的软件」迁移。查重：480 亿融资（9-09）、SWE-2 Flash 产品（11-05/06）已报，今日为估值上修至 750 亿、拟募 20 亿+的新一轮融资阶段。

Claude 破 3SUM/APSP 数十年上限、Signal 屏蔽截图挡 AI 读屏、Together AI 提示词泄露 —— 能力与防线同步升级
4 Columbia 与 MIT 论文：Claude 发现的算法将 3SUM 压到 O(n^1.9992)、APSP 压到 O(n^2.9995)，推翻两项长期算法假设，并用 Lean 4 形式化验证 🧮 AI 数学 / 算法突破 / P0
Columbia 与 MIT 研究者发表论文，展示由 Claude 发现的算法在两项经典算法难题上取得多项式改进：3SUM 问题达 O(n^1.9992)、全对最短路径（APSP）达 O(n^2.9995)，双双突破长期被认为难以逾越的复杂度上限，等于推翻了沿用数十年的 3SUM 与 APSP 假设。更关键的是，团队用 Lean 4 对新算法做了形式化验证，正确性可被机器逐步核验。这与昨日「Claude 参与黎曼猜想证明」呼应但主题不同：黎曼是数论千禧年难题、仍待学界核验；本次是算法复杂度的具体改进、已形式化落地，是可验证、可复现的工程成果。算法突破有实际价值——3SUM/APSP 是计算几何、图分析的基础原语，复杂度下降理论上会传导到依赖它们的工程系统。查重：黎曼证明（11-21）已报，本条为算法复杂度独立论文，全新事件。

5 Signal 移动端默认屏蔽截图：iOS 27 与 Android 版阻止 Siri、Gemini 等系统级 AI 读取聊天，称屏幕读取是「生存级隐私威胁」 🔒 隐私 / 智能体对抗 / P1
加密通讯应用 Signal 在 iOS 27 与 Android 版中默认屏蔽截图：一旦检测到截屏尝试即拦截，目的是阻止 Siri、Gemini 等操作系统级 AI 智能体通过屏幕读取聊天内容。Signal 将「智能体屏幕读取」定性为对隐私的生存级威胁（existential privacy threat）——当 AI 能代替用户看屏、读消息，端到端加密保护的「传输安全」就形同虚设，因为数据在被读取那一刻已泄露。该动向在 AI HOT 热度榜获关注（+1183 热度），是「AI 无孔不入」后，应用侧以产品手段正面设防的标志性动作。攻防焦点从传输管道转到「屏幕」，这是智能体普及后全新的攻击面；Signal 默认开启而非可选开关，把隐私从「用户责任」拉回「产品责任」，对同行有示范压力。业界趋势一致：让 AI 通过合规接口取数据，而非靠屏幕抓取。查重：该主题归档零命中，为全新事件。

6 Together AI 通报 serverless 提示词泄露事件：AI 编码 agent 把私有凭证提交到公开 GitHub，6–7 月多家模型提示词样本被下载 ⚠️ 安全 / 供应链 / P1
Together AI 发布安全事件通报：因一个 AI 编码 agent 把私有 Hugging Face 仓库凭证提交到了公开 GitHub 仓库 xorl，未授权方据此下载了 2026 年 6–7 月提交给 MiniMax M3、GLM-5.2、Kimi K2.6 等 serverless 推理服务的存储提示词样本，并在其中搜索其他服务凭证。官方披露了泄露范围、成因与已落实的整改，建议用户评估自身是否受影响、以及是否开启 ZDR（零数据保留）。这是又一起「AI 编码 agent 因凭证管理不当导致供应链数据外泄」的真实案例——能自动写代码、提交仓库的 agent，一旦凭证管理失当，会「规模化」地犯错，破坏力远超人工误操作；泄露的不只是数据，还有提示词样本——对依赖专有 prompt 的工作流等同于核心方法外泄。查重：该主题归档零命中，为全新事件。

7 研究者在 AI 服务链埋入 200 万个金丝雀链接：「零数据保留」承诺也照漏不误 🕵️ 隐私研究 / 供应链 / P1
研究者在经过 OpenRouter 等 AI 路由的请求中埋入约 200 万个金丝雀链接（canary links），用来追踪敏感信息是否会沿 AI 服务链外泄。结果显示，这些数据「像筛子一样」大量外泄——即便服务方承诺「零数据保留（zero data retention）」，敏感内容仍会在多个环节被记录、转发或缓存。报道给出具体泄露路径与 OpenRouter 的回应细节，为「AI 供应链到底安不安全」提供可测量的实证，而非停留在厂商承诺层面。厂商政策承诺与实际数据流向之间存在落差，金丝雀方法让这种落差变得可观测、可量化；请求经过多个中间路由与服务商，每一跳都可能留存数据，「链条长度」本身就是风险。与 #6 Together AI 泄露构成同一主题簇：一个是已知事故，一个是系统性测量，共同指向 AI 供应链隐私亟需第三方验证。查重：该主题归档零命中，为全新事件。

8 browser-use 1.0 发布：单一 Python REPL 替代 24 个浏览器动作，原生 CDP 驱动并给出同基准分数与成本对比 🛠️ 开源工具 / AI agent / P1
Browser Use 发布 browser-use 1.0，用单一的 Python 持久 REPL（交互式解释器）加上原生 Chrome DevTools Protocol (CDP) 访问，替代了 0.x 版本的 24 个独立浏览器动作。官方用同一基准的分数与成本对比，说明把大量离散工具收敛成一个可编程 REPL 的取舍与适用边界。这一思路与近期 agent 工具链「从多工具调用走向少而强的执行原语」的趋势一致，项目也进入 GitHub Trending 榜单。工具收敛 = 更少的幻觉面：动作越少、越接近通用编程原语，agent 需要「猜」的工具选择就越少，稳定性和可控性更高；原生 CDP 绕过层层封装直接驱动浏览器，延迟更低、能力更完整，适合复杂网页交互自动化。查重：该主题归档零命中，为全新事件。

编辑点评

今天这 8 条摆在一起，主线只有一句：资本抢团队，AI 破数学，隐私筑高墙。

① 资本三笔（#1–#3）。亚马逊约 75 亿收 Decart、英伟达至少 5 亿收 Inception、Cognition 估值冲 750 亿——三笔同台，买的不是当下营收，而是「跨芯片迁移」「扩散生成」「能写代码的 Agent」这些下一代架构与能干的团队。二级市场在杀 AI 股，一级市场却在给「能交付的软件」加价，钱正在从「买算力」转向「买干活的人和产品」。

② 数学与边界（#4–#6）。Claude 发现的算法把 3SUM/APSP 的数十年复杂度上限往前推了一步（#4），并用 Lean 4 形式化验证——AI 已从「解已知题」迈向「产出人类未得结果」；与此同时 Signal 默认屏蔽截图挡 AI 读屏（#5）、Together AI 因 agent 误提交凭证泄露提示词（#6），能力与防线在同一天升级。

③ 隐私与工具（#7–#8）。200 万金丝雀戳破「零数据保留」神话（#7），提醒我们厂商承诺须经第三方验证；browser-use 1.0 用单一 Python REPL 收敛 24 个动作（#8），则是 agent 工具链「少而强」的提效样本。

今天最该拎出来的不是某笔天价并购的爆点，而是两个方法论：一是「宣称」和「验证」必须分开写——AI 时代最稀缺的不是结论，是可核查的过程，这点在 #4 的 Lean 形式化里体现得最纯粹；二是「可验证的边界」正在成为刚需——从 Signal 的门闩到金丝雀的实测，给无孔不入的智能体装上可审计的护栏，和给它更强的能力一样重要。

一句话：资本用三笔天价买卖抢团队抢架构，AI 破数学上限，隐私侧被迫筑墙

今天最高分给到 #1 亚马逊 75 亿收 Decart（9.4 / P0）：一家被 Anthropic 尽调后放弃、被英伟达拒绝的公司，最终被亚马逊以近乎翻倍的价格收入囊中——买的正是「削弱英伟达软件锁定 + 补齐 Trainium 生态」的战略能力，是这轮「抢架构」并购潮最清晰的一笔。

五条可执行线索：① 浏览器自动化 agent（browser-use）做竞品官网/活动页定期快照、社媒数据巡检，先用非敏感页面小范围试点；② 编码 Agent（Cognition 类）用于活动 H5 小工具的快速原型，缩短创意到 demo 的距离；③ 扩散生成（Mercury 类）在 12/28 API 关停前可低成本实测批量草稿图/分镜，厂商自测性能需自建基准复核；④ 权限 hygiene——检查是否有 AI 工具把含密钥/凭证的代码提交到公开仓库，给 agent 的凭证最小权限、定期轮换；⑤ 未发布物料与玩家数据默认按「可能被留存」处理，能脱敏就脱敏、能本地就本地，把数据处理链路透明度纳入工具选型。
