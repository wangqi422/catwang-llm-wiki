8

约束 = 复利

元方法论

核心主张：给会漂的系统加结构化约束，短期看像加麻烦，长期是复利发动机。

约束复利四步法：

1. 找 anchor
对齐该参照什么？
例：--cref 锚点图 / capture_type 五类
2. 强制必填
不加约束的入口在哪？
例：ingest 强制判断 / Prompt 强制版本号
3. 暴露偏离
漂移时如何被看见？
例：weekly-audit / INDEX-by-type Dataview
4. 反馈回流
修正后的能量去哪？
例：used_by 回填 / contribution_count 累计

判断公式：「如果未来这件事至少会发生 5 次，且每次的输入有 70% 的相似度，加约束。」

Source: @catwqwang · 本周 Vault 连接发现

单一变量锁定法
