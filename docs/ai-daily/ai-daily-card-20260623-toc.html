🤖 前沿模型 & API
今日最重磅的模型发布与 API 变革
1 Gemini 3.5 Pro 进入 GA 窗口：2M 上下文 + Deep Think 推理模式 🔥 9.4
Google Gemini 3.5 Pro 已进入 GA 窗口（6/23-30），搭载 200 万 token 原生上下文（生产级前沿模型最大），Deep Think 推理模式 gated 在 $250/月 Ultra 层。在 Fable 5 转付费、GPT-5.6 未发的空窗期切入，时机精准。
来源：Google I/O 2026 · The Decoder · Build Fast with AI
2 OpenAI 收购 Astral：uv + ruff 并入 Codex AI 编程工具链 🔥 9.2
OpenAI 收购 Astral——uv（Python 包管理器）和 ruff（linter/formatter）背后的公司。两个工具已成为 Python 生态事实标准。收购使 OpenAI 直接控制 Codex Agent 的工具层，从模型到包管理到代码质量全栈优化。
来源：OpenAI 官方 · The Decoder
3 Google Interactions API 默认化：Gemini 转型 Agent 原生平台 🔥 9.0
Google 将 Interactions API 提升为 Gemini 默认接口，淘汰 generateContent。新 API 带 Managed Agents（Linux 沙箱）、后台长任务、多工具链式调用。标志 LLM API 从"单请求-响应"向 Agent 原生范式转变。
来源：Google DeepMind · The Decoder · 微博
4 Fable 5 转为按量付费：$10/M input tokens，订阅制断裂 ⚠️ 8.8
Claude Fable 5 不再包含在订阅中，需单独购买额度。API 定价 $10/M input、$50/M output——是 Opus 4.8 的两倍。13 天免费窗口因出口管制缩水至 4-5 天，Anthropic 未承诺补偿。
来源：Anthropic · Build Fast with AI

5 OpenAI Patch the Planet：GPT-5.5-Cyber 扫描开源漏洞，已发现数十个 CVE 🛡️ 8.6
OpenAI 联合 Trail of Bits 启动 Patch the Planet，用 GPT-5.5-Cyber（CyberGym 85.6%）扫描 cURL、Python、Go 等开源项目。已发现 Linux 内核 8 个指针泄漏 PoC + 24 个提权漏洞，Firefox CVE 在 Pwn2Own 前两天修复。
来源：OpenAI · letsdatascience · Trail of Bits
6 即梦音乐模型上线：国风/戏腔/粤语/国摇一网打尽 🎵 8.4
字节即梦 AI 上线音乐生成模型，支持国风、戏腔、粤语、国摇。五段式提示词框架（风格→信息→人声→乐器→节奏），6 积分/首，每日免费额度可生成十几首。即梦 Q1 月活 1352.5 万稳居赛道首位。
来源：字节跳动 · 腾讯新闻

7 Sakana AI Fugu：多小模型编排匹敌 Fable 5 + Mythos 5 🧠 8.2
东京 Sakana AI 发布 Fugu，通过编排多个小型 LLM 协同工作，在标准基准上匹配 Anthropic 顶级模型性能。动态路由子任务到专门小模型，算力成本仅一小部分。挑战"前沿能力必须万亿参数"假设。
来源：Sakana AI · The Decoder
8 Groq 6.5 亿美元融资转型 AI 算力服务商 💰 8.0
Groq 完成 6.5 亿美元融资，从芯片厂商全面转型 AI 算力服务商。同期 SpaceX 与 Reflection AI 达成数十亿美元算力合作（月付 1.5 亿美元接入 Colossus 2）。算力赛道从芯片层向全栈服务层扩展。
来源：Groq Inc. · 赛迪网 · 彭博社
