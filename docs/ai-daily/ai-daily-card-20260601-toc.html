i. AI Model & Agent 3 items

AI 模型 & Agent

NVIDIA 全栈延伸 + 国产开源新标杆 + AI 编程定价变局

1 NVIDIA GTC Taipei：Nemotron 3 Omni + Vera CPU 交付 #芯片 #Agent
黄仁勋在台北音乐中心发表 GTC Taipei 主题演讲，正式发布开源多模态模型 Nemotron 3 Omni（视频+音频+图像+文本推理），同时宣布 Vera CPU 已交付 Anthropic、OpenAI、SpaceXAI 和 OCI。还预告下半年 Grace Blackwell + Vera Rubin + "一款未公开惊喜产品"。NVIDIA 年度对台投资增至 1500 亿美元。9.5/10
2 MiniMax M3 开源：MSA 架构 + 1M 上下文 + 超越 GPT-5.5 #国产模型 #开源
MiniMax（稀宇科技）6 月 1 日正式发布新一代开源大模型 M3，首创 MSA 稀疏注意力架构，计算速度较同类开源方案提升 4 倍+，1M 上下文预填加速 9 倍、解码加速 15 倍。SWE-Bench Pro 等权威评测超越 GPT-5.5 和 Gemini 3.1 Pro。极限任务：24 小时连续运行、近 2000 次工具调用、自主复现 ICLR 论文。9.3/10
3 GitHub Copilot 切换 token 按量计费 #AI编程 #定价
6 月 1 日起 GitHub Copilot 正式从固定月费切换为 token 按量计费，AI 编程低价补贴时代终结。有从业者月费从 $29 暴涨至 $750。Copilot 现已贡献 GitHub 平台 46% 的代码——AI 生成代码从"尝鲜"变成"默认"。9.0/10
ii. Industry & Infrastructure 3 items

行业 & 基础设施

微软自研模型反击 + COMPUTEX 硬件对决 + 软银欧洲算力

4 Microsoft MAI 自研模型将驱动 GitHub Copilot #AI编程 #生态
微软将在 Build 2026（6/2-3）发布 MAI 自研 AI 模型，包括专为 GitHub Copilot 设计的编程模型。由 Mustafa Suleyman 领导的 MAI 部门开发，直接回应 Claude Code 在企业市场的抢攻。2026 年 4 月微软与 OpenAI 重签合约，解除微软训练顶级模型的限制。8.8/10
5 COMPUTEX 2026 开幕：Vera Rubin NVL72 vs AMD Helios #芯片 #算力
6/1-5 亚洲最大科技展 COMPUTEX 2026 台北举行，主题 "AI Together"。NVIDIA 展出 Vera Rubin NVL72 液冷机柜（72 GPU + 36 CPU），AMD 推出 Helios 服务器机柜正式对标。AI 供应链紧张预计持续至 2027 年底，全球内存芯片营收预计翻倍至 5950 亿美元。8.5/10
6 软银 750 亿欧元投资法国 AI 算力集群 #算力 #投资
软银集团宣布在法国投资最高 750 亿欧元 建设大型 AI 算力园区，总算力规模 5GW，有望成为欧洲最大。首期 3.1GW 计划 2031 年建成。携手施耐德电气在敦刻尔克打造 AI 基础设施与机器人制造产业中心。8.2/10
iii. Trends & Policy 2 items

趋势 & 政策

芯片出口管控收紧 + 具身智能标准落地

7 美国封堵 AI 芯片出口漏洞，中国海外子公司受限 #政策 #芯片
美国商务部 5/31 发布新指引，封堵中国公司通过海外子公司（如马来西亚）获取 NVIDIA Blackwell / AMD MI350x 的漏洞。新规要求向总部在中国的实体出口先进芯片即便在境外也需许可。漏洞存在近一年，可能有 数十万片 芯片已通过第三国流入。8.0/10
8 具身智能基准测试国标实施 + MiniMax 拟科创板上市 #标准 #IPO
6/1 起《YD/T 6770—2026 具身智能基准测试方法》正式实施，统一 AI Agent/机器人能力评估。《人形机器人全生命周期管理规范》"一机一码"同步发布。同日 MiniMax 在港交所公告拟科创板上市，M3 开源 + IPO 双线并进。7.8/10
