1 OpenAI 网络安全模型一次跑出 948 个 Linux 内核提权漏洞，API 成本约 121 万美元 🔐 安全 / Agent 流水线
11 月 4 日，OpenAI 发布安全研究报告，用一款尚未正式公布的网络安全模型驱动端到端流水线，完成 Linux 内核漏洞的「发现 → 动态验证 → 可利用性评估 → 补丁生成 → 人工复核」。10 月中旬的一次完整运行中，Scout 智能体先筛出 5034 个审计目标 / 约 280 万行代码（约占内核 7%），12 小时产出 2308 个去重候选漏洞；隔离虚拟机动态复现 1724 个（74.7%，仅 3.1% 属模型分析错误），最终生成 291 个信息泄露 PoC 与 1169 个本地提权利用程序，经变体归并统计为 948 个独立 LPE 漏洞。全流程消耗 121.34 万美元 API 额度，平均每个 LPE 约 1279 美元，利用开发阶段占 77.59 万美元。从演示变成可计量流水线：五阶段全自动化，交付物含根因分析、最小化崩溃 PoC、候选补丁与完整 exploit，直接交安全研究员复核提交；相比 7 月 GPT-5.6 Sol 的 166 个 LPE，三个月后同一加固环境多出 5 倍以上。「新利用技术」是比数量更硬的信号：智能体使用至少 10 种全新漏洞利用技术并经第三方内核漏洞专家核验，测试在启用 SMEP / SMAP / KASLR / HARDENED_USERCOPY 的防护环境完成，另在 Google kernelCTF 拿到 25 个信息泄露 PoC + 21 个 LPE（112 小时、约 32,936 美元 API）。补丁也能反查人类：部分研究生成的补丁发现人类专家既有修复方案里的缺陷；10 天内已有 61 个 LPE 上游修复、43 个拿到暂存补丁、299 个在公开讨论或报告流程。模型自主性本身在换代：移除额外技术指导层后 GPT-5.6 Cyber 表现仍优于复杂编排的 GPT-5.5 Cyber，传统多层编排 + 人工指导的漏洞研究流程可能要重做；归属 Patch the Planet / Daybreak 安全计划。需要保留的判断：数字与成本均为 OpenAI 自报受控环境结果；按赏金估算的「1890 万–6630 万美元价值」是推演不是收益；模型同样可用于攻击侧，官方提醒加快修复、及时打补丁并点名沙箱、隔离、缩小攻击面与形式化验证。

2 OpenAI 发布 ChatGPT Images 2.6：原生 GIF 动图 + 参考图复用，生图提速 50% 🎨 图像生成 / 宣发工具
11 月 4 日，OpenAI 在 ChatGPT、Codex 与 API 同步上线 Images 2.6。最直观的变化是原生 GIF：一句提示词或上传一张图即可生成循环动图，支持调速、逐帧编辑、循环分享；同时新增参考图保存（自己、宠物、常用角色存一次反复调用）与 SVG 矢量输出。官方称生图速度较前代提升约 50%，ChatGPT + Codex + API 每周产出图像已超 40 亿张（9 月披露为 30 亿张）。全订阅档位、网页/桌面/移动端全球开放，价格与 2.5 版持平。开发者侧拆成两款模型：`GPT-Image-2.6 Flare` 主打速度，quality=low 时最快约 6 秒出图并优化海报、产品图等含文字排版；`GPT-Image-2.6 Sunburst` 主打中高画质细节与多轮编辑一致性；第三方 DesignArena 称 Sunburst 登顶 Image Arena 总榜、Flare 相对上代约快 2.6×（自报需复测）。新增三个可控维度：image markup 圈选指定修改区域进 API；`complexity` 参数控制模型「动笔前规划多少」，与管精细度的 `quality` 正交；GIF 走 `output_format: "gif"`，可控 `frame_count`（2–64）与 `frame_duration_ms`（20–2000）。GIF 的做法是「精灵图拆帧」：先画一张把连续动作分格排布的大图再按序拼成循环，因此同时考验单帧质量与跨帧角色/物体一致性；官方点名场景几乎全是社媒——品牌吉祥物动画、反应梗图、角色分镜试动作、静态商品图转循环广告。实测边界要认清：第三方实测帧数与画幅不总按提示词交付（要求 16 帧 4:3 实际给 12 帧方图）、背景与手部细节逐帧漂移、伞柄/持物关系易出错；编辑接口目前不支持直接输出 GIF 与 SVG，静态 SVG 不等于分层 PSD；真人脸、商标、品牌资产进动图前要单独过合规。和昨天主线呼应：昨日空间智能「换视角最强 39.7%」的冷水，今天用「参考图锁定 + 多轮一致性」在工程层面绕开一部分三维一致性——不靠模型理解世界，靠把角色固定成可复用参考。

3 甲骨文迫于美方施压取消与腾讯 70 亿美元 AI 芯片租约，涉东南亚 10 万枚芯片 🌐 算力管制 / 地缘
11 月 4 日，《金融时报》援引知情人士报道：甲骨文（Oracle）在特朗普政府施压下，取消了与腾讯一份价值约 70 亿美元、为期五年的 AI 芯片租赁合同。该合同 10 月 1 日首度披露，内容为通过甲骨文在东南亚多个数据中心向腾讯提供最多 10 万枚先进 AI 芯片的远程算力，用于大模型训练与智能体工具研发，腾讯需预付 30% 租金，是其迄今规模最大的海外算力租约。美国官员主动接触甲骨文表达「强烈关切」后交易取消；同时广东省高级官员亦曾到访腾讯要求支持国产芯片。甲骨文、腾讯与美国政府均未发表官方声明。管制的落点从「芯片清单」移到「合同层」：美国出口管制限制先进芯片进入中国，但中企远程租用部署在海外的算力此前并未被全面禁止；这次没有新规出台，仅凭官员「表达关切」就让一份已签合同作废——合规压力被前置到交易签署之前。双向挤压：美方警惕中企经海外数据中心获取尖端算力，中方要求降低对美系芯片依赖；腾讯 2026 年 Q2 资本开支 527.84 亿元（同比 +176%、环比 +65%，单季历史新高），上半年 847.2 亿元已超 2025 全年 792 亿元，算力需求确定性被动摇。同期配套信号：英伟达被曝要求海外云客户自新合同起至少 51% 服务面向非中国客户（仍为非强制指导）；阿里、腾讯、字节大量订购 RTX Pro 5500 工作站卡，但有报道称 4 个月内仅能供货约 1%。对行业的含义：算力采购评估维度要加一条「这笔交易会不会被政治叫停」，海外租约、跨境云、第三方托管都得留备选路径；对国产算力栈（昇腾等）的适配从「可选项」变成「连续性保障」。需要保留的判断：报道基于匿名知情人士，合同取消原因、是否有替代方案、腾讯算力缺口如何补均未获官方确认，金额与芯片数量为 FT 口径。

4 世界模型扎堆乌镇：魔芯 MoWorld 2.0 昇腾原生 4D、百度 Apollo World、小米 WorldCast 🧊 世界模型 / 国产算力
11 月 4 日，2026 世界互联网大会乌镇峰会「发展新质生产力 强劲增量看 AI」论坛上，魔芯科技创始人兼 CEO 陈天润联合三家国家人工智能应用中试基地，发布基于华为昇腾原生的 4D 世界模型 MoWorld 2.0。继 7 月 1.0 后，2.0 把重力、弹力、浮力、光照、热力，以及刚体、柔体、流体、形塑体等物理要素整体融入空间建模与交互，输出可仿真、可实时渲染、可反复调用的 4D 高斯资产。同窗口还有百度发布物理 AI 世界模型 Apollo World、小米 WorldCast 3D 运镜在 REDMI K100 上线（平面照片还原为三维场景）——世界模型在同一天从论坛走进产品线。从「画面像不像」转向「动作之后世界怎么变」：MoWorld 2.0 不只对物体外观建模，也对交互关系、外力作用与环境变化实时推理；官方举例模拟「微风吹动书页、书签落地」需同时考虑风向力度、纸张柔性、书签重量、地板刚性与接触关系，生成结果可保留、可编辑、可反复调用，场景不再是一次性视频。性能与国产栈是硬指标：视频推理由 1.0 最高约 50 FPS 提升至约 70 FPS，3D/4D 高斯资产渲染 500+ FPS、手机端约 100 FPS；全程昇腾算力基座训练部署，公司测算推理成本最低可降至同等规模 GPU 方案的 30%，并压缩出约 6 亿参数端侧版本在麒麟平台跑推理；魔芯今年已完成 5 轮融资、合计 20 亿元。和 #3 形成同日对照：一边是海外算力租约被政治叫停，一边是「从底层芯片到模型架构全栈自主可控」的国产世界模型在乌镇首发——算力主权的答案不只靠买，也靠把模型压进自有硬件栈。落地场景明确写了影视与游戏：可复用场景资产支持自由运镜、物体编辑、天气切换，减少重复搭景、缩短分镜预演与概念验证周期；另有具身训练、自动驾驶长尾场景、工业数字孪生、文旅沉浸式内容等方向验证。需要保留的判断：性能、成本与「全球领先」均为发布方自述与测算，尚无第三方复测；三家基地合作仍处「分步推进应用验证、场景实施」阶段，量产与商业交付节奏未披露。

5 AI 编码并购日：OpenAI 收购 Pierre、Meta 收购 Conductor，Cat Wu 从 Anthropic 转投 OpenAI 🧩 并购 / 编码工作流
11 月 4 日，AI 编码赛道同日出现两笔收购与一次关键人事变动：OpenAI 宣布收购 Pierre Computer Company，后者打造的 Code Storage 及开源库 Trees / Diffs 已被用于 Codex 应用的文件浏览与代码差异审阅，OpenAI 计划把其能力并入 Codex、继续维护开源项目，交易待监管批准；Meta 确认收购 AI 编程初创公司 Conductor（2024 成立、今年 3 月刚完成 2200 万美元 A 轮），核心产品是把多个智能体部署到并行工作区分头处理同一项目，模型来自 Anthropic、OpenAI 等实验室，云服务将于 11 月 20 日关闭并删除云端数据。同日，Anthropic Claude Code 产品负责人 Cat Wu 宣布加入 OpenAI 负责 Core Products 产品管理。买的是工作流入口，不是模型：OpenAI 官方措辞是让 Codex 成为「团队与 AI 一起构建软件的地方，从最初的想法到最终发布」，并明确想改进 Git 工作流以适配人与编程智能体协作；Pierre 联创 Jacob Thornton 是 Bootstrap 联合作者，累计融资约 2400 万美元；批评者点出 GitHub 的核心矛盾——它最初为人类设计，而今天很多软件由 AI 编写。并行编排是另一条护城河：Conductor 让工程师把来自不同实验室的智能体放进并行工作区处理同一项目不同模块，Meta 买下的是「多智能体包工头」这层调度能力，将与 Nat Friedman、Alexandr Wang 的 MSL 体系整合。人才与产品口径同步迁移：Cat Wu 强调「打造保持用户控制的 agents」，与本期 #6 公约第六条「用户对重要事项的最终控制权」微妙呼应。对使用者的现实影响：Conductor 云服务 11 月 20 日关停并删除数据、核心功能保留到明年初，依赖第三方 Agent 编排服务的团队要立刻做数据导出与迁移；Pierre 承诺开源项目继续、Code Storage 客户可继续使用，交割前两家独立运营。需要保留的判断：两笔交易金额均未披露，Pierre 交易尚需监管批准；「并购整合」能否真把代码存储、审阅与并行协作融进 Codex / Meta 开发栈，要等后续产品动作，不宜按公告口径当作已交付能力。

6 乌镇发布《智能体发展自律公约》八条与智能体身份注册与解析平台 📜 治理 / 身份标识
11 月 4 日，乌镇峰会「智能体互信互联互操作」论坛正式发布《智能体发展自律公约》与智能体身份注册与解析平台。公约由中国信通院、腾讯、蚂蚁、阿里、抖音（火山引擎）、华为、小米、百度、奇安信、360 等 20 家单位在中国网络社会组织联合会组织下共同起草，共八条：健全信任体系、建设互联基础设施、提升互操作、提升安全防护、健全治理机制、保护用户权益、赋能千行百业、技术普惠共享。同期发布的身份注册与解析平台重点解决身份编码、跨域解析、可信互通，让不同主体的智能体可以互相发现与协作。把「户口」做成基础设施：公约第一条要求「分层次、可验证的智能体身份标识」与权限授予/控制、规则内嵌机制；第二条明确发展注册与解析、能力描述与发现、意图理解与转换、网络路由、资源调度与计量等技术标准；中央网信办数据与技术保障中心副主任薄兆一表述很直接——网络不仅要「连得通」，还要「认得出、信得过」。安全条款与本期 #1 直接对上：第四条要求前瞻性风险评估、运行监测、行为管控、异常熔断，防范越权操作、隐私泄露乃至行为失控；第六条保障用户对重要事项的最终控制权；蚂蚁集团陈亮判断「智能体的规模化上限，不在能不能干完一件事，而在能不能被托付一件事」。风险图谱已经量化：同窗口《智能体治理研究报告（2026 年）》指出幻觉从「输出错误」升级为「行动错误」，归纳三类数据泄露路径；浙江大学实测称智能体从发现漏洞到部署攻击最快 27 秒，9 款主流手机智能体存在 300 余项重点风险；业内口诀是「一码一智能体、可验证身份、最小权限、行为留痕、一键叫停」。与昨天的连续剧：11-04 期报道苹果首次把「AI 智能体可能不可预测行事」写进 10-K，今天这一条把同样要求从企业自律升级为带发起单位名单、带身份解析平台的行业基础设施，是合规主线从「披露」走向「可落地标准」的一步。需要保留的判断：公约属行业自律而非强制法规，无罚则与审计时间表，具体落实节奏与身份平台接入范围仍待观察。

7 编码模型「小而快」：Cognition SWE-2 Flash 与 Ricursive Ripple-65B 同日发布 ⚡ 开源权重 / 成本
11 月 4 日编码模型集中放量，两条路线同时指向「不必堆参数」：Cognition 发布 SWE-2 Flash（基于 Thinking Machines 的 Inkling-Small，276B 总参 / 12B 激活），在 RL 之前新增一段大规模中训练，把 Terminal-Bench 4.0 从基座 0.9% 拉到 20.0%、FrontierCode 2.0 从 3.2% 提到 24.0%，生成速度 200 token/s（旗舰 SWE-2 为 60）、价格为其 1/5，11 月 30 日前在 Devin Desktop / CLI 对 Pro、Max、Teams 用户免费。同日 Ricursive Intelligence 开源 Ripple-65B Preview：65B 稠密、Apache 2.0、12T token 预训练、1M 上下文，官方自报 Terminal-Bench 2.1 80.5、SWE-Bench Pro v2 Hard 79.1，训练成本约 3200 万美元，可在高配 MacBook Pro 本地跑。Cognition 的关键动作是「RL 之前插中训练」：先用高质量留出编码集 + token 效率曲线筛数据配方，收敛到数万亿 token 的科技文章/博客/代码混合，分三段训练、把最稀缺高价值数据放最后再进 RL——能力不是换更大模型，而是把通才做定向进修，五分之一成本拿八成能力。权重策略出现分叉：Ripple-65B 直接 Apache 2.0 全放；Cognition 反而不公开权重，理由是训练中强化了网络安全能力（ExploitBench 从 11.3% 提到 34.8%），攻击侧同样可用，改为面向可信产业伙伴与实验室的「定向分享」；同日 Kimi K3.1 Pro 也按 10-24 承诺放出 2.8T 权重（属已公告排期兑现，本期不单列）。「超过所有美国开放权重模型」是有定语的：官方表格里 GLM 5.3 Flash（41.8%）与 DeepSeek V4.1 Flash（42.3%）在 Terminal-Bench 4.0 上都高于 SWE-2 Flash 的 20.0%，中文模型在该基准仍领先一档；所有跑分均为厂商自评，评测环境、超时与验证脚本不统一，跨实验室横比只作参考。适用边界：优势在标准代码智能体任务（代码评审、功能迭代、文档维护、终端运维、CI 工单），超长仓库重构、跨项目月级工程仍低于旗舰；Ripple-65B 的完整模型卡、量化版本与工具调用协议仍待补齐。

编辑点评

八条新闻其实在讲同一个动作的两面：模型把手伸过了界，各方同时开始给边界签字。

① 伸过界这半边，密度罕见地高，而且第一次全部带上了可计量的账单。OpenAI 用五阶段流水线跑出 948 个提权漏洞、121.34 万美元 API、单个 1279 美元，还顺手发现 10 种新利用技术、61 个已上游修复——攻防不再是「人海 + 赏金」，而是一张算力发票；同一天 ChatGPT Images 2.6 把 GIF、SVG、参考图与圈选编辑压进一句话，每周 40 亿张图；编码侧则用 65B 与 276B 的小模型证明「中训练 + RL」能拿五分之一成本换八成能力。共同点是：交付物不再像演示，更像可以进流水线、可以开发票、可以排期的东西。

② 签字这半边，签得比昨天更具体。甲骨文在美方「表达关切」后取消与腾讯 70 亿美元、10 万枚芯片的海外租约——没有新规，只靠一次接触，管制就前置到了合同层；同一场乌镇峰会里，魔芯把 MoWorld 2.0 压进全国产昇腾栈、输出可自由运镜的 4D 资产，中国信通院则联合 20 家单位给智能体发「户口」：身份注册与解析平台 + 公约八条 + 最小权限 / 行为留痕 / 异常熔断；编码工作流也没闲着，OpenAI 买 Pierre、Meta 买 Conductor，把代码存储、差异审阅与并行编排一起收进平台。昨天苹果在 10-K 里写下的「管不住」，今天变成了「可验证身份 + 一键叫停」的行业清单。

③ 而最后那组数字，是给这场狂飙标了个刻度：76% 选民反对社区建数据中心、45 项公投 33 项限制，Uber 3.2 亿订单只有 4 单来自 AI 智能体，CloudOpsBench 里最强模型也只完成 60% 云运维任务。能力跑得比「被允许」快，也比「真被用」快——这既解释了为什么今天到处都在划线，也解释了为什么划线的人不是模型厂商自己。

今天最高分给到 #1 OpenAI 948 个 Linux 内核提权漏洞（9.5 / P0）：它的分量不在数字，而在第一次把「模型找洞」变成有单位成本、有交付物、有上游修复记录的可复核流水线。对宣发团队而言，这条和 #2 恰好构成一组必须同时做的动作——一边用 Images 2.6 把产能拉满，一边把依赖、沙箱、补丁节奏和权限审计补齐。

四条可以立刻执行的线索：① Images 2.6 当天开一条试点（现有角色立绘存参考图 → 3 个动作 GIF → 重点验跨帧一致性与帧数 / 画幅是否听话，真人脸与商标仍人工终审）；② 内部工具链做一次安全与依赖复盘（对齐 #1 的补丁节奏、沙箱隔离、一键叫停）；③ Agent 权限对齐公约八条清单（身份可验证 / 授权范围 / 操作留痕 / 异常熔断 / 用户最终控制权）；④ 供应商连续性检查（Conductor 11-20 关停导出数据、批量生成不锁死单一推理供应商、预算沿用单条素材成本口径）。
