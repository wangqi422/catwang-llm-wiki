1 Anthropic 递归自我改进报告：80% 合并代码由 Claude 编写 9.5
Anthropic 研究院发布《当AI建造自身》报告，首次量化披露递归自我改进数据：2026 Q2 工程师人均每天合并的代码量是 2024 年的 8 倍，其中超过 80% 由 Claude 编写。AI 可靠完成任务的时长约每 4 个月翻倍，Claude Opus 4.6 已能处理 12 小时级长程任务。报告同时警告完全递归自我改进可能增加人类失去控制权的风险。

2 Google Gemma 4 12B：革命性无编码器架构，16GB 本地运行 9.2
Google 发布 Gemma 4 12B，采用革命性无编码器（Encoder-Free）架构，完全取消传统多模态模型中的编码器组件。视觉输入仅需一次矩阵乘法即可处理，音频信号直接投射到文本 token 维度空间。16GB 显存笔记本流畅运行，Apache 2.0 开源，累计下载超 1.5 亿次。
🌐 无编码器架构
视觉仅需一次矩阵乘法+位置嵌入+归一化，计算复杂度大幅降低
💻 16GB本地运行
120亿参数可在笔记本运行，Multi-Token Prediction 加速推理
来源：aibase.com/news/28643 · #开源模型 #多模态
3 Perplexity Computer：通用数字工作者 Agent 发布 9.0
Perplexity 发布 Computer——不是聊天机器人，而是"通用数字工作者"。用户描述目标后，Computer 部署子 Agent 自动浏览、研究、创建，连接 Gmail/Slack/Notion/Calendar 等数百个 App，可运行数小时甚至数月。口号："Chat answers. Agents do tasks. Computer works."
🤖 全民Agent时代
对标 OpenClaw 但面向非技术用户，浏览器端运行，零配置上手
🔗 生态共振
同日 Anthropic 扩展 Cowork 13 个企业插件，Notion 发布 Custom Agents
来源：Perplexity Official / The New Stack · #Agent #生产力
4 ChatGPT 推出 Dreaming 记忆系统，事实准确率翻倍 8.7
OpenAI 推出 ChatGPT 记忆系统重大升级 "Dreaming" 架构：引入后台持续运行自动化流程，跨多轮对话综合提炼用户信息，主动更新记忆状态。事实记忆准确率从 41.5% 跃升至 82.8%，偏好遵循率从 31.4% 升至 71.3%，时效性准确率从 9.4% 飙升至 75.1%。
来源：OpenAI Official · #AI记忆 #ChatGPT

5 DeepSeek 700 亿融资 + Code 即将发布 8.5
DeepSeek 完成 700 亿元融资，Code 产品即将发布，ACM 竞赛金牌得主崔添翼挂帅。美国 AI Agent 初创公司 Lindy 已将 100% 流量从 Claude 切换到 DeepSeek V4，称每年节省数百万美元且性能提升。V4 参数量 1.6T，支持 1M 上下文，限时输出价格 6 元/百万 Token。

6 微信开放 A2A Agent-to-Agent 能力 8.3
微信正与华为、荣耀、小米、OPPO、vivo 合作推出 A2A（Agent-to-Agent）助手能力，用户可通过手机语音助理发起微信音视频通话或向好友发送消息。荣耀已首批接入，YOYO 智能体可直接语音发微信。这是微信首次以合作形式向手机厂商开放 Agent 调用能力。

7 英伟达 Cosmos 3 物理AI模型 + 收购 Kumo AI 8.2
英伟达在台北 GTC 大会发布 Cosmos 3 物理AI基础模型，采用全新混合 Transformer 架构，集成视觉推理、世界生成和动作预测，是全球首款完全开放的全模态物理AI模型。同日收购 Kumo AI（商业预测基础模型），联合创始人 Jure Leskovec 已加入英伟达。成立 Cosmos Coalition 全球联盟推动物理AI生态。
来源：NVIDIA GTC Taipei · #物理AI #英伟达
8 Anthropic 开源 AI 漏洞发现框架 8.0
Anthropic 在 GitHub 开源 defending-code-reference-harness 框架，实现基于 Claude 的自主漏洞发现与修复完整流水线：侦察→发现→验证→报告→补丁。提供 /threat-model、/vuln-scan、/triage、/patch 等 Claude Code 技能集，使用 Docker + ASAN 沙箱隔离。同日 Claude Code GitHub Action 爆出提示注入漏洞，安全风险与防护能力同步暴露。
来源：GitHub / Anthropic · #AI安全 #开源
