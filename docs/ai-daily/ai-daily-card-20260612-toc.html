1 OpenAI 收购 Ona：为 Codex 补齐云运行底座，Agent 进入"持久战" 9.3
OpenAI 收购初创公司 Ona（原 Gitpod GmbH），将其安全云执行和编排技术整合进 Codex 生态。Ona 专为 AI 智能体提供安全、预配置的云端沙盒环境，使 Agent 在开发者关闭工作站后仍可持续运行。Codex 周活跃用户从 4 月的 300 万增至逾500 万，增长67%。这是 OpenAI 12 个月内第三笔编程工具收购（此前收购 Astral 和 Alex Codes）。
☁️ 持久云沙盒
Agent 在客户云环境中运行，本地设备关闭任务不中断
🔒 企业级安全
哈希加密校验恶意程序、隔离敏感凭证、阻断恶意外联
🎯 战略转向
从"模型更强"转向"Agent 跑得更久、更安全"
来源：OpenAI 官方 · #收购 #AI编程
2 SpaceX 史上最大 IPO 今夜登陆纳斯达克：募资 750 亿美元 9.2
SpaceX 以代码 SPCX 登陆纳斯达克，发行价135 美元/股，募资750 亿美元，刷新全球 IPO 纪录。完全摊薄估值约1.77 万亿美元，超越特斯拉跻身美国市值第七。IPO 获超4 倍超额认购。星链是唯一盈利板块，2025 年营收 186.7 亿美元，正成为全球边缘 AI 推理骨干基础设施。
🚀 1.77万亿估值
超越特斯拉，跻身美国市值第七，史上最大 IPO
📡 星链=AI骨干网
从通信基础设施升级为全球边缘 AI 推理骨干
来源：证券时报 · #IPO #AI基建
3 Agents' Last Exam：AI 智能体"真干活"考试，最强仅通过 24% 9.0
UC Berkeley 联合 250+ 专家发布 ALE 基准，含 1490 个真实专业任务（3D 建模、游戏引擎搭建、特效合成等），覆盖 55 个行业。最强配置 Codex + GPT-5.5 整体通过率仅24%，最难档仅8.6%，多数模型得零分。GPT-5.5 意外击败 Fable 5（24% vs 22%），逆转了传统 benchmark 上 Fable 5 碾压 GPT-5.5 的格局。78% 失败来自"理解/方法"层面，瓶颈是领域知识而非代码能力。

最强 AI Agent 真实干活通过率不到四分之一
🔄 GPT-5.5逆转
传统 benchmark 上 Fable 5 碾压 GPT-5.5，真干活测试反而输

78% 失败来自领域理解，不是代码执行能力

4 Anthropic 启动 Claude Corps：1.5 亿美元派 1000 名 AI 研究员 8.7
Anthropic 投入1.5 亿美元，分三批将 1000 名早期职业人才派驻 400+ 家非营利组织，12 个月全职 AI 应用。研究员年薪8.5 万美元（Anthropic 全额承担），接收机构获 1 万美元补助 + 最高 2500 美元 Claude 额度。首批 100 人 10 月入职，申请截止 7 月 17 日。隐性门槛：接收机构必须是 Claude for Nonprofits 付费客户。
🎓 人才管道
1000 人在一年内深度绑定 Claude 生态，任期后携带技能进入市场
🔗 生态绑定
公益外衣下是产品绑定——需为 Claude 付费客户才可申请
来源：Anthropic 官方 · #社会责任 #AI人才
5 Cursor Auto-review：用分类器智能体管控 AI 编程自主性 8.5
Cursor 发布 Auto-review 运行模式，用专门的LLM 分类器子 Agent替代传统"允许/拒绝"二元权限判断，实现三层决策：白名单→沙箱→分类器。SDK 同步支持 Auto-review，可用自然语言指令校准分类器行为（如"禁止 rm -rf"）。配合自定义工具和嵌套子 Agent，Cursor SDK 从"编辑器插件"进化为"Agent 运行时"。
🎛️ 自主性旋钮
从"开关"变成"旋钮"，Agent 自主性可精细调节
📝 自然语言规则
用自然语言引导分类器，如"只读检查可放行，删除操作须暂停"
来源：Cursor 官方 · #AI编程 #安全
6 Krea 2 发布：美学优先的 AI 图像模型，创意从"提示词"转向"操控杆" 8.3
Krea AI 发布 Krea 2（K2）基础图像模型，两个变体——Medium（更快更稳定，适合插画/动漫）和Large（超 2 倍参数，适合照片级真实感）。核心创新是"生成式滑块"：最多 4 个风格参考图各自独立强度调节。Moodboard 功能可读取数十张图片的视觉语言，生成"品味档案"+ 关键词 + "避坑清单"。四档创造力参数让"创意"成为可调参数。
🎨 美学连贯性
模型做审美解读而非逐字翻译，视觉意图优先
🎚️ 生成式滑块
4 个风格参考独立强度调节，创意从写提示词变成调参数
来源：Krea AI / Magnific · #AI图像 #创作工具
§ 3 Multimodal & Agents 2 items

多模态与Agent

混合推理编排与对话式视频编辑

7 Perplexity Computer 混合推理：本地与云端模型自动分配任务 8.2
Perplexity Computer 今夏引入"混合智能体推理"模式：系统根据任务类型和数据敏感度，在本地紧凑模型和云端前沿模型间自动切换。敏感数据严格留守本地，高推理需求自动发往云端。Deep Research 已集成进 Computer，可协调20+ 前沿模型，Opus 4.6 作为主推理引擎。Search as Code 架构让 Agent 生成 Python 构建搜索管线，token 使用量降低85%。
🔀 混合路由
本地处理敏感数据，云端执行重推理，自动路由无需预选
📝 Search as Code
Agent 生成 Python 构建搜索管线，token 使用降低 85%
来源：Perplexity · #AI Agent #混合推理
8 Gemini Omni Flash 上线：视频创作从"生成一次"变"聊着改" 8.0
Google I/O 2026 发布的 Gemini Omni Flash 已上线，支持对话式视频编辑：用户可用自然语言连续修改视频，换环境、换视角、调氛围、替换局部元素，同时保持角色一致性和物理规律。支持多模态输入（文本+图片+音频+视频），可用自己的声音和形象创建数字分身。所有生成内容内嵌SynthID不可见数字水印。已向全球付费用户开放，并免费内置到 YouTube Shorts。
💬 对话式迭代
多轮对话增量修改，微调一处不需重做整段视频
🔒 SynthID水印
所有生成内容内嵌不可见数字水印，可溯源验证
来源：Google DeepMind · #AI视频 #多模态
Epilogue
今日 AI 行业的三个关键词：持久化、落地检验、生态绑定。OpenAI 收购 Ona 为 Codex 补上"持久运行"底座，Agent 从"聊一聊"正式进入"替你干活几天"的阶段；ALE 基准无情揭示 AI Agent 在真实工作中的通过率仅 24%，给"Agent 取代人类"的叙事泼了一盆冷水；Anthropic 的 Claude Corps 和 Cursor 的 Auto-review 则从不同角度回应了同一个问题——AI 能力越强，管控越重要。SpaceX 今夜以 1.77 万亿估值登陆纳斯达克，与 OpenAI 和 Anthropic 的 IPO 进程形成三巨头共振。对 CODM 宣发团队而言，今天最值得关注的两个工具：Krea 2 的 Moodboard + 风格滑块（品牌视觉统一性的工程化方案）和 Cursor Auto-review（宣发自动化工作流的安全网）。
