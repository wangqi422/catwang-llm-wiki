1 黄仁勋辞任英伟达 CEO：33 年时代落幕，CFO Colette Kress 临时接棒，市值一日蒸发 1820 亿美元 🪑 公司治理 / 算力格局 / P0
美东时间 11 月 12 日，NVIDIA 官网发布公告：联合创始人黄仁勋（Jensen Huang）即刻辞去总裁、CEO 及董事会成员职务，结束自 1993 年创立以来长达 33 年的掌舵。董事会同步公布「双轨过渡」：执行副总裁兼 CFO Colette Kress 出任临时 CEO（继续兼任 CFO），资深董事、前新思科技 CEO Harvey C. Jones 出任公司历史上首任董事会主席（打破 33 年不设主席的惯例），正式 CEO 遴选已启动、内外部候选人同时考虑。官方强调运营、客户承诺与产品路线图不中断，2027 财年 Q3 财报仍按计划于 11 月 17 日盘后发布。资本市场剧烈反应：11/12 开盘一度暴跌逾 14%（最低约 151 美元），收跌 4.34% 报 166.19 美元，市值一日蒸发约 1820 亿美元（超 1.2 万亿元人民币），自 2025 年 7 月以来首次跌破 4 万亿美元；本周累计跌 10.96%、市值蒸发约 4928 亿美元。同日 AMD 涨 5.86%、博通涨 5.54%，CoreWeave 跌近 7%；摩根士丹利、美银将其移出首选名单，富国、花旗下调目标价。真正的风险是「创始人即战略」不可复制：NVIDIA 五年售出近 1400 万颗旗舰 AI 芯片、占市场约 85%，黄仁勋本人是 CUDA 生态、对 neocloud 的财务担保、过去一年在欧洲近 100 亿美元投资等关系网的唯一枢纽。Azeem Azhar 与 Tomasz Tunguz 均指出，与 1985 年乔布斯离任不同，这次没有准备好的继任者；Tunguz 把换帅类比「央行换主席」，传导路径覆盖初创融资条件、开源生态节奏与定制芯片格局。与软件端形成同日对照：同日 Anthropic 正式向 SEC 提交 IPO 注册声明、定档 11/19 纳斯达克上市（估值目标 1.3–1.45 万亿美元），OpenAI 完成 150 亿美元融资（融前估值 1.25 万亿）、Q3 营收约 100 亿美元环比 +50% 但运营亏损 109 亿——硬件王座松动与软件公司进场定价发生在同一天。边界：辞职原因、间谍传闻与调查均为媒体 / 官方多口径拼合，NVIDIA 公告只谈「过渡」不谈原因；盘中跌幅各报道口径 13%–14% 不等，继任者未定，一切影响评估均为推演。

2 Google 发布 Gemini 4 Hydrogen 并全球全渠道推送：跑分倒挂自家旗舰，单任务成本仅 Sonnet 5.5 的 32% ⚡ 模型发布 / 性价比 / P0
北京时间 11/12 傍晚至 11/13 凌晨，Google DeepMind 正式发布 Gemini 4 Hydrogen 并即日起向全球所有用户推送，覆盖桌面 / 移动 / 网页、Gemini App、Google Search（AI Mode 默认模型）、AI Studio、Gemini API、Android Studio 与 Gemini for Business；付费 Pro / Ultra 用户可在 Antigravity 使用，免费用户无需手动选模型，提示词合适时经自动模型选择即可用上。它补齐 Gemini 4 系列的「日常快速执行」档：Carbon / Argon 负责复杂推理与长程自主，Hydrogen 主打日常编码与智能体工作流。官方数据：默认 high 档任务完成速度为 Gemini 3.8 Flash 的 2.5 倍，Terminal-Bench 4.1 从 18.2% 升至 57%，虚构信息减少超 80%，输出约 200 token/s；新增 low / medium / high / xhigh 四档思考强度。第三方评测：Artificial Analysis 智能指数默认 high 档 51 分（超过更大更贵的 Argon 50 分）、xhigh 档 54 分，仅比 Claude Sonnet 5.5(max) 与 GPT-6.1 Sol(max) 各低 1 分，但每任务成本约为 Sonnet 的 32%（xhigh $3.16 / high $1.87）；AA-Omniscience 幻觉率 8%（Sonnet 5.5 为 43%、GPT-6.1 Sol 为 52%）。Cursor 同步接入，CursorBench 4.0 默认 effort 54.3%（3.8 Flash 为 39.6%）；Agent Arena 第 5 名且为前十中最快（中位 5.3 分钟 / 任务、$1.60）。定价 $1.50/M 输入、$7.50/M 输出（思考 token 按输出计），完整 100 万 token 上下文统一计价不分阶梯，缓存输入 $0.075/M。同步向 Ultra 用户推送 Antigravity 内置 Orchestrator：Carbon 做架构规划、Hydrogen 做编码与测试，官方称配额少用 24%、耗时降 19%。「跑分倒挂 + 成本倒挂」是本次最值得注意的结构变化：一个 Flash 档位的模型在智能指数上超过自家上代旗舰 Argon，成本却只有约 19%；企业选型口径正从「跑分谁高」转向「元每任务 + 成功率」。成本压力从「塞多少上下文」挪到「吐多少输出」：输出单价是输入的 5 倍且思考 token 按输出计费，做 Agent 时优先砍冗余输出。边界：CursorBench / SWE-sweep / Agent Arena 多为第一方或单一评测口径、混合 effort 档位不完全可比；VentureBeat 指出其价格约为 Claude Haiku 5.5 / GPT-6 Luna 等低价模型最低标准价的 15 倍，「便宜」是相对旗舰而非绝对低价；OSWorld 与 Terminal-Bench 4.0 仍由 Sonnet 5.5 领先。

3 Anthropic 三连发：Claude Opus 5.5 转正当家默认，Claude Meetings 开进视频会议，Claude Tag 发布创业指南 🎙️ 办公智能体 / 默认入口 / P0
11/12–11/13，Anthropic 一天内连发三份官方内容。① 宣布 Claude Opus 5.5 成为 Pro、Max、Ultra、Team 四档套餐的默认模型，并推荐作为研究、分析、写作等知识工作的日常主力；同步给出完整模型矩阵与定价：Haiku 5.5（$0.10/$0.50）、Sonnet 5.5（$2/$10）、Opus 5.5（$4/$20）、Fable 5.2（$8/$40），全家族共享 100 万 token 上下文。官方建议：习惯「Sonnet 日常 + Opus 重度」的团队值得重新评估，更强模型用更少工作量完成任务往往抵消更高单价；效果不如预期时先调高 effort 档位再换更强模型。② 推出 Claude Meetings beta：Claude 以可见参会者身份加入团队视频通话（首发原生支持 Google Meet，后续扩展 Zoom / Teams），会中回答语音或文字提问、协作创建文档与白板等 Artifacts，会后自动汇总笔记、转录文本与行动项并沉淀在专用会话页；面向 Team / Enterprise 逐步开放，官方同步公布 beta 范围、免费期限与隐私默认设置。③ 发布 Claude Tag 创业公司使用指南，基于 Kikoff、NavigateAI、Orderful、Moritz 等 8 家高增长公司访谈，总结 on-call 分诊、Thread to PR、公司大脑、自助数据、例行报告五大场景及频道配置建议。同期还有 Claude 自托管 Managed Agents 私测、Claude for Manufacturing 插件（17 项制造技能）。从「事后总结」前移到「实时参会」是办公智能体最难的一步：会议里有上下文、潜台词与社交压力，能不抢话、被点名才精准发言，比离线纪要难得多。「默认模型」是一次静默但重量级的产品决策：不改功能、不改价格，却把绝大多数用户的主力从 Sonnet 切到 Opus 5.5，本质是 Anthropic 判断「能力溢价已经盖过单价」。与 #2 正面照面：同一天，Google 用低单价 + 全渠道抢高频任务，Anthropic 用高能力 + 默认入口抢知识工作，企业选型从「选一个最强模型」变成「按任务分层」。边界：Meetings 仍是 beta、限 Team / Enterprise、平台仅 Google Meet；官方未公布会议场景准确率、误触发率与人工满意度数据；Pro / Team 标准席位不含 Fable 5.2（按用量额度计费）。

4 李飞飞 World Labs 开放世界模型 Atlas：应用 + 全量 API，一张图生成关键帧、视频片段与 3D Gaussian splats 🌍 世界模型 / 空间智能 / P1
北京时间 11/12 傍晚，李飞飞创办的 World Labs 宣布世界模型 Atlas 向所有人开放，李飞飞本人转发官宣并表达期待。同步上线 Atlas 资源站点与两款网页应用：Viewfinder（用 Atlas 空间智能从单张图像生成可探索的世界）与 Chisel（3D 创作工作流），并开放驱动 Atlas 应用的全部 API 端点供开发者和 Agent 调用。三类空间输出共用一个入口：关键帧、视频片段、3D Gaussian splats。AI HOT 近 24h 聚合池对该事件有 5 条以上独立命中（开放公告、资源站上线、Viewfinder、Chisel、API 端点），是当天创意工具侧最集中的发布。世界模型从「演示」变成「可调用的基础设施」：过去 Atlas 类能力多以论文 / Demo 形式出现，这次直接给应用 + API + Agent 可调用端点，空间内容生成门槛下探到「一张图进、一段视频或一个 3D 场景出」。与视频生成模型是两条路线：后者生成像素序列，世界模型生成的是有空间一致性的场景表征（3D Gaussian splats），天然适合反复取景、换机位、做延展，这正是宣发物料最常遇到的「一版主视觉延展多机位」需求。与 #5 智能眼镜、同日 Figma 3D transforms open beta 连成一条链：空间内容从生成、编辑到呈现的链路正在被一次性铺齐。查重说明：归档早期条目曾出现 World Labs / 李飞飞 / Atlas 相关标签（当时为 Frameboy 等阶段性演示），今日为「向所有人开放 + 应用与全量 API 端点」的新阶段，不是重复选题。边界：官方未公布生成分辨率上限、单场景耗时、商业授权与定价细节；「向所有人开放」的区域与速率限制以资源站点为准；3D Gaussian splats 输出仍需下游引擎渲染，不等于可直接进游戏管线。

5 Google Gemini 智能眼镜开启预购：395 美元起、12 月 10 日发货，实时翻译 + 免手 Gemini 👓 可穿戴 / 硬件入口 / P1

6 Replit Agent 学会替企业花钱：Stripe Link / Visa 代购 + Google Ads 投放，逐笔审批由代码强制执行 💳 Agent 权限 / 商业闭环 / P1
11/12，Replit 给 Replit Agent 新增两项能力：① 通过 Stripe Link 与 Visa 为企业代购物资；② 在 Replit 内直接创建并投放 Google Ads，覆盖 Search、YouTube 等渠道。购物与投放都在同一对话里完成，智能体从「帮你写代码、跑任务」跨到了「拿着付款凭据替你花钱」。安全设计是本次重点：支付需逐笔审批，且审批检查由代码强制执行（而非提示词约定），官方给出完整流程与权限说明。同日的对照事件还有：美联航以网络安全与合规风险为由封禁个人 AI 智能体代客订票、OpenRouter 发布 Agent 防死循环四层防护。智能体从「帮你写」跨到「替你买」，动作边界第一次被产品化：能下单、能投广告意味着 Agent 开始持有真实付款凭据与预算，权限模型从「能看什么」升级到「能花多少」。「审批由代码强制执行」最值得抄：把权限从 prompt 约束下沉到执行层，避免越狱或幻觉直接绕过，这是所有要接内部系统的 Agent 都该照做的分层。平台 / 支付 / 工程三方同日给 Agent 画线：美联航封禁代订（平台准入）、逐笔审批（支付）、防死循环与成本上限（工程），说明 2026 下半年 Agent 的竞争焦点已从能力转向可控性。边界：代购与投放的地域、额度、企业资质门槛未完全公开；逐笔审批意味着高吞吐场景仍需人工介入，尚非全自动；与「Grok Build 分享链接漏洞致 3.7 万个应用公网可访问」同属 Agent 权限治理议题，但为不同事件。

7 Epoch AI 卫星影像测算华为和林格尔：10.5 万颗 Ascend 910C ≈ 8.1 万张 H100 等效算力 🛰️ 算力信号 / 可复核口径 / P2
11/12，Epoch AI 通过卫星影像与冷却设备模型估算：华为和林格尔数据中心已投运约 105,000 颗 Ascend 910C 与 8,000 颗 Ascend 910B 芯片，对应约 81,000 张 H100 等效算力，约为全球最大 AI 数据中心 SpaceX Colossus 2 的 7%。报告同时公开了「用公开影像量化算力规模」的方法路径，让「中美算力差距」第一次有了第三方可复核的数字口径。把差距从口号变成可复核数字：卫星影像 + 冷却负荷 + 芯片型号反推等效算力，第三方可按同一方法复核与更新，比厂商发布会口径更接近真实供给。口径从「芯片型号与出货量」换成「已投运的等效算力」：这是评估国产算力供给时更有意义的单位，也提醒团队别把「规划产能」当「可用算力」。与 #1 形成呼应：一边是 NVIDIA 治理层变动给全球算力供给带来治理折扣，一边是国产算力有了可比对口径，供应链评估需要同时看两条线。边界：数字为第三方推算而非厂商披露，误差来自冷却模型假设与芯片利用率；只能当方向信号，不能写进采购依据或对外材料，真要选型仍以厂商可核验的实测吞吐与交付周期为准。

八条其实在讲同一件事：「计价单位」正在悄悄换轨。黄仁勋离场，让市场第一次为「一个人的缺席」重新定价；Gemini 4 Hydrogen 让模型选型从跑分变成「元每任务」；OpenRouter 用 460 美元给多语言物料标了价；Epoch AI 用卫星影像给国产算力标了价。当能力足够便宜、足够铺开之后，真正稀缺的不再是「谁更聪明」，而是「谁能把权限、口径与账本先写清楚」。

① 开场是最重的一条人事，也是最重的一次重新定价（#1）。黄仁勋即刻辞去 NVIDIA 总裁、CEO 与董事职务，CFO Colette Kress 临时接棒、Harvey C. Jones 任首任董事会主席，股价收跌 4.34%、市值一日蒸发 1820 亿美元。分量不在股价，而在它让「创始人即战略」这条隐含假设第一次被公开检验——占全球 85% 旗舰 AI 芯片份额的公司把指挥棒暂时交给一位 CFO，整个 AI 行业都要为治理不确定性重新算一次账。11/17 财报是首场压力测试。

② 中间五条是「系统接管」的两组动作（#2–#6）。Gemini 4 Hydrogen 全渠道推送、跑分倒挂上代旗舰且成本仅 Sonnet 5.5 的 32%；Anthropic 让 Opus 5.5 转正当家默认、把 Claude 开进视频会议；World Labs 开放 Atlas、Gemini 智能眼镜定档 12/10 发货、Replit Agent 开始替企业代购与投广告。一边是把能力无条件铺给所有人，一边是 Agent 刚开始替企业花钱就被平台、支付与工程三方同日画线（美联航封禁代订、逐笔审批、防死循环）——放权和收口，是同一天完成的动作。

③ 收尾两条落到算账（#7–#8）。Epoch AI 用卫星影像与冷却模型估算华为和林格尔约 8.1 万张 H100 等效算力，把「差距」变成可复核数字；OpenRouter 用约 460 美元重译全站 7 种语言，并给出 Agent 防死循环四层防护。一个往上游给算力标价，一个往下游给工程兜底，都是「系统不依赖某个人」的具体样子。

一句话：一个人的退场，换来一整套系统的接管。能力越便宜、铺得越广，越要把权限、口径与账本先写清楚——今天所有大动作，都在把「靠一个人」换成「靠一套系统」。

今天最高分给到 #1 黄仁勋辞任英伟达 CEO（9.6 / P0）：分量不在股价，而在它让占全球 85% 旗舰 AI 芯片份额的公司第一次要为「一个人的缺席」重新定价，并与同日软件端进场公开定价形成钱流向的转折，是本期所有叙事的起点。

五条可以立刻执行的线索：① 把 GPU / 云渲染长期合同的签署节点推到 11/17 财报之后，并把单一硬件路线的备选方案补进风险清单；② 用 Hydrogen 承接批量切图校验与文案初筛，在 AI Studio 用真实工单对比 high / xhigh 的成功率与账单，优先砍冗余输出而非塞更长上下文；③ 内部单次会议试点 Claude Meetings，明确未定稿物料不进会议共享空间；④ 用 Viewfinder 从一版定稿 KV 延展多机位空镜做 A/B，重点验收 IP 元素跨机位一致性与商用授权；⑤ 给所有在跑的 Agent 补上步数与成本双上限，并把「能下单 / 能投广告」的权限与额度单列、独立支付凭据。
