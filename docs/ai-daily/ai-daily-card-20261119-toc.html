3 OpenAI×AMD 用模型优化芯片：不到 5 个月给旗舰 GPU IP 抠出最高 14% PPA（约一年进度），Jalapeño 自研芯片流片验证，携手 Synopsys 进 EDA 🔧 模型造芯片 / 自研 silicon / P0

4 Palo Alto Networks 拟 45 亿美元全股票收购 Applied Compute：前 OpenAI 研究员创办的开放权重后训练与推理平台，加码企业 AI 安全 ⚔️ 收购 / AI 安全 / P0
11 月 18 日，网络安全巨头 Palo Alto Networks 宣布拟以 45 亿美元全股票交易收购 Applied Compute——前 OpenAI 研究员创办、专注开放权重 AI 模型后训练与推理的平台。Palo Alto 称收购将帮其向企业提供「安全的开放权重 AI 模型」；CEO Arora 强调企业不只要防传统攻击，还要确保 AI 模型与应用能安全部署。官方未披露金额与时间（45 亿为媒体口径）。同日 Q1 营收 34.45 亿（+39%）、上调全年指引、股价盘后涨约 9.9%。这是继 Stripe 收购 OpenRouter 后又一笔「模型层被平台方收编」交易。查重：Applied Compute 零命中。对宣发：短期不影响素材生产，但「安全厂商接管模型部署」意味着未来用 AI 生成未发布 KV、角色设定会有更规范权限与审计——提前养成「敏感素材走内部合规渠道、不传公共模型」的习惯，省去返工。

6 地平线发布 LoFT 原生视频几何基础模型：双循环 Transformer、297 万序列/9.62 亿帧训练，SpatialBench 等多项深度估计达 SoTA，动态物体 +41.7% 🧊 视频几何 / 具身智能 / P1
11 月 18 日地平线机器人实验室发布 LoFT，官方称全球首个从底层完全面向连续视频建模的三维感知基座。不同于「逐帧估计 + 后处理拼接」，LoFT 把连续视频当时空连续体，仅靠普通 RGB 视频流就联合预测相机位姿、内参及逐帧深度，恢复场景三维结构。核心是双循环 Transformer：第一循环用局部/全局时序注意力聚合跨帧信息，第二循环显式更新位姿与内参并反馈下一轮，实现「边看边定位、边建模边优化」。训练侧自建数据工厂，累计 297 万条序列、9.62 亿帧，覆盖雨雾逆光运动模糊等极端场景。在 SpatialBench / ClassicBench / VRBench 多项深度估计达 SoTA，动态物体深度估计 +41.7%。查重：LoFT 零命中，地平线首个基础模型。对宣发：连续视频三维重建可把实拍素材快速转场景粗模/空间数据，为赛季场景 KV、武器展示视频做前期布局参考；目前偏研究/机器人用途，离出片有距离，真正落地仍以成熟图生 3D 工具为主。

编辑点评

今天这 8 条摆在一起，主线很清晰：AI 竞赛正在从「模型排行榜」升级为「资本、芯片、版图」三条战线同时开打。Anthropic 把整家公司摆上柜台、83 美元一股敲出史上最大 IPO；Palo Alto 用 45 亿把开放权重模型收进安全版图；英伟达的董事会清洗、20 万请愿、美方联合声明把「治理与地缘」推到台前；OpenAI 则直接用模型给 AMD 的芯片抠出 14% PPA——当模型能反过来设计造模型的芯片，「谁掌握定价权」的答案已从「谁的模型强」变成「谁同时握住资本、算力和供应链」。

① 资本敲钟与定价（#1 / #2 / #3）。Anthropic 83 美元敲出史上最大 IPO（#1），Gemini 4 Neon 用中间档反超顶配、成本低 32%（#2），OpenAI 用模型给 AMD 芯片抠出 14% PPA（#3）——定价权从模型延伸到股权与产线。

② 并购与治理重构版图（#4 / #5 / #6）。Palo Alto 45 亿收购 Applied Compute（#4）、英伟达治理剧第三幕（#5）、地平线 LoFT 视频几何基座（#6）——资本、权力与底层能力各自重构。

③ 工具继续降本提效（#7 / #8）。Perplexity 把监测→抓取→调度连成 Agent 底座（#7）、商汤 U1 Pro 登 DesignArena 第二 + 开源量化（#8），把成本压低、门槛降低。

对做内容的人是一喜一忧：喜的是模型越来越便宜、越好用、越容易批量调用，把 AIGC 当水电用的门槛在快速消失；忧的是产业越往资本与版图集中，工具的定价、供给、合规就越受大厂财报与地缘博弈牵动——今天英伟达换帅，明天可能就是某家云厂商涨价或某模型限流。越是「大事件密集」的日子，越要把落地清单写实、把风险预案留足。

一句话：敲钟、换帅、抠芯片，AI 从比模型强变成比谁能定下整个版图的价

今天最高分给到 #1 Anthropic IPO（9.4 / P0）：83 美元、813 亿、史上最大 IPO，是「AI 从技术叙事转向资本叙事」最完整的样本。但真正的落地清单很具体 —— Perplexity Monitor API 盯竞品更新、Gemini 4 Neon 做多智能体编排与文案整理、商汤 U1 Pro + 地平线 LoFT 做视觉与三维场景前期探索。

五条可执行线索：① 用 Perplexity Monitor API 盯竞品官网/社媒更新，一有新动作自动通知，抢在第一时间做应对物料；② 用 Gemini 4 Neon 做 PDF/图表/视频→结构化报告，批量整理竞品素材与活动页原型，中文 KV 主视觉交给专门图像模型；③ 用商汤 U1 Pro + 本地量化权重批量跑视觉风格测试，正式 KV 仍由设计师定稿；④ 地平线 LoFT 作为三维场景粗模的技术储备观察，落地先用成熟图生 3D 工具；⑤ 把英伟达治理与出口管制列为排期外部变量，海外云渲染/跨境素材预留供应商替代与合规预案，未发布 KV 走内部合规渠道。
