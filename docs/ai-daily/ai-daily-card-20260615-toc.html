§ 1 Model Releases 2 items

模型发布

速度翻倍与旗舰重构

1 Kimi K2.7 Code 高速版今日上线 9.2
月之暗面发布 Kimi K2.7 Code 高速版，输出速度达180-260 Token/s，较标准版提升5-6 倍。Code Benchmark 得分提升21.8%，token 消耗降低30%。高速版资费为标准版2 倍，但速度提升 5-6 倍，性价比显著优于标准版。这是国内首个在代码生成速度上突破 200 Token/s 大关的模型。
⚡ 5-6x 速度飞跃
180-260 Token/s 输出，代码生成从"等答案"变成"秒出"
📈 Code Bench +21.8%
不只是快，代码质量同步跃升
💰 2x 价格 5x 速度
高速版定价 2 倍但速度 5-6 倍，实际单位成本更低
来源：@Kimi_Moonshot · #代码模型 #速度
2 Claude Fable 5 — Anthropic 双层架构旗舰 9.5
Anthropic 发布 Claude Fable 5，采用双层架构（快速推理层 + 深度思考层），MMLU-Pro 达98.3%，刷新公开模型最高纪录。引入 Constitutional Self-Correction 机制，模型可在推理过程中自行检测并修正逻辑错误。用户可通过 /model fable 一键切换，API 兼容现有 Claude 接口。
🏆 MMLU-Pro 98.3%
公开模型新天花板，全面超越前代
🔄 Constitutional Self-Correction
推理过程中自检自纠，错误率大幅下降
⚡ /model fable 切换
一行命令切换旗舰模型，无缝集成现有工作流
来源：@AnthropicAI · #旗舰模型 #双层架构
§ 2 Agent & Ecosystem 3 items

Agent 与生态

一行调出、永久降价与音视频一体

3 Google Managed Agents 公测：一行 API 调出沙箱 Agent 8.8
Google DeepMind 开放 Managed Agents 公测，开发者通过一次 API 调用即可分配一个运行在沙箱 Linux 环境中的全托管 Agent。Agent 拥有独立文件系统、网络访问权限和持久化存储，支持长时间运行任务。无需自建基础设施，按运行时间计费。
🖥️ 沙箱 Linux 环境
一次 API 调用分配完整沙箱，Agent 拥有独立文件系统
🔧 全托管
无需自建基础设施，Google 负责运维、扩缩容和安全隔离
来源：@GoogleDeepMind · #AI Agent #全托管
4 DeepSeek V4 永久降价 75%：成本仅为 GPT 的 1/30 8.5
DeepSeek V4 宣布永久降价 75%，Pro 和 Flash 双模型均开源。支持100 万 token 上下文窗口，成本仅为 GPT 同级模型的1/30。开源策略 + 极致低价的组合拳，继续对 OpenAI 和 Anthropic 的定价体系施加压力。
💰 永久降价 75%
不是促销，是永久定价调整
📐 100 万 token 上下文
超长上下文窗口，单次可处理整本书级内容
来源：@deepseek_ai · #开源模型 #价格战
5 Kling 2.6 音视频一体：原生音频 + 视频一次性生成 8.7
字节跳动发布 Kling 2.6，首次实现原生音频 + 视频一次性生成，无需二次配音或音画对齐。支持4K 分辨率输出，音画同步精度达毫秒级。此前视频生成需要先出画面再单独生成音频，Kling 2.6 将两步合为一步，大幅简化创作流程。
🎬 音视频同生
原生音频与画面一次生成，毫秒级音画同步
📹 4K 输出
支持 4K 分辨率，满足专业创作需求
来源：@BytedanceTalk · #AI视频 #音视频一体
§ 3 Tool Upgrades 3 items

工具升级

全能视觉、Agent 模式与设计画布

6 Qwen3.7-Plus：视觉中国第一，看想写做验一个模型全搞定 8.3
阿里发布 Qwen3.7-Plus，在中文视觉理解基准上登顶国内第一。实现"看-想-写-做-验"五步闭环：看（图像理解）→ 想（推理分析）→ 写（内容生成）→ 做（工具调用）→ 验（结果校验），单一模型完成全链路任务，无需多模型编排。
👁️ 看想写做验
五步闭环一个模型搞定，省去多模型编排的复杂度
🇨🇳 视觉中文第一
中文视觉理解基准登顶，本土化优势显著
来源：@Alibaba_Qwen · #视觉模型 #全能
7 NotebookLM Agent 模式：自动发现来源 + 云电脑 + 多格式导出 8.0
Google NotebookLM 上线 Agent 模式，支持自动发现来源——模型会根据研究主题自动搜索并推荐相关资料。新增云电脑功能，Agent 可直接在云端执行代码、处理数据。支持多格式导出（PDF、Markdown、音频播客），从"笔记本"进化为"研究助手"。
🔍 自动发现来源
根据研究主题自动搜索推荐相关资料，省去手动收集
💻 云电脑执行
Agent 直接在云端执行代码、处理数据，无需本地环境
来源：@GoogleDeepMind · #AI研究 #Agent模式
8 Cursor 3.7 Canvas Design Mode：多选元素 + 语音叙述 + 上下文报告 7.8
Cursor 发布 3.7 版本，新增 Canvas Design Mode。支持多选元素批量编辑，语音叙述功能可口述设计意图让 AI 执行，上下文报告自动生成设计决策文档。从代码编辑器进一步向"AI 设计协作平台"演进。
🖱️ 多选元素
批量选中 UI 元素进行统一样式调整，效率倍增
🎙️ 语音叙述
口述设计意图，AI 理解并执行，降低操作门槛
来源：@CursorAI · #AI编程 #设计模式

今日 AI 行业的三个关键词：速度、托管、降价。Kimi K2.7 Code 高速版把代码生成推到 260 Token/s，Claude Fable 5 以 98.3% MMLU-Pro 重构旗舰天花板——速度和精度同时突破。Google Managed Agents 用一行 API 调出沙箱 Agent，DeepSeek V4 永久降价 75% 把成本压到 GPT 的 1/30——AI 从"谁更聪明"正式进入"谁更便宜、谁跑得更快"的 Agent 工作流竞赛。Kling 2.6 音视频同生、Qwen3.7-Plus 五步闭环、NotebookLM Agent 模式、Cursor 3.7 Design Mode，四款工具从不同维度降低 AI 使用门槛。对从业者而言，今天最重要的信号是：模型能力已不是瓶颈，编排成本和运行速度才是决胜点。
