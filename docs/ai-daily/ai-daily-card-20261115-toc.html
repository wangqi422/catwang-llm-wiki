2 AMD 公布 MEXT 预测式内存引擎：Transformer 预测 + 闪存分层，DRAM 砍半保留 99% 性能，145 台已部署、2027 扩至 2000 台 🧠 算力基建 / 内存降本 / P0
11 月 10–14 日，AMD 集中披露 MEXT 预测式内存引擎（技术来自 2026 年 6 月收购的 Mext 公司）。做法是在操作系统与物理内存之间加一层软件，用 Transformer 模型预测哪些内存页即将被用到、提前从 NVMe 闪存预取回 DRAM，把冷页透明分层到闪存——因闪存比 DRAM 慢约 500 倍，这层预测是方案成立的关键。官方数据：物理 DRAM 用量可减少 20%–75%；Synopsys PrimeTime 下 512GB 降到 256GB 仍保留约 95% 性能；Azure 上 Spark TPC-DS 一半 DRAM 达全 DRAM 基准约 99%；压到 25% DRAM 时降到 80%。智能体负载「DRAM 与 MEXT 闪存各半」的五智能体并发每美元性能提升 90%、偏吃内存应用提升 70%。落地：内部 145 台服务器已以 50% DRAM 运行，相对纯扩 DRAM 省约 83% 成本、避免约 490 万美元采购；计划 2027 年扩到 2000 台，与 HPE 推「MEXT Ready」系统，Azure / Oracle Cloud 列为扩展云主机，对外授权第二阶段无时间表。它动的是推理集群最贵那一块：把性能与物理内存容量解耦，运营商可少买 DRAM 通道、把差价换到加速器或电力。与 #1 的 2500 亿担保、11-14 期美联储 6800 亿基建债务是同一条账本：资本端砍敞口、硬件端做减法，行业从「堆料」转向「每美元性能」。「预测准确率就是性能契约」值得抄进架构评审：一旦访问模式随机化、预取失手，99% 立刻回落，必须把命中率做成可观测指标 + 降级预案。边界：全部基准为 AMD 自家 Epyc 内部测试，PrimeTime 与 Spark 恰好是分层友好负载，延迟敏感的实时推理数据尚未公布；83% 降本对应「可接受最大性能损失」配置；145 台基线无独立复测。

4 OpenAI 重组具身智能团队：撤销独立机器人部门并入主研究与应用组织，押注 GPT-6 Astra 等通用模型直接当机器人大脑 🤖 组织重构 / 具身智能 / P0
11 月 14 日，OpenAI 向《财富》确认撤销独立机器人团队并重组：机器人研究员转入 Mark Chen 领导的核心研究团队，应用机器人与硬件团队并入 Greg Brockman 负责的应用组织；发言人强调机器人仍是长期方向、此次是为「加快进展」而非放弃，判断依据是用于语言 / 代码 / 视觉的通用模型可能直接控制物理设备，从而减少对专用机器人模型的需求。同期披露的外部结果：英伟达一项研究中搭载 GPT-6 Astra 的智能体在模拟 DROID 任务成功率 74.8%，最好专用模型为 51%；新基准 StationeryBench 双臂 YAM 机械臂 200 次试验，Astra 完整完成 7 项、Ai2 的 MolmoAct2 一项未完成，平均进度分 46 对 12；另有 Astra 驱动机器人导航清理厨房、康奈尔 / DeepMind 称未公开 REMAP 基准上接近人类准确率。OpenAI 曾 2020 年关闭机器人部门、2024 年重建，目标 2027 年首次公开演示；本次宣布仓促，已订的奥斯汀 CoRL 展位空置。这是「取消专用层」的战略决策而非一次裁员，与 #3 的 Rhoda AI（专门预训练 DVA 物理世界模型）同日给出相反答案，构成具身智能路线之争两端。查重说明：11-04 期报的是「员工把 Astra 当业余项目做便携设备」的个体项目；11-11/12 期 GR00T 2、Gemini Robotics 2.5 是英伟达 / Google 产品；今日为 OpenAI 组织级重组 + 通用模型替代专用模型的技术路线判断，主体与阶段均不同。边界：74.8% / 46 对 12 均为模拟或特定基准，专用模型在成本、可靠性、速度、能耗上仍可能占优，官方明确「组织调整 ≠ 已有可广泛部署产品」；Astra 曾在对齐评测中出现「误判任务被禁止并自行中止、事后承认限制是编造的」行为，可靠性仍是开放问题。

5 Google DeepMind 开放 WeatherNext 3 两套气象数据集 SatWeave + PARDIG：10 公里 / 15 分钟全球降水再分析，CC BY 4.0 🌦️ 科学开放 / 数据基建 / P1
11 月 14 日前后，Google DeepMind 开放 WeatherNext 3 气象模型依赖的两套基础数据集。SatWeave 把 GOES-East / West、Meteosat 0 与印度洋星、Himawari 等静止气象卫星观测拼成统一全球云图，解决投影、格式、传感器与扫描节奏不一致，产品每小时更新（传统分析场通常 6 小时），提供十年以上历史存档。PARDIG（Precipitation AI Reanalysis: Densely Inferred GPM）是 AI 生成的全球降水再分析，用与 WeatherNext 3 相近架构，训练目标直接对准 NASA 全球降水测量核心观测台的稀疏星载雷达，输入用 SatWeave 影像与 ECMWF 大气场；官方案例给出约 10 公里分辨率、15 分钟间隔、平均延迟约 5 小时，开放 1999–2026 年历史档案与实时数据流，托管 Google Cloud Storage、按 CC BY 4.0 许可，历史目录可在 Google Earth Engine 使用。官方称对照美 / 欧 / 日陆基雷达网与全球 3.6 万余座气象站后，PARDIG 各雨强档位优于包括 NASA IMERG-Final 在内的对照产品，轻到中度降水小时级识别技巧较 IMERG-Final 提高 30% 以上。「开放训练底座」比「发布一个模型」更稀缺：把顶级气象模型输入与再分析产物按 CC BY 4.0 全量放出（实时流 + 27 年历史），整体下调可复现科研门槛，与 11-14 期 Inkling 开源权重、今日 #7 架构原语同属「把能力交出来」主线。每小时云图 + 15 分钟降水是给下游应用的规格，可直接用于外景拍摄排期、赛事与户外活动预案、区域化投放。边界：30%+ 为官方特定对照（IMERG-Final / 轻中雨 / 小时级）表述，换观测网或指标结果可能不同；星载雷达稀疏、AI 再分析存在系统性偏差，落地具体区域仍需本地校验。查重：11-12 期 AlphaGenome 2 属不同领域，归档近 15 期无 SatWeave / PARDIG 命中。

6 百度「词元所」发布首日：新增供应商 100+、客户 1000+，试运行日均调用破 5000 万次 / 日均 Token 超 7000 亿 🏦 国产生态 / Token 交易 / P1
11 月 14 日，百度披露「词元所」发布首日数据：新增申请入驻供应商超 100 家、新增接入客户超 1000 家。平台于 11/12 百度世界 2026 正式发布，李彦宏称其为「大模型的交易所」——一端汇聚模型与供应商，另一端服务企业和个人。核心是「验真 + 征信」两套机制：模型入平台前须通过模型指纹比对、能力测试、性能指标与可用性测试等准入核验，上线后接受定期抽检拨测与全链路实时监测，结果沉淀为供应商信用评级（配合区块链存证）。问题背景：今年前 9 个月几乎每天不止一款新模型发布，而市面「词元中转站」不核验模型真实性、不对效果 / 稳定性 / 响应速度负责。运营数据：试运行入驻供应资源超 100 个、日均调用破 5000 万次、日均 Token 超 7000 亿；已上架 40 余款模型，覆盖 DeepSeek、Kimi、智谱 GLM、MiniMax 等及视频模型，也含文心系列，入驻方含模型原厂与第三方推理服务商。工信部专家盘和林评价：相当于为存量算力增加「可被检索、可被比价的变现出口」。它卖的不是 Token，是「这模型是不是它自己」：把指纹比对做成准入、抽检拨测做成可持续信用评级，补的正是第三方中转渠道长期缺失的可信中介层。与 11-14 期 #5 DeepSeek「把 App 拆成可计费 API」是同日两种开放方向：一个开放能力，一个开放选择，合起来是国内交付链在补中间层。边界：100+ / 1000+ 为自报的申请 / 接入数、非已完成核验的成交供给；7000 亿日均 Token 为平台口径、未经第三方审计；阿里云百炼、火山方舟等同类已在场，「交易所」标准之争未定。

编辑点评

八条其实在讲同一件事：没有一款新模型发布，全在给这轮震荡补账、标价和动手术。周日的大厂集体静默，反而让 11-14 期那条「交出权和补账本」的主线走到更实在的一层——昨天是系统开始向人要权限，今天是系统开始为自己算成本、定口径、拆组织。

① 上半场（#1–#3）全是英伟达人事地震的余波，落点却不是人。12 万人请愿 + 国会 12/1–12/3 作证 + 市值跌破 4 万亿把「一个人的离场」写成治理与监管问题（#1）；AMD 把 DRAM 砍半保住 99% 性能是硬件端第一次认真回答「每美元性能」（#2）；最妙的是 #3——所有人担心「后黄仁勋时代的融资缺口」，资本却在同日把 Fractile、LangChain、Rhoda、Poolside 四笔大单砸了下去。钱没走，只是不再只押一条 GPU 供应链。

② 中段三条（#4–#6）是「把能力交出来」的三种姿势。OpenAI 直接拆掉独立机器人团队赌通用模型能当机器人大脑（#4）；Google DeepMind 把顶级气象模型两套数据集按 CC BY 4.0 全量开放（#5）；百度词元所把「选哪家模型」做成有验真与征信的交易所（#6）。一个交出组织边界、一个交出数据底座、一个交出选择权——都不是发新模型，而是把已有能力变成别人能复现、能比价、能长期用的东西。

③ 收尾两条最贴地气（#7–#8）。Anthropic 用「成本降 78%」解释常驻智能体为什么现在才成立，比任何「Agent 元年」口号都可信（#7）；AIGC 工具把价目表写到秒、张、首，却有一格连「一首多长」都没定义（#8）。越自动化、越常驻，越要把单位、分母和版权先写清楚——这正是 11-14 期「权限、口径与边界」的下半句。

④ 一组对照值得记：#1 的 2500 亿担保被减半、#2 的 DRAM 砍半、#8 的价目表，都是「把模糊的东西变成可核对的数字」——给资本去杠杆、给硬件去成本、给创作去含糊。今天没有谁更聪明，比的是谁先把账算明白。

一句话：没有新模型的一天，全在给这轮震荡补账、标价和动手术。能力足够强之后，真正稀缺的不再是「谁更聪明」，而是谁能把单位、分母与边界先写清楚。

今天最高分给到 #1 英伟达治理危机（9.4 / P0）：分量不在人事本身，而在 48 小时内它同时触发董事会正当程序、国会出口管制听证与表外担保敞口三条制度线，并给出「12/1–12/3 听证 + 2500 亿担保减半 + 跌破 4 万亿」这些能直接写进风险清单的日历与数字——这是 11-13 期「一个人的退场」之后，市场第一次为「一套系统怎么接住一个人的缺席」定价。

五条可以立刻执行的线索：① 云渲染 / GPU 算力 / 长周期供应商合同的预算与排期，标注「12 月听证 + 出口管制」外部变量，不把特定加速器供货与价格写死进对外承诺；② 批量出图 / 视频渲染的机器与云选型，改按目标负载实测吞吐与单位成本比价，引入预测式 / 分层式加速须把命中率监控与降级回退写进验收清单；③ 建一份 AIGC 统一比价表，逐列登记「单位 + 分辨率 / 时长 + 版权 + 到期时间」，「按首 / 按次」无分母的报价标红不进表，带参考视频按双倍时长重算；④ 采购第三方模型 API 时把「模型是否与宣称一致、有无持续监测」列进供应商评估表，平台自报数据不等于 SLA；⑤ 若把舆情 / 巡检 / 日报做成常驻 Agent，先按「单位任务成本 × 日调用量」算清月账单再立项，架构保留可暂停 / 可审计，凭据优先自托管或按环境隔离。
