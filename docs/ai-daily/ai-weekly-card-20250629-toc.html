iii. Methods & Prompts 2 items
🧠 方法论与 Prompt
2 个可复用的 AI 方法论
8 Karpathy 的 CLAUDE.md · AI 编程四条铁律 GitHub 17万星
OpenAI 联合创始人 Andrej Karpathy 发布的 AI 编程规范文档，直指 LLM 写代码的三大通病：错误假设、过度复杂、无关改动。
## CLAUDE.md 核心规则 1. 编码前思考 - 遇到不明确的需求，主动清而非猜测 2. 简洁优先 - 能用 50 行实现，绝不写 200 行 3. 精准修改 - 只改动任务相关的代码 4. 目标驱动 - 明确验证标准，对结果负责
实战效果
代码行数减少 40%，代码评审时间缩短 25%
获取方式
GitHub: karpathy/claude-code-guidelines
∘ @karpathy / X 原帖 & GitHub 社区
