i. Global Giants & Vertical AI 3 items
🌐 海外巨头 & 垂直行业
Anthropic 双线突进 · Claude Science + 登陆 Azure + 出口管制解除
1 Anthropic Claude Science 发布：60+ 科学数据库 + 审核代理 + 内部药物发现项目 🔥 头条
Anthropic 7/1 正式发布 Claude Science——首个面向科学家的统一 AI 工作台，整合 60+ 科学数据库（UniProt / PDB / ChEMBL）+ 60+ 预置技能（基因组学 / 蛋白质组学 / 结构生物学 / 化学信息学）。同步宣布启动内部临床前药物发现项目，聚焦"传统药企不感兴趣"的蓝海靶点；承诺资助最多 50 个科学项目。与英伟达深度合作接入 Evo 2 / Boltz-2 / OpenFold3 三大生命科学模型。
2 Anthropic Claude 全系登陆 Microsoft Foundry · Azure 生态一统 🔥 巨头合作
Anthropic 6/29 宣布 Claude 模型正式登陆 Microsoft Foundry（Azure AI Foundry），企业用户可直接在 Azure 环境中部署和调用，沿用 Azure 现有身份认证、计费、治理体系。首批支持 Claude Opus 4.8 和 Claude Haiku 4.5，与 Azure 既有企业服务完全打通。Anthropic 同时是 AWS Bedrock 主力合作伙伴——双云战略成型，打破"OpenAI 即 Azure"的单一绑定。
3 美国商务部解除 Anthropic Fable 5 + Mythos 5 出口管制 · 7/2 恢复全球访问 政策
美国商务部 7/1 正式撤销对 Claude Fable 5 和 Mythos 5 的全球出口管制，Anthropic 在 X 宣布"我们将于明天开始恢复访问权限"。6/12 因"国家安全风险"被迫关闭 → 6/27 首批"可信美国机构"开放 → 7/1 全面撤销，前后不到三周。附带条件：Anthropic 需主动识别安全风险 + 配合美国政府制定后续发布协议 + 报告恶意活动。OpenAI CEO 奥尔特曼公开批评"政府挑选客户"——前沿 AI 模型从"行业自律"升级为"国家审批"。

4 华为 openPangu-2.0-Flash 920 亿参数全栈开源 · Pro 505B 7 月放出 🔥 国产开源
华为 6/30 正式开源 openPangu-2.0-Flash（920 亿参数，激活 60 亿），同步预告 7 月放出 openPangu-2.0-Pro（505B 总参 / 18B 激活）。余承东重新挂帅盘古，本次打破行业惯例——除常规四件套外，额外开源预训练代码、后训练代码、昇腾专属训推算子，业内首次"授人以渔"全栈开源。512K 上下文 + MoE 架构 + 昇腾原生训练，国产芯片 + 国产框架 + 国产模型全栈闭环。
5 DeepSeek V4 正式版 7 月中旬定档 + 峰谷定价 · 昇腾 950PR 跑通 🔥 国产模型
DeepSeek 7/1 通过 API 通知：V4 正式版定档 7 月中旬，同步启用峰谷定价机制——V4 Pro 常规 6 元 / 高峰 12 元（每百万 tokens 输出），Flash 常规 2 元 / 高峰 4 元；高峰时段为每日 9:00-12:00、14:00-18:00。V4 自预览版起便全面部署于华为昇腾 950PR 平台，成为全球首个万亿参数级开源大模型完成"英伟达 CUDA 生态 → 国产算力底座"全栈迁移的标杆案例。
6 Kimi 新一轮融资投前估值 315 亿美元 · 6 月中旬 ARR 突破 3 亿美元 国产资本
月之暗面 Kimi 上一轮 200 亿美元估值融资近日完成交割，新一轮融资已启动，投前估值升至 315 亿美元（约 2143 亿人民币）。本轮沟通中披露：6 月中旬 ARR（年度经常性收入）突破 3 亿美元（约 20.41 亿人民币），增长主要来自模型迭代带动的开发者使用和 API 收入提升，目前 API 收入占整体 7 成以上且继续走高。估值一年半翻 3 倍，B 端付费 + 开发者生态已经跑通。

7 Karpathy LLM Wiki "autocompiler"：5 天 5000+ stars · 终结 RAG 的新范式 🔥 思想革命
前 OpenAI 创始成员 Karpathy 4/4 在 GitHub 发布 LLM Wiki Gist——把个人笔记当"不可变源代码"，让 LLM 做"编译器"，一次性把零散材料编译成结构化、互相链接的 Wiki；每加新素材，AI 自动更新关联页面、加固或挑战已有判断。5 天破 5000+ stars / 3000+ forks。核心金句："知识应该只编译一次，然后保持更新"（vs RAG 每次查询都从零检索）。三层架构：raw/ → pages/ → index.md+log.md + Schema 层作为知识宪法。
8 软银 Vision Fund 2 追加 OpenAI 10 亿美元 · 计划年内再追加两笔 10 亿 资本
软银集团 7/1 宣布通过 Vision Fund 2 向 OpenAI 完成追加 10 亿美元投资，并表示计划在今年 10 月 1 日前再完成两笔同等规模追加——合计 30 亿美元。软银 OpenAI 累计持仓已超 300 亿美元，是 OpenAI 最大外部股东之一。声明将此系列投资解释为"对 OpenAI 长期技术路线图的高度认同 + 构建 AI 生态系统的战略布局"。主权资本 + AI 巨头绑定模式正在固化。
