🧠 模型 & Agent
DeepSeek V4.1 Flash 用新架构反超自家 Pro，OpenAI 把 Codex harness 做成托管 Agents API，Cursor Projects 上协调者智能体
1 DeepSeek V4.1 Flash 发布：新架构反超自家 Pro，KV Cache 缩 437 倍 🧬 架构
9 月 10 日 DeepSeek 发布 V4.1 Flash：552B 参数 MoE，采用全新 Causal Encoder-Decoder 非对称架构（输入激活 8B / 输出激活 16B），原生多模态视觉理解。官方称相对初代 KV Cache 缩小约 437 倍、HBM 需求降至 1/4、SSD 降至 1/8；Artificial Analysis 智能指数 40 分，超过自家 V4 Pro 成为新旗舰。支持 1M token 上下文、MIT 许可；最高降价 60% 并推峰谷定价（闲时半价），V4 Pro 将于 9/14 起路由至 Flash。腾讯 WorkBuddy / CodeBuddy / OpenCode 已全量接入。信号是「架构创新取代堆算力」成为降本主路径。
2 OpenAI Agents API 公测：把 Codex harness 做成托管服务 ⚙️ 平台
OpenAI 上线 Agents API 公测，把内部 Codex harness 封装成托管服务：平台负责 session 管理、任务编排、上下文压缩与失败恢复，应用侧只提供 tools 与执行环境。四核心概念 Agent / Environment / Session / Events-Items，支持代码执行、文件、MCP over HTTP、web search、skills、subagents（可配并发上限）与 artifacts；沙盒可选 OpenAI 自托管或 9 家合作方（Cloudflare、Vercel、Modal 等），无额外费用。信号是「Agent 运行时被平台化」——复杂度从「造引擎」降到「写业务逻辑」；限制是数据仅驻留美国、不支持 ZDR。
3 Cursor Projects 发布：协调者智能体调度数千子智能体 🤖 Agent
Cursor 于 9 月 10 日发布 Projects（beta）：在单一持久线程中运行一个「协调者智能体」——它不写代码，只规划、派活、验收，任务委派给数千个子智能体并行执行。配套云端专属计算机（合上笔记本不中断）+ 本地补位，共享上下文跨机器同步、可累积数月；Subscriptions 可监听 Slack、PR、定时任务自动触发。官方自报新用户 PR 合并率 +30%、主力用户 6 倍（无方法论说明，需谨慎看待），未公布计费与预算上限。背景是 OpenAI 因 SpaceX 收购将于 11/12 起终止向 Cursor 供模型。
ii. Industry & Infrastructure 3 items
🏭 行业 & 基础设施
Anthropic 154 页威胁情报报告指控 2 亿次蒸馏交互，工信部「人工智能+软件」定 KPI，SpaceX 再签算力大单
1 Anthropic 154 页威胁情报报告：2 亿次蒸馏交互 + 生化导弹滥用拦截 🌐 安全政策
Anthropic 发布 154 页威胁情报报告：① 指控 7 家中国实验室累计近 2 亿次蒸馏交互、5 场独立行动——阿里单家 5–7 月 1.51 亿次、峰值近 300 万/天、3500+ 欺诈账号；攻击目标是 reasoning trace（如伪装成「翻译成片假名日语」的提示注入）。② 披露国家级行为体尝试用模型设计导弹与致命病原体、监视异见人士。需客观说明：全部指控为 Anthropic 单方陈述，部分基于间接推断，中方及被点名企业此前已明确反驳（外交部称中国 AI 是「自立自强成果」，商务部批评美方「政治化、双重标准」）。攻防焦点正从「输出内容」转向「推理过程泄漏」。
2 工信部印发《"人工智能+软件"专项行动实施方案》：2028 年覆盖 2 万家企业 📋 政策
工信部印发 《"人工智能+软件"专项行动实施方案》，量化目标：到 2028 年覆盖 2 万家规上软件企业、打造 100 项智能化技改项目、培育 100 个智能体软件标杆应用、孵化 5 个以上优质开源项目；2030 年关键软件全面智能化升级。配套用算力券等普惠政策降低软件企业算力成本。信号是「AI+软件」从倡导变成有明确 KPI 的专项行动，且「智能体软件」被单列标杆类别——Agent 已被政策层认定为软件的下一代形态；算力券用财政工具直接解决「用不起」的落地障碍。
3 SpaceX 再签 AI 算力大单：年化 133 亿美元，年底 ARR 冲千亿 🛰️ 算力
SpaceX CFO 于 9 月 10 日透露，公司本月新签一笔 AI 算力托管协议，自 12 月起月入约 11 亿美元、年化约 133 亿美元；目标年底 ARR 达 1000 亿美元。SpaceX 已与 Anthropic、谷歌、Reflection AI 签署多年期算力协议，并计划明年发射首批轨道计算卫星。信号是「算力供给格局被跨界重构」——航天公司携发射与带宽能力切入数据中心；头部客户仍签多年期大额长约印证算力需求未见顶；轨道计算是长期期权（太空免费散热与太阳能，但发射成本与延迟待解）。
iii. Trends & Tools 2 items
📈 趋势 & 工具
环球音乐 UMG 与 ElevenLabs 签多年授权协议，OpenAI 上线全双工语音 GPT-Live-1
1 环球音乐 UMG 与 ElevenLabs 签多年授权协议：「艺人参与」写进条款 🎵 音乐版权
环球音乐集团（UMG）与 ElevenLabs 签署多年许可协议，这是 ElevenLabs 首次与大型唱片公司合作。双方共建「基于授权音乐 + 艺人参与」的 AI 音乐平台，支持 remix、mashup、全新演绎与个性化语音，平台独立于现有 Music API 与 ElevenMusic 产品线。关键背景：UMG 目前仍在起诉 Suno，而 Suno 恰在前一日（9/9）发布用 WMG/BMG/Believe 授权数据训练的 v6。信号是「AI 音乐进入按厂牌逐个谈的谈判期」——「艺人参与」被写进条款意味着艺人从被使用方变成共创分账方；平台隔离则暴露了「授权音乐 vs 通用生成」的合规隔离设计，「要么起诉、要么授权」正在终结灰色地带。
2 OpenAI 上线 GPT-Live-1 全双工语音 API：交互性 45.4% → 80.1% 🎙️ 语音
OpenAI 在 API 中上线 GPT-Live-1 全双工语音模型：支持边听边说、处理被打断，可与开发者自有模型与 harness 搭配。官方数据交互性测试从 45.4% 提升至 80.1%，定价 0.05 美元/分钟。同期 HeyGen 开源极简实时参考技术栈（GPT-Live + LiveAvatar + HyperFrames），演示刻意把长期记忆外置到服务端而非模型上下文。信号是「实时语音 Agent 跨过商用门槛」——从对讲机式交互变成通话式交互；行业共识是「状态外置」；但 0.05 美元/分钟对大规模 C 端场景仍偏贵。

编辑手记

今天是 AIGC 日报第 47 期，主线是「Agent 基础设施化 + 内容授权合规化」：#2 OpenAI 把 Codex harness 做成托管的 Agents API、#3 Cursor 用「协调者 + 数千执行者」重新分层 Agent 架构——Agent 的竞争从「模型能力」上移到「运行时与编排层」；#7 UMG 与 ElevenLabs 签协议把「艺人参与」写进条款，与昨日 Suno v6 的授权训练形成连续剧——内容端从「抓取再说」转向「按厂牌逐个谈、按条款分账」。一边是技术栈被平台收编，一边是内容权被合约界定，共同说明：AI 行业正在从「跑马圈地」切换到「定规矩」阶段。

模型侧的主角是架构而非参数：#1 DeepSeek V4.1 Flash 用 Causal Encoder-Decoder 非对称结构把 KV Cache 压缩 437 倍、HBM 需求降到 1/4，智能指数反超自家 Pro——在算力受限背景下，「结构效率」正在取代「堆规模」成为新的性能来源；#8 的 GPT-Live-1 则用「全双工」这一个交互维度的改进，把语音 Agent 的可用性推过商用线，说明单点体验的突破同样价值巨大。

争议与政策仍在收紧：#4 Anthropic 154 页报告把「蒸馏」从商业争议推向国家安全议题（须注意：全部指控为 Anthropic 单方陈述，中方及被点名企业已明确反驳，本刊仅客观呈现）；#5 工信部则用 2 万家企业的 KPI 与算力券，给国内「AI+软件」按下加速键——对外是边界收紧，对内是政策托底，国产 AI 生态在双重力量下加速成型。

落到宣发工作，本期五条可执行线索：① 音乐授权清单 → #7 是最直接的动作项，立即建立「AI 音乐平台 × 厂牌授权状态」对照表（UMG→ElevenLabs、WMG/BMG/Believe→Suno v6，UMG 仍在诉 Suno），宣发用 AI 做 PV/集锦配乐前先查表，涉及艺人人声的二次演绎必须走艺人参与条款；② 成本优化 → #1 DeepSeek V4.1 Flash 的峰谷定价（闲时半价），把批量文案改写/素材打标/多语言本地化排到夜间跑；③ 架构借鉴 → #3 的「协调者 + 执行者 + 验收」分层，改造宣发批量物料流水线，比单 Agent 串行更可控；④ 合规红线 → #4 提醒跨境模型调用存在收紧风险，涉密版本信息不出境、核心链路多源备份，#8 的语音玩法务必先走 IP 与配音授权；⑤ 政策窗口 → #5 的「100 个智能体标杆」与算力券，宣发侧内部 AI 工具立项可关注配套支持与标杆申报机会。
