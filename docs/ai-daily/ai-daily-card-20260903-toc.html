🧠 模型 & Agent
Meta Muse Spark 1.3 编码登顶，OpenAI Astra 循环深度引发安全恐慌，Google Gemini 3.8 Flash 六周第三款，Anthropic Claude 5.1 缓存降价
1 Meta 发布 Muse Spark 1.3：编码与长周期智能体登顶，DeepSWE 75.4 超 Opus 5 ⚙️ 编码
Meta 发布编码模型 Muse Spark 1.3，首席 AI 官 Alexandr Wang 称其为「史上最大跃升」。在长周期编码基准 DeepSWE v1.1 以 75.4 分登顶，首次正面超越 Opus 5（74.0）与 GPT-5.6 Sol；长上下文 MRCR 达 98.5 分，与 GPT-5.6 Sol 的 91.5 拉开代差。效率同步跃升：工具调用减 20%、Token 消耗减 25%，且「先确认再执行、遇到歧义主动提问」，9 项智能体测试 5 项第一、全部前二，价格维持 $1.25/百万输入不变。
2 OpenAI 旗舰 Astra 被曝「循环深度」架构，隐藏推理过程引发安全恐慌 🛡️ 安全
据 The Information 报道，OpenAI 旗舰模型 Astra 采用「循环深度」技术：文本在同一网络层反复循环处理，35 亿参数模型可等效调用 500 亿参数算力，但会隐藏推理过程、削弱思维链监控。Redwood Research 首席科学家 Ryan Greenblatt 直指这「可能是 AI 安全/对齐史上最糟的发展」。OpenAI 已推迟 Astra 发布并增加 CoT 监控；Anthropic 与 Google DeepMind 据报已在讨论同类路线，引发「不可监控」的逐底竞争担忧。
3 Google 发布 Gemini 3.8 Flash：六周第三款，价格不变但「更努力」实际成本升 40% ⚡ 模型
Google 发布 Gemini 3.8 Flash，六周内第三款 Flash。价格维持 $0.75/$3.75 不变，但模型「更努力工作」——复杂任务执行更多推理步骤、迭代调用工具，实际任务成本比 3.7 Flash 高约 40%。Terminal-Bench 2.1 达 90.8%（超 GPT-5.6 Terra 87.4%），输出速度 305 token/s 最快；但 DeepSWE 71% 仍低于 Opus 5。同发仅限认证防御者的安全变体 Flash Cyber。
4 Anthropic 推出 Claude 5.1：缓存读取降 75%，可连续运行数十小时复杂任务 🤖 Agent
Anthropic 推出 Claude 5.1（Fable 5.1 + Mythos 5.1 共享底座）。长周期能力上，Terminal-Bench-Science 从 24.7% 跃升至 52.6%、AutomationBench 从 17.1% 升至 31.4%，可连续运行数十小时复杂任务。缓存读取价格降 75%，典型任务成本降约 25%、高度 Agent 化任务最高降 45%，第三方超长程基准 FrontierSWE v2 大幅领先。

月之暗面 500 亿美元估值递表港股 IPO，博通 AI ASIC 客户结构剧变
1 月之暗面秘密递交港交所 A1，500 亿美元估值启动港股 IPO 💰 融资
中国「AI 六小虎」之一的 月之暗面本周以保密形式向港交所递交 A1 文件，正式启动港股 IPO，并以 500 亿美元投前估值推进最后一轮融资。今年 7 月，2.8 万亿参数模型 Kimi K3 数小时登顶 Frontend Code Arena（1679 分超 GPT-5.6 Sol）；ARR 半年从 1 亿到 3 亿美元，成立三年累计融资超 376 亿元，估值从 43 亿一路飙至 500 亿美元，标志国产大模型进入资本化收获期。
2 博通财报：Anthropic/OpenAI 将成 AI ASIC 前两大客户，AI 芯片收入连年翻倍 🔌 芯片
博通 FY2026 Q3 财报：AI 半导体收入 $16.7B、同比 +221%，占总收入 56%。CEO 陈福阳预测 Anthropic、OpenAI 将超越 Google成为 AI ASIC 前两大客户，定制芯片正成前沿模型厂标配。公司预计 2027 年 AI 芯片收入 $115B、2028 年 $230B，连续两年翻倍，把「数据中心押注 AI」的投资逻辑写成财报数字，也印证了推理侧的「去英伟达化」。

📈 趋势 & 工具
李飞飞 World Labs 发布 Atlas 世界模型，VAST Tripo P2.0 直出可绑骨 3D 拓扑
1 李飞飞 World Labs 发布 Atlas 世界模型：单图生成 1 分钟 1440p 可控运镜视频 🎬 世界模型
李飞飞创办的 World Labs 发布新一代世界模型 Atlas，采用多模态自回归扩散 Transformer，把图像/视频/3D 统一进共享空间上下文。输入 1–6 张图 + 相机路径可生成最长 1 分钟、1440p 视频，支持像素级相机控制；2–3 张照片即可重建可走动的 3D 场景。盲测相机控制 94% 胜 Seedance 2.5、93% 胜 FLUX 3，公司今年 2 月刚完成 10 亿美元融资。
2 VAST 发布 Tripo P2.0：直出原生四边面拓扑，3D 生成进入「可绑骨」阶段 🧊 3D
3D AIGC 公司 VAST 发布 Tripo P2.0，核心突破是生成阶段直出原生四边面拓扑（三角面最高 5 万、四边面 2.5 万），无需额外重拓扑即可绑骨动画。布线沿物体结构展开、密度按需分配，更接近专业建模师习惯。底层为入选 SIGGRAPH 2026 的 Nexus 扩散框架，公司半年累计融资约 50 亿元，3D AIGC 进入「可生产」阶段。

编辑手记

今天是 AIGC 日报第 39 期，AI HOT 聚合 100 条近 24h 动态，主线是「编码/长周期 Agent 军备赛白热化」+「AI 安全拉响架构级警报」+「国产大模型资本化」三条大线：Meta Muse Spark 1.3 首次在 DeepSWE 正面超 Opus 5、Google 六周三款 Flash、Anthropic Claude 5.1 缓存降价 75%，把「编码与长周期 Agent」推成头部厂商正面战场；OpenAI Astra 的「循环深度」架构则把「思维链监控」这道安全闸门推到行业聚光灯下；月之暗面 500 亿美元递表港股，宣告国产大模型进入资本化收获期。

最值得宣发团队关注的是 #7 Atlas 世界模型 + #1 Muse Spark 1.3。前者是直接可用的创作工具——几张参考图生成可控运镜视频、重建 3D 场景，正对海报/品牌短片/场景概念设计这条素材产线；后者是可无人值守的长流程 Agent 底座，可承接竞品监控、批量素材生成，且「先确认再执行」降低了自主运行风险。

行业级信号是 #2 Astra 循环深度 + #5 月之暗面 IPO。前者是 AI 安全的架构级警钟——团队引入自主 Agent 做自动化时，必须保留可审计推理记录 + 权限隔离 + 人工兜底，不能接入「不可解释的自主决策」；后者是国产大模型资本化的标志事件，意味着国产 Kimi/GLM/豆包系的多模态与 Agent 能力将持续加码，是成本与合规的备选。

落到宣发工作，本期五条可执行线索：① 视频/3D 工具 → Atlas（可控运镜视频）与 Tripo P2.0（可绑骨 3D 资产）列入素材产线备选；② 编码 Agent → Muse Spark 1.3 / Claude 5.1 承接竞品监控、批量生成等长周期自动化；③ 成本结构 → Flash 系走量控成本、旗舰精修，按真实 Token 账单做预算；④ 自主 Agent 安全 → 引入前先做权限隔离 + 输出审计 + 人工兜底；⑤ 国产备选 → 跟踪 Kimi K3.1 及后续多模态/Agent 能力。
